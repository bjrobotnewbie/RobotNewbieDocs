# 现代控制工程

- [现代控制工程（第五版）京东](https://item.jd.com/29509167109.html)

## 概述

### 基本信息
- 书名：**现代控制工程 第五版**
- 作者：**尾形克彦（Katsuhiko Ogata）**
- 译本：电子工业出版社 经典中文版
- 地位：**全球现代控制领域天花板级经典教材**，自动化、机器人、宇航、具身智能**必读神书**，国内外高校研究生、机器人研发通用教科书。

### 作者风格特点
尾形克彦日裔美籍控制泰斗，写书特点：
1. **数学严谨但通俗易懂**，推导一步步来，不跳步；
2. **重物理意义、重建模、重状态空间**；
3. 经典控制+现代控制**完整打通**，衔接极其顺滑；
4. 例题超多、典型、贴近机电、机器人、动力学系统。

### 全书章节结构（第五版）
#### 第一部分：基础数学与经典控制
1. **控制系统绪论**
   反馈控制基本概念、控制工程发展、典型机电系统案例。
2. **数学模型**
   微分方程、传递函数、**机械系统/电气系统建模**、结构图、信号流图。
   → 机器人**刚体建模、关节动力学**必看。
3. **时域分析**
   一阶/二阶系统响应、稳态误差、劳斯稳定判据。
4. **根轨迹法**
   根轨迹绘制、参数设计、系统动态校正基础。
5. **频域分析**
   伯德图、奈奎斯特、稳定裕度、频域校正。

#### 第二部分：现代控制核心（全书精华，机器人/具身必学）
6. **状态空间建模与分析**
   状态方程、状态变量选取、矩阵指数、系统响应。
7. **能控性、能观性**
   判定准则、标准型分解，**现代控制设计的基石**。
8. **状态空间系统设计**
   极点配置、**状态观测器（全维/降维）**、状态反馈设计。
9. **最优控制**
   变分法、极小值原理、**LQR线性二次最优控制**。
   → 机械臂、足式机器人、无人机轨迹跟踪**标配理论**。

#### 第三部分：非线性+离散控制
10. **非线性控制系统**
    相平面法、描述函数法、非线性系统稳定性。
11. **离散时间控制系统**
    Z变换、离散系统建模、离散状态空间、数字控制器设计。
    → 机器人嵌入式、数字控制、采样系统必备。


### 三本经典控制教材定位
1. **胡寿松 自动控制原理**：**国内考研专用**，经典控制体系最全，做题刷题首选。
2. **多尔夫 现代控制系统**：**工程应用+MATLAB+案例多**，偏系统设计。
3. **Ogata 现代控制工程（尾形）**：**现代控制教科书天花板**，**状态空间、LQR、能控能观 学这本最舒服**，机器人/具身智能**最优学习用书**。
