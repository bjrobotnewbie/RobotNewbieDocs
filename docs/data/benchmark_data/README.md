# 基准数据集

基准数据集是用于机器人算法评估和比较的标准数据集，提供统一的测试环境和指标。本章节涵盖机器人领域常用的基准数据集。

## 项目列表

- [Calvin](data/benchmark_data/calvin/README.md)
- [embodied-agent-interface](data/benchmark_data/embodied-agent-interface/README.md)
- [Libero](data/benchmark_data/libero/README.md)
- [MetaWorld](data/benchmark_data/metaworld/README.md)
- [Robogen](data/benchmark_data/robogen/README.md)
- [Robotwin](data/benchmark_data/robotwin/README.md)
- [SimpleRenV](data/benchmark_data/simplerenv/README.md)

## 分类说明

| 数据集 | 应用领域 | 特点 |
|------|---------|---------|
| **Calvin** | 具身智能 | 语言条件下的机器人操作 |
| **Libero** | 具身智能 | 长视界机器人任务 |
| **MetaWorld** | 机器人学习 | 模拟机器人操作环境 |
| **Robogen** | 机器人生成 | 机器人形态与控制生成 |
