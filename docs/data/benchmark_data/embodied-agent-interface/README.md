# Embodied Agent Interface

- [官方网站](https://embodied-agent-interface.github.io/)

## 概述

Embodied Agent Interface 是一个专门用于评估大语言模型（LLM）在具身智能任务中高层决策能力的基准。它关注 LLM 在理解任务、分解子目标和序列化动作规划等方面的表现，而不涉及底层的运动控制或物理执行。

该基准通过设计一系列需要逻辑推理和任务规划的具身场景，测试 LLM 是否能够将抽象的自然语言指令转化为可执行的动作序列。它适用于研究 LLM 作为具身智能体“大脑”的能力边界，探索语言模型在机器人任务规划、情境理解和决策制定中的潜力与局限性。
