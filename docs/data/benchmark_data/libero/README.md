## 概述

LIBERO (Lifelong Robot Learning) 是一个专注于机器人终身学习能力的基准测试平台，包含程序化生成的任务管道、视觉运动策略架构以及终身学习评估设置。它模拟了机器人在连续任务序列中的学习场景，要求算法能够在学习新任务的同时保持对旧任务的性能。

该基准的核心挑战在于克服灾难性遗忘问题，即模型在学习新任务时不会忘记之前学到的技能。LIBERO 提供了多个任务套件，涵盖不同的操作难度和泛化要求，用于评估算法在顺序学习、知识迁移和持续适应方面的能力。
