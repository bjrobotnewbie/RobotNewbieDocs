# RoboGen

- [GitHub](https://github.com/Genesis-Embodied-AI/RoboGen)
- [官方网站](https://robogen-ai.github.io/)

## 概述

RoboGen 是一个自动化生成机器人学习资源的框架，能够生成多样化的任务场景、物体配置以及带标注的训练数据。与直接生成策略的方法不同，RoboGen 专注于为机器人学习提供高质量的数据基础设施。

该系统利用大语言模型和生成式 AI 技术，自动设计新的操作任务、构建相应的仿真环境，并生成带有专家演示和标注的数据集。这种方法可以大幅降低数据收集的成本和时间，为训练鲁棒的机器人操作策略提供大规模、多样化的数据支持。RoboGen 特别适用于解决真实世界机器人学习中数据稀缺和分布单一的问题。
