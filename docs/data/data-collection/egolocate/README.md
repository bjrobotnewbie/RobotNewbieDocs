# EgoLocate - 自中心定位动作捕捉

## 项目简介

EgoLocate 是由 Xinyu Yi 开发的自中心定位动作捕捉项目，项目主页介绍了基于自中心视角的动作捕捉方法。

## 官方链接

* 项目主页：<https://xinyu-yi.github.io/EgoLocate/>

## 核心特点

* **自中心视角**：从第一人称视角进行定位
* **创新方法**：不同于传统第三人称捕捉
* **研究者开发**：学术研究项目

## 适用场景

* 自中心动作捕捉研究
* 第一人称人机交互
* 机器人遥操作数据采集
* 计算机视觉研究
