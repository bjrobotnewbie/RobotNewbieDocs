# IsaacTeleop - NVIDIA统一遥操作框架

## 资源简介

IsaacTeleop 是 NVIDIA 开发的统一遥操作框架，用于仿真和真实机器人的遥操作数据采集。官方定义为"sim & real robot teleoperation 的统一框架"。

## 官方链接

* GitHub仓库：<https://github.com/NVIDIA/IsaacTeleop>

## 核心特点

* **统一框架**：同时支持仿真和真实机器人
* **多种输入设备**：支持多种遥操作设备
* **NVIDIA生态**：与 Isaac Sim 深度集成
* **数据采集流程完整**：从遥操作到数据存储一站式支持
* **活跃开发**：最近持续更新

## 支持的机器人

* 机械臂
* 人形机器人
* 四足机器人

## 适用场景

* 跨仿真-真实机器人遥操作采集
* 大规模数据收集
* 模仿学习数据集构建
* 机器人遥操作研究

## 适用人群

* NVIDIA Isaac 生态开发者
* 机器人数据采集研究者
* 具身智能研究者
* 工业机器人开发者
