# PNP - 六IMU人体动作捕捉

## 资源简介

PNP 是一个基于6个惯性测量单元（IMU）的实时人体动作捕捉系统，通过融入非惯性力改进了 PIP 方法，能够实时捕捉人体全身运动。

## 官方链接

* GitHub仓库：<https://github.com/Xinyu-Yi/PNP>

## 核心特点

* **六IMU配置**：仅需6个惯性传感器即可实现全身运动捕捉
* **实时捕捉**：支持实时运动捕捉
* **非惯性力融合**：通过引入非惯性力提升捕捉精度
* **开源免费**：GPL-3.0 许可证

## 核心技术

* 基于惯性测量单元（IMU）
* 改进的 PIP（Propagative Inertial Poses）方法
* 融合非惯性力约束
* 实时运动重建
