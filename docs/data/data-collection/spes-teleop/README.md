# teleop - WebXR手机VR遥操作

## 资源简介

teleop 是 SpesRobotics 开发的开源项目，能够将你的手机或 VR 头盔变成机器人机械臂遥操作设备，通过 WebXR 技术实现遥操作。

## 官方链接

* GitHub仓库：<https://github.com/SpesRobotics/teleop>

## 核心特点

* **WebXR技术**：基于WebXR标准
* **低成本方案**：使用手机或VR头盔，无需专用硬件
* **ROS2集成**：原生支持 ROS2
* **模仿学习**：支持数据采集和模仿学习
* **Apache 2.0**：开源免费商用

## 核心功能

* 将手机/VR变为遥操作控制器
* 实时运动捕捉和重定位
* ROS2 话题发布
* 数据记录与存储

## 适用场景

* 低成本机器人遥操作
* 快速演示数据采集
* 个人研究者数据收集
* 教育和学习用途

## 适用人群

* 个人研究者
* 学生项目
* 低成本数据采集需求
* ROS2 开发者

## 学习建议

* 准备支持 WebXR 的手机或VR设备
* 配置 ROS2 环境
* 调试运动重定位参数
* 开始采集演示数据
