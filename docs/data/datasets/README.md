# 机器人数据集

机器人数据集是用于训练和评估机器人智能系统的重要资源，包含各种机器人感知、操作和导航任务的数据。本章节涵盖机器人领域常见的各类数据集。

## 分类说明

| 数据集 | 数据类型 | 应用场景 |
|------|---------|---------|
| **通用机器人数据集** | 多模态，多任务 | 通用机器人学习 |
| **操作数据集** | 机器人操作，抓取 | 机器人操作学习 |
| **导航数据集** | 视觉导航，SLAM | 机器人导航学习 |
| **具身智能数据集** | 语言-视觉-动作 | 具身AI研究 |
