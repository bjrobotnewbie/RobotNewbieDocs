# F1-VLA
F1: A Vision-Language-Action Model Bridging Understanding and Generation to Actions, arXiv 2025.

## 核心特性
- 桥接理解与生成的视觉语言动作模型
- 结合世界建模知识增强VLA性能
- 在理解和生成之间找到平衡提升泛化
