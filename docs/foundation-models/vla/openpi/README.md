# OpenPI (PI-Zero)
Physical Intelligence 开源的通用机器人策略模型 PI-Zero，基于大规模机器人数据预训练的扩散-based VLA模型，具备出色的泛化能力，支持多种机器人形态和任务。

## 核心特性
- 基于Flow Matching扩散架构，直接生成连续动作，无需离散化
- 在大规模机器人交互数据上预训练，具备强大的零样本迁移能力
- 支持单臂、双臂、移动操作等多种机器人构型
- 原生兼容LeRobot生态系统，数据处理、训练、部署全流程开箱即用
- FluxVLA等主流工程框架已原生集成OpenPI模型推理
