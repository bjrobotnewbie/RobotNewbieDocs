# StarVLA
星桥资本团队开源的通用VLA框架，支持多种VLM基座，生态活跃，适配多种机器人平台。

## 核心特性
- 框架设计开放灵活，支持多种VLM基座（QwenPI-v2/QwenPI-v3/Bridge-RT-1等）
- 原生支持多种机器人构型，开箱即用
- 社区活跃，持续更新功能
- 提供完整训练部署 pipeline
