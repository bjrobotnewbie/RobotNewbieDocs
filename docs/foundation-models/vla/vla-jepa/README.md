# VLA-JEPA
VLA-JEPA: Enhancing Vision-Language-Action Model with Latent World Model, arXiv 2026.

## 核心特性
- 使用潜在世界模型增强视觉语言动作模型
- 结合JEPA（Joint Embedding Predictive Architecture）架构
- 通过预测潜在表示学习世界模型知识
