# X-VLA
清华大学AIR 开源的高扩展跨实体VLA模型，IROS'25冠军工作，通过软提示实现可扩展跨实体学习，在低参数量条件下刷新多项基准性能。

## 核心特性
- IROS 2025 AGIBot World Challenge 冠军方案
- **软提示**（Soft Prompts）技术，为每个机器人平台引入实体特定的可学习软提示
- 有效解决跨实体、异构机器人数据学习难题
- 首个完全开源实现**120分钟无辅助自主叠衣任务**的VLA模型
- 仅0.9B参数量，在五大权威仿真基准全面刷新SOTA性能
