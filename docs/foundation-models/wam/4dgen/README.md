# 4DGen
Geometry-aware 4D Video Generation for Robot Manipulation, ICLR 2026.

## 核心特性
- 几何感知的4D视频生成，专为机器人操作设计
- 考虑空间几何约束，生成更符合物理规律的视频
- 支持机器人操作任务的数据生成和世界建模
