# Cosmos Policy
NVIDIA 开源的世界动作模型，专为通用机器人设计，具备出色的零样本泛化能力和实时控制性能。

## 核心特性
- 基于140亿参数自回归视频扩散模型构建
- 支持7Hz实时闭环控制
- 在LIBERO基准测试中达到82.2%成功率
- 支持多种机器人构型和任务场景
- 原生支持跨机器人本体迁移
