# Diffusion Reward
Diffusion Reward: Learning Rewards via Conditional Video Diffusion, ECCV 2024.

## 核心特性
- 通过条件视频扩散学习奖励函数
- 利用视频扩散模型生成未来帧来计算奖励
- 在强化学习中使用世界模型提供奖励信号
