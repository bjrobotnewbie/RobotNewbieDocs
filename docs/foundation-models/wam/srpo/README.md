# SRPO
SRPO: Self-Referential Policy Optimization for Vision-Language-Action Models, arXiv 2025.

## 核心特性
- 视觉语言动作模型的自引用策略优化
- 基于世界模型的自参照优化方法
- 提升VLA模型在复杂任务中的性能
