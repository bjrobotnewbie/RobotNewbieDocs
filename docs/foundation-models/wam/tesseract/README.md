# TesserAct
TesserAct: Learning 4D Embodied World Models, ICCV 2025.

## 核心特性
- 学习4D具身世界模型，捕捉空间和时间维度的环境动态
- 基于显式世界建模提升机器人泛化能力
- 支持复杂环境中的长期预测和规划
