# UnifoLM-WMA-0
宇树科技开源的世界模型动作框架（WMA），为具身智能机器人提供仿真引擎和策略增强的完整解决方案。

## 核心特性
- 提供完整的仿真引擎，可生成高质量机器人交互数据
- 通过世界模型预测未来状态，增强策略学习
- 统一框架支持世界模型和动作生成联合训练
- 原生支持宇树机器人平台，开箱即用
- 集成在UnifoLM家族，与UnifoLM-VLA互补增强
