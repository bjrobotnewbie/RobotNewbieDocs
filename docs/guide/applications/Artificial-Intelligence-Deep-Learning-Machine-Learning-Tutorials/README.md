## 项目介绍
本项目是Synapsa团队推出的免费AI实践教程，可在Google Colab、Kaggle、Binder、GitHub Codespaces、Jupyter等任意环境运行，核心聚焦于工业场景下的AI应用落地，提供符合欧盟AI法案要求的可复现证据、模型验证、预测性维护、文档提取、检索增强生成（RAG）、AI智能体、多智能体协作（MCP）及仿真人形机器人等方向的实践课程，所有课程均为可操作的交互式笔记本形式。

## 主要特性
1. 课程为可操作的交互式笔记本，自带自动评分功能，练习运行后即时校验，支持隐藏提示、带部分评分规则的参考答案
2. 课程内容紧扣工业实际需求，所有计算结果可复现，相关结论均标注原始来源
3. 支持多环境一键运行，首个单元格自动安装课程所需指定版本依赖，避免环境冲突
4. 覆盖欧盟AI法案合规、模型风险验证、预测性维护等多个工业AI核心应用场景
