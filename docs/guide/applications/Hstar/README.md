# Hstar

[CVPR 2026] 360°思维：野外中的类人视觉搜索

## 项目链接

- GitHub: <https://github.com/THUSI-Lab/Hstar>
- 项目主页: <https://humanoid-vstar.github.io/>

## 项目介绍
本项目是CVPR 2026收录的*Thinking in 360°*，聚焦野外类人机器人视觉搜索任务，旨在实现类人机器人在真实户外环境中完成全景视觉搜索相关任务。

## 主要特性
1.  针对野外复杂户外场景设计，支持360°全景视觉感知的类人机器人视觉搜索方案
2.  面向真实无约束野外环境优化，适配类人机器人的实际落地应用需求
3.  提供完整的任务落地框架，可直接用于类人机器人视觉搜索相关研究与开发。
