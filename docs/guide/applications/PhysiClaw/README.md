## 项目概述

## 项目介绍
PhysiClaw是一款实体AI代理，可通过摄像头读取手机屏幕、触控笔模拟人手操作手机，无需在手机上安装任何软件、无需API/ADB/OAuth，仅需解锁手机放置即可工作。
它可完成日常手机端任务：点外卖、采购 groceries、叫车、缴费、回复消息等所有手动可完成的手机操作，用户可通过自然语言向其专属WhatsApp账号下达指令。

## 主要特性
1.  **无侵入式操作**：不依赖手机API，通过视觉+触控模拟真人操作，不会触发反机器人检测
2.  **通用适配**：可兼容几乎所有手机应用，不受应用封闭性限制
3.  **自然交互**：通过WhatsApp以纯自然语言接收任务指令，支持任务确认与结果回复
4.  支持macOS/Windows/Linux运行，需搭配专属硬件（机械臂、触控笔、摄像头）以及iPhone使用，单步操作耗时数秒，兼顾通用性与可靠性。
