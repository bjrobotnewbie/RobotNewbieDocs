# UrbanGround

UrbanGround：从本地感知到城市空间代理——基于真实规模城市的视角

## 项目链接

- GitHub: <https://github.com/UrbanGround/UrbanGround>
- 项目主页: <https://urbanground.github.io/>

## 项目介绍
UrbanGround是一个面向真实城市规模的机器人智能研究项目，旨在从局部感知实现空间自主能力。项目提供了官方项目页面、数据集、论文资源，采用MIT开源协议，支持多语言文档。其应用场景覆盖真实城市环境下的机器人任务，包括楼梯通行、街道探索、地图视角控制、地点检索、地图传送、行人导航等。

## 主要特性
1.  支持真实城市大尺度环境下的机器人空间智能研究
2.  配套提供Hugging Face开源数据集与学术论文
3.  内置多种城市机器人落地任务演示
4.  提供多语言本地化文档，方便全球开发者使用
