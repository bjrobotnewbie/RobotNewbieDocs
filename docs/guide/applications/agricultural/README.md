# 农业机器人应用

农业机器人是智慧农业的核心装备，通过自动化、智能化技术提升农业生产效率，降低人力成本，解决农业劳动力短缺问题。

## 核心应用场景
- **种植管理**：自动插秧、施肥打药、作物巡检
- **采摘分拣**：水果/蔬菜自动采摘、智能分选分级
- **畜牧养殖**：自动喂料、环境监测、疫病防控
- **林业作业**：树木种植、病虫害防治、森林防火巡检
- **渔业养殖**：水质监测、自动投喂、捕捞作业

## 代表性项目
- 极飞科技农业无人机
- 大疆农业植保无人机
- 采摘机器人
- 智慧养猪机器人
- 水产养殖巡检机器人
