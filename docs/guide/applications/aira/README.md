## 项目链接

- GitHub: <https://github.com/airalab/aira>
- 项目主页: <http://aira.life>

## 项目介绍
AIRA（Autonomous intelligent robot agent）是一款自主智能机器人代理项目，旨在实现人机、机器人之间的标准化经济交互，可将各类机器人接入基于以太坊的机器人服务市场。本仓库属于Robonomics研发历史存档，并非当前最新实现，最新代码可查看Airalab组织的 pinned 仓库。

## 主要特性
1.  支持机器人与人类、机器人之间的标准化经济交互
2.  可对接以太坊生态的机器人服务市场
3.  提供Airalab社区专属Nix软件源与二进制缓存加速部署
4.  提供预编译的VirtualBox镜像快速上手
