# 自动驾驶应用

自动驾驶是集环境感知、决策规划、运动控制于一体的综合技术，是人工智能和机器人技术在交通领域的核心落地场景。

## 核心应用场景
- **乘用车**：L2+辅助驾驶、L4/L5全自动驾驶出租车
- **商用车**：港口无人集卡、干线物流自动驾驶重卡
- **末端配送**：园区无人配送、快递外卖无人车
- **矿区作业**：露天矿山无人运输、矿区自动驾驶矿卡
- **封闭场景**：机场/园区接驳车、景区观光车
