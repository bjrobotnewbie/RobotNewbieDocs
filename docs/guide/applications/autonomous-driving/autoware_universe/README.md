## 项目概述

Autoware Universe 是 Autoware 生态系统的基础支柱，在增强自动驾驶技术的核心功能方面发挥着关键作用。该仓库是 Autoware Core/Universe 概念的关键组成部分，管理着广泛的软件包，大大扩展了自动驾驶汽车的能力。

Autoware 是目前最活跃的开源自动驾驶项目之一，提供完整的自动驾驶软件开发栈，包括感知、定位、预测、规划、控制等各个模块。Autoware Universe 包含了大量扩展功能包，丰富了核心功能。

项目提供完整的文档，支持开发者入门和二次开发，有活跃的社区维护，代码覆盖率持续监控，质量保证较好。
