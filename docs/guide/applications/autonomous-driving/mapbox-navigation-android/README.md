# mapbox-navigation-android

Mapbox 导航 SDK 用于 Android

## 项目链接

- GitHub: <https://github.com/mapbox/mapbox-navigation-android>
- 项目主页: <https://docs.mapbox.com/android/navigation/overview/>

## 项目介绍
这是面向Android平台的Mapbox导航SDK，为Android应用提供地图导航能力。用户可通过官方完整文档完成安装和使用，还可参考迁移指南将旧版本(v2)项目升级至v3及更高版本。可通过Stack Overflow的#mapbox+android标签获取社区帮助，或在GitHub仓库提交问题反馈bug、发起功能需求。
