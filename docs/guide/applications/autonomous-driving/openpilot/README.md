# openpilot

- 项目链接：https://github.com/commaai/openpilot
- 项目主页：https://comma.ai/openpilot

## 项目概述

openpilot 是一个机器人操作系统，目前它为超过 300 款支持车辆的自动驾驶辅助系统进行升级，实现了自适应巡航控制（ACC）、自动车道保持（ALC）和前方碰撞预警（FCW）等功能。

主要特点：
- 开源项目，MIT 许可证
- 支持 300 多款车型，社区活跃
- 提供完整文档和开发路线图
- 支持开发者贡献，有活跃的 Discord 社区
- 可在 comma 硬件上运行，也支持自定义硬件

该项目是目前最受欢迎的开源自动驾驶辅助项目之一，让普通车主也能体验先进的驾驶辅助功能。
