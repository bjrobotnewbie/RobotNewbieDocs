# unidrivevla

UniDriveVLA：融合理解、感知与行动规划，实现自动驾驶

## 项目链接

- GitHub: <https://github.com/xiaomi-research/unidrivevla>

## 项目介绍
UniDriveVLA是一款面向自动驾驶的统一框架，旨在整合感知、理解与动作规划能力。该项目由华中科技大学与小米汽车等团队联合开发，已发布预印本论文、代码、模型权重与配套数据集，支持在nuScenes等自动驾驶数据集上开展训练与评估。

## 主要特性
1.  统一自动驾驶全流程：打通环境感知、场景理解到动作规划的完整链路
2.  配套完整工具链：提供数据准备、模型预训练、训练推理的全流程代码与脚本
3.  开源资源丰富：已在HuggingFace发布模型权重与数据集，支持nuScenes等主流自动驾驶评测框架
4.  适配多场景自动驾驶任务，可用于研发端到端自动驾驶系统
