## 项目概述

## 项目介绍
本项目是社区维护的Waze GPS语音导航包存档仓库，收集并整理了已下架的经典、定制语音包链接，帮助用户找回官方应用中消失的喜爱的角色、名人语音包，解决用户找不到心仪语音的痛点，目标是让这些语音包易于查找、安装，并由社区持续维护。

## 主要特性
1.  收录了大量已从官方Waze应用下架的经典、定制语音包，包含众多名人、角色配音
2.  提供可直接跳转安装的语音包链接与mp3源文件下载地址
3.  安装流程简单：在安装Waze的设备上打开本仓库，点击语音链接即可唤起Waze完成下载安装
4.  由社区持续维护，避免语音包资源随旧论坛、过期站点丢失
