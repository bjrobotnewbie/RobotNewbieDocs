# awesome-reliable-robotics

机器人研究，展示其在真实世界中的可靠性与鲁棒性（持续更新）

## 项目链接

- GitHub: <https://github.com/philfung/awesome-reliable-robotics>

## 项目介绍
这是一个精选的机器人学学术资源合集，聚焦于真实场景下的机器人可靠性与鲁棒性研究，持续更新中。项目最初为个人学习笔记，后开放共享，要求收录的研究必须报告真实机器人硬件实验结果，而非仅仿真结果，欢迎社区贡献。

## 主要特性
1.  **核心收录方向**：包含VLA、Online RL、SLAM等方向的真实机器人落地研究
2.  **资源维度**：按论文名称、发布时间、实际实验成功率、研究类别、链接及详细信息整理
3.  **示例案例**：收录了VLA-Precision等前沿工作，其在9项高精度化学实验中实现98.3%平均成功率，最高带来10.9倍吞吐量提升
4.  采用MIT开源协议，支持社区共建贡献。
