# 外骨骼机器人应用

外骨骼机器人应用涵盖外骨骼在康复医疗、工业助力、军事增强和日常辅助等场景中的落地实践。本页面聚焦"用来做什么"，外骨骼本体形态详见机器人形态分类。

## 核心应用场景

- **康复医疗**：中风/脊髓损伤患者的步态训练、上肢功能康复、神经可塑性促进
- **工业助力**：搬运装卸减负、装配线姿势支撑、长时间作业疲劳缓解
- **军事增强**：士兵负重行军增强、弹药搬运助力、长距离巡逻耐力提升
- **日常辅助**：老年人行走辅助、行动障碍者生活自理、坐姿转站立辅助
- **运动训练**：运动员力量训练辅助、运动损伤预防与恢复

## 代表性项目

- **HAL（Cyberdyne）** - 筑波大学商业化康复外骨骼，最早获医疗器械认证
- **Ekso Bionics** - 下肢康复外骨骼，用于中风和脊髓损伤康复
- **ReWalk** - 下肢外骨骼，帮助截瘫患者重新行走
- **Sarcos Guardian XO** - 全身动力外骨骼，工业搬运增强
- **傅利叶智能** - 下肢康复外骨骼，国内康复医疗广泛应用
- **迈步机器人** - 下肢康复外骨骼，中风康复训练
- **Harvard FlexOEGar** - 柔性踝外骨骼，轻量化行走辅助
