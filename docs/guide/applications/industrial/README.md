# 工业机器人应用

工业机器人是智能制造的核心装备，广泛应用于汽车、3C、半导体、新能源等领域，大幅提升生产效率和精度。

## 核心应用场景
- **焊接/喷涂**：汽车车身焊接、喷漆作业
- **装配**：3C产品精密装配、半导体封装
- **搬运/码垛**：物流分拣、仓储搬运、重物码垛
- **检测**：视觉缺陷检测、尺寸测量、质量管控
- **打磨抛光**：五金件、汽车零部件表面处理
