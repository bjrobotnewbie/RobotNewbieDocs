# joycon-robotics

Joycon-Robotics: 低成本、便捷的单/双臂机器人远程操作

## 项目链接

- GitHub: <https://github.com/box2ai-robotics/joycon-robotics>

## 项目介绍
Joycon-Robotics是一款低成本、易上手的单/双臂机器人遥操作工具，基于任天堂Joy-Con手柄实现机器人控制。支持Ubuntu 20.04/22.04（带蓝牙）及Windows系统，可用于机器人远程操控、RLBench-ACT数据采集、适配Robosuite仿真环境等场景。

## 主要特性
1.  支持单/双Joy-Con手柄，提供单臂/双臂遥操作能力
2.  内置偏航漂移补偿与自动校准功能，优化控制稳定性
3.  可自定义机器人初始位姿、运动限位等参数
4.  适配ViperX 300S、So-100 Plus等轻量化协作机械臂
5.  支持输出全按键编码值，兼容RL训练数据采集与仿真环境对接
6.  提供快速蓝牙配对与自动重连机制，连接便捷稳定
