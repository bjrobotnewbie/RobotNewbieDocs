# lehome_solution

我的解决方案获得 LeHome 挑战赛第一名（在线）和现实世界比赛第二名。

- GitHub: <https://github.com/IliaLarchenko/lehome_solution>

## 项目介绍
本项目是2026 ICRA LeHome挑战赛的获奖解决方案，该赛事基于LeRobot SO-ARM101双机械臂平台开展衣物折叠机器人竞赛。本方案在62支参赛队伍中取得线上仿真赛第1名、实物决赛第2名的成绩。
项目提供了完整的异步分布式强化学习（RL）流程、模型训练、自动数据采集、DAgger与手动遥操作数据采集方案，可复现仿真与实物机器人上的策略训练与评估流程，附带技术报告、博客教程与预训练模型权重。

## 主要特性
1.  适配LeHome挑战赛官方竞赛环境，基于Pi0.5与openpi框架构建策略模型
2.  支持仿真与实物机器人两种部署场景，包含完整的训练-采集-评估闭环流程
3.  提供线上赛与线下赛两套专用预训练策略权重
4.  附带完整的演示视频与技术文档，可作为机器人衣物折叠任务的参考实现
