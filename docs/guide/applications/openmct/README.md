## 项目概述

## 项目介绍
Open MCT（Open Mission Control Technologies）是NASA埃姆斯研究中心开发的下一代Web端任务控制框架，支持桌面和移动设备的数据可视化。它可用于航天器任务数据分析、实验漫游车系统的规划与运营，也可作为通用开源框架，为任何产生遥测数据的系统构建规划、运营及分析类应用。

## 主要特性
1.  基于Web的跨平台任务控制可视化框架
2.  由NASA实际应用于航天任务场景，稳定性经过验证
3.  可扩展适配各类遥测数据系统
4.  提供完整的本地开发部署流程，依赖Git和Node.js环境，通过npm即可快速启动本地服务。
