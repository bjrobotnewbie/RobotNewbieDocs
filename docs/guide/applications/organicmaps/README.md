# organicmaps

🍃 Organic Maps 是一款面向超600万旅行者、游客、徒步旅行者和骑行者的免费 Android 与 iOS 离线地图应用。它使用众包更新的 OpenStreetMap 数据，由社区满怀热爱开发而成。无广告、无追踪、无数据收集、无捆绑垃圾软件。欢迎捐款支持我们的开发！

## 项目概述

## 项目介绍
Organic Maps是一款隐私优先的离线地图与GPS应用，面向徒步、骑行、驾驶用户打造。它基于OpenStreetMap众包数据开发，由原MapsWithMe（MAPS.ME）团队核心成员发起，开源社区维护，全球用户量超600万，支持Android、iOS多平台安装，无广告、无追踪、不收集用户数据。

## 主要特性
1.  基于OpenStreetMap的详细离线地图，包含其他地图未收录的地点
2.  提供骑行路线、徒步步道、步行路径，以及等高线、海拔剖面、山峰坡度信息
3.  支持步行、骑行、驾车的语音导航
4.  内置地铁地图与公共交通路线查询，支持快速离线搜索
5.  支持KML、KMZ、GPX、GeoJSON格式的轨迹与书签导入导出
6.  深色模式、低存储空间占用，可查看景点的维基百科介绍
7.  完全免费开源，无广告、无数据收集、无强制注册与推送通知
