## 项目介绍
text-to-cad是一个面向CAD、机器人学与硬件设计的智能体技能工具库，支持通过自然语言生成、检查、导出各类设计工件，可用于快速将文本需求转化为可落地的硬件/机器人设计文件。项目提供在线文档与演示Demo，基于Python 3.11+开发，遵循MIT开源协议。

## 主要特性
1.  **核心功能**：支持生成、处理CAD与机器人描述类设计文件，可导出STEP、STL、3MF等通用CAD格式，以及URDF、SDF、SRDF等机器人专用格式
2.  **适用场景**：用于CAD建模、硬件设计、机器人仿真与配置流程，帮助智能体快速完成本地设计文件的创建与流转
3.  配套完善的技能工作流，覆盖设计、审查、加工切片全流程环节。
