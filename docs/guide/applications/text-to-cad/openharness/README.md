# openharness

终极编码代理及更广泛领域的解决方案。囊括所有代理、所有机器。一个统一指挥中心。从代码开始，再跟随好奇心，跨学科构建：从 CAD、电路、机器人、游戏到音乐。

## 项目链接

- GitHub: <https://github.com/autonomous-ai/openharness>
- 项目主页: <https://www.autonomous.ai/harness>

## 项目介绍
openharness是面向编码智能体及更多场景的全能管控中心，可统一管理各类编码智能体与设备，支持从代码开发延伸至CAD、电路、机器人、游戏、音乐等跨领域创作场景，为开发者提供高效的跨设备、跨智能体管控能力。

## 主要特性
1. 统一管控多类编码智能体：支持Claude Code、Codex、Cursor、Copilot等十余款主流编码智能体，可在同一界面并行管理；
2. 便捷跨设备联动：无需SSH密钥、Tailscale或端口转发，仅需密码即可将笔记本、家庭服务器、GPU设备等各类机器接入管控；
3. 键盘优先操作：提供⌘P、⇧⌘I等快捷键，支持快速查找、跳转任务、拆分界面，可自定义按键映射；
4. 端到端加密：代码、密钥、按键输入均在本地加密，中继节点仅转发密文，保障数据安全；
5. 轻量高性能：原生应用（非Electron），关闭后智能体仍可运行，M2 Max设备上CPU占用约0.1%，内存占用约304MiB，响应延迟低。
