# Cloud-API-2

DJI Cloud API 2 官方仓库——一款免费的 PaaS 服务，专为 DJI 基站和无人机提供支持。

## 项目链接

- GitHub: <https://github.com/dji-sdk/Cloud-API-2>
- 项目主页: <https://developer.dji.com/cn/cloud-api-2/>

## 项目介绍
Cloud-API-2是DJI官方推出的面向DJI Dock及无人机硬件生态的免费PaaS平台，旨在为软件集成商与开发者提供DJI原厂能力开放支持，助力高效完成二次开发与垂直行业解决方案交付。

## 主要特性
1. 免费开放：License完全免费，不限设备台数，可在DJI开发者平台快速申请。
2. DaaS SDK：面向对象、协议无感、链式调用，屏蔽底层协议细节，大幅提升集成效率。
3. 前端独立组件：提供驾驶舱、航线编辑器等开箱即用组件，支持配置化与主题定制，配合AI Plugin加速开发。
4. 功能丰富：覆盖设备管理、实时直播、远程操控、媒体管理、模型重建等多场景能力，持续迭代更新。
5. 辅助开发工具：内置虚拟设备模拟器、AI开发插件、开源Demo，二次开发无需强依赖真机，降低开发门槛。
