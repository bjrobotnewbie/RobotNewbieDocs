# DroneAid

面向急救人员的空中侦察员。DroneAid 利用机器学习探测地面受困者发出的求救信号。

## 项目链接

- GitHub: <https://github.com/Call-for-Code/DroneAid>

## 项目概述

## 项目介绍
DroneAid是一款面向应急救援人员的空中侦察开源项目，基于机器学习识别地面求救信号。项目核心是一套符号语言，用于训练视觉识别模型，该模型可分析无人机直播视频，检测并统计特定求救标识，同时配套仪表盘可在地图上标记求救位置并启动响应流程。
项目可扩展适配无人机、飞机乃至卫星平台，其符号语言也可用于训练其他视觉识别方案。该项目起源于2018年，2019年作为Linux基金会的Call for Code开源项目重构发布，当前托管于Linux基金会。

## 主要特性
1.  内置标准化求救符号语言，可在传统通信中断时帮助受灾群众表达需求
2.  支持通过VR渲染符号来训练视觉识别模型
3.  可部署在无人机等空中平台上实时分析视频流，识别求救标识
4.  配套仪表盘可视化标记求救位置，辅助救援响应
5.  支持多平台扩展，适配多种空中/航天采集设备
