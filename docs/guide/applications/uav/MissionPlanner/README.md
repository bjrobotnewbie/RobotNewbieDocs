# MissionPlanner

- 项目链接：https://github.com/ArduPilot/MissionPlanner
- 项目主页：http://ardupilot.org/planner/

## 项目概述
MissionPlanner是ArduPilot项目的地面控制站软件，基于C# .NET开发，用于控制和管理无人机、机器人等自主移动设备。其核心特点包括：
1. 支持Windows、Android、OSX/IOS等多平台，适配不同的开发和使用场景
2. 提供稳定版本下载和详细的变更日志，方便用户跟踪项目更新
3. 完整的编译指南，支持使用Visual Studio 2022进行二次开发
4. 活跃的社区论坛和开源社区支持，用户可以获取帮助和贡献代码
5. 支持多种ArduPilot固件的配置、调试和任务规划

该项目遵循开源许可证，用户可自由使用、修改和分发软件源代码。
