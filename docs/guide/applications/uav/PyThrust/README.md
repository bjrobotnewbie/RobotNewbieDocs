# PyThrust

无人机设计中的开源电动推进系统分析与优化框架

## 项目链接

- GitHub: <https://github.com/Setuav/PyThrust>

## 项目介绍
PyThrust是一款开源的无人机电动推进系统分析与优化框架，可用于无人机设计中的多学科设计优化（MDO），支持基于OpenMDAO的协同设计。它能够完成稳态性能求解、匹配厂商实测数据的自动校准，以及将理论设计匹配到真实无刷电机和螺旋桨目录的数据库检索功能。

## 主要特性
1.  支持系统阻力参数校准，可拟合厂商实测数据
2.  集成OpenMDAO实现悬停协同设计与参数优化
3.  内置经验螺旋桨数据库，可检索真实量产部件
4.  可生成推进系统悬停效率热力图等分析结果
5.  提供完整的官方文档与示例教程，支持快速上手
6.  采用Apache 2.0开源协议，可通过PyPI快速安装部署
