# 无人机应用

> **形态-应用交叉引用说明**：无人机作为一种机器人形态，其结构和分类描述归入 [空中机器人](/guide/robot-forms/aerial-robots/README)。本页面聚焦无人机在各个行业的具体应用场景和落地案例。

无人机是空中机器人的核心载体，集成了飞行控制、计算机视觉、自主导航等技术，在民用和工业领域得到了广泛应用。

## 核心应用场景
- **消费级**：航拍、旅拍、娱乐竞速
- **工业级**：电力巡检、光伏巡检、林业巡检、管道巡检
- **测绘领域**：地形测绘、国土规划、3D建模
- **应急领域**：消防救援、地震/洪水应急侦察、救灾物资空投
- **物流领域**：偏远地区/海岛快递配送、医疗物资紧急运输
