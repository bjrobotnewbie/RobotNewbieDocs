# YMapper

- 项目链接：https://github.com/YLabs-FPV/YMapper
- 项目主页：https://ymapper.yarosfpv.com

## 项目概述

YMapper 是一个**跨平台无人机测绘任务规划工具**，用于为大疆无人机创建自动航测/摄影测量任务，支持航点规划，可以导出到 DJI Fly 和 Litchi 应用。

只需几次点击就能创建完整的测绘任务，非常方便。

### 核心特点

- **跨平台**：支持 Windows、Linux、MacOS 和 Android
- **易用**：几次点击就能创建任务
- **可定制**：可根据需求调整任务参数
- **兼容 DJI Fly**：支持支持航点功能的大疆无人机
- **兼容 Litchi**：可以导出任务到 Litchi，用于不支持航点的大疆无人机

### 支持的机型

**DJI Fly**:
- DJI Mini 4 Pro、Mini 5 Pro
- DJI Air 3、Air 3S
- DJI Mavic 3 (Regular/Cine/Classic)
- DJI Mavic 4 Pro

**Litchi**:
- Mini 2、Mini SE、Air 2S
- Mavic Mini 1、Mavic Air 2、Mavic 2 Zoom/Pro
- Mavic Air 1、Mavic Pro 1
- Phantom 4 系列、Phantom 3 系列
- Inspire 1、Inspire 2、Spark

**Litchi Pilot (beta)**:
- Mini 3、Mini 3 Pro、Mavic 3E/3T
- Matrice 4、Matrice 30、Matrice 300/350 RTK、Matrice 400

YMapper 让无人机航测任务规划变得简单，是航拍测绘爱好者的实用工具。
