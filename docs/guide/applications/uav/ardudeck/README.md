# ardudeck

一个 GCS 统御一切。ArduPilot、Betaflight、iNav 合而为一。任务规划、PID 调优、OSD 模拟器、FlightGear 的 SITL 仿真。跨平台支持（Windows/macOS/Linux）。

## 项目概述

## 项目介绍
ArduDeck是一款开源跨平台地面站软件，基于Electron、React和TypeScript开发，可统一支持ArduPilot（MAVLink协议）、Betaflight、iNav三种飞控的全流程操控。支持通过USB、无线电、IP或蜂窝链路连接单台或多台飞行器，覆盖连接、配置、校准、任务规划、飞行测试、数据分析全 workflow。当前处于Beta 1 (0.1.0)版本，已可用于实际飞行作业。

## 主要特性
1.  一站式功能：集成任务规划、PID调参、OSD模拟器、搭配FlightGear的SITL仿真
2.  跨平台支持：可在Windows、Mac、Linux系统运行
3.  多协议兼容：支持MAVLink v1/v2与MSP v1/v2通信协议
4.  开源免费，采用GPL-3.0开源许可，提供官方文档、社区论坛与Discord交流渠道。
