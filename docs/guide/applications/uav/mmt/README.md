# mmt

媒体管理工具 - 使从 GoPro 及其他运动相机/无人机导入视频和图片的过程更加易于接受。

## 项目链接

- GitHub: <https://github.com/KonradIT/mmt>
- 项目主页: <http://mmt.camera>

## 项目介绍
MMT（Media Management Tool）是一款媒体管理工具，用于简化从GoPro、Insta360、DJI无人机/运动相机以及安卓设备导入视频和照片的流程。开发者基于过往的零散脚本开发了该统一解决方案，参考了dji-utils、gopro-linux、dohpro等项目。
目前支持导入的设备包括全系列GoPro、Insta360 X2/GO2/X3、DJI Osmo Pocket 1/2及多数Mavic系列机型，还有所有安卓设备（针对Pixel 6谷歌相机做了专属优化）。支持从SD卡、USB设备IP等路径导入素材，可通过配置文件自定义处理逻辑。

## 主要特性
1.  **核心功能**：支持相机素材导入、设备固件更新、已连接设备列表查看
2.  **灵活配置**：可自定义输出目录、项目名称、日期格式、文件复制缓冲区大小，支持按日期范围筛选导入素材
3.  **设备适配**：针对GoPro提供了跳过辅助文件、按相机/日期排序等专属参数
4.  **多平台兼容**：支持Windows、Linux等系统，可从发行版页面下载安装包
