## 项目概述

## 项目介绍
QGroundControl（简称QGC）是一款跨平台无人机地面站软件，支持Android、iOS、Mac OS、Linux、Windows系统，专为支持MAVLink协议的无人机（包括PX4和ArduPilot平台）提供完整的飞行控制与任务规划能力。

## 主要特性
1.  **任务规划**：支持规划、编辑并执行自主航点、测绘、结构扫描任务
2.  **实时飞行视图**：集成地图、仪表与完整飞行器遥测数据的实时飞行显示界面
3.  **车辆配置**：提供传感器校准、遥控器、飞行模式、电源设置的引导式配置向导
4.  **参数调优**：通过Fact系统查看、编辑所有飞行器参数
5.  **视频流传输**：基于GStreamer的UDP RTP/RTSP视频流，支持飞行画面录制
6.  **多机支持**：可同时连接并监控多架飞行器
7.  **MAVLink工具集**：内置MAVLink监视器、控制台以及日志下载分析功能
8.  **跨平台**：单套代码库即可适配Windows、macOS、Linux、Android、iOS全平台
