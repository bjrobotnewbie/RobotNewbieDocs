## 项目概述

Skybrush Server 是 **Skybrush 生态系统**的服务器组件，这是一个开源的无人机灯光秀和无人机群管理框架。

Skybrush Server 负责处理与无人机的通信通道，在其上提供抽象层，这样前端应用（如 Skybrush Live）不需要知道它们正在与哪种类型的无人机通信。

### 核心功能

- **无人机通信抽象**：统一接口支持多种无人机类型，前端无需关心具体无人机型号
- **可扩展架构**：通过扩展模块扩展功能，可以在启动时自动加载或运行时动态加载
- **内置扩展**：大部分功能都以扩展形式实现
- **支持时钟同步**：提供精确时钟同步
- **RTK 改正源**：支持 RTK GPS 改正数据
- **天气服务**：集成天气预报服务

### 主要特点

- 支持无人机群灯光秀编排和表演
- 支持多种无人机自动驾驶仪
- 基于 Python 开发，易于扩展
- 使用 uv 进行依赖管理，环境隔离干净
- 文档完善，活跃开发

### 生态系统

- Skybrush Live：前端可视化界面
- Skybrush Server：后端服务器（本项目）
- 支持多种无人机编队表演

Skybrush 是目前最流行的开源无人机灯光秀解决方案，被世界各地的表演团队使用。
