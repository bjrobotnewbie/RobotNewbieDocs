# visualize_uav_trajectory

在视频中可视化无人机的轨迹

## 项目链接

- GitHub: <https://github.com/XXLiu-HNU/visualize_uav_trajectory>

## 项目介绍
visualize_uav_trajectory是一款无人机视频轨迹可视化工具，可将无人机飞行轨迹以叠影形式叠加在视频画面中，生成适配顶刊的无人机轨迹可视化结果，支持快速复现论文配图。

## 主要特性
- 无需复杂调参，通过Codex工具即可调用，支持直接在仓库或安装后调用
- 可生成原分辨率叠影、末端局部放大图、论文合图及可编辑PPTX，保留关键帧配置与复现命令
- 支持自然语言调整，可修改轨迹叠影清晰度、图片排版、亮度色调等细节
- 输出内容包含PNG图片、PPTX文件及可核查的关键帧配置，适配论文插图展示需求
