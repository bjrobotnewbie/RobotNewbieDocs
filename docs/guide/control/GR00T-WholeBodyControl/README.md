## 项目概述

GR00T-WholeBodyControl是NVIDIA发布的**人形机器人全身控制一体化开发部署平台**，包含多个GR00T模型的全身控制实现。主要内容：

1. **解耦式WBC**：NVIDIA GR00T N1.5和N1.6中使用的解耦控制器设计，下肢使用强化学习，上肢使用逆运动学
2. **GEAR-SONIC系列**：最新一代通用人形全身控制器
3. **MotionBricks**：用于动画和机器人交互式运动控制的实时隐式生成模型
4. **完整教程**：提供端到端VLA工作流教程，包括遥操作数据采集、Isaac-GR00T N1.7微调、SONIC全身控制部署

该项目为人形机器人全身控制研究提供了完整的参考实现，涵盖从训练到部署的全流程。
