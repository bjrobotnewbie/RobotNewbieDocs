## 项目概述

## 项目介绍
LADAC是一款开源的MATLAB/Simulink飞行器建模、飞行动力学仿真与飞行控制开发框架，全称为Library for Aircraft Dynamics And Control。
它支持从小型无人机、多旋翼飞行器到运输机、柔性气动弹性构型的全品类飞行器开发，覆盖从组件级建模、控制器开发到完整非线性仿真、软件在环测试、代码生成以及搭配ArduPilot进行飞行测试的全流程工作流，已被应用于固定翼无人机、多旋翼、eVTOL飞行器、运输机、气动弹性飞行动力学模型、主动阵风载荷减缓以及先进飞行控制方法等研究项目中。当前该软件仍处于活跃开发的研究阶段，各组件成熟度、验证状态存在差异。

## 主要特性
1.  **模块化建模**：提供固定翼、多旋翼、eVTOL等飞行器及其子系统的完整/组件级模型，支持刚体/柔性体运动方程、气动/推进/执行器/传感器等模块化组件，可通过参数快速定义可复用的飞行器仿真模型，支持悬挂载荷与多体构型。
2.  **气动建模**：支持大攻角/侧滑角非线性有限翼模型、基于涡格法的翼型粘性耦合模型，可完成气动导数、下洗流、分布载荷、弯矩计算，涵盖定常/非定常翼型气动、动态失速、襟翼效应模型，支持刚性/气动弹性机翼以及机身、螺旋桨、旋翼、诱导速度建模。
3.  **飞行动力学与气动弹性**：基于四元数的刚体运动方程，基于结构模态的柔性体模型，提供结构建模、降阶、载荷传递与可视化工具，支持气动与结构模型耦合，内置大气湍流与离散阵风模型。
4.  **制导与控制**：提供非线性动态逆(NDI)、增量非线性动态逆(INDI)控制方法，支持控制效能建模与约束控制分配，内置姿态、加速度、高度、位置、轨迹控制模块，支持多种飞行模式与航点导航，附带线性系统、滤波与控制器开发工具，包含两款可配置的INDI自动驾驶仪。
