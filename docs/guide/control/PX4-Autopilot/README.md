## 项目概述

## 项目介绍
PX4 Autopilot是一款开源的无人机及无人载具自动驾驶堆栈，是行业主流的自动驾驶开发基础。它支持多旋翼、固定翼、VTOL、地面机器人等多种平台，可运行在NuttX、Linux和macOS系统上，采用BSD 3-Clause开源许可协议。

## 主要特性
1.  **模块化架构**：基于兼容DDS的发布/订阅中间件uORB构建，模块支持并行化且线程安全，可自定义配置并裁剪非必要功能。
2.  **广泛硬件适配**：支持多款自动驾驶飞控板，通过Pixhawk生态兼容大量传感器、数传电台和执行器。
3.  **开发者友好**：原生支持MAVLink以及ROS 2集成，提供完整的SITL仿真、硬件在环测试和飞行日志分析工具，拥有活跃的开发者社区。
