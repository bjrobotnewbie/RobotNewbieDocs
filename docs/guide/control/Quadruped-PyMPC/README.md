## 项目概述
该项目是一个基于单刚性体模型的四足机器人模型预测控制器，使用Python编写，支持梯度法（通过ACADOS）或采样法（通过JAX），可在真实机器人和Mujoco仿真环境中测试，适用于四足机器人的运动控制研究和开发，提供了多种优化选项和适配策略。
