## 项目概述

bipedal-locomotion-framework是一套用于**在人形机器人上实现双足行走**的C++库集合。主要特点包括：

1. **组件化设计**：将双足行走所需的各个功能拆分为不同的库，便于复用和维护
2. **C++17标准**：采用现代化C++17开发
3. **conda安装**：推荐使用conda进行安装，方便 dependency 管理
4. **持续开发中**：目前仍处于实验性开发阶段，API可能会有变化

该项目为人形机器人双足行走研究提供了一套基础算法库，方便研究者在此基础上进行开发。
