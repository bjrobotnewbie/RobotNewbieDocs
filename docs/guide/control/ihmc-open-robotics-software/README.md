## 项目概述

IHMC Open Robotics Software是一套**开源机器人软件**，包含先进的下肢运动算法和动量核心优化，支持多种顶级机器人系统。主要特点：

1. **支持多种机器人**：支持Atlas、Valkyrie等人形机器人平台
2. **跨平台**：在OSX、Windows、Ubuntu上测试，可以在其他平台工作
3. **开源Apache 2.0**：完整开源，可以自由使用
4. **Maven/Gradle支持**：方便使用发布的jar包

该软件库包含了多年机器人研究积累的高质量算法，为人形机器人和 legged 机器人研究提供了很好的基础。
