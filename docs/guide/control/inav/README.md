# inav

- 项目链接：https://github.com/iNavFlight/inav

## 项目概述

INAV 是一款功能强大的开源飞行控制器固件，专注于导航功能，支持多旋翼、固定翼、滑翔机、 rover、船等多种无人机和航模设备。

INAV 支持目前最流行的 F4、AT32、F7 和 H7 飞控，提供开箱即用的出色性能。主要功能特性：

- **导航功能**：支持位置保持、高度保持、返航和航点任务
- **固定翼支持**：对固定翼飞机和飞翼提供出色支持
- **传感器支持**：GPS、皮托管、声纳、激光雷达、温度、BlHeli_32 电调遥测等多种传感器
- **OSD 支持**：支持字符和像素两种 OSD 模式，集成 DJI OSD，显示所有元素、系统消息和警告
- **可编程**：支持逻辑条件、全局函数和全局变量，可以通过 GUI 对 INAV 进行编程
- **VTX 支持**：支持 SmartAudio 和 IRC Tramp
- **遥测支持**：支持 SmartPort、FPort、MAVlink、LTM、CRSF 等多种遥测协议
- **RGB LED 灯带支持**：支持多色 RGB LED 灯带
- **黑盒记录**：支持黑盒飞行数据记录，便于事后分析

INAV 提供完整的工具链：
- INAV Configurator：官方桌面配置应用，支持 Windows、macOS、Linux
- INAV Blackbox Explorer：黑盒日志分析工具
- 黑盒命令行工具：用于黑盒日志转换和分析
- 支持 EdgeTX/OpenTX 遥测界面

项目社区活跃，提供完整的文档和教程，包括固定翼指南、自动弹射指南、模式指南、机翼调优等PDF文档，还有 YouTube 视频教程。最新版本是 9.0.1，持续更新维护。
