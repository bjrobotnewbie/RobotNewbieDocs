# madflight

- 项目链接：https://github.com/qqqlab/madflight
- 项目主页：https://madflight.com

## 项目概述
madflight是一个工具包，用于使用Arduino IDE或PlatformIO为ESP32-S3、ESP32、RP2350、RP2040和STM32等开发板构建高性能飞行控制器。核心特点包括：
1. 支持多种主流微控制器开发板，降低硬件成本
2. 提供仅几百行代码的示例程序，包含完整的飞行控制器逻辑
3. 底层传感器和IO管理由madflight库处理，简化开发流程
4. 提供详细的文档和入门指南，方便快速上手
5. 包含四轴飞行器和飞机的飞行测试示例代码

该项目适合DIY飞行控制器开发，用户可以使用低成本的现成开发板搭建自己的飞行控制系统。
