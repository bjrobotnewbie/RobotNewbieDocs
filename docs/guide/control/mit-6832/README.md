# MIT 6.832 Underactuated Robotics（Spring 2022）
这门课程聚焦欠驱动机械系统的非线性动力学与控制，以计算方法为主要方向，帮助机器人实现行走、奔跑、游泳、飞行与精细操作等灵活高效的动态行为，由Russ Tedrake教授主讲，属于MIT研究生级别课程。

## 课程定位与背景
当前机器人运动普遍偏保守，依赖全程保持完整控制权限的控制系统；而生物运动更具爆发力，常出现瞬时控制权限下降的情况。课程围绕**不具备完整控制权限的非线性系统**展开，引导学习者理解并利用机械自身动力学特性，突破传统控制思路局限。

## 主要内容与覆盖方向
- 讲解机器人操作臂的非线性动力学建模方法
- 介绍最优控制、鲁棒控制在欠驱动场景的应用
- 覆盖面向动态系统的运动规划算法
- 结合生物运动案例，落地到足式移动、柔性操作、水下机器人、飞行器等场景

## 先修要求
- 基础线性代数与微分方程知识
- 具备Python编程能力，可完成算法实现与仿真验证
