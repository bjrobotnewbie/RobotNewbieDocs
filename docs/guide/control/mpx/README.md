## 项目概述

## 项目介绍
mpx是一个基于JAX的模型预测控制（MPC）与轨迹优化库，专为腿式机器人开发。它支持在GPU上实现并行计算，可集成到学习流水线中，提供了多种腿式机器人的控制示例，包括Talos、H1、Aliengo、Go2等。

## 主要特性
1.  **True GPU并行计算**：支持时域与状态空间并行扫描，将复杂度从经典的$\mathcal{O}(N(n + m)^3)$降低至$\mathcal{O}(\log^2{n}\log{N} + \log^2{m})$，无需近似或离线预计算。
2.  **支持JAX自动微分与向量化**：求解器完全可微，可轻松集成到RL类学习 pipeline 中，支持批量环境运行。
3.  **多射击SQP配方**：并行求解KKT系统，保证求解精确性与快速收敛性。
4.  **兼容MJX模型**：支持MJX全身体动力学，提供多款腿式机器人的官方示例。
5.  提供两种求解器切换：Primal-dual LQR与GPU-FDDP，可通过配置文件修改`solver_mode`切换。
6.  支持多环境并行MPC运行，提供通用与简化刚体动力学两种控制器封装类。
