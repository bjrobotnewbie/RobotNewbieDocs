# panda-py

Python 绑定，用于实时控制 Franka Emika 机器人。

## 项目链接

- GitHub: <https://github.com/JeanElsner/panda-py>
- 项目主页: <https://jeanelsner.github.io/panda-py/>

## 项目概述

## 项目介绍
panda-py 是一款针对Franka Emika（Panda）机器人的Python绑定库，用于实现机器人实时控制，可帮助开发者提升开发效率。项目提供了官方文档、示例教程与Jupyter Notebook案例，支持直接在机器人上运行测试，还附带了带有ROS 2封装的Franka Desk REST API客户端扩展。可通过PyPI快速安装，适配FER和FR3两款Franka机器人，需根据机器人固件版本匹配对应libfranka版本。

## 主要特性
1.  提供Franka Emika机器人的Python实时控制接口，简化开发流程
2.  附带官方文档、教程案例与可直接运行的示例代码
3.  支持ROS 2封装的Franka Desk REST API扩展
4.  可通过PyPI快速安装，默认搭载libfranka 0.9.2，支持自定义版本适配不同机器人固件
5.  兼容Franka Emika Robot（FER）与Franka Research 3（FR3）两款机器人型号
