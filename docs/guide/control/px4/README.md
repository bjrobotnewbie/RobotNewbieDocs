## 简介
PX4是一个开源的自动驾驶软件栈，主要用于无人机和地面机器人，提供可靠的飞行控制和导航功能，拥有活跃的开发者社区和广泛的硬件支持。

## 项目链接
- GitHub仓库: https://github.com/PX4/PX4-Autopilot

## 主要特性
- 支持多种无人机和地面机器人平台
- 实时飞行控制和导航
- 广泛的传感器和执行器支持
- 活跃的社区和文档资源
