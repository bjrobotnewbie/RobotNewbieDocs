# vlsa-aegis

一种名为 AEGIS 的视觉 - 语言 - 安全行动架构，其中包含一个基于控制屏障函数的可插拔安全约束层。

## 项目链接

- GitHub: <https://github.com/THU-RCSCT/vlsa-aegis>
- 项目主页: <https://arxiv.org/pdf/2512.11891>

## 项目介绍
vlsa-aegis（全称Vision-Language-Safety Action Architecture）是一款视觉-语言-动作架构，核心为名为AEGIS的可插拔安全约束层，基于控制障碍函数实现，用于保障机器人动作执行的安全性，可应用于机器人操作任务场景，解决现有视觉-语言动作模型在任务执行中存在的安全风险问题。

## 主要特性
- 提供可插拔的安全约束层，无需对原有视觉-语言动作模型进行大幅修改即可集成使用
- 能在完成机器人操作任务（如将杯子放入碗中、将苹果放入篮子）的同时，保障动作执行的安全性，避免传统基线模型出现的安全违规问题
- 配套相关研究成果已发布arXiv论文，提供项目页面及Hugging Face数据集支持
