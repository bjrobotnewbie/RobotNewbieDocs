## 项目概述

## 项目介绍
本项目是一款针对人形机器人运动操作规划与控制的全身体非线性模型预测控制器（NMPC），基于扩展更新版的ocs2框架，可实时优化全扭矩级动力学模型，生成多样化人形机器人行为。支持通过游戏杆进行速度和基座高度交互控制，适配Unitree G1等硬件平台，后续还将支持1X Neo机器人。

## 主要特性
1.  **两种MPC控制方案**：
    - 质心动力学MPC：基于全身体运动学和质心动力学优化，支持单刚体模型或完整质心动力学模型，可配置6自由度接触相关成本与约束
    - 全身体动力学MPC：针对接触力和关节加速度优化，可计算规划 horizon 内的关节扭矩
2.  硬件无关性，支持多个人形机器人平台
3.  支持Docker化和本地两种部署方式，可通过Colcon工作区快速搭建开发环境
