# DroneDB

用于地理空间数据存储的自由开源软件。

## 项目链接

- GitHub: <https://github.com/DroneDB/DroneDB>
- 项目主页: https://dronedb.app

## 项目概述

## 项目介绍
DroneDB是一款免费开源的现代化地理空间数据管理平台，支持云端存储、可视化与分享地理空间数据，可处理正射影像、点云、3D模型、地理标记文件等多种类型数据，提供了Web端演示站点。项目采用MPL 2.0开源协议，支持Windows和Linux跨平台运行。

## 主要特性
1.  **智能索引**：自动提取图像EXIF、栅格数据(GDAL)、点云(PDAL)和矢量文件的元数据
2.  **交互式可视化**：基于Web的正射影像、3D点云、纹理模型、360°全景查看器
3.  **地理空间分析**：支持飞行路径可视化、元数据提取、数据集分区和STAC目录
4.  **多样分享方式**：提供直接链接、嵌入代码、TMS瓦片、COG、EPT瓦片等分享选项
5.  **云同步协作**：可与DroneDB Hub同步数据集实现团队协作
6.  **格式支持广泛**：覆盖栅格、点云、3D模型、矢量文件、视频、360全景等数十种格式
7.  **跨平台兼容**：支持Windows和Linux系统
