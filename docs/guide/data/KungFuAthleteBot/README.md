数据集：https://huggingface.co/datasets/LuluCao/KungfuAthleteBot

## 项目概述
KungFuAthleteBot是一个专为人形机器人设计的功夫运动数据集，其核心内容包括：
1. 数据集来源于运动员的日常武术训练视频，总计197个视频片段，经过自动时间分割得到1726个子片段
2. 使用GVHMR进行运动捕捉，结合基于GMR的重定向技术，处理得到848个运动样本
3. 涵盖日常训练活动等多种功夫动作，经过多轮人工筛选和样本细化，保证数据质量
4. 提供项目主页、论文、视频演示（包括YouTube和Bilibili）以及完整的数据集下载链接
5. 支持人形机器人的运动模仿和技能学习研究

该数据集为功夫动作在人形机器人上的迁移提供了丰富的训练数据，推动了机器人运动模仿领域的发展。
