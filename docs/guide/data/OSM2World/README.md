# OSM2World

将 OpenStreetMap 数据转换为三维世界模型的转换器

## 项目链接

- GitHub: <https://github.com/tordanik/OSM2World>
- 项目主页: <http://osm2world.org/>

## 项目介绍
OSM2World是一款开源转换器，可以基于OpenStreetMap数据生成多种格式的三维世界模型，项目官网提供了文档、下载资源、示例截图与联系方式。

## 主要特性
1.  核心功能为将OpenStreetMap数据转换为三维世界模型，支持多种输出格式
2.  开源可自由使用部署，可通过`mvn package`在项目根目录完成编译打包。
