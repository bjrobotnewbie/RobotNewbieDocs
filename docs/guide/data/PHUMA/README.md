## 项目概述
PHUMA是一个物理可靠的人形机器人运动数据集，其核心特点包括：
1. 基于大规模人类运动数据，通过精心的数据整理和物理约束的重定向技术生成高质量的人形机器人运动数据
2. 支持人形机器人的步态学习、运动模仿和策略训练等研究场景
3. 被NVIDIA的ProtoMotions原生支持，可直接用于训练人形机器人策略
4. 提供简单快捷的下载和安装脚本，方便研究人员快速获取数据集
5. 包含详细的文档和使用指南，支持Python 3.9及以上版本

该数据集为人形机器人的运动学习提供了高质量的训练数据，推动了人形机器人运动控制领域的发展。
