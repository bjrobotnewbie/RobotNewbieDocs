# 机器人数据

机器人数据是机器人学习和智能决策的基础，包括数据集、传感器数据、训练数据等。本章节涵盖机器人领域常见的数据集和数据处理技术。

## 分类列表

- [Benchmark Data](./benchmark_data/README.md)：标准基准数据集，用于算法对比和模型评估
- [Datasets](./datasets/README.md)：各类机器人数据集，用于机器人学习和模型训练
- [数据采集](./data-collection/README.md)：动作捕捉系统、遥操作采集等数据采集技术

## 分类说明

| 分类 | 核心内容 | 应用场景 |
|------|---------|---------|
| **Benchmark Data** | 标准基准数据集 | 算法对比，模型评估 |
| **Datasets** | 各类机器人数据集 | 机器人学习，模型训练 |
| **数据采集** | 动作捕捉、遥操作采集 | 构建演示数据集，模仿学习 |

## 数据在机器人学习中的重要性

高质量数据是机器人学习的基础：

- **模仿学习**：需要高质量的人类演示数据
- **强化学习**：需要大规模交互数据
- **仿真到现实**：准确采集帮助降低域差距
- **泛化能力**：多样化数据提升模型鲁棒性
