## 项目概述

## 项目介绍
Bagel是一款面向物理世界数据的自然语言交互工具，被称为"实体界的ChatGPT"，支持与机器人、无人机、IoT等领域的数据集对话。用户无需专业领域知识，即可通过自然语言查询物理设备产生的数据，例如查询IMU传感器是否过热。它兼容Docker部署，无需额外本地依赖，支持跨多种数据源进行自然语言分析。

## 主要特性
1.  **自然语言交互**：使用日常口语提问，无需专业编程或SQL知识
2.  **透明可追溯**：基于确定性SQL查询实现，无黑箱LLM逻辑，可预览执行流水线
3.  **多LLM兼容**：支持Claude Code、Gemini、Cursor、Codex等多款大模型
4.  **广泛格式支持**：覆盖ROS1/ROS2、MCAP、PX4/ArduPilot、MQTT、TimescaleDB等数十种机器人、无人机、IoT和车载数据格式
5.  **可扩展能力**：支持自定义新增功能，支持单机、集群或边缘部署
6.  **兼容现有工具**：不替代现有数据处理工具，而是简化复杂查询流程，可将结果导出至PlotJuggler等平台
