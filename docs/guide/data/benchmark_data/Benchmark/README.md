## 项目介绍
AnyVisLoc是首个针对低空多视角观测条件下无人机（UAV）视觉定位的大规模基准测试集，适配2.5D航拍与卫星参考地图，遵循“图像检索→图像匹配→透视n点（PnP）定位”的统一框架，相关论文已被CVPR 2026 Findings收录，完整数据集与升级后的测试代码现已公开。

## 主要特性
1. 针对低空多视角UAV视觉定位场景设计，填补该领域大规模基准的空白；
2. 提供标准化的基准测试流程，支持自定义数据集与视觉定位方法的测试；
3. 配套完整的数据集下载渠道（百度网盘、OneDrive），包含UAV图像示例、参考地图示例等内容，可用于验证各类视觉定位算法的性能。
