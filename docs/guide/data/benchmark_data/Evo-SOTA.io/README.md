# Evo-SOTA.io

本网站用于收集 VLA 领域最先进（SOTA）的研究成果。

## 项目链接

- GitHub: <https://github.com/MINT-SJTU/Evo-SOTA.io>

## 项目介绍
本项目是VLA与灵巧操作领域的前沿技术（SOTA）排行榜网站，用于收集并展示视觉语言动作（VLA）模型和灵巧操作模型在对应机器人基准测试中的最新性能表现，已部署为公开在线站点。

## 主要特性
1.  **覆盖多类基准测试**：收录了LIBERO、LIBERO Plus、Meta-World、CALVIN等8个VLA模型评测基准，以及Adroit、DexArt、Bi-DexHands共3个灵巧操作评测基准
2.  **标准化性能展示**：每个基准对应专属的核心评测指标，如平均成功率、完成任务数等，统一呈现模型性能排名
3.  **自动部署更新**：通过GitHub Actions实现站点自动部署更新，保障数据时效性。
