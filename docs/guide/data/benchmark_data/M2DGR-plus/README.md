## 项目链接

- GitHub: <https://github.com/SJTU-ViSYS/M2DGR-plus>

## 项目介绍
M2DGR-plus是ICRA2022、ICRA2024论文成果M2DGR数据集的扩展与更新版本，属于面向地面机器人的多模态、多场景SLAM数据集，配套算法为Ground-Fusion，遵循GPL-3.0开源协议，仅用于学术研究，商业用途需联系作者。

## 主要特性
1. 基于原M2DGR数据集扩展更新，适配多场景地面机器人SLAM研究
2. 配套发布M2DGR-benchmark，可用于测试最新LiDAR-visual SLAM算法性能
3. 关联资源库包含LiDAR-Visual SLAM、轮式SLAM、Isaac Sim相关工具列表，持续更新中
