# M3DGR

M3DGR：面向地面机器人的多传感器、多场景及大规模基线 SLAM 数据集（IROS 2025）

## 项目链接

- GitHub: <https://github.com/sjtuyinjie/M3DGR>

## 项目介绍
本项目是IROS 2025收录的面向地面机器人的多传感器、多场景、大基线SLAM数据集M3DGR，同时配套了对应的鲁棒传感器融合SLAM解决方案。项目旨在为前沿SLAM算法提供全面基准测试，包含官方论文、数据集、基准测试代码以及配套的Ground-Fusion2模块化SLAM框架，可用于地面机器人在复杂退化环境下的定位与建图。

## 主要特性
1.  **多传感器基准数据集**：支持多传感器融合SLAM测试，包含多场景与系统性退化环境数据，支持大基线场景测试
2.  **模块化SLAM框架**：Ground-Fusion2框架可集成异构传感器，支持鲁棒定位与高质量建图
3.  **全面算法评测**：已完成超过40种前沿SLAM方法的基准测试，可直接复用评测流程
4.  配套更新了Ultra-Fusion融合系统，统一支持WIO、VIO、LIO、LVIO，可配置优化框架，支持轮式/GNSS融合与在线标定
