# PerceptionBench

感知基准：评估多模态大语言模型中的原子视觉感知

## 项目链接

- GitHub: <https://github.com/MoonshotAI/PerceptionBench>

## 项目概述

## 项目介绍
PerceptionBench是专为评估多模态大语言模型（MLLMs）的原子视觉感知能力打造的基准测试集。当前主流基准测试要么无法隔离感知能力，将感知错误与推理、知识错误混淆，要么仅覆盖窄碎片化领域。本项目通过分析42个现有基准中前沿MLLMs的早期失败点，构建包含10项原子感知能力的错误分类体系，据此打造了3000道经过验证的测试题，每道题仅考察单一感知能力，难度来自感知而非推理或知识。

## 主要特性
1.  **测试集规模**：包含3000道验证问题，覆盖10项原子感知能力，其中60%来自现有基准的失败子问题拆分，40%为新增题目，样本池超17000条。
2.  **评估标准**：采用统一提示词对16款前沿MLLMs（10款闭源、6款开源）进行测试，使用GPT-oss-120B作为自动评判工具，其与人工标注一致性达99.7%，以准确率作为评分指标。
3.  **核心发现**：当前所有模型准确率均未超过60%，感知相关幻觉是平均表现最弱的能力，且整体得分掩盖了模型在细分感知能力上的巨大差异，可用于精准诊断MLLMs的视觉感知边界。
