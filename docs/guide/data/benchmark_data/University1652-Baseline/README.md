# University1652-Baseline

ACM Multimedia 2020 University-1652：一个基于无人机的地理定位多视角多源基准数据集 :helicopter:，该数据集标注了全球72所大学中的1652座建筑。

## 项目概述

## 项目介绍
本项目是ACM MM 2020论文**University-1652: A Multi-view Multi-source Benchmark for Drone-based Geo-localization**的官方基线代码与数据集仓库。该数据集收录了全球72所大学的1652栋建筑的多视角多源数据，包含无人机视角、卫星视角、地面街景三种视图数据，可用于无人机地理定位相关研究。项目提供数据集申请通道、基线代码以及多种资源链接，包括论文、演示视频、中文介绍文档等。

## 主要特性
1.  **多视图任务支持**：核心任务为无人机视角到卫星视角的目标定位，可通过无人机图像/视频匹配相似卫星图像以实现建筑地理定位
2.  多源数据覆盖：包含无人机、卫星、地面街景三类视图数据
3.  高引用量基准：该数据集相关研究引用量已超500次，是无人机地理定位领域的经典基准数据集
4.  配套资源完整：提供数据集下载申请、基线代码、数据样例、论文与演讲幻灯片等完整研究支持资源
