## 概述

CALVIN (Composing Actions from Language and Vision) 是一个语言条件的机器人操作任务基准，专注于评估机器人在自然语言指令下的长期操作能力。它结合了多模态输入（视觉和语言）和长视野任务规划，要求机器人能够理解复杂的语言指令并执行多步操作序列。

该基准包含多个需要长时间 horizon 才能完成的任务，如“拿起红色的方块放到蓝色容器里，然后关闭抽屉”。CALVIN 强调语言 grounding、多模态感知融合以及长程任务分解与执行的能力，适合研究语言到动作的映射、任务规划和记忆机制。
