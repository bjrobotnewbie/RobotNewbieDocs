# FluxBisim

FluxBisim 是 FluxVLA 生态系统中的一个基准测试项目，专注于机器人学习中的双模拟（Bisimulation）相关研究和评测。作为一个基准数据集/测试框架，为机器人视觉-语言-动作模型提供标准化的评测基准。

## 项目特点

- 隶属于 FluxVLA 开源生态系统
- 提供标准化的基准测试环境
- 支持双模拟方法在机器人策略学习中的评测
- 与 FluxVLA 框架无缝集成
