# lamaria

城市尺度视觉 - 惯性 SLAM 基准测试（ICCV 2025）。

## 项目链接

- GitHub: <https://github.com/cvg/lamaria>
- 项目主页: <https://www.lamaria.ethz.ch/>

## 项目介绍
LaMAria是一个ICCV 2025收录的城市规模第一视角视觉惯性SLAM基准测试数据集，由苏黎世联邦理工学院等机构联合发布。数据集包含约22小时、70公里的轨迹数据，附带测量级控制点提供厘米级精度的真值。它支持在真实复杂场景（弱光、移动平台、曝光变化、传感器校准时变）下评估SLAM系统，提供23个训练序列和63个测试序列。

## 主要特性
1.  城市规模的第一视角视觉惯性SLAM基准数据集，拥有厘米级高精度真值
2.  覆盖真实复杂户外场景，可测试SLAM系统在多种现实挑战下的表现
3.  提供官方下载脚本与数据转换、评估工具，支持将VRS格式转换为ASL/ROSbag格式，可基于控制点、伪真值、EVO工具进行多维度评测
4.  配套提供示例视觉惯性优化代码，方便快速上手测试
