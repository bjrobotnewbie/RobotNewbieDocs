## 项目介绍
the_well是一个由PolymathicAI开发的大规模机器学习数据集项目，核心为15TB的时空物理系统数值模拟数据，涵盖生物系统、流体动力学、声学散射、磁流体动力学、超新星爆炸等16类领域，可单独使用或作为基准套件，用于推动机器学习与计算科学研究。项目支持通过PyPI安装，提供Python接口，可结合PyTorch等框架构建数据加载流程，相关成果已发表于NeurIPS 2024，数据集也可在Hugging Face获取。

## 主要特性
1. 数据规模大：15TB多领域物理模拟数据，覆盖跨学科物理场景；
2. 易用性强：提供Python包与API，支持直接从PyPI安装，可快速集成至训练流程；
3. 多场景适配：可作为独立数据集或基准套件，适配机器学习模型的训练与评估需求；
4. 资源支持：配套官方文档、教程，提供详细使用指引。
