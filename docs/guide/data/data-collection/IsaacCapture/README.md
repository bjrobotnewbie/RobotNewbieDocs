# IsaacCapture

机器人遥操作的统一框架

## 项目链接

- GitHub: <https://github.com/NVIDIA/IsaacCapture>
- 项目主页: <https://nvidia.github.io/IsaacCapture/>

## 项目介绍
Isaac Teleop（项目名IsaacCapture）是一套用于采集高保真自我中心视角与机器人数据的统一框架，旨在解决机器人学习中的数据瓶颈问题，通过简化设备集成、标准化高保真人类演示数据采集，推动设备与数据的互操作性，支持仿真与真实机器人遥操作场景。

## 主要特性
- 支持仿真与真实机器人遥操作的统一技术栈
- 提供标准化设备接口
- 具备灵活的重定向框架
- 支持XR头显操控夹爪/三指手、XR头显搭配手套操控灵巧手、坐姿全身移动操作、基于GR00T-WholeBodyControl的全身移动操作等场景，还计划支持非XR设备遥操作、云端机器人仿真遥操作、带桌面/XR头显沉浸式相机流的远程遥操作等功能
- 依赖Python 3.11+、Isaac Lab 3.0.0+等技术栈，遵循Apache 2.0许可，可参考官方文档完成安装与使用。
