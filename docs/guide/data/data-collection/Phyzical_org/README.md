# Phyzical_org

基于 Web 的具身智能操作数据——elizaOS 就绪的回合、轨迹数据库转换器、链上可追溯性。为智能体机器人堆栈提供的燃料站。

## 项目链接

- GitHub: <https://github.com/Phyzicalorg/Phyzical_org>
- 项目主页: <https://phyzical.org>

## 项目介绍
phyzical是一款基于浏览器的机器人遥操作数据平台，专为elizaOS打造，是智能体机器人栈的数据源补给站。用户无需硬件基础和专业知识，仅通过浏览器即可像游玩3D网页游戏一样，通过鼠标拖拽机械臂末端执行器，借助逆运动学控制仿真机械臂，平台会以30-60Hz的频率记录关节位置、末端姿态、物体姿态、动作指令等轨迹数据，同时将数据来源（数据ID、内容哈希、贡献者）锚定在链上，为视觉语言动作（VLA）、模仿学习训练提供高质量人类演示数据。

## 主要特性
1.  零门槛数据采集：仅需浏览器即可完成机器人演示数据录制，无需实体机器人和专业技能
2.  标准化数据输出：生成符合elizaOS要求的轨迹数据，可直接兼容其`trajectory_db`格式
3.  链上数据溯源：为每条演示数据提供不可篡改的来源证明
4.  适配elizaOS生态：专为elizaOS机器人栈设计，填补其缺少大规模人类演示数据的短板
