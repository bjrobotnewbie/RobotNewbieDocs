# Teleopit

- 项目链接：https://github.com/BotRunner64/Teleopit
- 项目主页：https://botrunner64.github.io/Teleopit/

## 项目概述

Teleopit是**为人形机器人设计的轻量级可扩展全身远程操作框架**。主要特点包括：

1. **支持多种输入**：支持从BVH运动数据和Pico 4 VR进行实时运动重定向到Unitree G1机器人
2. **支持多种环境**：可以在MuJoCo仿真中运行，也可以部署到真实硬件
3. **完整教程**：提供Pico Sim2Sim、Pico Sim2Real、训练等完整教程，还有中文文档
4. **轻量级可扩展**：架构轻量，便于扩展支持不同硬件和场景

该框架让人形机器人远程操作变得简单易用，降低了研究门槛，支持从仿真到实物的快速迁移。
