## 项目概述

## 项目介绍
UMI-3D是一套完整的端到端SLAM与数据处理流水线，可将原始rosbag录制文件转换为可直接用于具身操纵学习的训练数据集。项目包含硬件、SLAM处理、策略训练三大子模块，支持从数据采集到模型训练的全流程工作流，可处理激光雷达点云、IMU、相机图像等多传感器数据。

## 主要特性
1.  完整流程：支持从rosbag原始数据到Zarr格式训练数据集的全链路处理，涵盖标定、SLAM、数据对齐与数据集生成
2.  多传感器支持：可处理LiDAR、IMU、相机采集的机器人操作数据
3.  适配主流训练框架：生成的Zarr数据集可直接用于Diffusion Policy等RL训练任务
4.  配套完整生态：提供硬件设计、传感器标定、策略训练部署的全套解决方案
