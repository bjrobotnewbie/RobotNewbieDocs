# DexCap - 灵巧操作可扩展便携式动作捕捉

## 项目简介

DexCap 是一个可扩展、便携式的灵巧操作动作捕捉数据采集系统，官方标题为"Scalable and Portable Mocap Data Collection System for Dexterous Manipulation"。由斯坦福大学李飞飞团队开发，专注于人手灵巧操作数据采集。

## 官方链接

* 项目主页：<https://dex-cap.github.io/>
* GitHub代码：<https://github.com/j96w/DexCap>
* 数据集：<https://huggingface.co/datasets/chenwangj/DexCap-Data>

## 主要特点

* **可扩展**：支持大规模数据采集
* **便携式**：硬件设计便于携带和部署
* **灵巧操作专用**：专为手部灵巧操作设计
* **完整数据集**：已公开 DexCap-Data 数据集

## 核心技术

* 多相机手部动作捕捉
* 便携式硬件设计
* 标准化数据采集流程
* 可直接用于模仿学习
