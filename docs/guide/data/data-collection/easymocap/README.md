# EasyMocap - 简易人体动作捕捉

## 项目简介

EasyMocap 是浙江大学 3DV 实验室开发的开源人体动作捕捉项目，专注于让人体动作捕捉更易于使用。GitHub 仓库由 zju3dv 维护。

## 官方链接

* GitHub仓库：<https://github.com/zju3dv/EasyMocap>

## 主要特点

* **开源易用**：开源项目，易于使用和部署
* **多人动作捕捉**：支持多人同时动作捕捉
* **基于视觉**：基于计算机视觉的方法
* **活跃维护**：持续开发更新

## 核心功能

* 单/多人人体姿势估计
* 人体动作捕捉
* 三维重建
* 相机标定
