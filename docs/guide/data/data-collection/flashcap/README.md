# FlashCap - 毫秒级精准人体动作捕捉

## 项目简介

FlashCap 是一种基于闪烁LED和事件相机的毫秒级精准人体动作捕捉方法，官方项目页面描述为"Millisecond-Accurate Human Motion Capture via Flashing LEDs and Event-Based Vision"。

## 官方链接

* 项目主页：<http://www.lidarhumanmotion.net/flashcap/>

## 主要特点

* **毫秒级精度**：实现毫秒级准确动作捕捉
* **LED闪烁调制**：利用LED闪烁进行编码
* **事件相机**：结合事件相机提高时间分辨率
* **创新方法**：不同于传统视觉动作捕捉的新方案

## 核心技术

* Flashing LEDs 调制编码
* Event-Based Vision 事件相机
* 高精度时间同步
* 人体姿态重建
