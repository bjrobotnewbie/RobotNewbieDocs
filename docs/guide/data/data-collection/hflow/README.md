# hflow

开源 SDK，用于构建机器人和物理 AI 的数据质量、处理、增强和策展管道。

## 项目链接

- GitHub: <https://github.com/Hebbian-Robotics/hflow>
- 项目主页: <https://hebbianrobotics.com>

## 项目介绍
HFlow是Hebbian Robotics（YC S26）推出的开源SDK，面向机器人与物理AI领域，用于构建可扩展的多模态数据流水线。它将大型机器人数据团队专属的生产级数据工具与实践普及化，支持用户接入现有Python转换、质量检查、标注与增强逻辑，自动处理流程编排、存储、版本管理与数据整理工作。

该工具支持为每个处理的数据片段添加溯源信息，可将流水线渲染为可视化图谱，并将元数据与质量证据存入可查询的目录，支持回溯输出生成过程、监控全流程与无需加载原始录制文件即可调研数据集。其输入输出边界采用MCAP格式，可兼容来自人类佩戴相机、遥操作机器人、自主策略等多种来源的多模态时序数据。当前处于pre-v1阶段，核心生命周期已实现端到端可用。

## 主要特性
1.  开箱即用的生产级机器人数据流水线工具，降低开发门槛
2.  支持自定义Python数据处理、质检、标注与增强逻辑
3.  内置流程编排、存储、版本管理与数据整理能力
4.  提供数据溯源、流程可视化与可查询元数据目录
5.  兼容MCAP标准格式，支持多模态时序数据接入
