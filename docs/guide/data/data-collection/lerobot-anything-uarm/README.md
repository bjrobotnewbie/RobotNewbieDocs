# LeRobot-Anything-U-Arm - 跨形态遥操作

## 资源简介

LeRobot-Anything-U-Arm 是上海交通大学 MINT 实验室开发的项目，实现了基于 LeRobot 的跨具身遥操作。项目名称为"U-Arm: Lerobot-Everything-Cross-Embodiment-Teleoperation"。

## 官方链接

* GitHub仓库：<https://github.com/MINT-SJTU/LeRobot-Anything-U-Arm>

## 主要特点

* **LeRobot 生态集成**：与 Hugging Face LeRobot 框架深度集成
* **跨形态遥操作**：支持不同机器人形态之间的遥操作
* **演示数据采集**：专为模仿学习数据采集设计
* **开源社区**：活跃的开发和维护
