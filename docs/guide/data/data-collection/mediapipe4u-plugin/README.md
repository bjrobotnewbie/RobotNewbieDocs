## 项目简介

Mediapipe4u-plugin 是基于 Google MediaPipe 的动作捕捉插件，提供中文说明文档，方便中文用户使用。

## 官方链接

* README中文文档：<https://github.com/endink/Mediapipe4u-plugin/blob/main/README_CN.md>
* GitHub仓库：<https://github.com/endink/Mediapipe4u-plugin>

## 主要特点

* **基于MediaPipe**：利用Google MediaPipe 现成解决方案
* **中文文档**：提供中文说明文档
* **插件化**：方便集成和使用
* **轻量级**：不需要昂贵硬件

## 核心功能

* 人体姿态估计
* 手部关键点检测
* 动作捕捉
* 实时姿态估计
