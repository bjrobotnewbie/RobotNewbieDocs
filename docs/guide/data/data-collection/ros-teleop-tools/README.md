# teleop_tools - ROS通用遥操作工具

## 资源简介

teleop_tools 是 ros-teleop 组织维护的一套通用遥操作工具集合，为任意机器人提供一套通用遥操作工具。自2013年开始维护，是 ROS 生态中最经典的遥操作工具包。

## 官方链接

* GitHub仓库：<https://github.com/ros-teleop/teleop_tools>

## 主要特点

* **通用工具集**：一套通用遥操作工具适用于任意机器人
* **ROS生态集成**：完美融入 ROS 生态系统
* **多种输入设备**：支持键盘、游戏手柄等多种输入
* **长期维护**：自2013年持续维护至今
* **社区广泛使用**：被大量ROS项目使用

## 包含的工具

* **joy_teleop**：游戏手柄遥操作
* **key_teleop**：键盘遥操作
* **teleop_tools**：通用工具库
