# XR Teleoperate - Unitree人形遥操作

## 资源简介

xr_teleoperate 是 Unitree Robotics 开发的开源项目，实现了使用 XR 设备对 Unitree 人形机器人进行遥操作。项目拥有 1488+ stars，是目前最受欢迎的人形机器人遥操作项目之一。

## 官方链接

* GitHub仓库：<https://github.com/unitreerobotics/xr_teleoperate>

## 主要特点

* **XR设备支持**：支持虚拟现实设备进行人形机器人遥操作
* **Unitree人形机器人**：专为 Unitree G1、H1 等人形机器人设计
* **运动重定位**：将人体运动映射到机器人关节空间
* **实时遥操作**：低延迟远程控制
* **开源社区活跃**：持续更新维护
