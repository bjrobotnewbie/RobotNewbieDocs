## 项目简介

XRMoCap 是 OpenXRLab 推出的动作捕捉项目，由 openxrlab 组织维护，提供开源动作捕捉工具链。

## 官方链接

* GitHub仓库：<https://github.com/openxrlab/xrmocap>

## 主要特点

* **OpenXRLab 生态**：属于 OpenXRLab 项目生态
* **开源工具链**：完整开源动作捕捉工具
* **模块化设计**：便于扩展和定制
* **社区维护**：活跃的社区开发

## 核心功能

* 多视图动作捕捉
* 三维人体重建
* 数据预处理工具
* 姿势估计
