# AgriLiRa4D

AgriLiRa4D: 面向复杂农业环境的多传感器无人机 SLAM 数据集

## 项目链接

- GitHub: <https://github.com/zhan994/AgriLiRa4D>
- 项目主页: <https://zhan994.github.io/AgriLiRa4D/>

## 项目介绍
AgriLiRa4D是一款面向复杂农田场景的多传感器无人机数据集，专为提升挑战性农业环境下的SLAM鲁棒性而设计。该数据集可用于训练、测试农业无人机的定位与建图算法，相关资源包含项目官网、论文以及Hugging Face数据集仓库。

## 主要特性
1.  **多传感器配置**：搭载多类传感器采集农田场景数据，适配主流机器人感知算法
2.  **复杂农田场景适配**：针对农田特有的地形、作物、光照变化等挑战场景采集数据
3.  支持ROS生态，可直接用于SLAM、RL相关的机器人算法研发与验证
4.  提供完整的数据集下载渠道与配套技术文档，方便开发者快速上手。
