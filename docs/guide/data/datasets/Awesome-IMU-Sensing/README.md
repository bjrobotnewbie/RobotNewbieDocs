# Awesome-IMU-Sensing

## 项目概述

## 项目介绍
本项目是面向可泛化人体活动识别（HAR）与IMU传感的数据集、论文及资源汇总仓库，依托论文《Towards Generalizable Human Activity Recognition: A Survey》搭建，梳理了大量基于IMU的HAR相关研究资源。

## 主要特性
1.  **研究趋势梳理**：统计了近十年IMU-based HAR领域的年度发文量增长情况，以及针对领域偏移、数据异构问题的泛化学习研究近年的爆发式增长。
2.  **完整资源目录**：
    -  涵盖泛化训练场景：组内、跨人、跨设备、跨传感器位置、跨活动、跨数据集
    -  收录IMU单模态、多模态数据集，数据整理工具与基准测试方案
    -  按范式分类的模型-centric方法：监督学习（域不变、多任务、联邦学习）、弱监督/半监督/主动学习、无监督学习、自监督学习、大模型辅助学习
    -  包含数据-centric研究方法论
3.  可通过引用对应论文获取该资源汇总的详细说明。
