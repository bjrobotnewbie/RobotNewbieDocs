# DroneAudioDataset

## 项目链接

- GitHub: <https://github.com/saraalemadi/DroneAudioDataset>

## 项目介绍
DroneAudioDataset是一个无人机音频数据集，包含室内环境下录制的无人机螺旋桨噪声，还通过添加随机噪声片段进行了人工增强，是论文《Audio Based Drone Detection and Identification using Deep Learning》的配套数据集，仅用于教育和非商业学术研究。

## 主要特性
1. 数据集分为二分类和多分类文件夹，其中“未知”类噪声片段来自ESC-50环境声音分类数据集，白噪声来自Speech Commands数据集，还补充了自制静音片段以平衡数据集；
2. 明确限制禁止用于军事、国防等相关用途，商业使用需获得版权方书面许可；
3. 包含第三方数据集材料，需遵守对应数据集的许可条款；
4. 使用时需引用指定的会议论文。
