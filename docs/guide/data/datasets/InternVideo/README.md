## 项目概述

## 项目介绍
InternVideo是面向多模态视频理解的视频基础模型系列项目，收录了InternVideo全系列相关研究与配套数据集，涵盖通用视频基础模型、大规模多模态视频理解模型、长上下文视频多模态大模型、长时序智能体推理模型以及真实世界通用视频理解模型等方向，同时提供了配套的大规模视频文本数据集InternVid。

## 主要特性
1.  完整的视频基础模型产品线：包含InternVideo、InternVideo2、InternVideo2.5、InternVideo3、InternVideo-Next多个迭代版本，覆盖从基础单模态到多模态长上下文、智能体推理的全场景视频理解需求
2.  配套大规模数据集：提供InternVid全量2.3亿视频文本对标注数据集，支撑多模态视频理解与生成模型训练
3.  持续更新的模型与资源：陆续发布各版本模型权重、技术报告、训练与推理脚本，部分版本附带视频智能体实现方案，所有资源可通过HuggingFace获取。
