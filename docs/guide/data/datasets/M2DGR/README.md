## 项目概述

## 项目介绍
M2DGR是一款面向地面机器人的多模态多场景SLAM数据集，入选RA-L2021与ICRA2022。该数据集可用于测试SLAM、RL等机器人算法，官方还提供了扩展数据集M2DGR-plus。

## 主要特性
1.  **多模态传感器配置**：包含视觉、激光雷达、IMU、GNSS、事件相机、热红外图像等丰富的感知数据
2.  **多样化真实场景**：覆盖电梯、街道、房间、大厅等多种实际环境
3.  **高挑战性基准**：对LIO-SAM、ORB-SLAM3等主流前沿SLAM算法存在较大测试难度，可用于验证新算法的性能上限。
