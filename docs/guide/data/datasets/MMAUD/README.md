# MMAUD

## 项目链接

- GitHub: <https://github.com/ntu-aris/MMAUD>

## 项目概述

## 项目介绍
MMAUD是ICRA 2024收录的多模态反无人机数据集，面向商用微型无人机威胁的检测、分类、跟踪与轨迹估计任务。数据集搭载了2台3D激光雷达、2台同步相机、1台毫米波雷达与4个音频阵列节点，可用于相关反无人机算法的研发与验证。

## 主要特性
1.  多模态传感器配置，覆盖激光、视觉、雷达、音频多类数据
2.  包含真实商用无人机的各类场景测试数据
3.  配套ground truth标注，支持数据格式转换与算法验证
4.  数据已通过rosbag压缩，可通过rosbag工具解压恢复原始帧率
5.  提供多渠道下载源，保障获取稳定性
