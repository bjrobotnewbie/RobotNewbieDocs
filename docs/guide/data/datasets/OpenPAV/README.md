# OpenPAV

Open-PAV 项目收集并组织来自商业自动驾驶车辆的各类数据，包括激光雷达、图像、视频和轨迹数据，并以统一向量格式存储。该工具提供经过校准的动力学模型（线性、IDM、Wiedemann-99 及基于机器学习的模型），并预配置参数，以支持仿真软件的高效研究与合作。

## 项目链接

- GitHub: <https://github.com/OpenPAV/OpenPAV>

## 项目介绍
OpenPAV（Open Production Automated Vehicle）是一款开源平台，用于量产自动驾驶汽车的数据采集、行为建模与性能评估。项目整合了多源自动驾驶数据集，包含激光雷达、图像、视频与轨迹等数据，并统一转换为矢量化格式，同时提供校准后的运动学模型（线性模型、IDM、Wiedemann-99、基于机器学习的模型）与预配置参数，可直接对接仿真软件，助力相关研究与协作。

## 主要特性
1.  整合了来自7家机构的14个开源自动驾驶数据集，覆盖美国、欧洲、意大利等多地的多样驾驶场景
2.  提供标准化矢量化格式的多模态自动驾驶数据
3.  内置多款经过校准的车辆运动学模型与预调参，可快速集成至仿真工具
4.  面向自动驾驶研发人员与学者，支持PAV动力学特性及相关影响的研究工作
