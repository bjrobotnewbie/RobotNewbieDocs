## 项目介绍
PhysInOne是CVPR 2026收录的Python视觉物理学习与推理套件，是目前规模最大的物理对齐AI训练数据集项目。它包含200万段视频，源自153810个动态3D场景，覆盖力学、光学、流体力学、磁学71种日常物理现象，搭配2231种常见交互物体、623种材质与528种3D背景。

数据集支持复杂多物体交互，每个场景包含1-3种物理现象，从13个视角录制，附带3D几何、语义标签、运动动力学、物理属性与自然语言描述等丰富标注。可用于物理感知视频生成、长短时序帧预测、物理属性估计、运动迁移等任务。

## 主要特性
1.  规模与多样性突出：超大规模多领域物理场景数据集
2.  标注全面：覆盖多维度物理与场景相关标注
3.  贴近真实场景：支持复杂多物体交互与动态物理过程
4.  训练子集已正式发布，测试子集开发中
