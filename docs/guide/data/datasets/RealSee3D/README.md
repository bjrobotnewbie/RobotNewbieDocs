# RealSee3D

RealSee3D：一个结合真实场景采集与程序化生成场景的多视图RGB-D数据集，可为各类3D视觉研究提供可扩展标注。

## 项目链接

- GitHub: <https://github.com/realsee-developer/RealSee3D>

## 项目概述

## 项目介绍
RealSee3D是一款大规模多视图RGB-D数据集，包含10000个室内场景，涵盖真实采集的住宅场景和程序化生成场景，为各类3D视觉研究提供可扩展的标注数据。数据集包含95962个房间、299073个视点/RGB-D对，支持通过官方网站申请下载，需签署数据使用协议。

## 主要特性
1.  **大规模覆盖**：10000个独特室内场景，包含真实场景与程序化生成场景
2.  **丰富数据类型**：提供全景RGB-D采集数据，实现完整房间级覆盖
3.  **全面标注支持**：包含像素级语义分割标注，后续还将开放CAD图纸、平面图、3D检测标签等标注
4.  **场景多样性**：1000个真实场景覆盖多样布局与装修风格，9000个程序化生成场景采用100+设计师精选风格模板，提供丰富家具模型与样式，适配模型训练与测试需求。
