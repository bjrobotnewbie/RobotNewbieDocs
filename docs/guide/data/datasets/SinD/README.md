# SinD

SinD: 基于无人机的中国信号化路口异构交通轨迹数据集

## 项目链接

- GitHub: <https://github.com/SOTIF-AVLab/SinD>

## 项目概述

## 项目介绍
SinD是清华大学车辆与 mobility 学院、清华智能汽车设计与安全研究院推出的无人机交通数据集，针对中国城市信号控制交叉口的混合交通场景录制。数据集共包含23条记录，单条记录时长8-22分钟，记录了交通参与者轨迹、运动状态参数、同步的交通灯状态以及高清地图数据，数据以CSV格式存储。

## 主要特性
1.  聚焦中国特色信号交叉口混合交通场景，填补国内相关公开数据集空白
2.  包含多类交通参与者轨迹、实时交通灯状态与高精度地图三类核心数据
3.  单条数据录制周期长，数据量充足，可支撑自动驾驶、SLAM、RL等相关算法研究与训练
4.  可视化代码基于公开开源项目二次开发，可快速实现数据集可视化验证
