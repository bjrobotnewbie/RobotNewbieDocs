# ARIO (All Robots in One)

- [官方网站](https://imaei.github.io/project_pages/ario/)

## 概述

ARIO (All Robots in One) 是一个多模态、多任务的综合性机器人数据集，整合了 2D 视觉、3D 视觉、文本、触觉和声音五种模态的数据。该数据集同时涵盖操作任务和导航任务，并包含仿真数据和真实数据，采用统一的数据格式且规模庞大。

其核心优势在于多模态融合和多任务覆盖，为研究跨模态感知、多任务学习和 sim-to-real 迁移提供了理想平台。统一的格式设计降低了数据处理的复杂度，使得研究者能够更专注于算法开发而非数据预处理工作。
