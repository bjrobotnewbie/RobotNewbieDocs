# 白虎数据集 (Baihu Dataset)

- [官方网站](https://www.openloong.org.cn/cn/datasets/baihu-dataset)

## 概述

白虎数据集是一个面向异构机器人平台的大规模数据集，涵盖多种场景和任务类型。该数据集的主要特点是本体覆盖面广，支持跨平台评估与训练。

通过收集不同形态机器人在多样化环境中的操作数据，白虎数据集为研究通用机器人策略和跨本体泛化能力提供了宝贵资源。其广泛的本体覆盖使得研究者能够探索适用于多种机器人平台的统一算法框架，推动具身智能向更通用的方向发展，特别适合用于验证算法在不同硬件配置下的适应性和可扩展性。
