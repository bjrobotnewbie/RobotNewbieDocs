# DexMimicGen

- [GitHub](https://github.com/NVlabs/dexmimicgen/)
- [官方网站](https://dexmimicgen.github.io/)

## 概述

DexMimicGen 是面向双臂桌面操作的增强版数据生成框架，采用 real2sim2real（真实到仿真再到真实）的技术路线。它能够通过少量人类演示生成大量高质量的训练轨迹，特别适用于复杂的双臂协作任务。

相比基础版本的 MimicGen，DexMimicGen 针对双臂操作场景进行了优化，能够更好地处理双手协调、精细操作等挑战性任务。该方法有效降低了双臂机器人数据采集的难度，为研究复杂操作技能的学习和泛化提供了丰富的数据支持。
