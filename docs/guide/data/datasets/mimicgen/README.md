# MimicGen

- [GitHub](https://github.com/NVlabs/mimicgen)
- [官方网站](https://mimicgen.github.io/)

## 概述

MimicGen 是一个基于 robosuite 和 MuJoCo 的数据生成框架，能够将少量真人演示扩增为大量仿真数据。该方法通过自动化技术将人类示范转化为多样化的仿真轨迹，显著降低了数据收集的成本和时间。

MimicGen 的核心价值在于解决了机器人学习中数据稀缺的问题。通过利用仿真环境的优势，它可以在无需额外人工干预的情况下生成大量高质量的训练数据，特别适合用于需要大规模数据的深度学习模型训练，同时保持了与真实世界任务的相关性。
