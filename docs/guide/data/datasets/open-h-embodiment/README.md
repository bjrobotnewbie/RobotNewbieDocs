# open-h-embodiment

Open-H-Embodiment 是一个社区驱动的基准数据集项目，旨在构建开放、共享的基础设施，以训练和评估用于医疗机器人领域的通用视觉 - 语言 - 动作（VLA）模型。

## 项目链接

- GitHub: <https://github.com/open-h/open-h-embodiment>

## 项目概述

## 项目介绍
Open-H-Embodiment是一个社区驱动的数据集项目，旨在为医疗机器人通用视觉-语言-动作（VLA）模型的训练与评估提供开源共享的基础数据支持。当前项目已更新至v2版本，采用LeRobot v0.6.0、数据集格式v3.0，v1版本可在Hugging Face获取。项目提供官方网站、Discord社区、数据集探索页面等交流与数据查看渠道，采用OpenMDW-1.1开源协议。

## 主要特性
1.  提供医疗机器人领域的配对视频与运动学数据集，支撑VLA模型研发
2.  支持社区贡献数据，提供标准化贡献流程，保障数据质量与一致性
3.  支持临床医生通过标注参与项目，同时面向数据集团队开放数据贡献通道
4.  数据集已上线Hugging Face平台，可快速获取与探索
