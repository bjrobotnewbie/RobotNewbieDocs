# Open X-Embodiment (RT-X)

- [官方网站](https://robotics-transformer-x.github.io/)

## 概述

Open X-Embodiment（也称为 RT-X）是一个大规模跨本体机器人数据集，汇集了来自 22 种不同机器人平台的百万级真实轨迹数据。该数据集覆盖了广泛的技能类型和任务场景，体现了"大规模、跨本体"的主要特点。

通过整合多个研究机构和实验室的数据资源，RT-X 为训练通用的机器人操作策略提供了丰富的数据基础。其多样化的机器人形态和任务分布，使得基于此数据集训练的模型能够更好地泛化到新的机器人平台和工作环境中，是推动通用机器人学习的重要基础设施。
