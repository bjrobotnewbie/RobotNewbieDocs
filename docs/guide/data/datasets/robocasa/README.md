# RoboCasa

- [GitHub](https://github.com/robocasa/robocasa)
- [官方网站](https://robocasa.ai/)

## 概述

RoboCasa 是一个基于 MuJoCo 的高保真厨房场景仿真平台，专注于家居环境中的机器人操作任务。该平台包含多个不同的厨房环境和丰富的物体模型，支持原子任务和组合任务的构建。

其特点是偏重家居厨房场景，提供了逼真的物理交互和视觉渲染。RoboCasa 适合研究家庭服务机器人在复杂、动态环境中的操作能力，特别是涉及多步骤任务规划、物体交互和环境适应的场景，为开发智能家居机器人应用提供了理想的测试平台。
