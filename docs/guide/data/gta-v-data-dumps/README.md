# gta-v-data-dumps

GTA V 数据 dump 适用于模组开发与脚本编写

## 项目链接

- GitHub: <https://github.com/DurtyFree/gta-v-data-dumps>
- 项目主页: <https://forge.plebmasters.de/>

## 项目介绍
本项目是面向GTA V模组开发与脚本编写的自动化数据转储集合，所有数据均为自动生成，部分补充了项目自研的GTA V研究数据。当前数据适配GTA V最新版本v3717.0（线上模式1.72，DLC: mp2025_02_g9ec），支持开发者提交数据使用问题或新增转储需求。

## 主要特性
1.  **覆盖多类游戏资源**：包含895个IPL、36万+条语音资源、364个粒子特效字典+2907个特效、247个行人场景名、235个场景组、2万+动画字典+26万+动画、557个移动剪辑集、207个步行移动剪辑集、6万+导航节点、740万+多边形导航网格，以及39个行人覆盖集合（纹身）
2.  **直接适配游戏原生接口**：所有转储数据均可直接搭配GTA V原生Natives脚本调用
3.  提供多种数据格式：多数为JSON格式，导航网格采用MsgPack压缩格式，方便不同开发场景使用
