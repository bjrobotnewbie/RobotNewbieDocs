# rerun

- 项目链接：https://github.com/rerun-io/rerun
- 项目主页：https://rerun.io/

## 项目概述
rerun是一个专为物理AI设计的数据层工具，其核心功能包括：
1. 支持多速率、多模态数据的日志记录，包括图像、点云、变换、时间序列、关节状态、视频等
2. 兼容多种数据来源和格式，包括机器人日志、人工数据采集、仿真数据、网络视频等，支持MCAP、rrd、LeRobot等格式
3. 内置可视化查看器，支持实时同步渲染所有数据，支持回放剧集、并排比较传感器数据、实时查看CV管道运行状态
4. 支持通过数据框或SQL查询数据，并直接流式传输到训练流程中
5. 基于Rust语言开发，采用专为多速率物理数据设计的列块存储结构
6. 提供Python、Rust等多种编程语言的SDK，支持跨平台使用

该工具为机器人和AI研究人员提供了一站式的数据管理和可视化解决方案，简化了多模态数据的处理和分析流程。
