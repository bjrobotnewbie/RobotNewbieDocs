# xtreme1

Xtreme1 是一款集成的多模态数据标注与标注平台，支持 3D LiDAR 点云、图像及大语言模型（LLM）的训练。

## 项目链接

- GitHub: <https://github.com/xtreme1-io/xtreme1>
- 项目主页: <https://www.basic.ai>

## 项目介绍
Xtreme1是一款开源的多模态机器学习训练数据一站式标注平台，支持图像、3D激光雷达点云以及LLM相关数据的标注、管理与本体管理，可提升计算机视觉和大语言模型相关项目的数据处理效率，适配2D/3D目标检测、语义/实例分割、激光雷达-相机融合等任务，同时提供企业版可申请免费演示。

## 主要特性
1.  支持图像、3D激光雷达、2D/3D传感器融合数据集的标注
2.  内置预标注和交互式AI模型，覆盖2D/3D目标检测、分割、分类任务
3.  可配置的本体中心，支持带层级的通用类别与属性配置
4.  提供数据管理与质量监控能力，可定位并修复标注错误
5.  支持模型结果可视化，辅助模型评估
6.  新增beta版LLM的RLHF标注工具
7.  集成图像数据 curated 与调试工具
