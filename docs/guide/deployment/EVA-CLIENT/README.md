# EVA-CLIENT

EVA-Client：面向真实机器人部署、评估与数据采集的统一框架

## 项目链接

- GitHub: <https://github.com/Noietch/EVA-CLIENT>
- 项目主页: <https://colalab.net/projects/eva-client/>

## 项目介绍
EVA-CLIENT是一款面向真实机器人的统一部署、评估与数据采集框架，主打"一套策略适配任意机器人"的全栈式真机开发方案，支持在浏览器中完成调试、数据录制、模型评估与结果可视化。

## 主要特性
1.  **核心功能**：支持远程遥操作、数据集录制、策略部署、性能评估全流程，无需额外本地调试工具
2.  **硬件兼容**：支持AgileX双臂机械臂、ARX X5等多款机器人，内置机器人适配库
3.  **交互方式**：支持WebXR VR控制器遥操作，支持双YAM主从式数据采集
4.  **数据导出**：支持导出为LeRobot v3.0、MCAP、HDF5多种标准数据集格式
5.  **辅助工具**：内置机器人添加、相机校准、SDK调试等自动化编码代理技能
6.  **技术栈**：基于浏览器轻量化部署，兼容ROS等主流机器人中间件协议
