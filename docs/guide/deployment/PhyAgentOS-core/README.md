## 项目概述

## 项目介绍
PhyAgentOS-core 是一款基于智能体工作流的自主进化具身AI操作系统，采用认知-物理解耦设计，以会话为中心的运行时框架，适配仿真与真实机器人场景，支持Python≥3.11，采用MIT开源协议。

## 主要特性
1.  **核心设计**：实现认知与物理解耦，提供会话为中心的具身智能运行时
2.  **功能迭代**：当前最新版本v0.1.7，已支持策略循环与原生内置路径基准测试、智能体验证与故障恢复服务
3.  **扩展能力**：搭载感知插件系统，支持YAML配置的传感器与环境感知，兼容多硬件接口
4.  **场景适配**：主分支聚焦仿真与真实机器人部署，游戏场景分支独立维护
5.  **配套支持**：提供完整通信协议规范、友好的入门流程，欢迎社区贡献PR
