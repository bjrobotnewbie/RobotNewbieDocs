# RoboJuDo

适用于机器人的开箱即用部署框架。只需部署，即可运行。

## 项目链接

- GitHub: <https://github.com/HansZ8/RoboJuDo>

## 项目介绍
RoboJuDo是一款机器人即插即用部署框架，主打“只需部署，即刻运行”。它属于FRoM-W1项目的一部分，支持Windows和Ubuntu平台，可适配Unitree G1、Unitree H1、FFTAI gr1等多款人形机器人，采用CC-BY-4.0开源协议。
针对当前很多机器人项目仅发布模型却缺乏部署代码的痛点，该框架提供统一的部署方案，让策略部署变得简单实用，可快速在仿真或实体机器人上完成多策略部署。

## 主要特性
1.  **开箱即用**：完成基础配置后，可在数分钟内将多种策略部署到仿真或实体机器人上。
2.  **模块化解耦设计**：采用Python优先开发模式，环境、控制器、策略模块可自由组合，仅需少量代码修改就能适配不同机器人和部署场景。
3.  **多策略无缝切换**：可在任务运行中快速切换不同策略。
4.  **轻量高效**：配置耗时短，可在机器人端流畅运行，通过UnitreeCpp SDK可让Unitree G1无需网线即可部署运行。
5.  已内置支持部署ProtoMotions G1跟踪器。
