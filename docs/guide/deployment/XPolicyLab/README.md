- GitHub: <https://github.com/XPolicyLab/XPolicyLab>
- 项目主页: <xpolicylab.github.io>

## 项目介绍
XPolicyLab是面向机器人策略评估与部署的统一标准开源生态系统，获IROS 26 ScaleInfra Workshop最佳工具论文奖项，作为策略代码与评估环境的中间层，可将N种策略与M种评估环境的适配复杂度从O(N×M)降至O(N+M)，支持在ROS、SLAM等相关机器人技术栈中使用。

## 主要特性
1. 环境隔离：策略模型可在独立的conda/uv环境中运行，与模拟器、基准测试或机器人客户端分离；
2. 远程部署：通过websocket实现策略服务器与环境客户端的跨机或单机连接；
3. 统一适配器契约：提供安装、数据转换、训练、服务、评估的统一高层生命周期；
4. 丰富策略库：已集成49种机器人策略，涵盖VLA、世界动作、模仿学习、记忆增强等类型，适配器可复用；
5. 多基准集成：支持RoboTwin、RoboDojo仿真及标准化真实机器人评估，无需将策略代码与单一环境耦合。
