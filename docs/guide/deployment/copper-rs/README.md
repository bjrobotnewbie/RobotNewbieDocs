# copper-rs

Copper是一个面向机器人的操作系统——可用于确定性地构建、运行和重放你的整个机器人系统。

## 项目概述

## 项目介绍
Copper是一款机器人操作系统，基于Rust开发，支持构建、运行和完全确定性复现机器人程序。它可兼容ROS2，通过Zenoh实现桥接，支持渐进式迁移；可部署在Linux服务器、工作站、单板计算机甚至裸机MPU上，覆盖飞行、自驾、水下、航天、人形机器人等多类机器人场景。项目提供浏览器在线演示，无需本地配置即可体验。

## 主要特性
1.  **Rust优先**：开发体验友好且内存安全
2.  **超低延迟**：零分配、面向数据的运行时，延迟低于亚微秒级
3.  **确定性复现**：每次运行结果完全一致，可逐比特复现
4.  **跨平台部署**：同一套代码可编译适配嵌入式硬件、工作站或浏览器环境
5.  **生态兼容**：支持与ROS2互通，支持从仿真到生产的全流程开发
