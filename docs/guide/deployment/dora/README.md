# dora

DORA（面向数据流的机器人架构，Dataflow-Oriented Robotic Architecture）是为简化基于AI的机器人应用开发而设计的中间件，提供低延迟、可组合的分布式数据流能力。应用被建模为有向图，也可称为流水线。

- GitHub: <https://github.com/dora-rs/dora>
- 项目主页: https://dora-rs.ai

## 项目概述

## 项目介绍
DORA（面向数据流的机器人架构）是一款基于Rust开发的中间件框架，用于简化基于AI的机器人应用开发。它将应用建模为有向数据流图（管道），提供低延迟、可组合、分布式的数据流能力，支持实时机器人与AI应用构建。

## 主要特性
1.  **高性能**：
    - 内部全Rust实现，比ROS2 Python快10-17倍，支持4KB以上消息的零拷贝共享内存IPC，4KB到4MB负载延迟稳定
    - 基于Zenoh共享内存数据平面，绕过守护进程降低35%延迟，大负载下吞吐量提升3-10倍，支持跨机器自动网络 fallback
    - 原生支持Apache Arrow列存内存格式，无序列化开销，支持跨语言绑定
    - 非阻塞事件循环，高负载下控制命令响应仍低于500ms
2.  **良好开发体验**：
    单CLI工具覆盖完整生命周期，支持本地开发、分布式部署、构建、日志、监控、录制回放等全流程操作。
3.  支持Python、Rust等多语言API，提供完整官方文档与示例。
