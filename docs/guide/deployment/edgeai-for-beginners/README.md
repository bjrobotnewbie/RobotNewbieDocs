# edgeai-for-beginners

本课程旨在引导初学者深入探索边缘 AI 的激动人心世界，涵盖基本概念、流行模型、推理技术、特定设备应用、模型优化以及智能边缘 AI 代理的开发。

## 项目链接

- GitHub: <https://github.com/microsoft/edgeai-for-beginners>

## 项目介绍
本项目是微软推出的Edge AI入门课程，面向零基础学习者系统讲解边缘人工智能相关知识，涵盖基础概念、主流模型、推理技术、特定设备应用、模型优化以及智能边缘AI智能体开发等内容，帮助初学者快速入门边缘AI领域。

## 主要特性
1.  支持多语言自动翻译，内容始终保持更新
2.  提供完整的入门学习路径，覆盖边缘AI全流程知识点
3.  附带快速上手流程，支持Fork、克隆仓库直接使用学习资源
4.  配套Discord社区，可与开发者和技术专家交流学习
5.  项目活跃度高，欢迎社区贡献PR与反馈问题
