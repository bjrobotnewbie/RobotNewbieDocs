# limioryn

面向具身智能的边云多智能体执行框架，实现 AI 代理与真实设备的可验证执行及熵受限恢复。

## 项目概述

## 项目介绍
Limioryn 是面向具身智能的端云多智能体（Multi-Agent）执行框架，可通过少量声明式代码构建连接真实设备与云端智能的AI Agent系统。它通过分层API统一设备能力、多智能体协作、受约束物理执行、状态确认与恢复，帮助开发者将智能构想落地为可验证、可恢复的工程系统。当前版本为0.39.0，处于公开预览阶段，涉及安全的系统需额外做风险评估与硬件联锁。

其适配场景包括智慧温室、智能家居楼宇、可穿戴助手、轻量工业边缘系统等需要感知环境、协同决策并安全作用于真实设备的具身智能应用。它不替代VLA模型、SLAM、机器人运动规划等技术，而是为上层智能与下层设备提供通用执行平面。

## 主要特性
1.  **分层能力抽象**：统一接入传感器、执行器的状态信号，定义标准化设备Capability
2.  **多智能体协作**：支持operator、reviewer、observer等角色分离规划、执行与复核权限
3.  **安全执行闭环**：通过设备ACK、状态对账、主动观测形成可验证的行动反馈，支持熵约束恢复机制
4.  **轻量化开发**：仅需少量声明式代码即可快速搭建具身智能系统，支持本地规则、云端LLM Agent或混合团队部署
5.  **端云协同**：支持本地与云端智能体协同，统一映射设备调用到MQTT/HTTPS等协议
