# RoboECC

论文《RoboECC：面向 VLA 模型的边缘 - 云协同部署的多因素感知代码》已获 IJCNN 2026 接收。

## 项目链接

- GitHub: <https://github.com/zhengzihaoPKU/RoboECC>

## 项目介绍
RoboECC是一款针对视觉语言动作（VLA）模型的边云协同部署框架，来自IJCNN 2026收录论文《RoboECC: Multi-Factor-Aware Edge-Cloud Collaborative Deployment for VLA Models》。该框架综合考量模型结构、边云硬件、云负载、激活尺寸和网络波动等多因素，可高效划分模型分段点并在线调整部署方案。
在Orin+A100平台上相比纯边缘部署实现3.16×–3.28×加速，Thor+A100平台实现2.10×–2.23×加速，调整开销仅为2.55%–2.62%。

## 主要特性
1.  **模型-硬件协同感知分段**：将异构VLA组件建模为串行层链，用屋顶线模型估算GPU延迟，在可配置云负载预算下搜索最优分段边界
2.  **网络感知部署调整**：通过轻量LSTM预测带宽变化，采用双阈值策略动态调整分段点
3.  **参数共享池**：最优分段附近的模块驻留于两端设备，仅更新执行元数据而非传输模型权重
4.  **细粒度LLaMA规划**：可在RMSNorm、注意力、MLP层内划分分段，并将残差张量纳入传输尺寸估算
