# sglang

SGLang 是一个面向大语言模型和多模态模型的高性能服务框架。

## 项目链接

- GitHub: <https://github.com/sgl-project/sglang>
- 项目主页: <https://sglang.io>

## 项目概述

## 项目介绍
SGLang是一款面向大语言模型与多模态模型的高性能推理服务框架，支持快速部署各类主流开源/闭源AI模型，提供原生TPU后端适配，可加速文本、图像、音频生成等任务，支持Day0级别的新模型上线支持。

## 主要特性
1.  搭载新一代推测解码技术DFlash与Spec V2，可实现最高25倍的推理性能提升
2.  支持扩散类模型加速，可优化图像、视频生成流程
3.  原生适配NVIDIA GB300、TPU等多类硬件平台
4.  快速支持最新开源模型上线，覆盖LLaMA系列、Nemotron、DeepSeek等主流模型
5.  提供完整文档、社区Slack交流渠道与开发路线规划
