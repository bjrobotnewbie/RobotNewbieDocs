# TensorRT LLM
## 项目定位
TensorRT LLM 是 NVIDIA 面向大型语言模型推理场景打造的开源优化库，依托 PyTorch 构建，提供易用的 Python API，可在 NVIDIA GPU 上实现高效的大模型推理部署，适配单卡、多卡及多节点等多种运行环境，兼容 NVIDIA 主流 GPU 架构，是大模型落地部署的常用工具。

项目官方资源：
- 代码仓库：https://github.com/NVIDIA/TensorRT-LLM
- 文档站点：https://nvidia.github.io/TensorRT-LLM/

## 基础能力
- 模型支持：覆盖主流大语言模型、多模态模型及视觉生成模型，提供模型适配指南与预设配置方案，降低模型接入成本。
- 推理部署：支持离线推理与在线服务部署，提供 trtllm-serve 等工具快速搭建推理服务，兼容 OpenAI 接口规范，便于集成现有系统。
- 分布式能力：内置多种并行策略，支持专家并行、分布式权重数据并行等，适配超大规模模型的跨卡、跨节点运行需求。
- 生态兼容：可与 NVIDIA Dynamo、Triton 推理服务器等组件协同，支持容器化部署、K8s 编排与 Slurm 集群管理，适配生产环境运维流程。

## 关键优化特性
- 注意力机制优化：支持多头、多查询与分组查询注意力，提供定制化注意力内核，适配不同模型的注意力计算需求，提升计算效率。
- 缓存与调度优化：采用分页注意力、KV 缓存管理、请求调度与重叠调度机制，优化缓存复用与请求处理流程，提升 GPU 利用率与请求吞吐能力。
- 量化加速：支持 FP8、INT4 AWQ、INT8 SmoothQuant 等多种量化方式，在保障精度的前提下降低显存占用，提升推理速度。
- 解码优化：集成推测解码、引导解码、N-Gram 解码等技术，通过提前生成候选token等方式降低推理延迟，适配高并发场景。
- 长文本支持：适配超长序列推理，支持分块上下文、滑动窗口注意力、稀疏注意力等方案，突破长文本处理的性能瓶颈。
- 混合专家模型优化：针对 MoE 模型优化通信策略与专家负载均衡，适配 NVIDIA Blackwell 等新一代架构，降低低延迟推理的开销。

## 开发与工具支持
- 开发接口：提供 LLM、AsyncLLM 等标准化 API，支持参数配置、采样设置、错误处理等功能，简化推理代码开发流程。
- 调试与评测：内置性能分析工具、基准测试工具 trtllm-bench 与模型评估工具 trtllm-eval，支持吞吐量、延迟等指标测试，便于性能调优。
- 定制扩展：提供新增模型适配指南、自定义注意力后端实现方案，支持按需扩展功能，满足个性化部署需求。
- 运维监控：支持 Prometheus 指标采集，提供服务健康检查工具，便于实时监控推理服务运行状态。

## 适用场景
适用于大语言模型、多模态模型的生产级推理部署，覆盖智能对话、内容生成、信息检索、数据分析等场景。可满足低延迟、高吞吐、大规模模型分布式推理等不同需求，帮助开发者在 NVIDIA GPU 上高效落地大模型应用。
