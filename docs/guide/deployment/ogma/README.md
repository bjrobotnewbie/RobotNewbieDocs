# ogma

面向飞行器与机器人应用的运行时监视器生成器

## 项目链接

- GitHub: <https://github.com/nasa/ogma>

## 项目概述

## 项目介绍
ogma是一款面向飞行与机器人应用的运行时监视器生成工具，基于ogma-cli提供命令行交互能力，可快速为机器人、无人机等搭载ROS、SLAM、RL等技术栈的项目生成专用运行时监视器，用于实时监控系统运行状态、捕捉异常行为并触发预警。

## 主要特性
1.  专注机器人与飞行应用场景，适配ROS生态及SLAM、强化学习等主流机器人开发技术栈
2.  通过命令行快速生成定制化运行时监视器，无需手动编写大量监控逻辑
3.  支持实时采集系统运行数据，可自定义监控规则与异常触发条件
4.  轻量化部署，可无缝集成到现有机器人开发流程中，辅助保障系统运行稳定性
