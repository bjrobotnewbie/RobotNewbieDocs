# Ollama

- [documentation](https://docs.ollama.com/)

Ollama 是面向个人与开发者的开源工具，用于在本地设备快速启动、运行与管理各类大型语言模型，让开源大模型在电脑上开箱即用，无需复杂环境配置与云端依赖。

## 定位与价值
Ollama 把大模型的部署、运行、管理流程高度封装，用简洁命令与标准化接口，降低本地使用大模型的门槛，兼顾隐私安全、离线可用与二次开发便利。

## 支持平台
- macOS
- Windows
- Linux
同时提供云端模型服务，可选用更大规模、更高性能的模型版本。

## 支持模型
覆盖主流开源大模型，持续更新：
- Llama 系列、Gemma 系列
- DeepSeek‑R1、Qwen 系列
- Mistral、Phi 等
支持不同参数规格与量化版本，适配消费级硬件。

## 主要能力
### 1. 极简部署与运行
- 一条命令完成模型拉取、加载与对话交互
- 自动处理依赖、格式与硬件适配
- 支持 Modelfile 自定义模型行为与参数

### 2. 完整模型管理
- 查看、下载、更新、删除本地模型
- 监控运行状态与资源占用
- 统一管理模型文件，支持路径自定义

### 3. 开放接口与开发集成
- 内置 REST API 服务，便于嵌入应用
- 提供官方 Python、JavaScript/TypeScript 库
- 兼容社区二十余种开发库，对接各类框架与工具链

### 4. 本地优先与隐私友好
- 推理全程在本地执行，数据不离开设备
- 支持离线使用，无网络也可稳定运行
- 适合隐私敏感场景与内部开发环境

## 快速开始
1. 前往官网下载对应系统安装包并完成安装
2. 终端执行命令启动模型：
```
ollama run 模型名称
```
3. 直接对话交互，或通过 API 接入项目使用

常用命令：
- `ollama pull`：下载模型
- `ollama list`：查看已安装模型
- `ollama rm`：删除模型
- `ollama ps`：查看运行中实例
