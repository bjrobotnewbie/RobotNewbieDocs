## 项目介绍
Robonix是一款具身智能操作系统（EAIOS），作为跨异构机器人构建具身智能的系统底层框架。它旨在从系统层面打造机器人的"大脑"，提供通用的运行基底，让AI模型无需针对每个机器人厂商的SDK重写，即可通过不同形态的机器人硬件完成感知、理解、规划与行动。

该项目将AI模型与技能视为程序，把机器人硬件抽象为可发现的能力接口，开发者只需一次适配机器人硬件，即可通过统一接口调用相机、激光雷达、底盘、机械臂、SLAM、导航、语音等能力，最终实现"一次训练，部署到任意机器人"的长期目标。当前项目仍处于早期开发阶段，API和内部设计可能在正式版本发布前发生变更。

## 主要特性
1.  跨异构机器人通用适配，实现硬件与AI模型解耦
2.  提供统一的机器人硬件能力调用接口
3.  支持多类机器人硬件集成，已适配AgileX Ranger Mini v3等多款机器人
4.  内置丰富的机器人相关能力包，支持快速部署具身智能应用
