# rosclaw

面向Physical AI与具身智能体的自进化运行时基础设施。通过e-URDF、沙箱安全、能力路由、实践捕获、物理内存、运行时干预与技能进化，将AI具身落地到实体机器人。

## 项目概述

## 项目介绍
ROSClaw是面向Physical AI具身智能体的自进化运行时基础设施，核心作用是将AI智能体落地到实体机器人中。它并非聊天机器人框架或简单的LLM转ROS封装工具，而是将AI代理、机器人本体、仿真沙箱、能力路由、物理记忆、实践捕获、运行时干预和技能进化整合为统一的运行层，用于构建可推理、安全运行、可记录复盘、可故障恢复并持续进化的具身智能体。

## 主要特性
1.  支持ROS 2 Humble/Jazzy版本，兼容Python 3.11+
2.  适配MuJoCo、Isaac Sim仿真环境，集成MCP协议
3.  提供e-URDF工具完成AI与机器人本体的绑定
4.  内置仿真沙箱保障物理操作安全
5.  支持能力路由、实践捕获、物理记忆存储
6.  具备运行时干预和技能自动进化能力
7.  提供一键安装脚本和交互式首配置向导，支持快速上手仿真演示
