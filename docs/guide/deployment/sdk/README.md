# sdk

Temi 是一款无与伦比的机器人平台，引入了一种全新的发展维度——运动。利用 Temi 的 SDK，开发者可以通过 Temi 的 Android 平板电脑创建新功能并引入新的应用场景。Temi 的运动和导航功能基于其 Linux 计算机运行，并集成了一个包含激光雷达、深度相机、驾驶相机和麦克风在内的 16 个传感器。我们鼓励开发者社区在 SDK 中提出建议并请求扩展功能，我们将根据您的需求进行调整。我们要让您创造前所未有的技能！我们将持续改进 SDK 及其文档。如有任何问题或想法，欢迎随时联系我们：developers@robotemi.com

## 项目介绍
temi SDK是面向temi机器人平台的开发工具包，开发者可通过temi自带的Android平板为机器人开发新功能、拓展使用场景。temi的移动与导航能力基于Linux计算机运行，搭载了激光雷达（Lidar）、深度相机、行车相机、麦克风等共16种传感器。该SDK会持续迭代优化并更新文档，开发者可通过developers@robotemi.com反馈需求与问题。

## 主要特性
1.  支持通过Gradle、Maven快速引入依赖，最新版本为1.138.0
2.  提供英文与简体中文两份官方文档
3.  基于Apache License 2.0开源协议
4.  可基于temi硬件能力开发定制化机器人技能，拓展移动交互相关的各类使用场景
