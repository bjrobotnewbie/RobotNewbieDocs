# vLLM
## 项目概述
vLLM 是面向大语言模型的开源高性能推理与服务框架，由加州大学伯克利分校团队发起开发，聚焦提升模型推理效率、降低显存占用与提升服务吞吐，广泛用于在线服务、离线批量推理、多模态与长文本场景。项目依托活跃社区持续迭代，提供完善文档、多硬件适配与生产级部署能力，可快速搭建高并发、低延迟的 LLM 服务。

- 代码仓库：https://github.com/vllm-project/vllm

## 设计思路与关键能力
vLLM 以显存高效利用与请求调度优化为方向，带来显著的服务性能提升：
1. **PagedAttention 显存管理**
借鉴操作系统虚拟内存分页思路，将 KV Cache 拆分为固定大小块，支持非连续存储与页表映射，大幅减少显存碎片，提升硬件利用率。
2. **动态连续批处理**
支持请求动态加入与退出调度，无需等待整批完成，保持 GPU 高利用率，提升单位时间处理请求数量。
3. **前缀共享复用**
相同提示前缀的请求可复用对应 KV Cache，减少重复计算，进一步降低显存开销并提速。
4. **多维度并行扩展**
支持数据并行、张量并行、专家并行等分布式模式，适配多卡/多节点集群，满足超大模型推理需求。
5. **量化与推理加速**
兼容 AutoAWQ、GPTQ、GGUF、FP8 等多种量化方案，搭配优化算子与推测解码，在精度可控前提下提速降耗。

## 核心功能场景
### 1. 推理服务
- 离线批量推理：支持批量文件、长文本、多轮对话等高吞吐离线任务
- 在线流式服务：提供低延迟、高并发的流式生成，适配聊天、助手等交互场景
- 多模态推理：覆盖文本、图像、音频等输入，支持视觉语言与语音相关任务

### 2. 服务与集成
- 兼容 OpenAI API 接口，现有应用与框架可无缝迁移
- 提供 Helm Chart、Docker、Kubernetes 等部署方式，适配云原生环境
- 对接 LangChain、LlamaIndex 等生态，支持检索增强、智能体等复杂流程
- 提供监控指标与日志配置，满足生产环境运维与观测需求

### 3. 工程化能力
- 多硬件支持：覆盖 GPU、CPU、TPU 等多种加速平台
-  LoRA 与多 LoRA 推理：支持轻量化适配与多适配器同时服务
- 结构化输出、工具调用、前缀缓存、上下文扩展等企业级特性
- 支持状态保存、暂停恢复、错误重试等稳定运行保障

## 适用场景与优势
- 高并发在线对话服务：显著提升单卡并发量，降低时延
- 长上下文大模型推理：高效管理超长序列 KV Cache，减少 OOM 风险
- 低成本私有化部署：在同等硬件下支持更大模型与更多请求
- 科研与二次开发：模块化设计便于定制引擎、添加算法与接入新硬件

## 生态与社区
vLLM 拥有活跃开源社区，持续新增模型支持、硬件适配与特性迭代，文档覆盖安装、示例、调优、故障排查等全流程，可快速完成从测试到上线。项目广泛用于科研、企业生产与云服务，成为主流 LLM 推理部署方案之一。
