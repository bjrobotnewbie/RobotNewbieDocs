## 项目介绍
这是一个具身人工智能安全领域的综述项目，也是首个统一的具身AI安全框架，整理了550+相关核心研究成果，涵盖感知、认知、规划、交互、智能体系统五大方向。项目提供了arXiv论文链接、官方项目主页以及每日更新的筛选论文页面，采用CC BY 4.0开源协议，持续维护中。

## 主要特性
1.  全面覆盖具身AI全链路的安全风险、攻击手段与防御方案
2.  收录超500篇顶会顶刊相关研究，定期更新筛选后的最新论文
3.  提供标准化的安全分类框架，方便研究者快速检索相关领域进展
4.  适配机器人、自动驾驶、RL智能体等各类具身AI落地场景的安全研究参考
