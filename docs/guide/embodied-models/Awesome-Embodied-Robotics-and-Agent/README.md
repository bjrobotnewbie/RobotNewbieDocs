# Awesome-Embodied-Robotics-and-Agent

- 项目链接：https://github.com/zchoi/Awesome-Embodied-Robotics-and-Agent

## 项目概述
这是一个精选的研究列表，专注于具身机器人或结合视觉语言模型（VLMs）和大型语言模型（LLMs）的智能体领域，其核心内容包括：
1. 收集了该领域的最新研究论文、数据集、模型和基准测试
2. 持续更新最新的研究进展，包括ICRA、CVPR、ICLR等顶级会议的论文
3. 涵盖具身导航、视觉语言动作模型、大型语言模型自主进化等多个研究方向
4. 提供了详细的分类和链接，方便研究人员快速查找相关资源
5. 欢迎社区贡献，用户可以提交pull request添加新的研究成果

该列表为具身智能和机器人领域的研究者提供了一站式的资源导航，推动了该领域的学术交流和研究进展。
