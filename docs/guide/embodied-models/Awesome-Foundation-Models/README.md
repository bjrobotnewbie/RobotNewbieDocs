# Awesome-Foundation-Models

用于视觉和语言任务的精选基础模型列表

## 项目链接

- GitHub: <https://github.com/uncbiag/Awesome-Foundation-Models>

## 项目介绍
本项目是一个精选的视觉与语言领域基础模型列表，基础模型指可适配多种下游任务的大规模预训练模型（如BERT、DALL-E、GPT-3），由斯坦福人类-Centered人工智能研究所首次推广。仓库仅收录附带开源代码的相关研究资源，涵盖多模态、大语言模型、视觉模型等多个细分方向的调研综述与模型资源。

## 主要特性
1.  聚焦视觉与语言任务的基础模型资源，仅收录带开源代码的项目
2.  整理了2024年及更早的相关领域综述论文，覆盖语言智能体、算法设计大模型、图像分割、多模态大模型、视频理解、机器人应用等众多细分方向
3.  提供部分综述的关联博客与原文链接，方便快速获取更多资料
