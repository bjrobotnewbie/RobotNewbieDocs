# Awesome-LLM-Robotics

一份将大语言/多模态模型用于机器人学/RL的论文综合列表，包含论文、代码与相关网站。

## 项目链接

- GitHub: <https://github.com/GT-RIPL/Awesome-LLM-Robotics>

## 项目概述

## 项目介绍
本项目是一个精选的学术资源汇总列表，收录了将大语言/多模态模型应用于机器人学、强化学习（RL）领域的相关论文、代码及相关网站，旨在为相关领域研究者提供便捷的资源导航。用户可通过提交PR或邮件添加新的符合要求的资源，按时间倒序排列并遵循指定格式即可。

## 主要特性
1.  **资源分类清晰**：按综述、推理、规划、操作、指令与导航、仿真框架、安全与对抗测试等方向进行分类整理
2.  **覆盖多维度研究**：涵盖了从基础综述到具体落地应用的全链条研究内容
3.  **附带补充资源**：多数论文附带了论文链接、项目网站等额外参考资源
4.  支持社区贡献，鼓励用户提交新增资源完善列表
