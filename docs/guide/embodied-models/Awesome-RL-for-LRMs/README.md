# Awesome-RL-for-LRMs

大推理模型的强化学习综述

## 项目链接

- GitHub: <https://github.com/TsinghuaC3I/Awesome-RL-for-LRMs>
- 项目主页: <https://arxiv.org/abs/2509.08827>

## 项目介绍
本项目是**面向大型推理模型（LRMs）的强化学习（RL）**领域综述，由清华C3I团队发起，相关论文已登上Hugging Face每日热门论文榜首。项目收录了该领域的核心研究成果，同时欢迎社区贡献未覆盖的相关工作。

## 主要特性
1.  **核心定位**：系统梳理RL赋能大型推理模型的研究脉络与技术方案
2.  **动态更新**：持续补充最新论文，并将按分类结构完善文献列表
3.  附带衍生研究：团队同期推出了面向智能体记忆、自进化智能体等相关领域的综述与开源项目，如OpenRSI、MARTI等工具框架。
4.  配套资源：提供论文演讲幻灯片，支持社区反馈与内容迭代。
