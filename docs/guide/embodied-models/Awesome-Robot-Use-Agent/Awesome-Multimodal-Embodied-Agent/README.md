## 项目介绍
本项目是一份关于多模态具身智能体（Multimodal Embodied Agents, MMEAs）的综述资源库，聚焦“多模态智能体从计算机使用场景迁移至机器人使用场景时会发生哪些变化”这一核心问题，配套相关研究论文与项目网站，由新加坡国立大学Show Lab维护。

## 主要特性
1. 围绕多模态具身智能体的核心研究方向，梳理计算机使用与机器人使用场景下的技术差异；
2. 关联PAPAV（Perceive, Anticipate, Plan, Act, Verify）具身智能体框架，覆盖多模态推理与物理动作结合的相关研究内容；
3. 作为综述类资源库，为相关领域研究提供系统性的参考资料。
