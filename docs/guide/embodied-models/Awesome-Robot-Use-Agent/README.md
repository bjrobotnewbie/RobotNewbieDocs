## 项目介绍
Awesome-Robot-Use-Agent（简称RUA）是一个精选的机器人使用代理领域资源合集，收录了该领域的论文、研究博客、开源工具、基准测试集以及社区演示案例，还包含基于GPT-6 Astra的演示项目。
机器人使用代理是一类AI系统，可根据用户指定目标进行推理、规划动作，通过机器人的技能与感知控制接口将机器人作为工具在物理世界执行任务，并能通过观测和执行反馈调整计划、修复失败任务。本项目支持通过其可搜索官网浏览全部资源。

## 主要特性
1.  资源分类完善：涵盖文章、论文、开源项目、基准测试、社区演示六大类，其中论文包含综述、方法框架、数据集、基准测试子类，开源项目包含系统框架、环境沙箱子类
2.  包含28个ROS相关工具、61个社区演示案例，累计收录189份资源
3.  提供可访问的在线搜索网站，支持快速检索相关资源
4.  支持社区贡献，欢迎PR提交新资源，采用MIT开源协议
