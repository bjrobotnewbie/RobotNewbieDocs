## 项目概述
BFM-Zero是一个基于无监督强化学习的可提示人形机器人行为基础模型，其核心特点包括：
1. 支持人形机器人的控制和行为学习，通过无监督强化学习实现自主行为获取
2. 提供预训练的checkpoint和多种部署方式，包括sim-to-sim和sim-to-real
3. 支持Isaac Sim或MuJoCo等仿真平台进行训练和测试
4. 提供完整的训练和评估管道，以及最小化的推理代码和教程
5. 采用Git LFS管理运动数据和模型文件，方便用户获取资源

该模型为人形机器人的行为学习和控制提供了强大的基础支持，推动了具身智能领域的发展。
