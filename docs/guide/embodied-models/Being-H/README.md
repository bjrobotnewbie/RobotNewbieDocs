# Being-H

- 项目链接：https://github.com/BeingBeyond/Being-H
- 项目主页：https://research.beingbeyond.com/being-h07

## 项目概述
Being-H是BeingBeyond团队推出的人本化具身基础模型系列，其核心内容包括：
1. 包含多个模型版本：Being-H0.7（旗舰WAM模型，基于自我中心视频的潜在世界行动模型）、Being-H0.5（旗舰VLA模型，支持跨具身体泛化的人本化视觉语言动作模型）和Being-H0（早期VLA预训练模型）
2. 提供详细的博客和论文链接，介绍每个模型的技术细节和应用场景
3. 包含模型下载和教程资源，方便用户快速上手使用
4. Being-H0模型被ICML 2026会议收录，获得学术领域的认可
5. 提供教育性的教程工作区，支持模型的后训练和部署示例

该系列模型为人本化具身智能的研究和应用提供了重要的基础支持，推动了具身人工智能领域的发展。
