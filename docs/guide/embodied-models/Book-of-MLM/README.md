## 项目介绍
本项目是《多模态大模型：新一代人工智能技术范式》的配套教学资源，该书系统讲解多模态大模型关键技术、基础模型与典型应用，面向低年级本科生、AI从业者及科研人员，以深入浅出的方式拆解技术细节与经典模型结构。全书共5章，覆盖大模型结构、多模态核心技术、典型模型、视觉问答/AIGC/具身智能等应用，以及迈向AGI的前沿方向，可满足32~56学时教学，已入选中山大学本科教材系列，同时被十余所高校采用配套课件。

## 主要特性
1.  **内容全面**：涵盖多模态大模型全技术栈，包含因果推理、世界模型、具身智能、多智能体等前沿方向
2.  **教学友好**：搭配2026版配套教学PPT，覆盖全书核心章节，已被多所高校用于课堂教学
3.  **配套完整**：提供全书目录、参考文献等教学资源，另有具身智能操作系统PhyAgentOS、视觉-语言因果推理框架CausalVLR等开源辅助资源
4.  **中英版本**：推出中文版与英文版书籍，适配不同读者需求
