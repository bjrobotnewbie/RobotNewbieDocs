# EgoHumanoid

- 项目链接：https://github.com/OpenDriveLab/EgoHumanoid
- 项目主页：https://opendrivelab.com/EgoHumanoid
论文链接：https://arxiv.org/abs/2602.10106

## 项目概述
EgoHumanoid是第一个使人形机器人能够从第一人称人类演示中学习全身动作与操作的框架，其核心特点包括：
1. 利用丰富的第一人称人类演示数据和少量机器人数据共同训练视觉语言动作策略
2. 引入了系统的对齐管道，包括视图对齐和动作对齐，解决具身差距问题
3. 在真实世界实验中，相比纯机器人数据的基线，性能提升51%，尤其在未知环境中表现更出色
4. 提供完整的硬件设置、环境搭建、数据收集和处理流程
5. 采用Apache 2.0开源许可证，方便研究人员使用和贡献

该框架为机器人从人类演示中学习提供了新的解决方案，推动了人形机器人操作和运动学习领域的发展。
