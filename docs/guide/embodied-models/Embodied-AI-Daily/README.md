## 项目介绍
本项目是一个每日自动更新的arXiv论文聚合仓库，聚焦于VLN、VLA、SLAM、3D视觉与具身智能领域。项目会自动抓取arXiv上符合预设关键词的最新论文，README中每个分类最多展示20篇相关论文，完整论文列表可查看`papers/`目录。项目还提供了专属网页端，同时支持通过Watch仓库获取每日邮件推送通知，issue区域会展示最新10篇更新的论文。

## 主要特性
1.  每日自动从arXiv更新目标领域最新论文
2.  覆盖VLN、VLA、SLAM、3D、具身智能等核心研究方向
3.  提供网页端浏览入口，同时支持邮件订阅更新
4.  部分论文附带DeepSeek API生成的AI深度总结
5.  完整论文列表可通过仓库内目录下载查看
