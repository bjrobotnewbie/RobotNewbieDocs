我的个人博客（具身智能）

## 项目链接

- GitHub: <https://github.com/TingdeLiu/tingdeliu.github.io>
- 项目主页: <https://tingdeliu.github.io/>

## 项目介绍
本项目是Tingde Liu的个人学术博客与研究知识库，基于Jekyll构建，部署于GitHub Pages，面向具备机器学习、深度学习基础的科研人员、学生及工程师，聚焦具身智能、视觉语言导航（VLN）、机器人学习等领域，提供系统且持续更新的研究笔记、论文解读、工程笔记等内容。

## 主要特性
1. 双语支持：提供英文与简体中文版本，英文版本包含完整的VLN综述、VLN论文合集及6篇具身导航周刊，支持语言切换，其余长文将逐步翻译；
2. 内容体系：涵盖18篇研究综述与论文解读、7篇技术博客、6篇具身导航周刊，包含模型、数据集、训练方法、系统架构、基准测试及真实机器人部署等内容；
3. 开源许可：代码采用MIT许可，内容采用CC BY 4.0许可，支持学术使用。
