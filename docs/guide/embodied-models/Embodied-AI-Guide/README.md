## 项目介绍
本项目是国内热门的具身智能中文知识库与资料索引，定位为具身智能领域百科全书，旨在帮助开发者快速建立领域认知并上手实践。项目于2025年3月正式开源，GitHub星标已突破10000，由具身智能初学者团队维护，欢迎贡献PR、参与社区交流与学术合作。

## 主要特性
1.  **学习路径清晰**：提供从入门到实践的完整指引，以实践项目带学，搭配百科式技术介绍覆盖领域全栈内容
2.  **配套实操教程**：推荐使用RoboTwin 2.0仿真平台完成具身智能操作策略全流程学习，平台集成50个双臂自动化数据合成、主流策略训测与评测系统，适配16GB以上显存显卡
3.  **社区生态完善**：附带Lumina具身智能社区入口，关联多个相关开源项目，可获取最新行业动态与资源
