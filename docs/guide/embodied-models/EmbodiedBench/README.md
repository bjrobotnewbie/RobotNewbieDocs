## 项目概述
EmbodiedBench是一个全面的基准测试平台，旨在评估多模态大语言模型（MLLMs）作为视觉驱动具身智能体的表现，其核心特点包括：
1. 被ICML 2025会议收录为口述论文，在具身智能领域有重要影响力
2. 支持CVPR 2026研讨会的基础模型与具身智能体挑战任务
3. 提供完整的评估框架和数据集，方便研究人员测试和比较不同模型的具身智能能力
4. 涵盖多种视觉驱动的具身智能场景，全面评估模型的多模态理解和决策能力
5. 提供详细的文档和使用指南，方便快速上手和开展实验

该基准测试平台推动了具身智能领域的模型评估和技术发展，为研究人员提供了标准化的测试方案。
