## 项目概述
FRoM-W1是面向语言指令的通用全人形机器人全身控制模型，能够根据自然语言指令实现人形机器人的全身控制，适用于具身智能和人形机器人领域的研究和开发，提供了代码、模型和数据集，已在arXiv上发布。
