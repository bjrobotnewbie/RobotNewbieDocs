## 项目介绍
GameScaling是一项针对具身智能体的持续预训练研究项目，聚焦于在多样化虚拟游戏世界中开展具身智能体的预训练工作，相关模型权重已托管于Hugging Face平台，同时配套有项目页面与arXiv论文。

## 主要特性
1. 面向多样化虚拟游戏世界的具身智能体持续预训练方案；
2. 模型权重可通过Hugging Face获取；
3. 配套有项目页面与学术论文，可供进一步研究参考。
