# HEX

## 项目概述

HEX 是一款针对全尺寸人形机器人的全身视觉-语言-动作框架。该框架结合了 Qwen-VL  backbone、统一本体感知预测器（UPP）以及流匹配动作头来预测连续的未来动作。

核心思想是将不同人形机器人的异构状态对齐到共享的身体部位槽中，并从跨具形人形数据中学习预测身体动力学，使得策略能够在不同人形平台间迁移，执行长范围全身操作。

在部署时，HEX 直接预测手臂、手和腰部动作，同时向基于强化学习的底层全身控制器提供高级命令来生成腿部动作，这种设计实现了协调稳定的人形操作。目前已发布了 VLA 的预训练和微调代码。
