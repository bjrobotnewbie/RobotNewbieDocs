## 项目概述
HY-Embodied是面向现实世界的实体基础模型系列，由腾讯 Robotics X 和 HY Vision Team 开发，包含了针对实体智能的基础模型，适用于具身智能和机器人领域的研究和开发，提供了高效的模型变体和复杂推理能力，支持空间-时间视觉感知和复杂的实体推理。
