## 项目概述
HoloMotion是一个全身人形控制的基础模型，通过参考条件化的MoE Transformer、大规模运动数据和优化的训练到部署流水线，实现了更强的运动跟踪和实时推理效率，适用于人形机器人的控制研究和开发，提供了从60M到0.4B参数的多种模型版本和80到2000+小时的运动数据。
