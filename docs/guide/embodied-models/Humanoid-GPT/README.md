## 项目概述
Humanoid-GPT是第一个GPT风格的人形运动Transformer，在十亿规模的运动语料库上使用因果注意力进行训练，用于全身控制，支持零样本运动追踪，已被CVPR 2026会议接收，适用于人形机器人的运动学习和控制研究。
