# OmTrackVLA

- 项目链接：https://github.com/om-ai-lab/OmTrackVLA

## 项目概述

OpenTrackVLA（OmTrackVLA）是一个完全开源的视觉-语言-动作（VLA）框架，能够将单目视频和自然语言指令转换为可执行的短地平线路径点。

该项目致力于民主化具身人工智能，发布了高效的 0.6B 参数 checkpoint 以及完整的训练流水线。

主要特点：
- 完全开源：发布模型权重、推理代码和完整训练栈，而不仅仅是推理封装
- 可访问性：设计用于在平价计算资源上进行复现、微调和部署
- 多模态控制：结合学习先验和视觉输入，通过简单的文本提示指导真实或仿真机器人

该项目基于 TrackVLA 的思想，是一个社区驱动的开放项目，让研究人员和开发人员能够共同改进这个技术栈。
