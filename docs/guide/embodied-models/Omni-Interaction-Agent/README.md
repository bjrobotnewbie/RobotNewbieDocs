# Omni-Interaction-Agent

开源端到端全向交互代理，支持自然全双工语音协作、连续音视频感知以及异步长时程代理执行。

## 项目链接

- GitHub: <https://github.com/Omni-Interaction-Gander/Omni-Interaction-Agent>
- 项目主页: <https://omni-interaction-gander.github.io/Omni-Interaction-Agent/>

## 项目介绍
Gander（即Omni-Interaction-Agent）是一款开源端到端全模态双向交互智能体，支持自然全双工语音协作、连续音视觉感知与异步长周期智能体执行。它可让用户在任务运行过程中随时插话、重定向任务或共享屏幕，实现实时语音对话、多模态感知与长时序任务执行的一体化交互。项目已在ArXiv发布论文，模型已上架Hugging Face，数据集即将开源。

## 主要特性
1.  **原生全双工交互**：支持自然对话、轮流发言、插话处理、反馈回应等习得式交互行为，可自主判断说话时机与内容
2.  **连续多模态感知**：将语音、视频、文本统一纳入因果时间线，基于用户实时输入、屏幕画面与场景完成对话 grounding
3.  **小脑-大脑架构**：通过流式对话模型与异步推理智能体结合，兼顾实时交互响应与长周期任务执行能力
4.  兼具自然表达、知识调用与指令遵循能力，可用于实时协作交互场景。
