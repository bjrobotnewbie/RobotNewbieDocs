# PhyAgentOS

PhyAgentOS 是一个基于智能体工作流构建的自进化具身AI操作系统。

## 项目链接

- GitHub: <https://github.com/PhyAgentOS/PhyAgentOS>
- 项目主页: https://phy-agent-os.net/

## 项目概述

## 项目介绍
PhyAgentOS是一款基于智能体工作流构建的自进化具身AI操作系统，采用认知-物理解耦设计，以会话为中心的运行时框架。它支持将推理与执行分离，仅需编写少量适配代码即可兼容不同硬件机器人，适配Python≥3.11环境，采用MIT开源协议。

## 主要特性
1.  **核心架构**：实现认知与物理解耦，基于会话为中心的运行时，一套代码可适配多硬件，新增机器人仅需编写约百行的Target Adapter，无需修改调度层
2.  **迭代更新**：当前最新版本v0.1.6，已支持Behavior 1K、Agent验证工具SessionVerfier，逐步完善了通信协议、感知插件系统、上手流程，支持仿真与真实机器人场景
3.  **应用场景**：可用于机器人抓取、视觉语言导航(VLN)等具身智能任务，支持快速搭建智能体基准测试环境，游戏智能体分支已独立维护。
