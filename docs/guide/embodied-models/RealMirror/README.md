## 项目概述

RealMirror 是一个全面的开源具身智能视觉语言模型（VLA）平台，已被 ICRA 2026 接收。该平台提供了完整的 VLA 研究基础设施，并推出了基于 Seed2Scale 方案的大规模上肢轨迹自动生成技术。

主要特点和更新：
- 基于 Seed2Scale 方案的大规模上肢轨迹自动生成，提供基于模式的生成范式，达到 SOTA 性能
- MirrorLimb 添加了手势遥操作功能，可以使用 PICO 对机器人进行更精确稳定的控制
- 即将提供基于 Seed2Scale 方案的轨迹自动生成示例数据集，以及相应的视觉物理回放工具和定量评估结果

该项目为具身智能 VLA 研究提供了完整开放的平台支持。
