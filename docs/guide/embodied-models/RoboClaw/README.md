RoboClaw 是一个具身人工智能助手。

## 项目链接

- GitHub: <https://github.com/MINT-SJTU/RoboClaw>

## 项目概述

## 项目介绍
RoboClaw是一款开源具身智能助手，目前处于早期开发阶段，聚焦于具身AI领域，支持社区协作开发。它提供了完整的具身智能工作流，当前已实现对话式机械臂设置、校准、遥操作、数据采集、训练与推理功能，后续还将推出网页控制面板与移动端支持。

## 主要特性
1.  开源开放，支持社区共建，可通过Issue、PR参与功能讨论与代码贡献
2.  覆盖机械臂对话式操控全流程，包含设置、校准、数据采集、模型训练与推理
3.  提供CLI交互方式，支持Docker与非Docker两种部署方案
4.  核心聚焦于具身AI架构、ROS2集成、模拟器适配与真实机器人落地等方向
