## 项目概述

VITA (Vision-to-Action Flow Matching Policy) 是 ICLR 2026 发表的一种无噪声、无条件约束的策略学习框架，通过直接将潜在图像映射到潜在动作来学习视觉运动策略。

该方法相比传统方法达到了最先进的性能和精度，同时显著减少了时间和空间开销，并加快了收敛速度。VITA 能够自然地学习以动作中心的视觉表示，从而使视觉和动作的潜在流形紧密对齐。这种归纳偏置使得仅使用 MLP 架构就能实现强大的性能。

项目已开源官方实现代码，并集成到 RoboVerse 框架中。
