# VLA-Handbook

- 项目链接：https://github.com/sou350121/VLA-Handbook

## 项目概述

本项目旨在为致力于进入 VLA（视觉-语言-动作）领域的算法工程师提供一份全中文、实战导向的学习与面试指南。不同于通用的 CV/NLP 面试手册，本项目聚焦于机器人学特有的挑战。

主要内容和功能：
- 每日自动更新内容，提供 PULSAR 每日精选和 15 个 VLA 方法族的趋势分析
- 支持 RSS 订阅，及时获取最新论文和动态
- 提供 VLA Expert Skill 工具，可让 AI 编程助手变成 VLA 专家
- 姊妹项目 Spatial-Intelligence-Handbook 专注于世界表示（3DGS/VGGT/深度基础模型等）
