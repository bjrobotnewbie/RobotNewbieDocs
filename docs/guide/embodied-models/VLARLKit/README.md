# VLARLKit

- 项目链接：https://github.com/VLARLKit/VLARLKit

## 项目概述

VLARLKit 是一个优雅且对研究者友好的 PyTorch 库，专门用于视觉-语言-动作（VLA）模型的强化学习研究。

主要特点：
- 实现简单清晰：策略、生成、运行器和模型层清晰分离，最小化抽象，易于阅读、修改和扩展
- 依赖解耦架构：模型后端使用独立的 uv 项目，基准环境作为独立 ZMQ 进程运行，避免核心库的依赖冲突
- 异步离线策略训练：支持异步离线策略训练，在模型更新时实现非阻塞数据收集

支持多种 RL 算法（PPO、GRPO、DSRL、RLT 等）、多种基础模型和多个基准测试环境，为 VLA 研究提供完整基础设施。
