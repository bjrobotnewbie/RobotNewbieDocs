## 项目概述

## 项目介绍
VLM-R1是一款稳定且可泛化的R1风格大视觉语言模型，主打通过强化学习（RL）优化视觉语言模型（VLM）完成视觉理解任务。项目基于Qwen2.5-VL，针对指代表达式理解（REC）等任务，对比了监督微调（SFT）和RL微调的效果：小训练步数下SFT与RL模型域内性能相近，但随着训练步数增加，SFT模型域外性能下降，而RL模型可将推理能力泛化至域外数据。其数学模型在4B参数以下的Open-Compass数学榜单排名第一，开放词汇检测（OVD）模型在OVDEval上达到当前最优性能。项目提供了Demo、数据集、模型权重下载渠道，以及技术报告和博客链接。

## 主要特性
1.  支持全参数GRPO强化微调
2.  支持冻结视觉模块的微调方式
3.  支持LoRA轻量化GRPO强化微调
