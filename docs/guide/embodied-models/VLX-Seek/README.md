# VLX-Seek

VLX-Seek 是一款原生视觉语言模型，使机器能够以高精度地“看”、“理解”并“推理”视觉世界。

## 项目链接

- GitHub: <https://github.com/om-ai-lab/VLX-Seek>
- 项目主页: <https://om-agent.com>

## 项目介绍
VLX-Seek是一款面向边缘端具身视觉的细粒度感知视觉语言模型（VLM），可让机器高精度地感知、理解并推理视觉世界。它不仅能识别图像中的内容，还可定位相关物体、确定指代实例，甚至判断目标是否不存在，适用于需要精准视觉定位与语义理解的具身智能场景。

## 主要特性
1.  采用区域检索与区域引用的本地化新思路，将候选区域编码为可寻址的区域令牌，由语言模型通过选择、比较和引用这些区域来完成定位任务，而非直接生成边界框坐标。
2.  支持云端与边缘端部署，提供了官方在线Demo、Hugging Face模型与博客教程，可快速体验与部署。
3.  适配多模态细粒度感知需求，可应用于需要精准视觉语义交互的具身智能场景。
