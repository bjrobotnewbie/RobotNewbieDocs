## 项目概述

## 项目介绍
本项目是一个视觉语言模型（VLM）领域的前沿综述与资源集合，持续更新中，收录了相关顶会论文与开源模型仓库。项目附带arXiv综述论文与实时趋势仪表盘，提供了VLM架构演进、基准测试、应用场景与挑战的全面梳理。

## 主要特性
1.  **架构演进梳理**：将VLM发展划分为四个阶段，其中第三阶段分为两个分支：
    -  Era3a：原生多模态输入+文本输出，代表模型包括Qwen3.5/3.6、GPT-5.4等通用旗舰模型
    -  Era3b：全模态统一I/O，支持图像、视频、语音生成，代表模型有BAGEL、DeepSeek-Janus-Pro、Sora 2等
    -  Era4：2026年起的世界行动模型，将动作作为一级模态，实现感知、生成与决策闭环
2.  覆盖全链路VLM资源，包含从基础对齐模型到通用多模态大模型再到跨模态生成、世界模型的全品类项目与论文。
