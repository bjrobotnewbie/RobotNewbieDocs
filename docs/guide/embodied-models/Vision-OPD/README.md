# Vision-OPD

Vision-OPD 是一种区域到全球的基于策略的自我蒸馏框架，它通过将模型自身的特权裁剪条件下的感知迁移至其全图策略，实现无需外部教师、标签或验证者即可在一次前向传播中完成细粒度视觉理解。

## 项目概述

## 项目介绍
Vision-OPD是一款面向多模态大模型的在线策略自蒸馏框架，采用区域到全局的知识迁移方式，将模型自身的带条件区域感知能力迁移至全图策略，可在单次前向传播中实现细粒度视觉理解，无需外部教师模型、标注数据、奖励验证器或推理阶段工具辅助。

该项目在V* Bench、ZoomBench、HR-Bench 4K/8K、MME-RealWorld中英文等多个细粒度视觉理解基准测试中取得了优异表现。

## 主要特性
1.  **无依赖训练**：无需外部教师模型、人工标注或验证工具即可完成训练
2.  **高效推理**：仅需单次前向传播即可实现细粒度视觉理解
3.  **适配多场景**：支持多种细粒度视觉理解基准测试，包括图像细节识别、高分辨率图像分析等场景
4.  提供完整的部署与评估流程，支持通过vLLM部署模型并使用OpenAI兼容API调用，同时提供标准化评测脚本。
