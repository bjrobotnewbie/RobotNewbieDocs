## 项目概述

WholeBodyVLA 是 ICLR 2026 发表的论文，提出了面向全身灵巧操作控制的统一潜在视觉-语言模型，用于大空间人形机器人运动操作控制。

这是一个统一的视觉-语言-动作框架，主要特点：
- 针对大空间人形机器人运动操作控制的视觉-语言-动作框架
- 一种新方法，可以从操作和操作感知运动视频中学习统一潜在动作，无需动作标注
- 面向运动的强化学习策略，能够在干扰下实现精确稳定的全身协调

该方法通过潜在动作模型（LAM）从无动作的第一视角视频中学习统一潜在动作，采用面向运动操作的强化学习策略实现精确稳定的全身协调。系统将第一视角图像和语言指令编码为潜在动作令牌，解码为双臂关节动作和运动命令，实现复杂运动操作任务的端到端控制。
