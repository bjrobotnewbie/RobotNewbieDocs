# WorldArena

- 项目链接：https://github.com/tsinghua-fib-lab/WorldArena
- 项目主页：https://world-arena.ai/

## 项目概述

WorldArena 是一个用于评估具身世界模型感知能力与功能效用的统一基准平台。该项目在 CVPR 2026 举办了相关挑战赛。

该基准平台提供：
- 完整的数据集（在 HuggingFace 上发布）
- 视频质量评估和具身任务评估
- 在线排行榜和提交系统
- 在线竞技场和人工评估支持

WorldArena 为研究社区提供了标准化的评估框架，用于比较不同具身世界模型的性能。
