# XR-1

- 项目链接：https://github.com/Open-X-Humanoid/XR-1
论文链接：https://arxiv.org/abs/2511.02776

## 项目概述
XR-1是一个通用且可扩展的视觉语言动作框架，支持在多种机器人形态和环境中进行稳健的多任务学习，被收录为ICML2026的口头报告论文。其核心特点包括：
1. 统一的视觉-运动表示学习：通过学习统一的表示实现跨不同机器人形态的任务迁移
2. 多功能性：支持从预训练到微调的完整VLA模型开发流程
3. 丰富的资源：已在HuggingFace和ModelScope上发布预训练模型和异构数据集样本
4. 持续更新：计划发布真实世界的部署示例

该项目目前已发布预训练/微调代码、预训练模型和数据集，正在开发真实世界部署示例。
