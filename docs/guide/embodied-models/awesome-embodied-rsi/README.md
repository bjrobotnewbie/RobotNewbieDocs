# awesome-embodied-rsi

Embodied 递归自我改进（Embodied RSI）研究、系统、基准及行业更新的精选列表。

## 项目链接

- GitHub: <https://github.com/cocacola-lab/awesome-embodied-rsi>

## 项目介绍
本项目是一个经过人工审核的精选列表，聚焦具身递归自我改进（Embodied RSI）领域，收录相关学术研究、系统实现、基准测试与行业动态，目标是推动“机器人自主改进机器人”的实现，搭建面向可通过交互经验持续自我进化的具身智能体的资源地图。

## 主要特性
1.  **分类清晰**：按照RSI能力等级分为L0到L4，核心收录L2-L4的高阶具身递归自我改进内容，L0-L1作为基础补充
2.  **内容全面**：包含39篇学术研究、2条行业动态、1个基准测试与2篇综述论文
3.  **维护活跃**：每周更新资源列表，提供中文翻译版本与分类 taxonomy 文档
4.  遵循`体验→评估→更新→重新部署`的闭环迭代逻辑，覆盖具身智能体从基础感知到开放式自主进化的全链路研究资源。
