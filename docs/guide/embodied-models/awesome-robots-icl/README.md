## 项目介绍
本项目是《In-Context Learning for Robots: Methods and Applications》论文的配套仓库，聚焦机器人领域的上下文学习研究，围绕“如何将上下文转化为动作”这一核心问题，整理了相关的方法、数据集与基准测试，覆盖582项研究成果，为机器人无需针对每个新任务重新训练即可利用演示、指令与交互完成任务的相关研究提供系统化的资源支撑。

## 主要特性
1. 按分类和发布时间组织机器人上下文学习相关的方法、数据集与基准测试资源
2. 覆盖从控制与策略学习到上下文任务学习、物理递归自我改进、集体知识演化的全链条研究内容
3. 关联论文、技术报告、代码等多类型研究资料，为机器人领域上下文学习的研究提供全面的参考集合
