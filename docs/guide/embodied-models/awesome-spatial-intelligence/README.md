## 项目概述

## 项目介绍
本项目是论文《Forging Spatial Intelligence: A Roadmap of Multi-Modal Data Pre-Training for Autonomous Systems》的官方资源汇总仓库，针对自主系统的多模态数据预训练领域构建了系统化分类体系，统一了该领域的术语、研究范围与评估基准。

## 主要特性
1.  **单模态预训练**：作为感知基础，通过对比学习、掩码建模、未来预测等自监督学习方法，从相机或LiDAR单传感器流中提取基础特征，为传感器专属任务提供基础表征。
2.  **多模态预训练**：利用跨模态协同融合异构传感器数据，分为以LiDAR为中心（将视觉语义融入几何信息）、以相机为中心（将几何先验注入视觉）以及统一框架三类，弥合语义与几何的差距。
3.  **开放世界感知与规划**：作为具身自主前沿方向，涵盖生成式世界模型、具身视觉语言动作(VLA)模型以及开放世界推理系统，实现从被动感知到主动决策的演进。

本仓库还包含相关基准数据集与论文引用信息，欢迎贡献PR。
