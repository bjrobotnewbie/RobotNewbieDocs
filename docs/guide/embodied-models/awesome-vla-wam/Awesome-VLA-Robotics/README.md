## 项目介绍
Awesome-VLA-Robotics是一个针对机器人领域视觉-语言-动作（VLA）模型的综合资源列表，收录了相关的优质研究论文、模型、数据集等内容，配套的综述论文即将发布，且欢迎社区贡献。该项目聚焦于面向机器人与具身智能的VLA模型，这类模型可整合视觉感知、自然语言理解与动作生成，实现端到端或紧密集成的处理，区别于传统机器人系统的模块化设计。

## 主要特性
- 资源分类清晰：涵盖VLA模型定义、综述论文、关键VLA模型及研究论文（按应用领域、技术方法细分）、数据集与基准测试、挑战与未来方向、相关资源列表等模块。
- 应用场景广泛：覆盖机器人操作、导航与移动操作、人机交互、任务规划与推理、人形机器人等多个机器人领域。
- 技术维度全面：包含模型架构、动作表示与生成、学习范式、输入模态与 grounding、微调改进方法等技术方向的内容。
