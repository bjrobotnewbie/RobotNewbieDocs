# awesome-vla-wam

一份精选的视觉 - 语言 - 动作（VLA）与世界动作模型（WAM）研究综述及更多相关内容

## 项目链接

- GitHub: <https://github.com/DravenALG/awesome-vla-wam>

## 项目介绍
本项目是一个精选整理的视觉-语言-动作模型（VLA）、世界动作模型（WAM）及相关机器人基础模型研究资源列表，旨在系统性梳理该领域的最新进展，理清不同研究方向间的关联，为机器人通用大模型开发提供参考。项目会随领域发展持续更新，欢迎贡献相关论文资源。

## 主要特性
1.  **分类清晰的资源框架**：涵盖VLA模型、WAM、策略模型、隐式动作模型、人类动作预训练、代码即策略等多个研究方向，同时提供机器人数据集、人机视角数据集、评测基准、物理引擎、软硬件工具等配套资源
2.  **明确定义说明**：对VLA、WAM等核心技术术语给出官方定义，例如VLA是基于预训练视觉语言模型构建的机器人策略，由RT-2正式提出
3.  **持续维护更新**：欢迎通过PR或Issue提交相关研究成果，共同维护高质量的领域资源列表
