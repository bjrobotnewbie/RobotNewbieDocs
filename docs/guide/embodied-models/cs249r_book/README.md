## 项目介绍
本项目是哈佛大学CS249r课程配套教材《Machine Learning Systems: Foundations, Scaling, Agentic AI, and Physical AI》（共四卷），官方网站为https://mlsysbook.ai。项目提供多语言版本文档，配套包含TinyTorch、MLSys·im等教学工具，以及实验课程、硬件套件相关的实践资源，用于讲解人工智能系统工程的原理与实践。

## 主要特性
1.  分为四卷内容：基础理论、模型扩展、智能体AI、物理AI
2.  提供中英日韩多语言文档支持
3.  配套完整的教学工具链与实践实验资源，涵盖代码、仿真、硬件套件等
4.  持续进行自动化构建与内容校验，保障文档与代码质量
