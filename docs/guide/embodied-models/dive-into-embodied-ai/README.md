# dive-into-embodied-ai

Build an embodied intelligent robot from scratch: Engineering implementation of intelligent decision-making methods including RL, World Model, VLA, covering skill tree modules such as simulation environment, controller, motion planning and perception system, and running through the complete "decision-making - control - perception" pipeline in real projects.

## 项目概述

## 项目介绍
本项目是具身智能入门与求职开源教程，旨在从零到一搭建具身智能机器人，完成强化学习、World-Model、VLA等智能决策方法的工程落地，覆盖仿真环境、控制器、运动规划、感知系统等模块，跑通"决策—控制—感知"完整链路。项目分为零基础入门、项目实战、理论技能树三个阶段，当前为Alpha内测版本，仍在重构完善中。

## 主要特性
1.  **内容分层**：提供零基础学习路径，从完整仿真项目建立整体认知，同时覆盖多类型机器人实战（四足、机械臂、人形等）与理论学习
2.  **实战覆盖**：已完成四足机器人仿真项目、强化学习与VLA基础理论内容，机械臂、双足机器人等实战章节部分可用
3.  **技术栈全面**：涉及MuJoCo、Isaac Lab仿真环境，ROS2，PPO、DDPG等RL算法，RT-1/RT-2、OpenVLA等VLA模型，完整覆盖具身智能工程链路
4.  支持在线阅读，采用CC BY-NC-SA 4.0开源许可协议。
