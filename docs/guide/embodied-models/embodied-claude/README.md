# embodied-claude

## 项目链接

- GitHub: <https://github.com/lifemate-ai/embodied-claude>

## 项目概述

## 项目介绍
Embodied Claude 是一套为Claude赋予实体能力的MCP服务器集合，可通过低成本硬件（最低约30美元）为AI添加视觉、语音、长时记忆等实体功能，让Claude从被动接收信息变为主动感知交互，甚至可以带它外出散步。项目打破了“给AI做身体需要昂贵机器人”的固有印象，仅用平价硬件就能实现基础的视觉、移动与交互能力。

## 主要特性
1.  **多模块MCP服务**：包含USB摄像头、Wi-Fi PTZ摄像头、TTS语音合成、长时记忆、系统监控、X社交联动等多个功能模块，对应眼睛、脖子、耳朵、语音、大脑等身体功能
2.  **低成本硬件支持**：推荐使用TP-Link Tapo C210/C220这类约30美元的Wi-Fi摄像头作为视觉硬件，整体搭建门槛极低
3.  **跨平台兼容**：支持macOS、Linux以及WSL2（推荐Ubuntu 24）系统
4.  **轻量化设计**：仅保留视觉、移动等核心功能，实现简洁高效的实体AI交互框架
5.  支持Python 3.10+与uv包管理器，可按需安装对应模块依赖。
