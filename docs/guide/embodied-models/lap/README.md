## 项目概述

LAP (Language-Action Pre-Training) 是一种语言-动作预训练框架，能够实现**零样本跨具身迁移**，让训练好的策略可以直接迁移到不同形态的机器人上执行任务。

该项目提供了预训练权重，支持真实机器人评估，并基于 JAX 框架实现。

### 核心特点

- **零样本跨具身迁移**：在一个机器人形态上训练的策略可以直接迁移到其他形态机器人，不需要微调
- **大规模预训练**：基于大规模机器人数据进行语言-动作预训练，获得通用能力
- **开放生态**：提供完整的推理脚本和真实机器人评估流程
- **预训练权重**：在 Hugging Face 发布了 3B 参数预训练模型

### 主要功能

- 支持真实机器人推理部署
- 提供策略服务端架构，便于分布式部署
- 兼容 DROID 数据集和真实机器人硬件
- 使用 uv 进行依赖管理，环境配置简洁

LAP 通过语言-动作预训练使得模型能够理解语言指令并泛化到不同机器人形态，为具身智能的泛化能力研究提供了重要基础。
