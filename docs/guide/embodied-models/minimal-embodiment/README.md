# minimal-embodiment

一个为大语言模型提供带有自我感知环路的闭环物理具身的极简软硬件架构。

- GitHub: <https://github.com/oliviazzzu/minimal-embodiment>

## 项目概述

## 项目介绍
本项目是论文《A Minimal Self-Perceiving Embodiment for Large Language Models》的参考实现，为大语言模型提供闭环物理实体与自我感知循环。硬件基于ESP32，搭载环境、光线、运动、声音四类传感器，以及触觉、OLED显示屏、蜂鸣器三类输出通道，其中两路输出可反馈回输入，让模型能够感知自身的动作。

项目包含桥接服务、ESP32固件等代码，论文对应的固定版本在`v1.0-paper`标签，`main`分支为迭代开发版本，新增了嗅觉等扩展感知能力。

## 主要特性
1.  **轻量软硬件架构**：仅依赖Node.js标准库构建桥接服务，固件为约1.1k行C++的Arduino草图
2.  **完整闭环感知**：支持传感器数据采集、动作输出，实现自我感知循环，可复现论文中的自我感知测量实验
3.  **可扩展设计**：预留扩展接口，可新增更多感知模块
4.  附带完整的实验验证数据与快速启动脚本，提供详细搭建指南
