# system1-agents

系统 1 决策模型（Jev、Laya、Cua-S1）作为智能体的大脑：浏览器使用、电脑使用、游戏与机器人学

## 项目链接

- GitHub: <https://github.com/ThinkFlowLab/system1-agents>

## 项目介绍
system1-agents 是为智能体提供 System 1 决策模型的工具，可基于预构建智能体或自定义智能体运行，支持浏览器操作、计算机操作、机器人任务及游戏场景，依托 Jev、Laya、Cua-S1 Nano 三类模型实现决策能力。

## 主要特性
- 性能优势：在相同任务得分下，速度比普通聊天模型最高提升6.39倍，成本最高降低25.3倍
- 部署灵活：支持从 Claude Code 或 Codex 启动，可快速构建或运行智能体
- 场景适配：覆盖浏览器操作、计算机操作、机器人任务、游戏等多类应用场景，开箱即用
