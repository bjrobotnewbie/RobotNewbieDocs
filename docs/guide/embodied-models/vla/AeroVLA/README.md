## 项目概述

## 项目介绍
AeroVLA（原名为AerialVLA）是一款被ECCV 2026收录的无人机视觉语言动作模型，采用极简端到端控制方案，可将原始视觉观测和模糊语言指令直接转换为连续物理控制信号，解决无人机视觉语言导航（VLN）中的语义鸿沟与自主性不足问题。
项目基于TravelUAV基准测试，在可见环境中实现了当前最优性能，在不可见场景中成功率达到主流基线的近三倍，具备优秀的泛化能力，同时支持仿真到现实的迁移。

## 主要特性
1.  采用精简双视图感知策略，减少视觉冗余同时保留导航与精准定位所需关键信息
2.  仅依赖机载传感器的模糊方向提示机制，无需依赖密集 oracle 引导
3.  统一控制空间整合3自由度运动指令与内置着陆信号，无需额外目标检测器即可完成精准着陆
4.  已开源训练代码、训练数据集、评估代码与预训练LoRA权重，支持自定义模型训练。
