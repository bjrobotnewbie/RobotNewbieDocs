# Awesome-Astra-Embodied-AI

GPT-6 Astra：面向具身智能与机器人应用的模型。

## 项目链接

- GitHub: <https://github.com/zjwzcx/Awesome-Astra-Embodied-AI>

## 项目介绍
本项目是面向具身智能与机器人领域的GPT-6 Astra资源合集，整理了基于Astra的机器人工作流与演示案例，按工作流分类并以发布时间倒序排列。

## 主要特性
1.  **零样本控制**：包含12个仿真部署案例、10个真实世界部署案例，涵盖双机械臂空间约束任务、纯视觉类人机器人控制、机器人抓取等场景
2.  **智能策略调用**：提供2个相关案例
3.  **实到仿真回放/数据部署**：包含6个相关案例
4.  **RL训练支持**：可构建RL训练环境并开展训练，共6个案例
5.  **公开基准测试与评估报告**：提供相关评测资源

项目收录了多个最新发布的机器人智能控制演示，支持从仿真到真实场景的机器人零样本控制，可用于机器人运动规划、具身智能算法验证与落地研究。
