# Awesome-Embodied-AI

精选具身智能列表：涵盖综述、视觉 - 语言模型（VLA）、数据集、模拟器、人形机器人、机器人学习及安全资源。

## 项目链接

- GitHub: <https://github.com/wadeKeith/Awesome-Embodied-AI>

## 项目介绍
这是一个精心整理且持续维护的具身人工智能（Embodied AI）资源合集，涵盖综述论文、视觉语言动作（VLA）模型、数据集、仿真环境、人形机器人、机器人学习以及安全相关资源，面向领域新手、研究者和开发者，提供快速入门和实践参考。项目目前收录超430个资源，分为10大研究与工具赛道，支持通过PR和issue进行社区维护更新。

## 主要特性
1.  覆盖完整具身AI生态：包含综述、感知模型、大脑模型、VLA模型、强化学习（RL）、机器人代码策略、上下文学习等多个赛道
2.  适配不同用户需求：新手可从综述入手，开发者可直接调用仿真、数据集工具，研究者可获取前沿模型与安全相关研究资源
3.  持续更新维护：近期新增了触觉预测、人形机器人操控导航、VLA安全、具身基准自动化等多个方向的最新研究成果
4.  支持社区贡献：可通过提交PR添加资源、修复链接或新增分类，欢迎Star和引用。
