# Awesome-LLM4AD

一份精选的自动驾驶领域大语言模型（LLM）、视觉语言模型（VLM）和视觉 - 语言 - 动作模型（VLA）及世界模型（World Model）资源列表（LLM4AD），持续更新中。

## 项目链接

- GitHub: <https://github.com/Thinklab-SJTU/Awesome-LLM4AD>

## 项目介绍
本项目是由上海交通大学ReThinklab维护的自动驾驶领域大模型（LLM4AD）资源汇总列表，持续更新以追踪该领域前沿进展，涵盖LLM4AD（自动驾驶大语言模型）、VLM4AD（自动驾驶视觉语言模型）、VLA4AD（自动驾驶视觉语言动作模型）等相关研究资源，包含对应论文、数据集等内容，还配套发布了相关综述论文《LLM4Drive: A Survey of Large Language Models for Autonomous Driving》。

## 主要特性
1. 聚焦自动驾驶领域的大模型相关资源，覆盖LLM、VLM、VLA、世界模型等细分方向
2. 资源分类清晰，包含研究论文、数据集等核心内容
3. 持续更新维护，同步领域最新研究进展
4. 提供引用指引，方便相关研究参考使用
