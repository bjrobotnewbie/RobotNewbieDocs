## 项目介绍
本项目是针对多模态智能研究的精选资源库，聚焦VLM、VLA、世界模型及通用具身智能方向，追踪从感知到决策的下一代智能体技术，收录前沿论文、开源代码与数据集，助力相关领域研究。

## 主要特性
1. 资源分类清晰，下设VLMs、VLAs、世界模型、通用具身智能四大专题，各专题对应独立资源文档；
2. 覆盖多模态智能全技术栈，从视觉感知与语言理解的桥接，到环境动态建模、端到端感知-决策闭环，再到真实世界通用智能体的相关资源均有收录；
3. 2026年4月完成全面更新，新增多款主流VLMs资源，新增世界模型与具身AI专题，补全训练数据集与评估Benchmark。
