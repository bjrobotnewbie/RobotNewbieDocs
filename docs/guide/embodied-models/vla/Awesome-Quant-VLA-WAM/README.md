为 VLA 和 WAM 模型定制的研究成果——涵盖 180 多篇论文、五类分类体系、路线图以及配套 PTQ 和 LIBERO 工具集（quant-vla）。

## 项目介绍
本项目是针对视觉语言动作模型（VLA）和世界动作模型（WAM）的量化研究精选列表，收录了180+相关论文，同时提供了五分类研究体系、研究路线图以及配套的PTQ量化工具库quant-vla。项目旨在将大型具身智能策略压缩为低比特模型，同时保留机器人的动作执行能力。

## 主要特性
1.  **完整分类体系**：涵盖迁移的LLM/DiT/VLM基线、VLA专属PTQ、量化感知训练、压缩部署、动作表示与WAM扩展五大类别
2.  **研究路线图**：梳理了2022-2026年的量化技术演进路径，从基础基线到VLA专属量化再到WAM扩展
3.  **配套工具**：即将开源的quant-vla工具栈，支持VLA的PTQ量化以及LIBERO环境评估，兼容OpenVLA、UniVLA等主流VLA架构
4.  新增了结果排行榜与分类对比表格，覆盖VLA与WAM两大模型方向，支持机器人具身智能场景下的模型压缩研究。
