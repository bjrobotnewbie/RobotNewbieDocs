# Awesome-VLA-Post-Training

视觉 - 语言 - 动作模型后训练方法集合

## 项目链接

- GitHub: <https://github.com/AoqunJin/Awesome-VLA-Post-Training>

## 项目介绍
Awesome-VLA-Post-Training 是一个持续更新的视觉-语言动作（VLA）模型后训练方法资源集合，为具身智能领域提供集中式研究更新、实用代码与实现见解，旨在提升VLA智能体在物理环境中的感知、推理与行动能力，聚焦环境感知增强、具身意识提升、任务理解与泛化深化、多组件集成调优等方向，面向VLA系统研究人员与从业者开放贡献。

## 主要特性
- 收录领域前沿研究成果，包含RT-1、RT-2、Octo、OpenVLA、RDT-1B等代表性VLA相关论文、基准与项目
- 持续迭代更新，已发布v2、v3版本，累计新增超150篇相关论文及对比基准
- 提供核心研究方向指引，助力VLA模型后训练相关研究与实践推进
