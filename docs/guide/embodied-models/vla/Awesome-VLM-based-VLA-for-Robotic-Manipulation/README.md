# Awesome-VLM-based-VLA-for-Robotic-Manipulation

一个精选的用于机器人操作的大型视觉语言模型（VLM）- 通用动作模型（VLA）模型列表。

## 项目链接

- GitHub: <https://github.com/iLearn-Lab/Awesome-VLM-based-VLA-for-Robotic-Manipulation>

## 项目介绍
本项目是面向机器人操作的基于大视觉语言模型（VLM）的视觉语言动作（VLA）模型精选资源库，配套于同名综述论文《Large VLM-based Vision-Language-Action Models for Robotic Manipulation: A Survey》。这类模型通过耦合感知、语言理解与动作生成，可让机器人解读自然语言指令、感知复杂环境并完成多样操作任务，具备强泛化能力。本仓库整理了综述中涵盖的全部相关研究论文、基准测试数据集与资源，方便开发者查阅参考，且会持续更新领域最新成果。

## 主要特性
1.  是首个针对该领域的系统性梳理资源库
2.  按模型架构分为单体模型（单系统、双系统）、分层模型（仅规划器、规划+策略）以及其他前沿方向（基于强化学习、零训练、从人类视频学习、基于世界模型等）分类整理
3.  附带数据集与基准测试板块
4.  持续更新领域最新发表的相关研究工作
