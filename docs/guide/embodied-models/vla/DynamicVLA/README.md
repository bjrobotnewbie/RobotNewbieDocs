# DynamicVLA

DynamicVLA: 面向动态物体操作的一体视听动作模型"（arXiv 2601.22153）的官方实现。

## 项目链接

- GitHub: <https://github.com/hzxie/DynamicVLA>
- 项目主页: <https://haozhexie.com/project/dynamic-vla>

## 项目介绍
DynamicVLA是官方实现的面向动态物体操作的视觉-语言-动作模型，来自南洋理工大学S-Lab的研究团队，对应arXiv预印本论文2601.22153。项目配套提供了DOM数据集与预训练模型，支持动态物体操控相关的机器人视觉语言任务，可用于机器人动态物体抓取、操作等场景。

## 主要特性
1.  专为动态物体操控设计的视觉-语言-动作模型
2.  配套开源DOM数据集，包含训练集、测试集、3D物体与场景资源
3.  提供基于DOM训练的预训练模型
4.  支持通过conda创建独立环境分别进行模型训练推理与Isaac Lab仿真评估，推荐Python3.10环境。
