## 项目概述

## 项目介绍
本项目是首个针对高效视觉语言动作模型（Efficient VLAs）的系统性综述仓库，覆盖了"数据-模型-训练"全流程相关研究。项目会持续更新维护，跟进领域最新进展。综述梳理了高效VLA的三大核心支柱：高效模型设计、高效训练、高效数据采集，同时涵盖了VLA基础、关键应用、挑战与未来方向，为可扩展具身智能发展提供基础框架。

## 主要特性
1.  **核心分类清晰**：将高效VLA划分为高效模型设计、高效训练、高效数据采集三大模块
2.  **覆盖维度全面**：模型设计包含高效架构、模型压缩等细分方向；训练涵盖高效预训练与后训练策略；数据部分包含高效采集与增强方法
3.  **持续更新维护**：会定期跟进最新顶会顶刊研究，近期已更新2025.11到2026.05的机器人操作相关高效VLA论文，重点关注模型、适配与数据效率
4.  提供官方论文与项目网站链接，方便快速获取详细综述内容
