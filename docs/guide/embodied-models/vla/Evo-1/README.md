# Evo-1

Evo-1：轻量级视觉 - 语言 - 动作模型，保留语义对齐

## 项目链接

- GitHub: <https://github.com/MINT-SJTU/Evo-1>

## 项目介绍
Evo-1是一款轻量级视觉语言动作模型，已被CVPR 2026收录，主打保留语义对齐能力。它支持在MetaWorld、LIBERO等机器人仿真环境以及真实机械臂（如xarm6、Aloha双臂）上部署，已集成到LeRobot、RLinf主流机器人学习框架，还提供了Jetson Orin部署方案。

## 主要特性
1.  **轻量化设计**：兼顾性能与部署效率，支持快速训练且降低GPU显存占用
2.  **多场景适配**：可完成单臂、双臂机器人任务，覆盖MetaWorld、LIBERO、RoboTwin共超百个机器人操作任务
3.  **完善生态**：提供官方代码、预训练模型权重、数据集以及多框架集成支持，包含完整的训练、推理与评测流程
4.  **语义对齐保障**：在任务执行中保留输入指令与动作的语义一致性，提升机器人任务完成精度
