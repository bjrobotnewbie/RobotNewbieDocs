# FASTER

[NeurIPS 2026] FASTER: 重新思考实时流视觉生成对抗网络

## 项目链接

- GitHub: <https://github.com/hku-sail/FASTER>
- 项目主页: <https://hku-sail.github.io/FASTER/>

## 项目介绍
FASTER是NeurIPS 2026收录的研究项目，为VLAs（视觉语言动作模型）的实时反应问题提供了新范式，基于openpi框架实现，同时包含Training-time RTC的非官方实现。该项目针对VLAs实时响应受推理延迟、动作块生成与执行方式双重约束的痛点，提出将快速动作采样过程压缩为单一步骤，实现了比π₀.5和X-VLA快10倍的加速效果，可满足乒乓球等高度动态任务的实时响应需求。

## 主要特性
1. 针对VLAs实时反应的核心瓶颈，创新异步执行下的快速动作采样范式；
2. 将采样过程压缩为单一步骤，实现10倍于现有主流模型的推理加速；
3. 支持高度动态任务的实时响应，已在乒乓球场景完成验证；
4. 提供官方实现及Training-time RTC的非官方实现，代码已开源。
