## 项目概述

## 项目介绍
Galahad 是一个针对视觉语言动作（VLA）策略的研究项目，聚焦于**指令盲视**问题：即VLA模型会通过位置捷径完成任务，而非真正理解指令文本，属于模仿学习中的因果混淆现象。项目提供了论文、验证模型、去混淆数据集、数据生成工具以及标准化测试套件，相关成果目前为预印本状态。

## 主要特性
1.  **问题诊断**：验证了指令盲视是可量化的因果混淆问题，现有模型在目标重命名测试中仅能0-1%正确完成语言接地
2.  **低秩数据修复方案**：无需修改模型架构，仅通过低秩更新的数据配方即可修复该问题，修复后接地准确率可达94.5%，远优于全量微调的12.5%
3.  **验证模型**：发布的Galahad模型可在目标重命名测试中200/200正确匹配新命名目标，中位误差仅2mm，同时支持7类参考语义轴的语言接地
4.  **标准化测试套件**：提供一键式测试工具，可快速评估任意兼容VLAWrapper的策略的语言接地、视觉使用、指令理解能力
