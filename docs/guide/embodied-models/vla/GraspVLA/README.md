# GraspVLA

[CoRL25] GraspVLA：基于十亿级合成动作数据的抓取基础模型

## 项目链接

- GitHub: <https://github.com/PKU-EPIC/GraspVLA>

## 项目介绍
GraspVLA是一篇被CoRL25收录的机器人抓取基础模型，基于十亿级规模的合成动作数据预训练而成。该项目提出了仅使用合成数据进行VLA模型预训练的高效范式，可实现直接的 sim-to-real 迁移，且具备优秀的零样本泛化能力。项目配套了SynGrasp-1B十亿帧合成抓取数据集，覆盖240个物体类别、超10000个物体，同时提供模型服务、仿真测试环境、真实机器人控制接口等工具。

## 主要特性
1.  推出SynGrasp-1B十亿帧合成抓取数据集，覆盖丰富的物体品类
2.  基于SynGrasp-1B预训练的GraspVLA模型，无需微调即可实现零样本真实世界抓取
3.  采用统一思维链框架，将自回归感知与基于流匹配的动作生成整合为单一推理流程，支持在合成动作数据与互联网级语义数据上联合训练，实现开放词汇抓取
4.  模型推理延迟约200ms，单张NVIDIA RTX L40s显卡仅需约9GB显存即可运行。
