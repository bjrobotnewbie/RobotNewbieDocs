# GreenVLA

Green-VLA：通用机器人 staged 视觉 - 语言 - 动作模型

- GitHub: <https://github.com/greenvla/GreenVLA>
- 项目主页: <https://greenvla.github.io/>

## 项目介绍
GreenVLA是一款面向通用机器人的分阶段视觉语言动作模型，由Sber Robotics Center机器人操作团队开发。该模型参数量约40亿，采用三级课程训练范式：
1.  **Base阶段**：多构型预训练模型，基于3000+小时机器人演示数据训练，具备多模态对齐能力的VLM骨干网络
2.  **R1阶段**：机器人专属适配，针对目标机器人进行监督微调
3.  **R2阶段**：强化学习策略对齐，在行为克隆基础上通过轨迹优化进一步优化策略。

项目提供了预训练模型、多机器人适配版本的权重下载，配套有论文、项目主页、快速入门和基准测试相关资源。

## 主要特性
1.  支持多机器人构型适配，已发布覆盖2B、5B参数量的多款预训练与微调模型
2.  采用分阶段训练流程，兼顾通用多模态能力与机器人专属任务性能
3.  基于PyTorch2.0+、Python3.11+开发，模型权重托管于HuggingFace Hub。
