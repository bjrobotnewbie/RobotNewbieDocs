# InternVLA-M1

InternVLA-M1：一种面向通用机器人策略的空间引导视觉语言 - 行动框架

## 项目链接

- GitHub: <https://github.com/InternRobotics/InternVLA-M1>
- 项目主页: <https://internrobotics.github.io/internvla-m1.github.io/>

## 项目介绍
InternVLA-M1是面向通用机器人策略的空间引导视觉-语言-动作（VLA）框架，支持在NVIDIA CUDA、Intel XPU或CPU上运行，适配多硬件环境，可用于机器人控制相关场景，相关研究成果已发布于arXiv，提供演示视频与项目页面。

## 主要特性
1. **模块化可扩展**：核心组件（模型架构、训练数据、训练策略、评估流程）完全解耦，支持各模块独立开发、调试与扩展。
2. **双系统双监督**：统一框架下集成语言头与动作头，可通过双监督实现协同训练。
3. **高效训练快速收敛**：通过大规模多模态预训练学习空间与视觉先验，经空间提示微调完成迁移，无需单独动作预训练即可在约2.5个epoch达到SOTA级收敛效果。
4. **适配多场景**：支持利用开源视觉语言模型（如Qwen2.5-VL）进行机器人控制，适用于联合训练动作数据集与多模态数据的团队，以及探索VLA架构与训练策略的研究人员。
