# Large-VLM-based-VLA-for-Robotic-Manipulation

用于机器人操作的基于大型视觉语言模型（VLM）的 VLA 模型精选列表。

## 项目链接

- GitHub: <https://github.com/JiuTian-VL/Large-VLM-based-VLA-for-Robotic-Manipulation>

## 项目介绍
本项目是面向机器人操作任务的大型VLM基Vision-Language-Action(VLA)模型精选资源库，配套发表于arXiv的综述论文《Large VLM-based Vision-Language-Action Models for Robotic Manipulation: A Survey》，目前正在IEEE TPATA Minor Revision阶段。
项目收录了该综述中梳理的所有相关研究论文、数据集与基准测试资源，旨在帮助研究者快速获取该领域的完整参考资料。大型VLM基VLA模型通过耦合感知、语言理解与动作生成，可让机器人理解自然语言指令、感知复杂环境并完成多样化操作任务，具备优秀泛化能力。本仓库会持续更新领域内最新发表的相关工作。

## 主要特性
1.  是首个针对大型VLM基VLA机器人操作模型的系统性整理资源
2.  按模型架构分为单体模型（单系统、双系统）、层级模型（仅规划器、规划器+策略）以及其他前沿方向（RL方法、免训练方法、人类视频学习、世界模型驱动VLA）分类组织资源
3.  同步收录该领域的数据集与基准测试资源
4.  持续更新领域最新研究进展，欢迎社区贡献内容
