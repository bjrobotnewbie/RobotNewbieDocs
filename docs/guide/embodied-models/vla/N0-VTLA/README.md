## 项目概述

## 项目介绍
N0-VTLA是一款基于隐式触觉令牌扩展的视觉-触觉-语言-行动模型，为预训练的视觉-语言-行动(VLA)模型引入触觉感知能力。它不会将触觉图像作为额外相机流输入，而是通过预测隐式触觉令牌来编码下一动作阶段的接触变化，并将其直接作为条件输入给流匹配行动专家。该模型可以捕捉视觉上难以分辨的力、滑动、对齐与卡滞差异等触觉信号。本仓库提供预训练权重、后训练工具和推理服务代码，支持将模型适配到自有机器人和任务中。

## 主要特性
1.  支持使用自有触觉视觉演示数据通过`train.sh`进行后训练
2.  提供数据转换与归一化统计计算脚本，可将数据集转换为标准32维格式
3.  支持通过WebSocket为实体机器人、ZMQ为模拟器提供策略推理服务
4.  附带验证脚本，可测试触觉通路有效性并确保模型在关闭触觉通路时与基础策略保持字节级一致性
5.  模型主干基于PaliGemma(gemma_2b)前缀 + Gemma(300m)行动专家构建
