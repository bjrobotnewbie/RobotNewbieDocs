## 什么是视觉语言动作模型(VLA)

VLA模型学习从\*\*(图像, 语言)\*\* 到**动作**的直接映射：

- 训练：从大规模人机交互数据中端到端学习
- 推理：直接输出动作，一步到位
- 优势：架构简洁，推理速度快
- 局限：缺乏物理直觉，泛化能力相对较弱

### F1-VLA

F1: A Vision-Language-Action Model Bridging Understanding and Generation to Actions, arXiv 2025。桥接理解与生成的视觉语言动作模型，结合世界建模知识增强VLA性能。

详细信息：[F1-VLA](/guide/embodied-models/vla/f1-vla/README)

### VLA-JEPA

VLA-JEPA: Enhancing Vision-Language-Action Model with Latent World Model, arXiv 2026。使用潜在世界模型增强视觉语言动作模型，结合JEPA架构。

详细信息：[VLA-JEPA](/guide/embodied-models/vla/vla-jepa/README)

### VideoVLA

VideoVLA: Video Generators Can Be Generalizable Robot Manipulators, NeurIPS 2025。提出视频生成器可以作为通用机器人操作器，将视频生成模型直接用于机器人控制。

详细信息：[VideoVLA](/guide/embodied-models/vla/videovla/README)

### UD-VLA

Unified Diffusion VLA: Vision-Language-Action Model via Joint Discrete Denoising Diffusion Process, arXiv 2025。通过联合离散去噪扩散过程构建VLA模型，统一扩散框架结合世界建模信息。

详细信息：[UD-VLA](/guide/embodied-models/vla/ud-vla/README)

### VLA-RFT

VLA-RFT: Vision-Language-Action Reinforcement Fine-tuning with Verified Rewards in World Simulators, arXiv 2025。在世界模拟器中使用验证奖励进行VLA强化微调，提升预训练VLA模型在下游任务的性能。

详细信息：[VLA-RFT](/guide/embodied-models/vla/vla-rft/README)

### GigaBrain-0

GigaBrain-0: 国内首个利用世界模型生成数据实现真机泛化的视觉-语言-动作（VLA）基础模型，由极佳科技开发。以世界模型为中心，通过世界模型平台 GigaWorld 构建完整具身数据体系，支持多模态输入输出，实现精准移动导航和长序列复杂操作。

详细信息：[GigaBrain-0](/guide/embodied-models/vla/gigabrain-0/README)
