# RoboICL

基于具身上下文学习的 GPT-6 Astra

## 项目链接

- GitHub: <https://github.com/Mosi-AI/RoboICL>

## 项目介绍
RoboICL是基于GPT-6 Astra的具身上下文学习机器人控制框架，属于少样本机器人学习方案，核心是利用冻结的通用视觉语言模型，无需更新机器人特定参数或训练视觉语言动作模型，仅通过演示和自身执行历史实现机器人控制。该框架已发布配套代码与800+交互式评估rollouts，可通过验证后的动作接口连接至RoboDojo平台。

## 主要特性
1. 采用双上下文源机制：演示上下文提供可执行的少样本机器人轨迹示例，交互记忆保留当前执行过程中的动作、反馈与观测结果；
2. 共享交互语法统一两类上下文格式，采用有界锚定记忆机制，保留关键早期与中间交互并留存最新结果用于即时修正；
3. 输入包含左腕、头部、右腕三目相机观测及机器人本体感知数据，可预测双臂笛卡尔动作序列实现闭环执行；
4. 适配Linux+NVIDIA GPU环境，需Isaac Sim 5.1兼容模拟器，模拟器与策略进程采用独立Python环境部署。
