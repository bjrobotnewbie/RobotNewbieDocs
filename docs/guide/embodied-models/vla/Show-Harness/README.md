# Show-Harness

只需一个视觉语言模型（VLM）代理即可控制机器人

## 项目链接

- GitHub: <https://github.com/showlab/Show-Harness>
- 项目主页: <https://showlab.github.io/Show-Harness/>

## 项目介绍
Show-Harness是新加坡国立大学Show Lab推出的基于视觉语言模型(VLM)的机器人智能体框架，能够直接操控实体机器人完成任务。项目提供了完整的工具链，包括数据采集、模型训练和机器人部署方案，配套发布了6个LoRA适配器模型与演示数据集，同时附带了多模态具身智能体综述项目。

## 主要特性
1.  支持两种使用模式，提供统一交互接口
2.  内置GUMI数据采集工具，可以快速收集机器人演示数据
3.  提供完整的训练流水线与插件扩展套件
4.  配套开源了预训练模型、演示数据集与项目代码
5.  可直接部署到实体机器人，实现基于VLM的机器人操控
