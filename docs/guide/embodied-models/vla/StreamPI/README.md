# StreamPI

StreamPI：面向视觉 - 语言 - 动作模型的流式多模态时序建模

## 项目链接

- GitHub: <https://github.com/hku-sail/StreamPI>
- 项目主页: <https://happinesslz.github.io/projects/StreamPI/>

## 项目介绍
StreamPI是面向视觉-语言-动作(VLA)模型的流式多模态时序建模方案，基于openpi开发，额外支持JAX多节点分布式训练，可在不损失模型性能的前提下大幅提升训练效率。该项目针对现有单帧VLA模型无法保留历史观测、窗口多帧模型重复计算全量历史导致算力浪费的问题，将每一组视觉观测与语言指令作为原子时序单元，通过单元内双向注意力保留跨模态对齐，单元间因果注意力捕捉时序上下文，并借助KV缓存避免重复计算历史观测，让预训练单帧VLA模型无需新增参数即可具备时序推理能力，同时支持灵活上下文长度与高效流式推理。

## 主要特性
1.  基于原子时序单元的流式时序建模，无需新增模型参数即可为单帧VLA模型添加时序推理能力
2.  采用KV缓存机制，避免重复计算历史观测，大幅提升推理效率
3.  支持JAX多节点分布式训练，适配大规模训练场景
4.  兼容灵活的上下文长度，支持流式推理与部署
