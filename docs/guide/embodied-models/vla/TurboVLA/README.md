# TurboVLA

TurboVLA: 32 Hz 实时视觉语言 - 动作模型，搭载 RTX 4090，显存占用小于 1 GB

## 项目链接

- GitHub: <https://github.com/H-EmbodVis/TurboVLA>

## 项目介绍
TurboVLA是一款实时视觉语言动作模型，可在RTX 4090显卡上以32Hz的速率运行，显存占用低于1GB。该项目来自华中科技大学与华为团队，提供了官方实现代码、模型权重与演示示例，相关论文已发布在arXiv，同时配有项目主页与Hugging Face模型仓库。

## 主要特性
1.  **极致轻量化高效推理**：在消费级显卡上实现实时运行，单帧推理显存占用小于1GB，帧率可达32Hz
2.  **面向机器人控制**：支持视觉、语言输入到机器人动作的端到端转换，可用于真实机器人任务的同步策略推理
3.  开源生态完善：已发布模型权重、训练与评估代码，采用Apache 2.0开源协议
4.  当前支持NVIDIA GPU，后续计划适配华为昇腾NPU。
