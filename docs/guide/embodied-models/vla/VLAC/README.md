# VLAC

VLAC：一种视觉语言 - 动作 - 批判者模型，用于机器人真实世界强化学习

## 项目链接

- GitHub: <https://github.com/InternRobotics/VLAC>

## 项目概述

## 项目介绍
VLAC是一款面向真实世界机器人强化学习的通用视觉-语言-动作-评判模型，同时配套推出了VLAC-cut视频评判工具。VLAC可基于图像和任务描述，实现任务进度预测与任务完成验证，还支持轨迹质量筛选，能过滤低质量机器人操作轨迹，提升模仿学习效果。项目还提供了在线交互式演示主页。

VLAC训练数据包含3000h+人类第一视角数据、1200h+公开机器人操作数据以及15h+自研操作数据，已推出2B、8B等不同参数量的模型版本。VLAC-cut则可对具身智能轨迹进行优劣片段剪辑，配套提供了带进度标注的数据集与基准测试集。

## 主要特性
1.  **成对比较机制**：提升稠密进度评判精度，可更好识别状态变化，支持以任意步骤作为轨迹起点
2.  **多模态能力**：支持任务进度跟踪、完成度判断、任务描述估计、视觉问答以及具身动作输出，具备完整VLA能力
3.  **灵活小样本学习**：支持零样本、单样本上下文学习，在不同实体、场景和任务中保持优秀性能
4.  **人类任务共情**：基于Ego4D人类数据集，理解通用任务，建立人类任务与具身任务的关联
5.  **轨迹质量筛选**：可评估采集的轨迹，基于VOC值过滤低质量轨迹，屏蔽低流畅度、低质量的动作数据
