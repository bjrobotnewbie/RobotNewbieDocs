## 项目概述

## 项目介绍
VLANeXt 是ICML 2026收录的机器人研究专用代码库，主打简洁且面向科研场景。它支持世界动作模型、隐式动作预训练与微调、类JEPA世界建模、轻量化VLA、语言-动作学习等多项前沿功能，同时兼容多种数据格式与并行评估，还保留了原版代码分支便于复现论文实验。项目提供了官方实现、论文主页、预训练模型以及相关精选开源项目链接。

## 主要特性
1.  支持多类机器人视觉语言学习（VLA）相关研究方向，覆盖世界建模、动作预训练等场景
2.  轻量化代码架构，通过统一配置、训练代码与模型代码适配多种实验设置
3.  提供完整的环境搭建教程，支持LIBERO、LIBERO-plus等主流机器人学习基准测试
4.  附带详细使用教程，方便快速上手配置与运行实验
