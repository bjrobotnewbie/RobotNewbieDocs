## 项目介绍
VLAct是一款基于表征为中心的持续预训练的通用视觉语言动作（VLA）骨干模型，打破了传统仅依赖数据扩容的VLA模型训练思路。项目已公开论文、代码、预训练骨干模型及下游检查点，在RoboDojo排行榜中位列35个策略的第6名，优于同期所有显式世界模型类动作模型。

## 主要特性
1.  采用表征为中心的持续预训练范式，而非单纯扩大训练数据规模
2.  支持通用机器人视觉语言动作任务，可适配多种下游机器人操控场景
3.  提供完整的预训练模型、下游权重及部署代码，可快速上手验证效果
4.  开源了项目主页、演示视频与Hugging Face模型仓库，方便开发者获取资源
