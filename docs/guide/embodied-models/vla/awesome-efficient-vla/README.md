## 项目概述

## 项目介绍
这是一个精选的高效视觉语言动作模型（Efficient VLA）领域路线图仓库，聚焦具身操控方向的高效VLA研究，提供实时更新的论文资源汇总。项目附带配套的交互式研究维基，可帮助研究者梳理、对比领域方法并构建个人知识体系，同时支持每周/双周更新，欢迎贡献最新研究成果。

## 主要特性
1.  收录覆盖架构优化、感知、动作生成与全流程的高效VLA相关论文，附带代码链接、会议信息、领域标签等完整资源
2.  提供效率瓶颈映射表，可根据关注的效率问题快速跳转对应分类板块
3.  配套交互式研究维基，支持针对性提问、跨论文方法对比，打造个性化学习 workspace
4.  定期更新领域最新进展，维护活跃的社区贡献渠道
