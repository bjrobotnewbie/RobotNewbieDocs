## 项目概述

## 项目介绍
本项目是一个精选的带记忆功能的视觉-语言-动作（VLA）模型与世界动作模型（WAM）研究论文合集，旨在解决长时序、部分可观测任务。项目由人工筛选整理，所有条目均经过论文原文验证，会持续跟踪该领域前沿进展。
项目关键词包括：记忆、关键帧选择、长时序任务、部分可观测性、POMDP、长上下文。

## 主要特性
1.  收录的论文均围绕具备长时序信息处理能力的记忆型VLA模型展开，覆盖长时序机器人操作、移动操纵等场景
2.  按年份整理了最新的前沿研究成果，目前已包含2026年的多篇顶会/预印本论文
3.  欢迎社区贡献相关优质论文或资源，可通过提交PR参与维护
