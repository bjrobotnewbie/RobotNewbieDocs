## 项目概述

## 项目介绍
本项目是一个精选的物理人工智能（Physical AI）学术论文与资源列表，聚焦于视觉语言动作（VLA）模型、世界模型、具身智能以及机器人基础模型。物理AI指通过机器人实体与物理世界交互，结合感知、推理与动作能力的AI系统。

## 主要特性
1.  **核心覆盖方向**：涵盖VLA架构、动作表示、世界模型、推理规划、学习范式、泛化部署、安全对齐等全链路技术方向
2.  **资源分类清晰**：按基础组件、算法架构、应用场景、工具资源等维度整理，包含经典预训练模型如CLIP、SigLIP等
3.  **覆盖多场景**：包含人形机器人、机械操作、自主导航等落地应用，以及Sim-to-Real迁移、数据集仿真平台等配套资源
4.  收录了学术论文、开源代码、基准测试工具、行业项目等多类型资源，方便开发者快速检索学习。
