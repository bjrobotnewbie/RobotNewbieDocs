## 项目概述

## 项目介绍
本项目是自动驾驶领域的视觉-语言-动作模型（VLA）综述资源库，针对传统模块化自动驾驶流水线存在的手工设计接口、规则组件难以适配复杂场景，且级联结构会放大感知误差的痛点，梳理了视觉-动作（VA）模型与VLA模型的发展历程。
项目将现有方法分为两大范式：端到端VLA，将感知、推理与规划整合为单一模型；双系统VLA，通过视觉语言模型（VLM）实现慢速审慎决策，结合规划器完成高速安全执行。项目附带官方论文、项目主页与HuggingFace排行榜资源。

## 主要特性
1.  系统性梳理自动驾驶VA/VLA模型的发展脉络，覆盖从早期视觉动作模型到现代VLA框架的全阶段研究
2.  提出清晰的方法分类框架，明确端到端与双系统两大主流VLA范式
3.  提供配套的学术论文、项目主页与评测排行榜资源，支持进一步学习与研究
4.  面向自动驾驶领域研究者与开发者，帮助快速掌握VLA技术栈与行业进展
