# every-embodied

With only basic Python knowledge, build your own embodied intelligent robot from scratch; gradually construct VLA/OpenVLA/SmolVLA/Pi0 from zero, and gain an in-depth understanding of embodied intelligence.

## 项目链接

- GitHub: <https://github.com/datawhalechina/every-embodied>

## 项目概述

## 项目介绍
本项目是面向具身智能的零基础入门教程，仅需掌握Python基础即可从零搭建具身智能机器人与相关模型。项目提供组队学习文档、完整学习地图与前沿算法复现资源，支持在线阅读学习，可帮助开发者深入理解具身智能技术栈，从零实现VLA/OpenVLA/SmolVLA/Pi0等主流模型。

## 主要特性
1.  低门槛入门：仅需Python基础即可上手学习
2.  完整学习路径：提供从0到1的具身智能搭建教程与学习地图
3.  前沿算法覆盖：支持复现VLA、OpenVLA、SmolVLA、Pi0等当前主流具身智能模型
4.  快速体验支持：提供一键运行的仿真Demo，可快速验证学习效果
5.  配套完整学习资源：包含组队学习文档与在线阅读版本，支持社区协作学习
