# GigaBrain-0

GigaBrain-0 是国内首个利用「世界模型」生成数据实现真机泛化的视觉-语言-动作（VLA）基础模型，由极佳科技（极佳视界）开发。该项目旨在通过世界模型为中心，无论在数据侧还是模型侧，彻底改变通用机器人大脑的开发方式。

## 主要特点

GigaBrain-0 拥有当前最先进的 VLA 模型架构：
- 支持图像、点云、文本、本体状态的多模态输入
- 输出结构化的任务规划和运动规划
- 在大规模数据上完成预训练，实现更精准的移动导航和长序列复杂操作

## 生态系统

搭配极佳视界自研「世界模型平台 GigaWorld」，构建最完整的具身数据体系，可以快速实现多种本体上复杂的机器人移动操作任务。

**开发理念**：通用本体+智能大脑+应用场景多轮闭环，高效打造最强应用生态

## 核心优势

- **最强泛化性**：通过世界模型生成数据实现真机泛化
- **最强实时、柔性操作**：支持流畅的实时操作
- **端到端全身控制**：直接输出全身控制
- **最强双臂协同**：实现最丝滑的双臂协同动作
- **原生模型+原生本体**：模型与本体深度适配

## 开发体验

- 具备先进的算法架构、强大的推理和规划能力
- 提供灵活的开发接口和完备的开发工具
- 配备基础智能大脑，快速适配各类下游任务
- 从标杆场景切入，打造数据闭环链路，逐步实现批量复制，最终实现场景通用
