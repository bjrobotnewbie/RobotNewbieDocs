# GR00T-N1.7
NVIDIA 开源的 Isaac GR00T 通用人形机器人基础VLA模型，支持开放推理，具备任务层级推理能力，支持精细指尖灵巧操作，适合商用部署。

## 核心特性
- 支持商用许可，可直接用于生产部署
- 任务和子任务层级推理，解决长时序任务中模型丢失连贯性的问题
- 支持细粒度灵巧操作，可完成小零件装配等接触丰富的复杂任务
- 基于扩散Transformer架构，支持多种机器人构型
- 完整训练代码和权重开源，生态完善
