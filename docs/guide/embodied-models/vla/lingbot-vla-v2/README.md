## 项目介绍
LingBot-VLA 2.0是一款实用的视觉语言动作(Vision-Language-Action)基础模型，旨在从大规模预训练落地到可靠的真实世界机器人应用。项目提供了论文、项目官网以及HuggingFace、ModelScope模型下载渠道，采用Apache-2.0开源协议。

## 主要特性
1.  **跨任务与跨机器人泛化能力**：重新设计的数据流水线收集了约6万小时预训练数据，包含20种机器人配置的5万小时机器人轨迹数据，以及1万小时第一人称人类视频数据。
2.  **扩展的动作空间**：统一的动作表示支持机械臂、末端执行器、灵巧手、腰部、头部和移动底盘的动作信号，不限于标准双臂操作。
3.  **预测动力学建模**：以未来预测作为代理任务，结合DINO-Video提供语义时间先验，LingBot-Depth提供几何感知线索。

该项目支持快速环境搭建，可基于PyTorch框架部署，同时已发布多款预训练权重供使用。
