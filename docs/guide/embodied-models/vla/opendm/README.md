## 项目概述

## 项目介绍
OpenDM是面向通用具身智能的开源项目，提供Dexmal下一代视觉语言动作模型（VLA）DM0.5的相关资源。DM0.5基于DM0的原生具身建模方案升级，可支持开放指令、长周期任务、动态扰动场景以及多形态机器人控制，面向研究者和开发者提供模型权重、训练推理脚本、数据集注册示例与评估流程。

## 主要特性
1.  支持开放世界通用机器人控制，适配多形态机器人
2.  可处理开放指令、长周期任务与动态扰动场景
3.  提供多版本预训练与微调模型权重，可在Hugging Face和ModelScope获取
4.  配套完整的训练、微调、评估与部署工具链，以及多款机器人适配改造指南
