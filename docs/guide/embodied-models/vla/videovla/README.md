VideoVLA: Video Generators Can Be Generalizable Robot Manipulators, NeurIPS 2025.

## 核心特性
- 提出视频生成器可以作为通用机器人操作器
- 将视频生成模型直接用于机器人控制
- 在CogVideo基础上预训练，获得更强泛化
