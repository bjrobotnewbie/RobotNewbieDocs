自变量机器人（X Square Robot）开源的端到端具身基础模型，统一跨层级 CoT 推理，支持复杂长时序操纵任务。

## 核心特性
- 统一跨层级链式推理（Unified Cross-Level CoT），无缝统一指令推理、子目标分解、细粒度动作生成
- 紧密耦合架构，实现视觉语言动作三者深度对齐
- 多策略训练课程，提升复杂长时序任务稳定性
- 能够处理复杂长时序操纵，解决当前VLA在长程任务中容易失去连贯性的问题
