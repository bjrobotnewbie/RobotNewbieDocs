## 项目概述

## 项目介绍
Embodied-Omni是浙江大学OmniAI团队开源的具身AI项目系列，专注于打造能在物理世界中感知、推理并执行行动的智能体。项目覆盖长时序任务规划、环境状态推理、自我反思以及真实机器人部署全流程，提供完整的数据引擎、训练方案、评测工具和部署代码。当前仓库包含两个子项目，支持从仿真到真实机器人的落地应用。

## 主要特性
1.  支持长时序任务规划、环境状态推理与行动自我反思
2.  提供端到端的完整工具链，包含数据生成、模型训练、评测和真实机器人部署代码
3.  包含Embodied-Reasoner与Embodied-Navigator两个核心子项目
4.  已在ACL 2026主会议发表相关研究，配套数据与模型已上传至Hugging Face
5.  兼容AI2-THOR等仿真环境，可快速完成从仿真到实机的迁移测试
