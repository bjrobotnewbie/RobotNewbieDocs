# HoloAgent

一个面向通用机器人的统一智能体系统，支持多模态感知、建图与定位、自主移动与操作，并可实现与用户的智能交互。

## 项目概述

## 项目介绍
HoloAgent是一款面向通用机器人的统一具身智能体框架，支持多模态感知、SLAM建图定位、自主移动与操作，可实现与用户的智能交互。它集成了闭环执行系统、3D空间记忆与机器人技能库，适配真实场景下的长时序任务，涵盖跨机器人协作、移动操作、主动探索等场景。目前已发布HoloAgent-0项目页面与论文，以及FSR-VLN快速-慢速视觉语言导航代码，框架代码即将开源。

## 主要特性
1.  **Embodied AgentOS**：统筹高层任务规划、运行时反馈与闭环机器人执行，可将语言指令转化为可监控的技能图
2.  **3D空间记忆**：基于物理空间表征支撑机器人推理，适配长时序任务
3.  **具身技能库**：连接智能体决策与可执行的导航、操作技能
4.  **FSR-VLN**：基于分层多模态场景图实现快速-慢速视觉语言导航
5.  支持真实机器人部署，可完成导航与动作协调、长时序移动操作、新环境主动探索、人机交互指令执行等任务。
