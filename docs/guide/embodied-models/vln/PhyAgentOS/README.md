# PhyAgentOS

PhyAgentOS 是基于代理工作流构建的自进化具身 AI 操作系统。

## 项目链接

- GitHub: <https://github.com/PhyAgentOS-Dev/PhyAgentOS>
- 项目主页: <https://phy-agent-os.net/>

## 项目概述

## 项目介绍
PhyAgentOS是一款基于智能体工作流构建的自我进化具身AI操作系统，采用认知-物理解耦设计，是会话驱动的具身智能运行时系统。该项目基于Python≥3.11开发，采用MIT开源协议，提供官方技术报告与项目官网。

## 主要特性
1.  **核心设计**：实现认知与物理模块解耦，以会话为中心管理具身智能运行流程
2.  **版本迭代**：当前最新版本v0.1.7，已支持策略循环与原生内置路径基准测试、智能体验证与故障恢复服务
3.  **扩展能力**：支持感知插件系统，可通过YAML配置传感器与环境参数，兼容仿真与真实机器人场景
4.  **生态支持**：内置ReKep/SAM3实机抓取、VLN完整流水线，支持行为1K基准测试，提供标准化通信协议与开发规范
