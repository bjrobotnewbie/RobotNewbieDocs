# Wall-X
- GitHub仓库: https://github.com/X-Square-Robot/wall-x
- 项目主页: https://x2robot.com/en/research

## 项目概述
Wall-X是一个基于具身基础模型的通用机器人开发框架，由X-Square Robot团队开发。该项目旨在构建具身基础模型，捕捉和压缩世界上最有价值的连续、高保真物理交互数据，通过模型决策与身体实际体验之间的直接反馈循环，实现具有泛化能力的智能系统，能够理解世界的运作方式并在其中高效行动。该仓库包含了WALL系列开源具身基础模型的训练和推理代码，支持数据准备、模型配置、流匹配、动作分支、服务部署和评估等完整流程。
