## 项目介绍
FACT是CoRL 2026收录论文《FACT: Failure-Aware Causal Training for World‑Action Models》的官方实现，是一款因果世界-动作模型，基于因果扩散Transformer架构，可联合对机器人动作、任务进度值和未来视频进行去噪处理，所有输出均以已执行动作作为条件。项目提供端到端的RoboTwin流程，涵盖数据准备、训练、推理及闭环模拟器评估，支持通过Hugging Face Spaces在线体验模型效果。

## 主要特性
1. 采用“先执行再想象”的设计，未来视频和任务进度值基于干净动作生成，避免目标泄露，部署时可直接解码动作无需生成视频；
2. 失败场景训练时跳过动作模仿损失，仅通过失败的未来观测和降低的任务进度值进行监督；
3. 推理阶段支持可选的N候选动作最优评分机制，通过值头对采样动作进行排序；
4. 提供完整的模型训练、推理及评估工具链，支持快速环境部署与模型运行。
