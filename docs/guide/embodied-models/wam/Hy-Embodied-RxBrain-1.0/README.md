## 项目概述

## 项目介绍
本项目是腾讯Robotics X、福田实验室和腾讯Hy团队联合推出的**Hy-Embodied-RxBrain-1.0**，也就是RxBrain，是一款具身认知通用多模态大模型，支持联合语言-视觉推理与想象能力。
它可以完成三大核心任务：一是具身理解与推理，支持基于图像、多帧视频的问答与链式思考；二是世界状态预测，能够模拟物理世界中动作产生的近期未来画面；三是联合子目标规划，可以将任务拆解为步骤，同时输出对应步骤的语言动作和预期达成的视觉目标图。

## 主要特性
1.  集成多模态能力，统一处理文本、视觉、生成任务
2.  支持具身场景下的理解推理、未来帧预测和任务规划
3.  已开源模型权重、推理代码、微调代码（覆盖VQA、多帧生成、交错规划任务），提供HuggingFace模型与Demo
4.  适配Python3.10+与CUDA GPU环境，提供完整的项目代码结构与示例场景。
