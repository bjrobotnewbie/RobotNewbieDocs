## 项目概述

## 项目介绍
LiLa-WAM是一款面向机器人操作任务的轻量级世界-动作模型，官方实现代码已开源。它仅需单张24GB消费级GPU即可完成训练，在50个RoboTwin 2.0清洁场景任务中平均成功率达90.48%，全模型参数规模0.5B，其中仅0.2B为可训练参数，在单张RTX 5090上训练全部50个任务仅需约110小时。项目已在RoboTwin 2.0、LIBERO以及真实机器人上完成验证，同时提供了论文与项目主页链接。

## 主要特性
1.  **轻量高效**：总参数0.5B，仅0.2B可训练，支持单张24GB GPU训练
2.  支持世界-动作联合建模：结合隐式未来状态预测与动作生成
3.  创新性使用视觉过渡令牌(VTT)技术
4.  多场景验证：覆盖RoboTwin 2.0、LIBERO仿真数据集与真实机器人实验
