## 项目概述

## 项目介绍
OpenETA是一款具身智能体范式项目，旨在将数字域的智能体能力延伸至物理世界，完成从数字智能到物理智能的闭环落地。其核心是将智能体嵌入世界的因果链中，让感知、行动、验证和学习形成连续统一的过程，实现对现实世界的理解与改造。项目支持仿真与真实机器人部署，可应用于长周期实体任务场景。

## 主要特性
1.  **因果闭环机制**：所有改变物理世界的行动都会触发新的感知校验，在推理、恢复或任务完成前必须完成观测更新
2.  **可替换规划器**：通过兼容OpenAI的接口对接不同LLM、VLM模型，支持主备推理端点切换
3.  **可组合物理能力**：通过标准化工具与MCP接口，可组合感知、抓取、放置、运动等原生机器人策略
4.  已支持真实机器人部署分支与针对LIBERO任务的轻量版本，在130个LIBERO任务中实现70.8%的Pass@1、90.0%的Pass@5指标。
