## 项目介绍
OpenWAM是一个开源研究栈，用于系统化开发世界-动作模型(WAMs)，将紧密耦合的设计拆分为模块化组件并支持可控实验。它包含三部分：
1.  OpenWAM-Infra：用于组合、对比模型、表征、训练、推理、部署和评估方案的模块化基础设施
2.  OpenWAM-Study：用于推导世界知识继承、世界与动作学习耦合、跨领域扩展等实用原则的可控研究
3.  OpenWAM-α：一个开源预训练世界-动作模型，基于51850万帧（约6400小时）的第一视角人类与机器人数据训练得到。

本项目配套有官方项目页面、arXiv论文以及Hugging Face模型与数据集仓库。

## 主要特性
1.  模块化设计，支持灵活组合不同的模型架构、数据处理流程与训练部署方案
2.  提供标准化可控研究框架，可复现并推导世界-动作模型的实用训练原则
3.  开源大规模预训练模型与配套数据集，支持机器人、具身智能相关研究与落地
4.  内置多机器人仿真环境评估基准，包括RoboTwin、LIBERO、RoboCasa等。
