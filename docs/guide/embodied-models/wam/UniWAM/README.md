# UniWAM

UniWAM 官方代码：统一世界 - 动作模型

## 项目链接

- GitHub: <https://github.com/UniWAM/UniWAM>

## 项目介绍
UniWAM是8B参数的统一世界-动作模型，官方代码仓库，采用混合专家Transformer（MoT）架构，融合语义理解、视觉预测与动作生成能力，通过联合多模态注意力实现各专家模块的信息交互。该模型通过物理-语言监督及机器人、人类第一视角、VQA数据的互补信号构建具身知识，可用于机器人具身智能相关任务。

## 主要特性
- 统一世界-动作架构：由物理推理器、世界生成器、动作预测器通过联合多模态注意力连接的MoT结构
- 物理-语言对齐：将机器人动作以自然语言表示，适配具身任务同时保留语言能力
- 多模态互补监督：预训练结合机器人演示、人类第一视角数据、VQA数据训练各专家模块
- 高效动作生成：未来视觉噪声增强与历史条件流匹配，减少去噪步骤
- 训练高效：在8张NVIDIA H100 GPU上对RoboTwin 2.0进行后训练仅需10小时
