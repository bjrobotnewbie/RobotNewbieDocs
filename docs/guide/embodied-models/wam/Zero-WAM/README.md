# Zero-WAM

基于人类视频的上下文世界动作建模以支持开放任务泛化

## 项目链接

- GitHub: <https://github.com/robbyant-research/Zero-WAM>
- 项目主页: <https://robbyant-research.github.io/Zero-WAM/>

## 项目介绍
Zero-WAM是一个面向开放域任务泛化的机器人学习项目，目标是实现零样本跨任务机器人操作：让策略仅依靠部署阶段的上下文，就能完成训练阶段未见过的任务。该项目将上下文学习引入机器人领域，把人类演示视频作为视觉任务指令，可通过语言指令或人类视频提示，生成因果视频-动作策略来预测未来机器人观测结果与可执行动作。

## 主要特性
1.  基于人类视频实现上下文世界-动作建模
2.  支持零样本跨任务机器人操纵，无需针对新任务进行训练
3.  可同时接收语言指令和人类视频两种任务提示
4.  能够预测机器人后续观测结果并生成对应执行动作
项目代码、模型与数据集预计2026年9月15日前正式发布，采用Apache 2.0开源协议。
