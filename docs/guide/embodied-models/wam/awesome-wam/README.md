# Awesome-WAM

一份经过整理、持续更新的，关于具身智能中世界动作模型（World Action Models, WAMs）的阅读清单、论文博客与资源合集。

## 项目链接

- GitHub: <https://github.com/OpenMOSS/Awesome-WAM>
- 项目主页: https://openmoss.github.io/Awesome-WAM/
- 综述论文: [World Action Models: The Next Frontier in Embodied AI (arXiv:2605.12090)](https://arxiv.org/abs/2605.12090)

## 项目概述

本项目是面向具身人工智能领域的世界行动模型（WAM）精选整理资源库，持续更新相关阅读清单、论文解读博客与学习资料，配套发布了首份系统性WAM综述。WAM是将预测世界建模与动作生成相统一的新兴具身AI范式。项目还附带了论文一键转结构化博客的开源工具。

## 主要特性

1. 提供首份系统性WAM综述，涵盖架构分类（级联式与联合式WAM）、训练数据、评估标准以及面向视觉语言行动（VLA）学习的世界模型相关内容
2. 收录每篇核心论文的结构化解读博客，帮助快速掌握论文核心思想、架构与贡献
3. 配套开源论文转博客的总结工具，附带官方项目页面、基准测试排行榜与交流社群链接，持续跟进领域最新进展
