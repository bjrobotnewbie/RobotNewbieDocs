## 项目概述

## 项目介绍
Flex-π是一款60亿参数的机器人操作多流世界-动作模型，仅通过单个模型权重文件，即可部署为视觉语言动作模型（VLA）、完整世界-动作模型或二者之间的任意模式。
该模型在训练阶段联合预测未来RGB图像、3D点云、DINOv3语义特征与机器人动作，依托冻结的现成编码器与Wan-2.2视频VAE实现多模态数据的统一 latent 空间建模，并通过跨模态强制训练让模型自主学习各模态间的关联。

## 主要特性
1.  **单 checkpoint 多部署模式**：一套权重支持56种输入输出流组合，可按需切换仅动作推理、仅视觉生成或全模态联合推理，无需额外训练，深度传感器为可选配置
2.  兼顾性能与延迟：动作单模态推理仅需60ms，全模态联合生成耗时193ms，可灵活平衡计算资源与推理效果
3.  精准支持机器人操作需求：不同于仅预测RGB隐变量的传统模型，该模型显式建模3D几何与物体语义特征，贴合实际操作场景需求
