Latent Action Pretraining from Videos, ICLR 2025.

## 核心特性
- 从视频中进行潜在动作预训练，无需交互数据
- 学习隐式动作表示，提升策略泛化能力
- 在大规模视频数据上预训练，可迁移到下游任务
