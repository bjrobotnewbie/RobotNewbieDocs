# mimic-video
mimic-video: Video-Action Models for Generalizable Robot Control Beyond VLAs, arXiv 2025.

## 核心特性
- 视频动作模型框架，超越传统VLA实现更好泛化
- 通过模仿视频学习通用机器人控制策略
- 在多样化环境中表现出更强的泛化能力
