WoVR: World Models as Reliable Simulators for Post-Training VLA Policies with RL, arXiv 2026.

## 核心特性
- 将世界模型作为可靠模拟器用于VLA策略后训练
- 在世界模型模拟器中进行强化学习微调
- 利用世界模型提供训练信号，无需真实环境交互
