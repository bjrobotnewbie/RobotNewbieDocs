# FluxVLA Engine
逐际动力开源的标准化VLA工程底座，打通数据处理、模型训练、仿真评测到真机部署全流程，大幅降低具身智能全研发周期的工程门槛。

## 核心特性
- All-in-one统一配置机制，单一配置文件统筹全链路参数
- 模块化解耦设计，支持自由替换视觉编码器、语言主干、动作头
- 原生支持VLM与VLA全栈覆盖，兼顾感知理解与动作训练
- 兼容Qwen、GR00T、Pi系列、DreamZero等主流VLM/VLA/WAM模型
- 推理速度提升5-10倍，集成实时控制轨迹平滑技术，解决动作抖动问题
- 支持Isaac Sim、LIBERO等主流仿真器，适配UR机械臂、ALOHA双臂系统、逐际动力TRON 2等多硬件平台
