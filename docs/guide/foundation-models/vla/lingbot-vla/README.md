# LingBot-VLA
蚂蚁集团灵波科技开源的具身智能VLA基座模型，基于2万小时真实机器人操作数据预训练，覆盖9种主流双臂机器人构型，具备跨本体、跨任务迁移能力。

## 核心特性
- 仅需150条演示数据即可实现高质量任务迁移
- 训练效率较StarVLA、OpenPI等主流框架提升1.5~2.8倍
- 提供含深度信息与不含深度信息的双版本选择
- 已与乐聚、松灵、星海图等多机型完成验证，兼容性强
