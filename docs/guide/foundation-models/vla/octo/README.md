# Octo
UC Berkeley / Stanford / Google DeepMind 联合开源的通⽤机器⼈策略模型，基于80万机器⼈轨迹训练，transformer 扩散策略架构，支持多种机器⼈构型。

## 核心特性
- 基于800k+多样化机器⼈轨迹预训练，具备出色泛化能力
- Transformer-based 扩散策略架构，支持语言指令和目标图像输入
- 模块化注意力结构，可以高效微调到新机器人
- 提供多种尺寸：Octo-Small 27M参数，Octo-Base 93M参数，消费级GPU可运行
- 原生支持多个RGB相机输入，可适应不同机器人形态
