# SmolVLA
Hugging Face 开源的轻量级紧凑型VLA模型，仅4.5亿参数，专为消费级硬件设计，让先进机器人技术走进更多开发者和爱好者。

## 核心特性
- 仅4.5亿参数，基于精简的 SmolVLM-2 视觉语言模型 + Flow-Matching Transformer 动作头
- 异步推理，将动作预测与执行解耦，实现实时响应，任务完成时间平均缩短约30%
- 完全基于 LeRobot 社区数据集开源训练，真正体现开源协同力量
- 在 LIBERO 和 Meta-World 等模拟环境中表现出色，真实世界任务平均成功率约78.3%
- 社区生态活跃，已有29+社区微调模型适配各种任务
