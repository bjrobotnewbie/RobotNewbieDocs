# UD-VLA
Unified Diffusion VLA: Vision-Language-Action Model via Joint Discrete Denoising Diffusion Process, arXiv 2025.

## 核心特性
- 通过联合离散去噪扩散过程构建VLA模型
- 统一扩散框架结合世界建模信息
- 在CALVIN基准上取得优异性能
