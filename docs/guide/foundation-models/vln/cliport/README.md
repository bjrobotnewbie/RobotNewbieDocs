# CLIPort
CLIPort是一个语言条件下的模仿学习智能体，可以学习单一的多任务策略，用于各种桌面操作任务，结合了CLIP的语义理解能力和TransporterNets的空间精度。

## 核心特性
- 端到端的语言条件化操作策略
- 结合CLIP的语义理解和TransporterNets的空间精度
- 只需少量演示数据即可泛化到新任务
- 支持模拟和真实机器人环境
- 多任务策略可以同时处理10+不同的桌面操作任务
