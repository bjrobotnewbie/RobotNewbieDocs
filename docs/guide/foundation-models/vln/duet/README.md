# DUET (Dual-scale GraphTransformer)
DUET是基于双尺度图Transformer的视觉语言导航模型，能够同时进行全局动作规划和细粒度跨模态理解，是VLN领域的经典基准模型。

## 核心特性
- 双尺度图Transformer架构，平衡全局规划和局部细节理解
- 动态构建拓扑地图，支持高效探索和长期动作规划
- 在R2R、REVERIE、SOON等多个VLN基准测试中取得SOTA性能
- 成为众多后续VLN研究的核心骨干架构
