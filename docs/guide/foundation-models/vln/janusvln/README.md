# JanusVLN

- [官方文档](https://miv-xjtu.github.io/JanusVLN.github.io/)

## 概述

JanusVLN 是西安交通大学提出的一种新颖的视觉-语言导航框架，灵感来源于人类大脑的功能分区。它解决了现有 VLN 模型的关键局限性，包括空间感知不足、计算冗余过大和内存开销过高。

该设计将语义理解与几何空间推理解耦，采用双重隐式记忆机制分别压缩视觉语义特征和三维空间表示。通过增量滑动窗口缓存策略，它能够高效过滤冗余视觉 token，并保持稳定的长期上下文建模。

通过将空间先验知识嵌入大型多模态模型，JanusVLN 极大地增强了环境理解和方向决策能力。在 R2R 和 RxR 等主流 VLN 基准测试中进行了评估，它达到了最先进的性能，在导航成功率和鲁棒性方面优于众多先进方法，为具身视觉-语言导航提供了一种高效且可推广的解决方案。
