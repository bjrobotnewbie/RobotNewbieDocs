# SkillNav
SkillNav是基于技能的模块化VLN框架，将导航学习分解为可重用的原子技能，实现灵活重组和泛化能力。

## 核心特性
- 模块化技能分解：将复杂导航任务分解为独立可重用技能
- 动态技能选择器：基于VLM的路由器动态选择最合适的技能
- 合成数据集生成：自动生成技能特定的指令轨迹对
- 在未见环境和新指令风格中表现出色
