# UrbanNav
UrbanNav是从网络规模人类轨迹中学习语言引导的城市导航方法，支持室外大规模环境导航。

## 核心特性
- 利用网络规模人类轨迹数据进行预训练
- 支持自然语言指令引导的城市级导航
- 适应复杂室外环境和动态场景
- 零样本泛化到未见城市区域
