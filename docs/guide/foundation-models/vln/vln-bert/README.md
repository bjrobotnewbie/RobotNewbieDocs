# VLN-BERT

VLN-BERT是基于BERT的视觉语言导航模型，通过循环神经网络增强，能够在导航过程中更好地理解历史信息和语言指令。

## 核心特性

- 基于BERT的视觉语言融合模型
- 引入循环神经网络处理导航历史信息
- 在标准VLN基准测试中取得优异性能
- 支持R2R、REVERIE等多个VLN数据集
