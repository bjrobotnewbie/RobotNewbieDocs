# Awesome-WAM
复旦大学开源整理的世界动作模型(WAM)研究综述，系统梳理了WAM领域的最新进展和分类。

## 核心特性
- 第一个系统性的WAM研究综述
- 梳理了完整架构分类：级联WAM、联合WAM等
- 提供结构化总结和未来研究方向
- 社区驱动持续更新
