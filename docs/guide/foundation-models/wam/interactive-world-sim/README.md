# Interactive World Simulator
Interactive World Simulator for Robot Policy Training and Evaluation, arXiv 2026.

## 核心特性
- 交互式世界模拟器，用于机器人策略训练和评估
- 支持人机交互训练和评估
- 提供可交互的环境用于世界模型研究
