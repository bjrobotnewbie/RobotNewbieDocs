# Large Video Planner (LV-P)
Large Video Planner Enables Generalizable Robot Control, arXiv 2025.

## 核心特性
- 大型视频规划器框架，实现通用机器人控制
- 基于视频生成模型进行长程规划
- 提升复杂任务中的泛化能力
