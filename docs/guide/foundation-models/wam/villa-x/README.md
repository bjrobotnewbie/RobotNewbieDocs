# villa-X
villa-X: Enhancing Latent Action Modeling in Vision-Language-Action Models, ICLR 2026.

## 核心特性
- 增强视觉语言动作模型中的潜在动作建模
- 改进潜在空间中的动作表示学习
- 提升VLA模型在复杂任务中的表现
