# AlohaMini

- 项目链接：https://github.com/liyiteng/AlohaMini

## 项目概述

AlohaMini (AlohaMini2) 是一个**开源带电动升降的双臂移动机器人**，专为具身智能研究设计，自建BOM控制在1000美元以内。主要特点：

1. **升级设计**：相比第一代全面升级：
   - 底座最大负载从10kg提升到70kg
   - 提升能力从5kg提升到30kg
   - 手臂 payload 从0.3kg提升到1kg
   - 手臂 reach 从40cm提升到52cm
   - 自由度从5+1提升到6+1
2. **易用性设计**：
   - 可在家用Bambu P2S上完全3D打印
   - 约120分钟即可组装完成
   - 开箱即用支持LeRobot，方便训练和部署
3. **完全开源**：硬件CAD、URDF、软件全部开源

AlohaMini2为人价美物廉的开源双臂移动机器人平台，降低了具身智能操作研究的硬件门槛。
