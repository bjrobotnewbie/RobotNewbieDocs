# FanControl.Releases

这是 Fan Control 的发布仓库，它是一款适用于 Windows 的高度可定制的风扇控制软件。

## 项目链接

- GitHub: <https://github.com/Rem0o/FanControl.Releases>

## 项目介绍
Fan Control是一款面向Windows平台的高度可自定义风扇控制软件，源代码闭源。它可以帮助用户精准调节电脑风扇转速，解决硬件散热问题，已获得知名科技博主JayzTwoCents推荐。软件支持开机以服务形式后台运行，无需用户登录即可生效，且已通过数字签名，可避免杀毒软件误报。

## 主要特性
1.  高度自定义风扇调速策略
2.  新增转速避障点设置，可避开风扇异响的转速区间
3.  支持以系统服务形式开机自启
4.  采用新版LibreHardwareMonitor替代WinRing0，解决杀毒软件误报问题
5.  提供插件扩展能力，可适配更多硬件设备
