# MicroManipulatorStepper
- GitHub仓库: https://github.com/0x23/MicroManipulatorStepper

## 项目概述
这是一个开源的低成本、易搭建的电动XYZ微操作器运动控制平台，能够实现亚微米级的精度。该平台设计用于光学对准、电子元件探测和显微镜检查等应用场景。其采用并联运动结构和微型球铰，实现了良好的机械刚度和较大的运动范围。电机使用现成的步进电机，由30kHz闭环控制器和非常精确的PWM信号驱动，通过“磁性齿轮”方法将低成本磁性旋转编码器的分辨率提高30倍，可实现低至50nm的步长。设备可以通过USB串行接口的简单G代码命令进行控制，易于集成到其他项目中，固件实现了完整的运动规划堆栈，支持预读功能以实现平滑准确的路径跟踪。
