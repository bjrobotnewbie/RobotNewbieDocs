## 分类说明

| 分类 | 核心内容 | 技能要点 |
|------|---------|---------|
| **嵌入式基础** | 微控制器、STM32、嵌入式 Linux | C/C++ 编程，外设驱动，RTOS |

| **传感器与执行器** | 各类传感器原理，电机驱动 | 电路设计，信号处理，PID 控制 |
