# SO-ARM100/101 Parallel Gripper
- GitHub仓库: https://github.com/roboninecom/SO-ARM100-101-Parallel-Gripper
- 项目主页: https://robonine.com

## 项目概述
这是一款由Robonine开发的轻量化3D打印平行夹爪，专为开源SO-ARM100/101机器人平台设计。该夹爪兼容Feetech STS3215和Waveshare ST3215伺服电机，即插即用，安装便捷。其核心参数包括：120N的夹持力、14mm/s的操作速度、84mm的最大开合行程以及0.5mm的重复定位精度，支持RealSense、Orbbec等USB相机集成。所有部件均可通过标准FDM打印机打印，总成本约62美元，组装仅需30-45分钟，是小型机器人项目的理想夹持解决方案。
