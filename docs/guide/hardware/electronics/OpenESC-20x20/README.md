# OpenESC-20x20

开源 4 通道 1 机 AM32 无人机专用 ESC。20x20 安装尺寸，6S 电压，每通道 AT32F421。KiCad 10，CERN-OHL-S-2.0。

## 项目概述

## 项目介绍
OpenESC-20x20 是一款开源4合1无刷电调(ESC)，属于incutec OpenDrone产品线，专为FPV穿越机设计。它采用20x20mm安装规格，支持6S输入，每通道搭载AT32F421G8U7主控与NSG2065Q栅极驱动器，搭配6颗MOSFET，运行AM32固件，通过标准8pin连接器支持DShot通信。项目采用KiCad 10设计，已通过OSHWA开源硬件认证（UID: BE000028），硬件版本Rev2已验证完成，可直接导出生产文件用于JLCPCB组装。

## 主要特性
1.  4独立通道设计，每通道独立主控与驱动电路
2.  支持6S电源输入，6层PCB布局
3.  兼容AM32固件与DShot通信协议
4.  附带QC测试治具、热分析脚本与完整生产文档
5.  遵循CERN-OHL-S-2.0开源许可，提供完整硬件设计源文件
