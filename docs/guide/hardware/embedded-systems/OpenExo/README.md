# OpenExo

开源外骨骼

## 项目链接

- GitHub: <https://github.com/naubiomech/OpenExo>
- 项目主页: <https://theopenexo.nau.edu/>

## 项目介绍
本项目是OpenExo开源外骨骼配套的 Teensy Nano 控制代码，基于双微控制器实现可穿戴机器人的控制。项目提供了完整的编译烧录、部署指南，以及详细的C++开发文档、硬件Wiki文档、官方Read the Docs软件文档和YouTube教学视频。

## 主要特性
1.  针对开源外骨骼OpenExo设计的专用控制代码
2.  采用双微控制器架构实现机器人控制
3.  配套完整的开发、部署、使用教程资源
4.  提供C++层面的底层软件文档说明
