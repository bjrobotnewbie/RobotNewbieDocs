# Tasmota

适用于基于ESP8266和ESP32设备的替代固件，支持通过webUI轻松配置、OTA更新、基于定时器或规则的自动化，具备可扩展性，可通过MQTT、HTTP、串口或KNX实现完全本地控制。完整文档位于：

- GitHub: <https://github.com/arendst/Tasmota>
- 项目主页: <https://tasmota.github.io/docs>

## 项目介绍
Tasmota是一款针对ESP8266和ESP32设备的替代固件，支持通过WebUI快速配置、OTA远程升级，可通过定时器或规则实现自动化控制，具备良好扩展性，可通过MQTT、HTTP、Serial或KNX实现完全本地控制，基于PlatformIO开发。

## 主要特性
1.  支持ESP8266和ESP32平台
2.  提供直观WebUI配置界面，支持一键WebInstaller快速安装
3.  支持OTA远程升级，无需拆解设备
4.  可通过定时器、自定义规则实现设备自动化
5.  支持MQTT、HTTP、Serial、KNX多种本地控制方式
6.  具备良好扩展性，可适配各类物联网设备场景
