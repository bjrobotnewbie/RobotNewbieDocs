# WLED

通过ESP32基于WiFi控制WS2812B及多种其他类型的数字RGB LED！

## 项目链接

- GitHub: <https://github.com/wled/WLED>
- 项目主页: <https://kno.wled.ge>

## 项目介绍
WLED是一款面向ESP32微控制器的高性能固件，可通过WiFi控制WS2812B等多款寻址型RGB LED，支持从简易LED灯带、大型2D矩阵到HUB75面板的各类LED设备。该项目最初由Aircoookie创建，目前由社区开发者维护。

## 主要特性
### 效果与视觉
1.  内置200+种动画效果，包含经典动画、音频响应效果与2D矩阵专属效果
2.  提供50+色彩预设调色板，搭配自定义调色板编辑器PixelForge
3.  支持2D LED矩阵与HUB75 RGB面板，支持灵活的面板映射
4.  原生支持音频响应效果，可通过麦克风、线路输入或网络音频源触发
5.  支持效果平滑过渡与抗锯齿绘图

### 分段与控制
1.  支持分段功能，可同时为LED系统的独立区域配置不同效果、色彩与调色板
2.  最多可存储250个预设配置，支持预设播放列表实现自动循环
3.  内置可配置调光曲线的夜灯功能，以及单输出独立自动亮度限制器

### 硬件支持
支持全系列ESP32芯片，ESP32可通过并行I2S+RTM实现最多17路LED输出。
