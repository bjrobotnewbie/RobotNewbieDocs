# esphome

ESPHome 是一个通过简洁而强大的配置文件控制 ESP32、ESP8266、BK72xx、RP2040，并可通过家庭自动化系统对其进行远程控制的系统。

## 项目链接

- GitHub: <https://github.com/esphome/esphome>
- 项目主页: https://esphome.io/

## 项目概述

## 项目介绍
ESPHome是一款针对ESP32、ESP8266、BK72xx、RP2040开发板的控制系统，用户可通过简洁且功能强大的配置文件管理设备，并通过家庭自动化系统远程控制设备。

## 主要特性
1.  支持多款主流物联网开发板，适配范围广
2.  采用配置文件方式管理设备，降低开发使用门槛
3.  可对接家庭自动化系统实现远程控制
4.  拥有官方完整文档、社区反馈渠道与官方Discord交流群，隶属于Open Home Foundation项目
