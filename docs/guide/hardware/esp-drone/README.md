# ESP-Drone
- GitHub仓库: https://github.com/espressif/esp-drone

## 项目概述
ESP-Drone是一个基于乐鑫ESP32/ESP32-S2/ESP32-S3系列Wi-Fi芯片的开源无人机解决方案，支持通过移动应用或游戏手柄进行Wi-Fi连接控制。该项目硬件简单，代码架构清晰且易于扩展，可用于STEAM教育等领域，主要代码从Crazyflie开源项目移植而来，遵循GPL3.0协议。支持ESP32、ESP32S2、ESP32S3等多款芯片，提供稳定模式、高度保持模式、位置保持模式等飞行模式，支持APP控制、cfclient客户端控制以及ESP-BOX3摇杆通过esp-now控制。该项目还提供了硬件原理图、iOS和Android应用源码等完整的开发资源。
