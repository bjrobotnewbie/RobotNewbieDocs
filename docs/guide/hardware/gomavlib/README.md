# gomavlib

Mavlink 库（2.0 和 1.0）用于 Go 编程语言

## 项目链接

- GitHub: <https://github.com/bluenviron/gomavlib>

## 项目介绍
gomavlib是一款基于Go语言实现的Mavlink协议（支持1.0和2.0版本）开发库，可通过串口、UDP、TCP或自定义传输协议与支持Mavlink的设备交互，可用于开发UGV、UAV、地面站、监控系统或路由设备。Mavlink是轻量且传输无关的协议，广泛应用于无人车、无人机通信，被Ardupilot、PX4等主流开源飞控支持，该库也是mavp2p路由的底层依赖。

## 主要特性
1.  **通信能力**：支持创建Mavlink节点，兼容串口、UDP（服务端/客户端/广播模式）、TCP（服务端/客户端）及自定义传输，支持域名与IP地址，可自动发送心跳包与Ardupilot设备的流请求（默认关闭）
2.  **协议支持**：完整编解码Mavlink 1.0与2.0协议，支持校验和计算与验证，兼容2.0版本的空字节截断、签名、消息扩展特性
3.  **方言管理**：内置标准方言库，支持自定义方言转换（提供XML定义转Go代码的生成工具），也可跳过方言直接路由原始消息
4.  **日志支持**：可读写tlog格式的遥测日志
