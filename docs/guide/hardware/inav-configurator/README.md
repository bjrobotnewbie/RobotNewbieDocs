## 项目概述

## 项目介绍
INAV Configurator是一款跨平台配置工具，用于配置[inav](https://github.com/iNavFlight/inav)飞行控制系统，支持多旋翼无人机（四轴、六轴、八轴）以及固定翼飞机等多种机型。

## 主要特性
1.  跨平台支持，提供独立安装包
2.  适配多种机型的飞行控制器配置
3.  官方提供GitHub Issues用于反馈技术bug，另有Discord、Facebook、RC Groups、Telegram、GitHub Discussions等社区支持渠道

同时提供Windows和Linux系统的安装方式：
- Windows：可下载对应架构的压缩包解压运行，或使用安装程序安装，首次运行需允许未签名应用
- Linux：提供rpm、deb安装包以及通用压缩包，支持x64、armv7l等架构，可通过包管理器或手动解压配置使用。
