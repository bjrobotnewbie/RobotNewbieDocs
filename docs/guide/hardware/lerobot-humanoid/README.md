# lerobot-humanoid

- 项目链接：https://github.com/Virgileboat/lerobot-humanoid

## 项目概述

lerobot-humanoid是一个**开源低成本人形机器人项目**，目标是构建一个人人可复现的实用人形机器人。整个项目从设计到部署完整涵盖：

1. **完整工作空间**：将整个LeRobot人形机器人项目整合在一个仓库中，包含机械设计、硬件、控制协同设计、硬件构建资源、机器人模型、运行时部署栈、仿真辨识等
2. **设计目标**：
   - 成本目标：硬件总成本低于5000美元（取决于采购渠道）
   - 轻量化结构：优先减重和可维护性
   - 3D打印优先：大部分定制机械零件可打印，完整文档
   - 研究友好：从CAD到运行时和辨识都提供可复现的完整流程
3. **模块化组织**：每个文件夹是独立的Git仓库，保持各自的开发历史

该项目为人形机器人研究者提供了一个开放可复现的硬件软件全栈方案，降低了人形机器人研究的门槛。
