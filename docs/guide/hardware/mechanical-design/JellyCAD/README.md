## 项目概述

## 项目介绍
JellyCAD是一款面向程序员、机器人开发者和参数化建模爱好者的现代化开源可编程CAD软件。

## 主要特性
1.  **核心定位**：面向技术开发者的可编程参数化CAD工具
2.  **构建支持**：提供两种编译方案：
    - CMake构建：依赖vcpkg管理Qt5、assimp、OpenCASCADE等第三方库，支持Windows 11平台
    - QMake构建：基于Qt 5.9.0+MSVC 14，支持Windows 7平台，需手动配置OpenCASCADE环境
3.  **适用场景**：快速创建参数化3D模型，适配机器人开发等需要可编程建模的工作流
