# 机械设计

机械设计涵盖机器人结构设计、CAD建模、材料选型和制造工艺等内容。本章节聚焦机器人开发中所需的机械工程实践知识。

## 项目列表

- [SolidWorks CAD教程](/guide/hardware/solidworks-cad/README) - 三维建模与装配
- [SO-ARM100/101 Parallel Gripper](/guide/hardware/SO-ARM100-101-Parallel-Gripper/README) - 并联机械夹爪设计
- [JellyCAD（面向程序员、机器人开发人员和参数化建模爱…）](/guide/hardware/mechanical-design/JellyCAD/README)
## 分类说明

| 项目 | 主要内容 | 技能要点 |
|------|---------|---------|
| **SolidWorks CAD** | 三维建模、装配体、工程图 | 草图绘制、特征建模、装配约束 |
| **SO-ARM并联夹爪** | 机械夹爪结构设计 | 连杆机构、运动学分析、3D打印 |

## 知识体系

机械设计在机器人中的应用主要包括以下方向：

| 方向 | 核心内容 | 机器人应用 |
|------|---------|-----------|
| **机械原理** | 连杆机构、齿轮传动、凸轮机构 | 关节设计、传动系统、末端执行器 |
| **CAD建模** | 三维建模、装配仿真、运动仿真 | 零件设计、整机装配、干涉检查 |
| **材料与选型** | 金属材料、工程塑料、复合材料 | 结构件选型、轻量化设计、强度校核 |
| **制造工艺** | 机加工、3D打印、钣金、注塑 | 原型制作、批量生产、成本优化 |
