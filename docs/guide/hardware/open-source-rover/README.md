# Open Source Rover

## 项目概述
JPL Open Source Rover是一个开源的六轮火星车项目，灵感来自NASA JPL用于火星表面探测的漫游车设计，可自行搭建。该项目完全使用现成的商用零部件（COTS）制作，旨在为对机械工程、软件、电子和机器人技术感兴趣的人提供教学和学习体验，同时也可作为崎岖地形研究的优秀平台。项目自2017年以来经历了多次迭代，具备独特的外观设计、高度的可定制性和强大的功能，硬件和电子设计时就考虑了头部显示器和机械臂等扩展功能，适合作为入门级机器人项目或研究平台。
