## 项目概述

OpenArm是一个**完全开源的7自由度人形机械臂**，专为物理AI研究和富接触环境部署设计。主要特点：

1. **设计理念**：高反向驱动性和柔顺性，考虑人机交互安全，同时具备实用的负载能力满足真实世界应用
2. **标准化研究环境**：OpenArm Cell提供统一背景、光照、相机位置的标准化环境，让全球研究可以在一致的评估条件下复现
3. **人形比例**：保持人类尺度比例，兼顾安全性、柔顺性和实用负载能力
4. **成本可控**：完整双臂系统价格在6500美元，为遥操作、模仿学习、仿真、富接触任务的数据采集提供灵活平台

OpenArm为物理AI研究提供了一个开放可复现的人形臂硬件平台，促进接触丰富环境中的机器人研究。
