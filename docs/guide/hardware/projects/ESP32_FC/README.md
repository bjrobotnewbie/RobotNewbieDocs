# ESP32_FC

基于 ESP32 的无人机飞行控制器研发研究

## 项目链接

- GitHub: <https://github.com/KyThuatUAV/ESP32_FC>

## 项目介绍
本项目是基于ESP32的四旋翼无人机飞控开源项目，面向学生和无人机爱好者，提供完整的软硬件方案与安装教程。硬件核心为ESP32-WROOM-DA主控，搭配ICM-20602惯性传感器、BMP388气压传感器，支持SBUS协议遥控器，通过LEDC输出标准PWM信号驱动4路ESC电机。固件运行在FreeRTOS上，利用ESP32双核心实现任务分离调度。

## 主要特性
1.  **飞行模式**：支持ANGLE角度保持模式、ALT HOLD定高模式，支持失联自动返航降落（以60cm/s速度平稳落地后停机）
2.  **校准功能**：集成陀螺仪自动校准（需无人机静置完成校准）、加速度计校准，自动生成校准参数
3.  **任务调度**：核心控制任务运行在核心1，500Hz频率执行IMU数据读取、姿态解算、高度卡尔曼滤波、PID控制与电机输出；遥控器解码、气压计读取任务运行在核心0
4.  配置简单：所有硬件引脚、遥控器通道、PID参数、校准数据均集中在主代码文件开头，便于修改调试
5.  适配Arduino开发环境，需使用指定版本ESP32核心2.0.17避免编译报错
