## 分类说明

| 项目类型 | 项目 | 特点 |
|---------|------|------|
| **机械臂** | AlohaMini、openarm、reBot-DevArm、MicroManipulatorStepper、SO-ARM100/101 Parallel Gripper | 串联/并联结构、遥操作/自主控制 |
| **无人机** | CF-Drone、ESP-Drone | 飞行控制、穿越/微型平台 |
| **移动机器人** | Open Source Rover、Sesame Robot | 轮式/履带式移动平台 |
| **人形机器人** | lerobot-humanoid | 全身人形硬件平台 |
