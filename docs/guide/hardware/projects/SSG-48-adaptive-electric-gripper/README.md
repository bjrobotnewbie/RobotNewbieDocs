## 项目介绍
SSG-48自适应电动夹爪是一款基于Spectral微型无刷直流驱动器的开源夹爪，支持力反馈控制，夹持力可在5N至80N之间调节，适配从易碎软质到坚固硬质的多种抓取对象，行程为48mm，自重400g。
该项目开源机械文件、固件与控制软件，可自定义夹持工具并适配各类机械臂，适用于装配作业与人机协作场景。用户既可直接购买成品，也可自行采购BOM清单内的零件，按照组装手册或视频教程搭建。

## 主要特性
1.  支持精准夹持力控制，适配多场景抓取需求
2.  全栈开源，包含机械、固件与控制软件
3.  轻量化设计，仅重400g，行程48mm
4.  兼容ROS2与Python API，配套GUI调试工具
5.  提供完整的搭建文档、BOM清单与使用指南
