# VolAnti

开源声学无人机检测。它监听螺旋桨而非无线电，因此可对抗完全无信号发射的光纤 FPV 无人机。

## 项目链接

- GitHub: <https://github.com/agamrossen/VolAnti>
- 项目主页: <https://agamrossen.github.io/VolAnti/>

## 项目介绍
VolAnti是一款开源声学无人机检测项目，通过监听无人机螺旋桨的声学特征而非无线电信号来实现检测，可应对无无线电信号的光纤FPV无人机。设备主体为91mm的盒子，搭载4个麦克风、ESP32-S3、电子纸屏幕和LoRa无线电，仅提供检测告警功能，无任何反制措施。实测在轻风环境下对悬停无人机的检测距离可达104米，从识别到告警仅需0.23秒，野外测试暂无误报，单电池续航18-22小时，全套硬件成本仅50-80英镑。

## 主要特性
1.  **非无线电依赖检测**：通过螺旋桨谐波特征识别无人机，可侦测无信号的光纤FPV无人机
2.  多设备组网：支持多单元通过LoRa联动告警
3.  低功耗长续航：单电池可工作18-22小时
4.  快速响应：从识别到告警延迟仅0.23秒
5.  低成本：全套硬件成本50-80英镑
6.  两种搭建方式：支持面包板快速验证和PCB成品组装
7.  断电留存告警信息：电子纸屏幕可保留告警时间记录
