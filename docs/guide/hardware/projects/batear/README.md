## 项目介绍
batear是一款基于ESP32-S3的超低成本、仅边缘计算的声学无人机探测器，可通过加密LoRa或有线以太网/PoE发送警报，专为空域防护设计，旨在以低成本声学方案替代传统昂贵的雷达或相机无人机检测系统，适用于民用空域防护场景。

## 主要特性
1. 硬件成本极低，采用ESP32-S3平台，仅需麦克风即可实现无人机检测；
2. 仅依赖边缘计算，无需云端处理，降低部署成本与延迟；
3. 支持加密LoRa或有线以太网/PoE两种警报传输方式，适配不同部署环境；
4. 为501(c)(3)非营利项目，资金透明，可用于民用空域防护技术的实地测试与硬件研发。
