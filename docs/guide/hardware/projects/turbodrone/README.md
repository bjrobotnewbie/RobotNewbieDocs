# turbodrone

对亚马逊上的畅销无人机进行逆向工程，以实现编程控制

## 项目链接

- GitHub: <https://github.com/marshallrichards/turbodrone>

## 项目概述

## 项目介绍
本项目是针对亚马逊热销的50美元级玩具无人机开发的逆向工程API与客户端，用于替代原厂闭源移动应用，实现电脑端程序化控制。这类无人机搭载1080P FPV摄像头、下视光流传感器，出厂即具备成熟的飞行控制参数，原本仅能通过专属手机APP操控。本项目通过逆向分析原厂APP通信协议，解锁了无人机的视频流获取与飞行控制能力，可将其用于各类编程实验与应用开发。

## 主要特性
1.  支持多款经过实测的热门无人机型号，包括Generic M10、Plegble PL-515、Karuisrc K417等，不同型号对应不同的适配实现方案
2.  可获取无人机FPV视频流，部分型号支持H.265视频解码
3.  支持通过电脑发送飞行控制指令，替代原厂手机APP
4.  可将廉价玩具无人机改造为可编程开发平台，用于机器人、SLAM、RL等相关实验
