- GitHub: <https://github.com/OpenCyphal/pycyphal>
- 项目主页: <https://opencyphal.github.io/pycyphal>

## 项目概述

## 项目介绍
pycyphal是Cyphal协议栈的Python实现，支持在GNU/Linux、Windows、macOS系统上运行。当前推出的PyCyphal v2以`pycyphal2`之名发布在PyPI，可与旧版v1的`pycyphal`在同一Python环境中共存，二者在Cyphal/CAN层面有线兼容，但API差异较大。官方提示原`pycyphal`包的维护将逐步停止，现有应用应迁移至`pycyphal2`的新API。项目官方文档与示例代码可分别通过指定链接和项目内`examples/`目录获取。

## 主要特性
1.  实现完整的Cyphal协议栈，提供增强版发布/订阅能力
2.  跨平台兼容主流桌面操作系统
3.  支持与旧版本共存，平滑升级过渡
4.  提供完整官方文档与可运行示例代码
