# reBot-DevArm

- 项目链接：https://github.com/Seeed-Projects/reBot-DevArm

## 项目概述

reBot-DevArm 是一个面向所有开发者的开源机械臂项目，提供完整的开源硬件+软件栈，支持具身智能研究开发。

主要特点：
- 100% 完全开源，包含硬件设计和软件
- 获得 OSHWA 开源硬件认证，采用 CERN-OHL-W-2.0（硬件）和 Apache 2.0（软件）许可证
- 支持 ROS Noetic 和 Humble
- 集成 LeRobot 框架和 Isaac Sim 仿真
- 支持自建机械臂、机器人学习和实际应用部署

项目提供多语言 README（中文、英文、日文、法文、西班牙文），是一个面向开发者社区的开源机械臂平台。
