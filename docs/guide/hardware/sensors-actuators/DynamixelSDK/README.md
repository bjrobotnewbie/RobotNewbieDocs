## 项目介绍
本项目是ROBOTIS出品的Dynamixel SDK，是一款面向Dynamixel执行器及基于Dynamixel的机器人平台的软件开发工具包，通过数据包通信实现对Dynamixel电机的控制。
它适配ROS多版本开发环境，同时支持多种编程语言，可用于快速开发Dynamixel相关的机器人控制程序。

## 主要特性
1.  支持Protocol1.0/2.0两种通信协议
2.  支持C、C++、Python、C#、Java、MATLAB、LabVIEW等多种编程语言，提供动态库、源码及示例代码
3.  适配Kinetic、Melodic、Noetic、Dashing、Foxy、Galactic、Humble等多版本ROS开发环境
4.  提供官方详细使用手册与ROS相关包文档支持
