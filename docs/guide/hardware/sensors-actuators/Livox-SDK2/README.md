# Livox-SDK2

接收激光雷达数据并控制激光雷达的驱动程序，支持激光雷达 HAP 和 Mid-360。

## 项目链接

- GitHub: <https://github.com/Livox-SDK/Livox-SDK2>

## 项目介绍
Livox SDK2是面向HAP、Mid-360等全系列Livox激光雷达的软件开发套件，基于C/C++开发，遵循Livox SDK2通信协议，提供易用的C风格API，可快速连接Livox激光雷达并接收点云数据。套件包含核心代码、API接口和三个示例程序，同时开放用户程序与Livox产品间的通信协议。

## 主要特性
1.  支持Linux（Ubuntu18.04+）、Windows10/11系统，兼容x86、ARM架构
2.  提供C风格API，可便捷集成进C/C++项目
3.  实现激光雷达数据接收与设备控制功能
4.  附带官方示例程序，包含快速启动、日志记录、多雷达升级等场景
5.  开放对应雷达型号的通信协议文档，支持中英文版本查阅
