# 传感器与执行器

传感器与执行器是机器人感知环境和执行动作的核心硬件。传感器负责采集环境信息，执行器负责将控制指令转化为物理运动。

## 知识体系

### 传感器

| 类型 | 常用器件 | 机器人应用 |
|------|---------|-----------|
| **视觉传感器** | RGB相机、深度相机、ToF | 环境感知、目标识别、视觉伺服 |
| **触觉传感器** | 压阻、电容、光纤触觉 | 抓取力控、滑动检测、材质识别 |
| **惯性传感器** | IMU、加速度计、陀螺仪 | 姿态估计、导航定位、运动控制 |
| **距离传感器** | 激光雷达、超声波、红外 | 避障、建图、距离测量 |

### 执行器

| 类型 | 常用器件 | 机器人应用 |
|------|---------|-----------|
| **直流电机** | 有刷/无刷直流电机 | 轮式驱动、关节驱动 |
| **步进电机** | 步进电机+驱动器 | 精密定位、轻负载运动 |
| **伺服电机** | 舵机、伺服电机 | 关节控制、末端执行 |
| **直线执行器** | 电动缸、直线电机 | 推拉机构、升降机构 |
