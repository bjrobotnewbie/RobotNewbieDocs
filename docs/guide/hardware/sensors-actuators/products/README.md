## 项目介绍
本项目是HiPNUC系列IMU/AHRS/MRU、INS设备的SDK与示例集合，提供读取、配置、记录设备数据的库、工具与代码样例。支持多平台开发，包含STM32开发例程、ROS/ROS 2驱动、C语言开发包、Python SDK与命令行工具，同时还提供EtherCAT适配、MATLAB数据分析工具、CAN J1939数据库等额外资源。

## 主要特性
1.  多平台支持：覆盖STM32、ROS1/ROS2、C/C++、Python等开发环境
2.  功能全面：支持串口、CAN、Modbus RTU通信，可实现数据记录、固件更新
3.  配套资源完整：提供官方下载渠道、产品手册、 datasheet以及调试工具CHCenter
4.  适配多种设备接口：包含UART、J1939、EtherCAT等通信方式的示例与驱动
