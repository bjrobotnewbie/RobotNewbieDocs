# Sesame Robot
- GitHub仓库: https://github.com/dorianborian/sesame-robot
- 项目主页: https://www.doriantodd.com/sesame

## 项目概述
Sesame Robot是一个基于ESP32微控制器的开源微型四足机器人项目，注重表情和运动表现，适合所有技能水平的制造者和工程师。该项目设计用于让用户快速上手步行机器人开发，构建过程仅需要基本的焊接技能、50-60美元的硬件组件、3D打印机和Arduino IDE的基础知识。仓库包含了CAD设计文件、STL文件、构建和布线指南，以及基于ESP32的控制器的基础和扩展固件，还附带了一些调试固件帮助用户快速完成项目组装。
