# Book-Mathematical-Foundation-of-Reinforcement-Learning
- GitHub仓库: https://github.com/MathFoundationRL/Book-Mathematical-Foundation-of-Reinforcement-Learning

## 项目概述
这是《强化学习数学基础》书籍的LaTeX源代码仓库。本书旨在从数学角度但以友好的方式介绍强化学习的基本概念、基础问题和经典算法，核心特色包括：从数学视角讲解强化学习，帮助读者理解算法的设计原理和有效性；严格控制数学深度并以易读的方式呈现；使用网格世界任务作为示例，帮助读者理解主题和算法；分离算法的核心思想与复杂细节，让读者快速掌握核心；内容组织连贯，各章节之间相互支撑，为后续章节奠定必要的基础。本书已由Springer出版。
