# Matrix Computations

## 资源简介

Matrix Computations（矩阵计算）是由 Gene H. Golub 和 Charles F. Van Loan 合著的经典著作，是数值线性代数领域的权威参考书。该书深入讲解了各种矩阵分解和线性方程组求解算法，理论严谨且注重算法分析，是机器人学、计算机视觉、机器学习等领域研究者的必备工具书。

## 主要内容

- 矩阵分析基础
- QR分解与最小二乘问题
- Cholesky分解与对称正定矩阵
- LU分解与高斯消元法
- 奇异值分解（SVD）
- 特征值问题求解
- 迭代方法求解大型稀疏线性方程组
- 矩阵函数计算

## 特色优势

- 理论深度与数学严谨性
- 覆盖几乎所有重要的矩阵计算算法
- 算法收敛性分析和复杂度分析详尽
- 包含大量参考文献，便于深入研究
