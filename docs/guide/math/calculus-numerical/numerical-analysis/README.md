# Numerical Analysis

## 资源简介

Numerical Analysis 是由 Richard L. Burden 和 J. Douglas Faires 合著的经典数值分析教材，被全球众多高校采用作为课程教材。本书讲解清晰，由浅入深，非常适合入门学习，每章包含大量习题和实际应用案例。

## 核心内容

- 非线性方程求根：二分法、不动点迭代、牛顿法、割线法
- 数值微分与数值积分：梯形法、辛普森法、高斯求积
- 线性方程组直接解法与迭代解法
- 插值与多项式逼近：拉格朗日插值、牛顿插值、样条插值
- 曲线拟合与最小二乘逼近
- 常微分方程数值解：欧拉法、龙格-库塔法、多步法
- 边界值问题求解

## 适用场景与学习人群

- 理工科本科生，系统学习数值方法基础
