# Calculus（Thomas）

## 资源简介

《Calculus》由George B. Thomas编写，是全球广泛使用的经典微积分教材，系统全面地讲解了微积分的基础理论和应用案例，适合理工科学生系统学习微积分。

## 官方链接

- 英文教材：<https://rodrigopacios.github.io/mrpacios/download/Thomas_Calculus.pdf>
- 中文译本：<https://item.jd.com/10080638540443.html>

## 核心内容

- 单变量微积分
- 多变量微积分
- 向量微积分与微分方程
- 数值方法与应用案例

## 适用场景与学习人群

- 理工科学生，系统学习微积分基础
- 教师与研究者，作为教学参考资料
- 机器人开发者，作为微积分参考手册
