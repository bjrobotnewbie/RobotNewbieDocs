# Deep Learning Drizzle

## 资源简介

Deep Learning Drizzle 是一个深度学习数学基础的交互式学习资源集合，由 kmario23 创建和维护。该项目提供了深度学习核心概念的详细解释、数学推导和代码实现，是学习深度学习数学基础的优质资源。

## 官方链接

* GitHub代码仓库：<https://github.com/kmario23/deep-learning-drizzle>

## 主要内容

* 深度学习数学基础（线性代数、微积分、概率论）
* 神经网络架构与设计
* 反向传播算法原理
* 优化算法详解
* 正则化与泛化
* 卷积神经网络基础
* 循环神经网络基础
