# Leedl Tutorial（李宏毅深度学习）

## 资源简介

李宏毅深度学习教程是由台湾大学电机工程学系李宏毅教授开设的深度学习课程，由Datawhale社区发起的中文学习教程。该课程讲解深入浅出，配合详细的课程视频和作业，是学习深度学习的经典中文入门资源。

## 官方链接

* GitHub代码仓库：<https://github.com/datawhalechina/leedl-tutorial>
* 官方课程网站：<https://speech.ee.ntu.edu.tw/~hylee/dl/>
* 哔哩哔哩视频课程：<https://www.bilibili.com/video/BV1nE41117zP/>

## 核心内容

* 深度学习基础概念
* 神经网络与反向传播
* 卷积神经网络（CNN）
* 循环神经网络（RNN/LSTM/GRU）
* Transformer与注意力机制
* 生成对抗网络（GAN）
* 自编码器与表示学习
* 深度学习优化技巧
* 网络压缩与知识蒸馏
* 无监督学习与自监督学习
