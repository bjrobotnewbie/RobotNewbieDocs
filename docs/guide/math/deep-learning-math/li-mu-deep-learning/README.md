# 动手学深度学习（李沐）

## 资源简介

由李沐博士等人编写的深度学习入门教材，采用PyTorch框架，理论与实践相结合，是学习深度学习数学基础的经典中文教材。全书配有完整的代码实现和视频课程，适合具身智能机器人开发者系统学习深度学习。

## 官方链接

* 官方网站：<https://d2l.ai/>
* GitHub代码仓库：<https://github.com/d2l-ai/d2l-zh>
* 哔哩哔哩视频课程：<https://www.bilibili.com/video/BV1PX4y1g7KC/>

## 主要内容

* 深度学习预备知识（线性代数、概率论、数值计算）
* 线性回归与 Softmax 回归
* 多层感知机（MLP）
* 卷积神经网络（CNN）
* 循环神经网络（RNN）
* 注意力机制与 Transformer
* 优化算法与正则化
* 计算机视觉与自然语言处理应用
