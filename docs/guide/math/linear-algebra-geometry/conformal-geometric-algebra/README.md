# 共形几何代数

**共形几何代数是几何计算的统一语言，为机器人学提供了优雅而强大的数学框架。**

## 什么是共形几何代数

共形几何代数(Conformal Geometric Algebra, CGA)是建立在Clifford代数基础上，将n维欧氏空间嵌入到n+2维共形空间中，从而实现了对各种几何实体的统一代数表示。

### 核心思想

传统线性代数使用坐标来描述几何，不同几何实体需要不同的数据结构：

- 点 → 坐标向量 $(x,y,z)$
- 平面 → 方程 $ax+by+cz+d=0$
- 圆 → 圆心+半径 $(x\_0,y\_0,z\_0), r$
- 球 → 类似圆
- 变换 → 矩阵 $R, T$

共形几何代数将**所有几何实体统一表示为" blades（ blade）"**：

| 几何实体 | CGA 表示        | 等级 |
| ---- | ------------- | -- |
| 点    | 向量 (1-blade)  | 1  |
| 点对   | 二向量 (2-blade) | 2  |
| 圆/线  | 三向量 (3-blade) | 3  |
| 球/平面 | 四向量 (4-blade) | 4  |

所有几何运算都变成简单的**外积(∧)、内积(⋅)、几何乘积**，无需记复杂公式。

### 共形映射

CGA 将欧氏点 ${\bf x} \in \mathbb{R}^3$ 映射为共形空间中的零向量：

$$ X = \frac{1}{2}r^2 e\_\infty + {\bf x} + e\_0 $$

其中 $e\_0$ 是原点，$e\_\infty$ 是无穷远点。这个映射保持角度不变（共形），因此得名"共形几何代数"。

## 为什么机器人学需要共形几何代数

机器人学本质上是**在三维物理空间中运动和交互**，离不开大量几何计算。传统方法存在许多痛点：

### 传统方法的痛点

| 问题         | 传统方法                | CGA 优势                  |
| ---------- | ------------------- | ----------------------- |
| **位姿表示**   | 需要齐次变换矩阵，公式复杂       | 平移旋转直接通过转子(rotor)表示，更简洁 |
| **逆运动学**   | 需要解复杂非线性方程组，几何意义不清晰 | 直接求交点、反射，几何直观，代码简洁      |
| **碰撞检测**   | 需要针对不同形状编写不同检测算法    | 统一距离计算，自然处理所有几何形状       |
| **运动规划**   | 需要复杂坐标变换，容易出错       | 几何关系直接用代数表达，减少出错        |
| **多刚体动力学** | 旋量理论公式复杂            | 旋量自然嵌入CGA，公式更简洁统一       |

### CGA 对机器人的核心价值

1. **几何直观 + 代数计算**
   - 保持几何直觉，不会迷失在坐标中
   - 所有运算都是可计算的，能直接生成代码
2. **统一表示**
   - 点、线、面、圆、球、运动副全部统一表示
   - 碰撞检测、距离计算接口统一
3. **不变性**
   - 几何关系不依赖坐标系选择
   - 代码更通用，更容易复用
4. **更简洁的公式**
   - 很多复杂几何关系在CGA中只有一行表达式
   - 减少代码量，降低维护成本

## 在机器人学中的典型应用

### 1. 运动学与逆运动学

- **正运动学**：每个关节变换对应一个转子，转子相乘得到总变换
- **逆运动学**：通过求几何交点直接求解，比如6DOF逆运动学可以用相交圆得到解

### 2. 碰撞检测

- 基于CGA计算几何图元之间的最短距离
- 机器人各连杆之间、机器人与环境之间的碰撞检测 <https://arxiv.org/html/2312.04598v1/>

### 3. 轨迹生成

- 在CGA中，圆弧轨迹天然就是圆，可以直接插值
- 比多项式插值更自然，更容易满足几何约束

### 4. 手眼标定

- 手眼变换可以用转子方程直接求解
- AX = XB 形式在CGA中更简洁

### 5. 视觉SLAM

- 相机投影几何在CGA中表示更简洁
- 直线、圆等特征提取和匹配更方便

### 6. 可变形物体建模

- 共形变换保持角度，适合描述形变
- 对柔性物体操作有潜在优势

## 和具身智能的关系

具身智能机器人需要在物理世界中进行精确的**空间推理和几何计算**：

- 当前大模型VLM方法往往只能给出定性描述（"在左边"），缺乏厘米级精度
- CGA提供了精确的几何计算工具，可以作为具身智能系统中的**几何推理引擎**
- 结合大语言模型 + CGA几何计算，可以实现"定性理解 + 定量计算"的混合架构

## 总结

共形几何代数不是"玄学"，而是**实用的工程数学工具**：

- ✅ **已经**在机器人碰撞检测、逆运动学得到实际应用
- ✅ 公式比传统方法更简洁，几何意义更清晰
- ⏳ 在具身智能几何推理中，还有很大潜力等待挖掘

如果你厌倦了传统坐标变换中复杂的矩阵公式，想试试更优雅的几何计算方式，共形几何代数值得深入学习。
