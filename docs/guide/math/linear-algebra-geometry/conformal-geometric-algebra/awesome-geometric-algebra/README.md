## 在机器人学中的重点推荐

如果你是机器人方向，建议从这些开始：

1. **入门**：先看 ganja.js 交互式教程，建立几何直观
2. **实践**：用 pygae/clifford 在 Python 中做实验
3. **高性能**：转到 C++ gafro 或 Rust kingdon 用于生产
4. **深入**：阅读共形几何代数在逆运动学应用的经典论文
