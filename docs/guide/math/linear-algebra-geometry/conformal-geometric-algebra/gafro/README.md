# gafro

**C++17 自动微分几何代数库，专为机器人优化设计。**

## 项目链接

- GitHub: https://github.com/idiap/gafro

## 项目简介

gafro 是一个现代 C++ 几何代数库，核心特色是**原生支持自动微分**。在机器人学中，很多任务（比如逆运动学优化、轨迹优化）需要计算雅可比矩阵，gafro 可以自动导出导数，省去手动推导的麻烦。

项目由 IDIAP 研究机构开发，专注于机器人学应用。

## 核心特点

### 1. **内置自动微分 (Automatic Differentiation)**
   - 一阶、二阶导数自动计算
   - 逆运动学优化中雅可比自动导出
   - 不用手动推导，减少出错

### 2. **C++17 现代设计**
   - 模板元编程，编译期优化
   - 零运行时开销
   - 与现有 C++ 机器人项目无缝集成

### 3. **专为机器人学优化**
   - 完美配合非线性最小二乘优化
   - 支持克勒索高斯-牛顿法 (Levenberg-Marquardt)
   - 适合逆运动学、手眼标定、位姿优化

### 4. **头文件-only**
   - 只需包含头文件，不用编译
   - 轻松集成到 cmake 项目
   - 跨平台支持

## 代码示例

```cpp
#include <gafro/gafro.hpp>

// 3D 共形几何代数

// 创建点

auto p2 = CGA::Point(0.0, 1.0, 0.0);

// 创建圆（自动微分兼容）
auto circle = p1 ^ p2 ^ CGA::einfinity;

```

## 在机器人学中的应用

### 典型场景

1. **逆运动学求解**
   - 基于CGA的逆运动学公式简洁
   - 雅可比矩阵自动微分得到
   - 比传统方法代码量少很多

2. **手眼标定**
   - 手眼变换在CGA中表示简洁
   - 优化求解时自动计算梯度

3. **轨迹优化**
   - 曲线拟合、路径平滑
   - 共形空间中圆弧插值更自然

4. **SLAM 位姿优化**
   - 几何约束在CGA中表达更简洁
   - 梯度自动计算，方便g2o/gtsam集成
