# 线性代数与解析几何（郑宝东）

## 资源简介

哈工大郑宝东教授的线性代数与解析几何视频课程，讲解线性代数核心概念与几何直观，帮助理解向量空间、矩阵运算、特征值等重要知识点在几何视角下的本质。

## 官方链接

## 主要内容

* 向量与向量空间
* 矩阵运算与线性变换
* 行列式及其几何意义
* 线性方程组求解
* 特征值与特征向量
* 正交性与最小二乘
* 二次型与几何应用
* 线性代数在几何中的应用
