# MIT 18.06 线性代数（Gilbert Strang）

## 资源简介

MIT 18.06是由Gilbert Strang教授开设的经典线性代数公开课，系统讲解了线性代数的核心概念、理论和应用，是机器人学、机器学习等领域的必备数学基础。

## 官方链接

- 公开课视频：<https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/>
- 中文翻译版本：<https://www.bilibili.com/video/BV1YZQ2BDECW/?spm_id_from=333.337.search-card.all.click>

## 核心内容

- 向量空间与子空间
- 线性变换与矩阵
- 行列式与特征值
- 正交性与最小二乘
- 线性代数在机器学习和机器人学中的应用

## 适用场景与学习人群

- 机器人学开发者，需要线性代数基础用于位姿表示、感知处理
- 机器学习、计算机视觉研究者
- 理工科高年级本科生及研究生

## 学习建议

- 配合《Introduction to Linear Algebra》教材学习
- 完成课后习题，巩固线性代数概念
- 结合机器人运动学、视觉感知等场景理解应用
