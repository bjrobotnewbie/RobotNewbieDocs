# Introduction to Linear Algebra（Strang）

## 资源简介

《Introduction to Linear Algebra》是Gilbert Strang教授编写的经典线性代数教材，系统全面地讲解了线性代数的基础理论，配套MIT 18.06公开课使用，是全球广泛使用的线性代数教材。

## 官方链接

- 教材官网：<https://math.mit.edu/~gs/linearalgebra/>
- 中文译本：<https://book.douban.com/subject/38398973/>

## 主要内容

- 线性代数的基本概念与理论
- 矩阵运算与行列式
- 向量空间与线性变换
- 正交性与最小二乘
- 特征值与特征向量
- 线性代数的应用案例
