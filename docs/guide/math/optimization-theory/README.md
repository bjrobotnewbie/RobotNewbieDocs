# 优化理论

优化理论是机器人学的核心数学基础，用于运动规划、控制、参数学习、感知建模等多个场景。本章节整理了相关的学习资源。

## 资源列表

- [Convex Optimization（Boyd）](./convex-optimization-boyd/README)：凸优化经典教材及在线课程
- [Ceres Solver/OSQP 开源优化库学习资源](./ceres-osqp/README)：机器人学常用优化库学习资源
- [g2o](./g2o/README)：通用图优化C++框架，广泛应用于SLAM和光束法平差的非线性最小二乘求解

> GTSAM 已归入"概率与统计"分类（见 [概率与统计/gtsam](../probability-statistics/gtsam/README)），基于因子图与贝叶斯网络的平滑与建图库。
