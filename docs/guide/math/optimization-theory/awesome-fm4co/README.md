# awesome-fm4co

关于组合优化的Foundation模型的最新研究论文

## 项目链接

- GitHub: <https://github.com/ai4co/awesome-fm4co>

## 项目介绍
本项目是面向组合优化领域大模型（FM4CO）的精选研究论文汇总，聚焦两大方向：一是利用现有通用大语言模型解决组合优化问题，二是构建组合优化专属领域大模型。相关研究可生成、优化问题解决方案或算法，还可用于提升求解器可解释性、自动化问题建模、简化领域工具使用流程。

## 主要特性
1.  覆盖两大研究分支：现有通用LLMs适配组合优化、组合优化领域专属基础模型
2.  收录论文包含供应链优化、图问题、TSP、MILP等典型组合优化场景
3.  标注了论文发表 venue、核心解决问题、额外研究亮点等关键信息，部分论文附带开源代码
4.  涵盖算法优化、问题可解释性、自动化建模等多类研究方向
