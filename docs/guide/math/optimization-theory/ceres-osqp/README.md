# Ceres Solver/OSQP 开源优化库学习资源

## 资源简介

Ceres Solver和OSQP是机器人学中广泛使用的开源优化库，用于解决非线性最小二乘问题和二次规划问题，是机器人运动规划、控制、参数辨识的重要工具。
