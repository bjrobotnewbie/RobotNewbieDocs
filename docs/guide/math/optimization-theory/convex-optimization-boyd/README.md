# Convex Optimization (Boyd)

## 资源简介

《Convex Optimization》是凸优化领域的经典教材，由Stephen Boyd和Lieven Vandenberghe编写，系统讲解了凸优化的理论基础、算法实现和应用场景，是机器人学、机器学习、控制工程等领域的必备数学基础。

- 在线教材：<https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf>
- 在线课程：<https://www.bilibili.com/video/BV1CYhGzTExt/?spm_id_from=333.337.search-card.all.click>

## 主要内容

- 凸集、凸函数、凸优化问题的基本理论
- 对偶理论与优化算法
- 线性规划、二次规划、半正定规划等具体问题
- 凸优化在机器人运动规划、控制、感知中的应用
