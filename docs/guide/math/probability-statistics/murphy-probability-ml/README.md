# Probability for Machine Learning（Murphy）

## 资源简介

《Probability for Machine Learning》是Kevin P. Murphy编写的经典机器学习概率理论教材，系统全面地讲解了概率统计在机器学习中的应用，为机器人学习提供了重要的数学基础。

## 官方链接

- 教材官网：<https://probml.github.io/pml-book/>

## 核心内容

- 概率统计基础
- 贝叶斯方法与图模型
- 机器学习中的概率模型
- 概率推断与学习

## 适用场景与学习人群

- 机器人学习研究者
- 机器学习、计算机视觉开发者
- 理工科研究生，学习机器学习概率基础

## 学习建议

- 配合开源代码库实践学习
- 完成课后习题，巩固概率统计知识
