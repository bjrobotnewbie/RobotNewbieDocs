## 项目概述

## 项目介绍
rednose是一款Python卡尔曼滤波库，可用于优化问题，尤其适配视觉里程计、传感器融合定位以及SLAM场景。它支持在线/离线运行，计算效率较高，能够提供精准的估计结果，且便于在Python中快速设计滤波器。

## 主要特性
1.  **符号雅可比自动计算**：基于sympy自动生成扩展卡尔曼滤波所需的雅可比矩阵，无需手动推导，避免人为计算错误，简化复杂非线性系统的建模流程。
2.  **支持误差状态卡尔曼滤波**：针对3D定位中的四元数姿态估计痛点，解决四元数冗余维度、归一化难题，适配三维空间状态估计需求。
3.  内置多种滤波变体可选，兼顾精度与计算复杂度，适配多数常规应用场景。
