# Probability and Robotics（Thrun）

## 资源简介

《Probability and Robotics》是Sebastian Thrun编写的机器人学概率理论经典教材，系统讲解了概率理论在机器人感知、定位、决策中的应用，是机器人学领域的必备参考书。

## 官方链接

- 教材官网：<https://robots.stanford.edu/probabilistic-robotics/>

## 核心内容

- 概率理论基础
- 贝叶斯估计与滤波
- 机器人定位与地图构建
- 概率规划与决策

## 适用场景与学习人群

- 机器人感知、SLAM研究者
- 机器人学研究生，学习概率机器人学
- 开发者，需要处理机器人感知中的不确定性

## 学习建议

- 配合开源代码库实践学习
- 完成课后习题，巩固概率机器人学概念
