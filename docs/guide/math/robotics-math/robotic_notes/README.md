本仓库包含我的关于李群和李代数、机器人及空间拓扑与配置、IMU、ROS2 Gazebo 集成、状态估计、VIO 和基于深度学习的 SLAM 的片段与教程。

- GitHub: <https://github.com/behnamasadi/robotic_notes>

## 项目概述

## 项目介绍
本项目是机器人学相关的代码片段与教程合集，覆盖李群李代数、机器人与空间拓扑构型、IMU、ROS2与Gazebo集成、状态估计、VIO、LIO以及基于深度学习的SLAM等多个机器人核心技术方向，同时提供了配套的安装部署教程。

## 主要特性
1.  **技术覆盖全面**：包含机器人学基础数学、多传感器融合、SLAM、深度学习视觉SLAM等主流机器人开发方向的学习资料
2.  **双语言支持**：提供C++和Python两种实现的代码示例，适配不同开发场景
3.  **标准化部署**：基于vcpkg管理C++依赖，使用conda管理Python依赖，提供详细的安装编译流程
4.  适配Ubuntu Linux平台，支持通过CMake和conda快速搭建开发环境，部分示例可通过Jupyter Notebook运行演示。
