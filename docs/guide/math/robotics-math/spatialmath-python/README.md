# spatialmath-python

使用 Python 创建、操纵并转换 2D 或 3D 中的位置和方向表示。

## 项目概述

## 项目介绍
该项目是MATLAB Spatial Math Toolbox的Python实现，用于在Python中创建、操作并转换二维、三维空间内的位置与姿态表示。其底层空间数学能力支撑机器人学与机器视觉领域的物体位姿描述需求，可通过PyPI、conda-forge安装，支持多Python版本，遵循MIT开源协议。

## 主要特性
1.  支持多种位姿与姿态表示：
    - 3D空间：`SE3`、`Twist3`、`UnitDualQuaternion`、`SO3`、`UnitQuaternion`
    - 2D空间：`SE2`、`Twist2`、`SO2`
2.  提供完整的数学运算与转换能力，可用于机器人、机器视觉相关的空间位姿处理场景。
