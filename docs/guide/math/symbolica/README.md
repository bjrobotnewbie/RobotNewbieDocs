# symbolica

- 项目链接：https://github.com/symbolica-dev/symbolica
- 项目主页：https://symbolica.io

## 项目概述

Symbolica 是一个高性能的计算机代数库，同时支持 Python 和 Rust，专为处理大型表达式、符号重写、精确多项式运算和优化数值计算而设计。该项目已被 CERN 以及苏黎世联邦理工学院、苏黎世大学、伯尔尼大学和卡尔斯鲁厄理工学院等研究机构信赖使用。

### 核心特点

- **双语言 API**：提供原生的 Python 和 Rust API 共享同一个符号计算核心
- **优化数值计算**：支持 JIT、C++、SIMD、汇编和 CUDA 代码生成，输出优化的数值求值器
- **快速多项式运算**：针对大型符号计算工作负载优化了多变量多项式运算
- **模式匹配与重写**：支持特定领域代数的模式匹配和重写操作
- **混合计算**：支持精确计算和数值计算混合，并带误差传播
- **流式处理**：提供流式工具处理大到无法完全存入内存的表达式

### 安装方式

**Python：**
```bash
pip install symbolica
```

**Rust：**
```bash
cargo add symbolica
```

### 使用示例（单摆校准）

Symbolica 可以结合符号操作、级数展开、替换、参数化线性系统求解和数值评估，完成完整的计算工作流：

1. 从一个由比例系数 `κ` 控制恢复扭矩的单摆开始，建立势能和扭矩方程
2. 将扭矩展开得到小角度模型
3. 在未知比例系数和传感器偏移的情况下，通过两次测量值求解线性系统得到参数拟合结果
4. 代入测量值得到最终计算结果

### 应用场景

Symbolica 适用于需要大规模符号计算的科研场景，包括粒子物理（CERN 已在使用）、机器人学中的运动学推导、优化问题中的符号微分、控制系统分析等需要精确代数运算的领域。
