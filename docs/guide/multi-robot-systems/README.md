# 多机器人系统

多机器人系统关注多个机器人如何组织、通信、协同、分工和完成任务。它描述的是机器人之间的关系和协同机制，不是单个机器人本体的物理形态。

## 分类体系

| 分类 | 说明 | 典型应用 |
|------|------|---------|
| [地面机器人群体](./ground-swarm/README) | 多个地面机器人协同 | 搜救、测绘、仓储调度 |
| [空中机器人集群](./drone-swarm/README) | 多无人机编队与协同 | 无人机表演、监控、巡检 |
| [水下机器人群体](./underwater-swarm/README) | 多个水下机器人协同 | 海洋探测、水下监测 |
| [微纳米机器人群体](./micro-nano-swarm/README) | 微纳米尺度群体协同 | 靶向给药、微操作 |
| [太空机器人群体](./space-swarm/README) | 太空环境下的多机器人协同 | 航天器巡检、轨道作业、行星探测 |
| [通信与协同机制](./communication-coordination/README) | 多机器人通信、数据平面、协同中间件 | 边缘机器人系统、跨平台协同 |
| [相关工作](./related_work/README) | 多机器人系统相关研究 | 论文、项目与综述 |

## 分类边界

- 单个四旋翼无人机属于机器人形态 / 空中机器人。
- 无人机集群属于多机器人系统 / 空中机器人集群。
- 无人机灯光表演属于应用场景，可交叉引用空中机器人集群。
- 多机器人路径规划、任务分配、协同建图等主题优先归入多机器人系统。
