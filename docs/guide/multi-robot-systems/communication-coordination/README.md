# 通信与协同机制

本分类收录多机器人系统中的通信、数据平面、协同中间件和跨平台数据流工具，重点关注多个机器人、传感器和边缘节点如何共享状态、任务和数据。

## 核心问题

多机器人系统与单机器人系统的本质区别在于"协同"，而协同的基础是通信。本分类关注以下核心问题：

| 问题 | 说明 | 典型方案 |
|------|------|---------|
| **通信拓扑** | 机器人之间如何连接（全连接、星型、网状） | WiFi Mesh、5G、自组网 |
| **数据共享** | 多个机器人如何共享状态、地图、任务 | DDS、ROS 2 通信、共享黑板 |
| **一致性** | 分布式系统中的状态一致性 | 共识算法、向量时钟 |
| **容错性** | 通信中断或节点失效时的系统鲁棒性 | 心跳检测、冗余链路 |

## 关键技术方向

### 1. 通信中间件

多机器人系统常用的通信中间件包括：

- **DDS (Data Distribution Service)**：ROS 2 的底层通信层，支持发布/订阅模式，提供 QoS 保障
- **ZeroMQ**：轻量级消息队列，适合高性能低延迟场景
- **MQTT**：物联网常用协议，适合带宽受限环境
- **Zenoh**：新兴的网络协议，支持.pub/sub 和 RPC，低开销

### 2. 协同框架

- **分布式任务分配**：市场拍卖、合同网协议、博弈论方法
- **协同路径规划**：多机器人避碰、编队保持、任务分配
- **共享建图**：分布式 SLAM、地图融合、协同探索

### 3. 跨平台数据流

多机器人系统中，传感器数据、控制指令、状态信息需要在不同平台间流转。这涉及：

- 数据序列化格式（Protobuf、FlatBuffers）
- 时间同步（NTP、PTP）
- 坐标系变换（TF tree）
