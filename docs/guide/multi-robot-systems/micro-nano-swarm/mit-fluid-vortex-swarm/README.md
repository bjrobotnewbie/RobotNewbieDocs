# MIT 流体涡流微纳米机器人群体

MIT 研究团队开发的数百个微米级磁控圆盘组成的群体，在旋转磁场中运动产生流体涡流，实现非接触式物体操控。

## 群体行为

- 每个微米圆盘独立受磁场控制
- 群体运动产生流体涡流效应
- 涡流相互作用实现协同操控
- 可驱动微型齿轮、旋转大质量物体

## 关键技术

- **微尺度流体力学**：利用低雷诺数下涡流效应
- **全局磁场控制**：单个简单，群体复杂行为涌现
- **自供电变体**：气泡破裂能量驱动，无需外接电池

## 典型应用

- 微流控生物分析
- 微米级组装
- 微小颗粒分选
- 微机电系统驱动
