# 相关工作

本分类收录多机器人系统相关的研究论文、综述和参考资料。

## 综述与关键论文

### 经典综述

| 论文 | 年份 | 核心贡献 |
|------|------|---------|
| **Multi-Robot Systems** (Yan et al.) | 2013 | 多机器人系统分类框架，涵盖架构、通信、协同 |
| **Swarm Robotics: A Review** (Dorigo et al.) | 2014 | 群体机器人技术的系统性综述 |
| **Distributed Multi-Robot Exploration** | 2005 | 多机器人协同探索的分布式算法 |

### 关键研究方向

#### 1. 多机器人路径规划
- **CBS (Conflict-Based Search)**：多智能体路径规划的经典算法
- **M* (M-star)**：基于 A* 的多机器人路径规划
- **Prioritized Planning**：基于优先级的规划方法

#### 2. 多机器人任务分配
- **OPTIMAP**：多机器人任务分配优化
- **MRTA (Multi-Robot Task Allocation)**：任务分配的分类框架
- **市场拍卖方法**：基于经济模型的任务分配

#### 3. 协同建图与探索
- **Distributed Pose Graph Optimization**：分布式位姿图优化
- **Multi-Robot SLAM**：多机器人 SLAM 的数据融合
- **Frontier-based Exploration**：基于前沿的协同探索

#### 4. 群体智能
- **Boids 模型**：基于群体行为的鸟群模拟
- **ACO (Ant Colony Optimization)**：蚁群优化算法
- **PSO (Particle Swarm Optimization)**：粒子群优化
