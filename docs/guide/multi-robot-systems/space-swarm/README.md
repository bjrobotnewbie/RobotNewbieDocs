# 太空机器人群体

太空机器人群体是群体机器人在太空环境的应用，多个机器人在微重力、高真空、强辐射等极端条件下协同完成航天器维护、轨道作业、行星探测等任务。

## 环境特点与挑战

太空环境特点：
- **微重力**：无浮力对流，运动方式与地面完全不同
- **高真空**：散热只能靠辐射，润滑与运动副设计受限
- **强辐射**：电子器件需要抗辐射加固
- **极端温差**：阳照面与阴影面温差可达数百摄氏度
- **通信延迟**：地月通信延迟约 1.3 秒，深空更久，必须高度自主

这些挑战使得太空群体机器人需要比地面和空中更高的自主性与可靠性。

## 典型应用

- **航天器表面巡检**：微型机器人群体在航天器外壳爬行检测
- **轨道协同作业**：多颗卫星协同完成在轨组装、维修
- **行星表面探测**：多辆探测车/微型探测器协同测绘与采样
- **太空建造**：群体协同组装大型空间结构
- **碎片清理**：群体协同捕获与清除轨道碎片

## 子分类方向

| 方向 | 作业环境 | 典型对象 |
|------|---------|---------|
| 轨道群体 | 近地轨道 / 深空轨道 | 在轨服务卫星群、航天器表面巡检微型群体 |
| 行星表面群体 | 月球 / 火星等地表 | 探测车群、跳跃式微型探测器群 |

## 代表性研究

- **AstroAnts（太空蚂蚁）** - MIT Media Lab 推出的月球轨道航天器外部检测与维护微型机器人群体，配备磁轮，可在微重力环境下吸附并爬行于航天器表面进行诊断
- **NASA Swarmathon** - NASA 主导的小型机器人群体协作探索项目
- **ESA HERACLES** - 欧空局月球探测协同任务概念

## 关键技术

1. **微重力运动**：磁吸附、抓持、喷气等非传统移动方式
2. **自主协同**：通信延迟下群体的分布式决策
3. **能量供给**：太阳能与无线能量传输
4. **抗辐射可靠性**：长期在轨运行的容错机制

## 与其他分类的边界

- 近地大气层内的无人机集群属于 [空中机器人集群](../drone-swarm/README)
- 单个太空机器人的本体形态归入 [机器人形态](/guide/robot-forms/README)（如爬壁机器人、特殊移动机器人）
- 本分类聚焦多个太空机器人之间的协同关系

太空群体机器人目前处于研究与概念验证阶段，随着月球与深空探测计划推进，未来需求将持续增长。
