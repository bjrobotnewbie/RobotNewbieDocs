# AstroAnts 太空蚂蚁机器人群体

AstroAnts 是 MIT Media Lab 推出的专为月球轨道航天器外部检测与维护设计的微型机器人群体，配备磁轮，能在微重力环境下吸附并爬行于航天器表面进行诊断工作。

## 任务目标

- 航天器外部状态检测
- 早期故障诊断
- 微小损伤识别
- 轨道航天器维护

## 关键设计

- **尺寸**：微型，单只蚂蚁尺度很小
- **吸附方式**：磁轮吸附，适用于航天器金属外壳
- **环境适应**：微重力环境优化设计
- **群体协同**：多只蚂蚁分工完成大面积检测
