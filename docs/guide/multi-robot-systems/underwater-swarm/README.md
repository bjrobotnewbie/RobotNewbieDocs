# 水下群体机器人

水下群体机器人是群体机器人在水下环境的应用，多个水下机器人协同完成海洋探测、环境监测等任务，面临通信、定位、控制等多重挑战。

## 环境特点与挑战

水下环境特点：
- **通信难**：无线电衰减大，只能声学通信
- **定位难**：GPS不能用，需要水声定位
- **扰动大**：水流扰动影响位置
- **能耗限制**：水下充电困难

这些挑战使得水下群体机器人比地面和空中难度大很多。

## 典型应用

- **海洋环境监测**：多个AUV监测海洋温盐深
- **海底测绘**：群体协同测绘海底地形
- **水下搜索**：搜索失事飞机黑匣子
- **水产养殖**：监测渔网和鱼类生长
- **海底管线检测**：检测石油天然气管线

## 代表性项目

- **Swarmanoid** - 欧洲异构群体机器人项目 http://www.swarmanoid.org/
- **AutoSwarm** - 澳大利亚CSIRO水下群体 https://www.csiro.au/en/research/
- **MBARI Swarm** - 美国蒙特雷湾水族馆研究所群体 https://www.mbari.org/

## 关键技术

1. **水声通信**：低速率水声通信组网
2. **协同定位**：没有GPS情况下协同定位
3. **路径规划**：考虑洋流的路径规划
4. **长时间续航**：节能策略，水下充电

水下群体机器人研究还在进行中，实际应用还比较有限，但随着海洋开发，未来需求会越来越大。
