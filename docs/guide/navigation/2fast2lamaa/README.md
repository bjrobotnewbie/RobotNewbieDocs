# 2fast2lamaa

大规模环境中的实时激光雷达 - 惯性导航与定位及建模范式

## 项目链接

- GitHub: <https://github.com/clegenti/2fast2lamaa>

## 项目介绍
2Fast-2Lamaa是一款面向大型场景的实时激光惯性里程计与建图框架，支持激光雷达与IMU融合定位建图，也可脱离IMU单独运行。它采用基于高斯过程的距离场作为地图表示，支持在线/离线动态物体移除，核心通过优化方式实现激光点云畸变校正，仅用11个状态变量完成运动畸变修正，可输出扫描到扫描里程计，并通过扫描到地图配准保证长期几何一致性。

## 主要特性
1.  支持三种运行模式：`imu`（融合IMU加速度计与陀螺仪预积分）、`gyr`（仅用陀螺仪预积分，假设全局匀速运动）、`no_imu`（假设全局匀速+匀速旋转运动）
2.  底层空间索引替换为i-Octree，提升运行速度并降低内存占用
3.  新增重力约束优化GP地图配准效果，适配郊区、隧道、高架、高速等多种大型场景
4.  支持生成8km级别的长轨迹全局地图，可用于大规模环境的定位与建图任务
