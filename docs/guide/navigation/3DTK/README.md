# 3DTK

3D Toolkit 提供处理 3D 点云的算法与方法。其中包括自动精确配准（6 自由度同时定位与建图，6D SLAM）及其他工具，例如快速 3D 查看器、平面提取软件等。

## 项目链接

- GitHub: <https://github.com/JMUWRobotics/3DTK>

## 项目概述

## 项目介绍
3DTK（The 3D Toolkit）是一款3D点云处理工具集，提供了高精度的自动配准算法，支持6D SLAM（同时定位与地图构建），还内置快速3D查看器、平面提取等工具，原生支持多种点云文件格式，且可轻松扩展支持新格式。项目支持Ubuntu、Debian、macOS和Windows系统编译，同时兼容ROS1（Kinetic、Melodic、Noetic），正在开发ROS2支持，部分工具还可适配3DConnexion SpaceMouse进行导航操作。

## 主要特性
1.  核心功能为3D点云处理，包含高精度6D SLAM自动配准
2.  附带快速3D查看器、平面提取等实用工具
3.  原生支持多种点云文件格式，可快速扩展新格式
4.  跨平台编译支持，适配Linux、macOS和Windows系统
5.  支持ROS1，正在开发ROS2兼容能力
6.  部分可视化工具支持3DConnexion SpaceMouse导航操作
