# All-3R-SLAM-in-this-Repo

- 项目链接：https://github.com/3D-Vision-World/All-3R-SLAM-in-this-Repo

## 项目概述

All-3R-SLAM-in-this-Repo是一个关于**3D几何基础模型（3R）及其在SLAM中的应用的精选参考文献列表**。该仓库整理汇总了近年来在3D几何 foundation models 领域的重要研究成果，主要内容包括：

1. **综述论文**：收集了关于前馈3D重建和视图合成的最新综述文章，帮助研究者快速了解领域发展
2. **3D几何基础模型**：系统整理了DUSt3R、Monst3r、LoRA3D、CUT3R、Reloc3r、DAS3R、MASt3R-SfM等众多代表性3R模型的论文链接、代码和项目主页
3. **SLAM相关方向**：涵盖了RGB-D SLAM、语义SLAM、神经SLAM等多个方向的最新研究进展
4. **持续更新**：跟踪收录顶会（CVPR、ICLR、ECCV等）最新发表的相关研究

这个仓库是3D视觉、几何基础模型和SLAM研究领域非常有用的资料汇总，方便研究者快速追踪领域最新进展。
