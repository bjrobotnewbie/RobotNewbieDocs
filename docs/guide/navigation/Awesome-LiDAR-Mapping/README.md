# Awesome-LiDAR-Mapping

论文集合：带有代码的 LiDAR 里程计/SLAM、动态物体去除以及多地图融合

## 项目链接

- GitHub: <https://github.com/hwan0806/Awesome-LiDAR-Mapping>

## 项目介绍
本项目是一个开源的激光雷达建图相关论文与代码汇总仓库，聚焦于激光雷达里程计/SLAM、动态物体移除、多地图拼接三大方向，为机器人长期自主作业提供核心技术支持。用户可通过PR或issue补充遗漏或分类错误的相关工作。

## 主要特性
1.  **分类全面**：按纯激光雷达、激光-惯性融合、多激光雷达、学习建图、静态地图构建（含算法移除动态物、学习分割）、多地图拼接等方向分类整理
2.  **持续更新**：近期新增了SR-LIO、PIN-SLAM等多篇顶会顶刊相关的开源方案
3.  附带实用的激光雷达里程计、SLAM框架（里程计+位姿图优化）、模型评测相关的优质仓库资源，以及同类精选汇总项目链接。
