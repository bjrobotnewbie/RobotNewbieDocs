## 项目概述

## 项目介绍
本项目是一个基于Transformer的SLAM相关研究论文整理清单，涵盖了光流估计、视图/特征匹配、立体匹配、深度估计、3D重建、位姿估计等SLAM相关任务的精选资源。

## 主要特性
1.  **核心覆盖范围**：收录了基于Transformer的完整SLAM、位姿跟踪、光流、视图匹配、建图等方向的研究成果
2.  **资源分类清晰**：按照任务类型划分为多个子模块，方便按需求检索
3.  **细节完善**：收录的论文附带发表年份、会议、代码仓库、关键技术说明等信息，例如VGGT-SLAM++、SceneVGGT等典型工作
4.  **社区共建**：欢迎提交PR或Issue补充遗漏的论文，支持任意形式的贡献完善清单。
