## 项目介绍
这是一个动态SLAM、终身SLAM相关的优质论文资源列表，聚焦于激光、视觉、多传感器融合等方向的动态环境SLAM与终身SLAM研究。项目收录了相关顶会顶刊论文，多数附带论文链接与开源代码仓库。

## 主要特性
1.  **核心方向**：涵盖动态环境SLAM、终身SLAM，包含检测移除动态干扰、检测跟踪动态目标两类主流鲁棒方案，同时收录部分动态建图相关优质内容
2.  **多模态支持**：覆盖视觉、激光、雷达、多传感器融合等多种传感器方案
3.  **时效性强**：更新至2026年8月，收录CVPR、WACV、IEEE RA-L等顶会顶刊最新研究
4.  **资源完整**：多数条目附带论文原文与作者开源代码/演示仓库
