## 项目概述
DotRecast是Recast & Detour的C#版本，是行业标准的导航网格工具集的C#移植版本，适用于.NET、Unity3D、游戏服务器等场景。该项目提供了完整的导航网格生成、路径查找和动态障碍物回避功能，支持多种平台和应用场景，是游戏开发和机器人导航领域的优秀工具。
