# ELite

[ICRA 2025] ELite：即时性邂逅基于激光的长期映射

## 项目链接

- GitHub: <https://github.com/dongjae0107/ELite>

## 项目介绍
ELite是ICRA 2025提出的基于LiDAR的终身建图框架，核心是将“短暂性”概念融入建图全流程，突破传统地图元素仅分为静态/动态的二元分类局限，通过双阶段短暂性建模实现多会话地图对齐、动态物体剔除，最终生成精准的长期可用地图，适用于需要长期环境感知的场景。

## 主要特性
1. 引入双阶段短暂性概念：Local ephemerality捕捉短期变化（如移动车辆与停放车辆的差异），Global ephemerality表征长期变化（如停放车辆与新建建筑的差异）；
2. 支持多会话地图无缝对齐，自动剔除动态干扰，保障终身建图的精度与可靠性；
3. 提供完整部署流程，支持CUDA加速匹配（可选安装pygicp），可基于停车场数据集快速测试运行。
