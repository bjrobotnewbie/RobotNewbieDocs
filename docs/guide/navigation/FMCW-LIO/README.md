# FMCW-LIO

FMCW-LIO：一种多普勒激光雷达 - 惯性里程计 [IEEE RA-L 2024]

## 项目链接

- GitHub: <https://github.com/IMRL/FMCW-LIO>
- 项目主页: <https://doi.org/10.1109/LRA.2024.3396636>

## 项目介绍
FMCW-LIO是IEEE RA-L 2024收录的4D多普勒激光雷达-惯性里程计框架，利用FMCW多普勒激光雷达的固有多普勒速度测量值实现精准位姿估计与静态建图，适用于结构退化场景。

## 主要特性
1. 引入运动补偿方案与多普勒辅助观测模型，支持流形上的状态估计；
2. 采用多普勒准则有效剔除动态点，提升几何观测一致性；
3. 集成无扫描、无运动、无对应关系的初始化方法Free-Init，降低使用门槛；
4. 提供配套论文、演示视频及公开数据集，便于复现与研究。
