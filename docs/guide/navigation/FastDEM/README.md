# FastDEM

嵌入式移动机器人的实时 2.5D 高程映射引擎：基于 C++17 的核心，可选 ROS1/ROS2 支持

## 项目链接

- GitHub: <https://github.com/Ikhyeon-Cho/FastDEM>

## 项目介绍
FastDEM是一款面向嵌入式移动机器人的超轻量2.5D高程地图引擎，核心基于C++17开发，可选择集成ROS1/ROS2支持。它能够以控制环路速率（Jetson Orin平台可达100Hz以上），将LiDAR或RGB-D点云增量融合为局部或全局地形高程地图，仅运行于CPU端，还支持地形后处理以支持下游导航和可通行性分析。

## 主要特性
1.  **极速运行**：Jetson Orin平台可达100Hz以上，单帧处理仅约10ms
2.  **轻量无依赖**：仅依赖Eigen，无需PCL、OpenCV或CUDA
3.  **ROS无关性**：提供简洁C++ API，可选ROS适配器
4.  **传感器适配**：支持LiDAR和RGB-D相机的物理测距模型
5.  **多估计器支持**：包含卡尔曼滤波（参数化）和P²分位数估计器（非参数化）
6.  **多地图模式**：支持机器人-centric和地图-centric两种建图方式
7.  **丰富后处理**：支持光线投射、不确定性融合、图像修复、特征提取等功能
