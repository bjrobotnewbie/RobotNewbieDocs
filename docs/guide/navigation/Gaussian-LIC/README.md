## 项目概述

## 项目介绍
Gaussian-LIC2是一款实时激光-惯性-视觉融合Gaussian Splatting SLAM系统，同时实现高精度鲁棒位姿估计与照片级真实感3D高斯地图构建，相关研究成果发表于ICRA 2025与IJRR 2026。项目提供了论文、项目主页与演示视频资源。

## 主要特性
1.  支持多传感器融合：融合LiDAR、IMU与相机数据
2.  实时运行：可在消费级GPU上完成实时建图与定位
3.  照片级重建：基于Gaussian Splatting输出高真实感三维场景模型
4.  支持主流Ubuntu 20.04环境，搭配NVIDIA RTX 3090/4090显卡即可部署运行
