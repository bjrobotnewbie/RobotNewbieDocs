## 项目概述

## 项目介绍
Ground-Fusion是一款低成本、适配复杂极端场景的地面SLAM系统，入选ICRA2024。该项目由上海交通大学殷杰团队开发，配套提供了M2DGR-plus数据集，同时附带论文、演示视频等相关资源。后续团队还推出了衍生项目Ultra-Fusion与Ground-Fusion++，并更新了M3DGR数据集。

## 主要特性
1.  主打低成本硬件适配，针对地面移动机器人场景优化
2.  针对SLAM常见极端场景具备强鲁棒性
3.  提供完整的开源代码与配套数据集，遵循GPLv3开源协议
4.  支持快速上手演示与二次开发适配
