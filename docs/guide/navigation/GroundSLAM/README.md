# GroundSLAM

GroundSLAM：一种利用地面纹理的仓储机器人鲁棒视觉SLAM系统

## 项目链接

- GitHub: <https://github.com/sair-lab/GroundSLAM>

## 项目概述

## 项目介绍
GroundSLAM是一款专为仓储机器人设计的鲁棒视觉SLAM系统，基于地面纹理实现无特征点的定位方案。它可在存在大量动态物体或开阔空间的仓储场景中提供可靠的位姿估计与定位，解决了传统前向相机或LiDAR定位方案在该类场景下的定位难题。系统包含无特征视觉里程计、基于地面纹理的回环检测与地图优化、地图复用三大模块，通过核互相关器实现图像级位姿跟踪，并采用自适应剪枝策略提升运行效率，在低纹理或高重复模式的地面图像场景下，相比传统基于特征的SLAM方案具备更强的鲁棒性与精度。

## 主要特性
1.  无特征点设计，基于地面纹理实现定位
2.  适配仓储等存在大量动态物体、开阔空间的复杂场景
3.  采用核互相关器完成图像级位姿跟踪、回环检测与地图复用
4.  搭载自适应剪枝策略优化运行效率
5.  支持ROS环境部署，提供完整编译与运行流程
