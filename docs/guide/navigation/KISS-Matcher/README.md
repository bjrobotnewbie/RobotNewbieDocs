## 项目概述
KISS-Matcher是一个快速、鲁棒且可扩展的点云配准工具，同时包含ROS2 SLAM示例。该项目采用“保持简单，可扩展”的设计理念，提供了C++和Python两种接口，支持Ubuntu和macOS等平台，兼容ROS2 Humble版本。其核心功能包括高效的点云配准算法和完整的SLAM实现，适用于机器人导航、三维重建等领域的研究和开发。
