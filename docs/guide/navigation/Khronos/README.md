# Khronos

时空语义 SLAM

## 项目链接

- GitHub: <https://github.com/MIT-SPARK/Khronos>

## 项目介绍
Khronos是一款面向动态环境的在线时空度量语义SLAM框架，可同时推理场景内的短期动态变化与长期场景变更。它能够构建全时段的时空地图，可检测包括人类、移动推车在内的短期动态物体，还能在机器人重访场景时识别出桌椅、物品摆放等长期场景变化，曾获2024年RSS杰出系统论文奖，目前已推出ROS2版本。

## 主要特性
1.  支持统一处理短期动态与长期场景变更的度量语义SLAM
2.  可生成全时段的4D时空场景地图
3.  支持开放集分割能力，适配多种动态物体检测
4.  提供数据集、真实场景运行、可视化、评估等完整工具链
5.  已推出ROS2版本，支持实时部署
