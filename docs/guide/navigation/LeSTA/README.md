# LeSTA

[RA-L '24] 基于移动机器人导航经验的自监督可达性学习：一种风险感知的自训练方法

## 项目链接

- GitHub: <https://github.com/Ikhyeon-Cho/LeSTA>
- 项目主页: <https://ieeexplore.ieee.org/document/10468651>

## 项目介绍
LeSTA是一个自监督移动机器人导航通行能力学习框架，仅通过短时间人工驾驶即可生成专属机器人的通行性模型，无需额外标注数据。它提供了从标签生成到实时通行性预测与建图的端到端流程，相关论文发表于IEEE Robotics and Automation Letters (RA-L 2024)，并将在ICRA@40进行展示，同时还发布了城市环境地形通行性公开数据集。

## 主要特性
1.  **自监督学习**：无需人工标注即可学习机器人专属通行性模型
2.  **端到端流程**：覆盖从手动驾驶数据采集、标签生成到实时通行性预测与建图全链路
3.  **多ROS支持**：已适配ROS Noetic，ROS2版本即将推出
4.  **轻量化部署**：模型可在单CPU核心上高效运行，无需依赖GPU
5.  配套提供相关开源工具如FastDEM快速高程建图库。
