# Leg-KILO

Leg-KILO：面向动态履带机器人的鲁棒性姿态 - 惯性 - 激光测距 odometry

## 项目链接

- GitHub: <https://github.com/ouguangjun/Leg-KILO>

## 项目介绍
Leg-KILO是一款面向动态腿式机器人的鲁棒运动-惯性-激光里程计系统，同时也是实时激光SLAM方案。项目已将kilo-map功能合并，可切换`legkilo-v2`分支查看Leg-KILO 2.0版本，支持ROS1和ROS2，采用MIT开源协议。

## 主要特性
1.  **混合特征高斯体素地图**：增量维护平面、NDT变体等不确定混合特征，适配结构化与非结构化环境
2.  **两级ESKF前端**：融合LiDAR与IMU，通过两级激光更新处理高动态运动：第一阶段沿扫描时序逐点校正运动畸变，第二阶段将畸变校正后的点云回传到机体坐标系，通过迭代ESKF优化全局一致性，适配腿式机器人激进运动
3.  **因子图后端**：基于Ceres实现因子图优化，紧耦合回环约束与里程计因子，搭配small_gicp、KISS-Matcher提升回环匹配精度，降低全局漂移
4.  **实时可视化与地图输出**：基于Iridescence实现3D实时可视化与调试，可输出轨迹用于算法评估，支持保存全局地图（单文件或分块瓦片）用于定位
5.  **跨平台适配**：支持ROS1/ROS2，多传感器配置参数复用性强，无需大量调参即可适配不同平台与传感器套件。
