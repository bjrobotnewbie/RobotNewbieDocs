# MASt3R-Fusion

基于前馈视觉模型与惯性测量单元（IMU）、全球导航卫星系统（GNSS）的集成，实现高性能 SLAM。

## 项目链接

- GitHub: <https://github.com/GREAT-WHU/MASt3R-Fusion>

## 项目介绍
MASt3R-Fusion是一款SLAM系统，基于MASt3R-SLAM改进，将前馈式点地图回归与IMU、GNSS等多传感器进行紧耦合融合，面向实用化、大规模三维感知与建图场景。该系统仅需8GB显存即可处理任意长度的序列数据。

## 主要特性
1.  高精度、高鲁棒性且具备度量尺度的建图能力
2.  支持全视图深度估计
3.  多传感器融合适配
4.  具备回环检测功能
5.  集成实时滑窗跟踪与全局一致性优化
6.  支持自动标定
