## 项目介绍
MBCompass是一款面向Android平台的现代化免费开源罗盘与导航应用，采用Jetpack Compose开发，无广告、无内购、无用户追踪。它定位介于基础罗盘与全功能导航软件之间，适用于徒步、旅行以及日常使用，可提供方向指引、实时定位和轨迹记录功能，同时兼顾轻量化、简洁性与低功耗特性。

## 主要特性
1.  纯FOSS开源，遵循GPLv3协议，支持Android API 23及以上版本
2.  无广告、无内购、无用户数据追踪
3.  集成罗盘、实时定位与轨迹记录功能
4.  轻量化设计，电池消耗低，界面简洁直观
5.  可通过F-Droid、Google Play、IzzyOnDroid以及GitHub等多渠道安装
