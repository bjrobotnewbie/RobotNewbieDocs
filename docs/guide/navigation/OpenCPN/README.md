# OpenCPN

一款简洁的海图绘制器/导航仪。这是一款跨平台船载GUI应用程序，支持：
* GPS/GPDS位置输入
* BSB光栅海图显示
* S57矢量电子海图显示
* AIS输入解码
* 航点自动舵导航

## 项目链接

- GitHub: <https://github.com/OpenCPN/OpenCPN>
- 项目主页: https://opencpn.org/

## 项目概述

## 项目介绍
OpenCPN是一款轻量级海图绘图/导航软件，是跨平台的船载GUI应用程序，主要作为船舶专职导航界面，用于日常航海导航作业。它基于wxWidgets开发，支持Windows、MacOS、Linux、Android系统，采用开源许可协议。

## 主要特性
1.  支持GPS/GPDS位置输入、AIS输入解码、航点自动驾驶导航
2.  支持BSB栅格海图、S57矢量ENC海图显示
3.  启动/关闭速度快，仅保留日常操作必需的工具栏按钮
4.  跨平台便携性强，已在实际船舶航行中投入使用
