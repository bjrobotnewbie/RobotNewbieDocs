# RESPLE

基于激光测距里程计的六自由度基于样条的递归运动估计器

## 项目链接

- GitHub: <https://github.com/ASIG-X/RESPLE>

## 项目介绍
RESPLE是首个基于B样条的递归6自由度状态估计框架，可用于激光雷达里程计。它支持构建统一的激光雷达相关里程计系统套件，包括纯激光里程计(LO)、激光惯性里程计(LIO)、多激光里程计(MLO)和多激光惯性里程计(MLIO)四种变体。
该项目已在多种真实场景数据集和自有实验中完成测试，适配空中、轮式、足式、可穿戴平台，可应用于室内、城市、野外等多种环境，支持不同类型激光雷达。

## 主要特性
1.  支持导出TUM格式的估计轨迹用于算法基准测试，可保存`.pcd`格式的建图结果
2.  提供手持设备演示方案与配套数据集
3.  已在Newer College、MCD、TudoRun等多个公开数据集上完成验证并公开评测参数与结果
4.  支持多传感器融合的激光雷达里程计系统开发
