## 项目概述

## 项目介绍
SOLiD是一款面向视场受限场景的激光雷达全局描述子，用于激光雷达位置识别，已被RA-L'24与ICRA'25收录。该项目由韩国SPARO实验室开发，提供官方开源代码，支持C++与Python开发，附带项目官网、论文PDF、arXiv预印本以及演示视频资源。

## 主要特性
1.  **核心功能**：实现当前领先的激光雷达全局描述子，解决视场受限下的激光位置识别任务
2.  **衍生生态**：已推出SOLiD-A-LOAM、SOLiD-PyICP-SLAM、Distributed-SOLiD-SLAM等配套工具，后续还将发布SOLiD-SLAM包
3.  **行业收录**：已被HeLiPR-Place-Recognition工具箱以及awesome-lidar-place-recognition开源列表收录
4.  技术栈：基于C++和Python开发，适配机器人与自动驾驶领域的激光SLAM、位置识别场景。
