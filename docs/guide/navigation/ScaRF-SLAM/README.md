## 项目介绍
ScaRF-SLAM是一款结合前馈模型与经典视觉SLAM的尺度一致重建方案，由牛津大学动态机器人系统团队与佐治亚理工学院联合开发。项目旨在解决传统视觉SLAM中尺度漂移、高精度稠密重建困难的问题，将深度学习前馈模型的高效性与经典SLAM的鲁棒性结合，实现精准的尺度一致三维重建。项目提供了论文、演示视频、B站教程与数据集下载链接。

## 主要特性
1.  融合前馈生成模型与经典视觉SLAM框架，兼顾重建效率与精度
2.  解决视觉SLAM常见的尺度不一致问题，输出真实尺度的三维重建结果
3.  支持稠密场景重建，可应用于机器人自主导航、三维数字孪生、实景建模等场景。
