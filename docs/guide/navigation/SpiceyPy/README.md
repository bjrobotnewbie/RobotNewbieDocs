## 项目概述

## 项目介绍
SpiceyPy 是一款基于 ctypes 和 Cython 开发的 Python 封装库，用于调用 NAIF 官方的 C 语言 SPICE Toolkit。SPICE 是行星科学领域进行太阳系几何计算的核心工具，面向行星科学领域的科研与工程人员。

## 主要特性
1.  提供 Python 风格的接口调用原生 SPICE 工具包
2.  支持通过 PyPI 和 Conda Forge 进行快速安装
3.  具备完整的持续集成测试与代码覆盖率保障
4.  附带完善的官方文档，且被 NAIF 官方推荐作为 Python 调用 SPICE 的接口
5.  遵循 Black 代码规范，代码风格统一。

使用时需注意项目按“原样”提供，使用风险自负。发布使用该库的成果时，需同时引用 SpiceyPy 和 SPICE Toolkit。
