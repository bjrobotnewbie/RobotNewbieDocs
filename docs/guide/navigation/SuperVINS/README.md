## 项目概述
SuperVINS是一个面向挑战性成像条件的实时视觉-惯性SLAM框架，集成了深度学习能力。该框架基于C++14开发，支持ROS1 Noetic版本，采用SuperPoint+LightGlue作为特征匹配方案，结合DBoW3实现闭环检测，能够在复杂光照、纹理缺失等挑战性成像条件下实现准确的实时位姿估计，适用于无人机导航、自动驾驶等领域的视觉定位任务。
