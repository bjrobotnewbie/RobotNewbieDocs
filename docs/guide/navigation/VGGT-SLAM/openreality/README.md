Open Reality：将手机视频转换为可查询的 AI 3D 场景。提供 MCP 工具以支持 Claude/Codex/Cursor（npm openreality-mcp），以及自托管的代理服务和 VGGT-SLAM 库，所有功能均集成于同一仓库。采用 BSD-2-Clause 许可证。

## 项目链接

- GitHub: <https://github.com/reality-opened/openreality>
- 项目主页: <https://open-reality.io/mcp>

## 项目介绍
openreality是一款将手机视频转换为可查询AI的3D场景的开源工具，是面向各类硬件的智能体操作系统，核心能力为视觉与动作结合，可让AI代理操控任意硬件。项目包含适配Claude、Codex、Cursor的MCP工具（npm包openreality-mcp）、可自托管的代理服务以及VGGT-SLAM库，采用BSD-2-Clause开源协议。
## 主要特性
1. 支持将手机视频实时重建为3D场景，基于VGGT-SLAM技术实现；
2. 提供MCP工具链，可对接主流AI编程助手；
3. 支持自托管部署，可使用本地GPU或Modal平台运行；
4. 支持导出机器人数据，具备场景校准为米级单位的能力，可用于AI代理交互场景。
