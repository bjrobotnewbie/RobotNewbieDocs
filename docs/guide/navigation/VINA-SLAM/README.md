## 项目概述

## 项目介绍
VINA-SLAM是一款基于体素的LiDAR-IMU SLAM框架，针对稀疏、重复几何结构场景（如长走廊、狭窄楼梯间）的SLAM可靠性差问题设计。该框架构建统一的3D全局体素地图，提取全局结构特征，通过法线引导匹配策略实现跟踪，并新增切空间度量为局部BA补充平面区域旋转约束，最后通过滑动窗口BA紧耦合IMU因子、法线一致性因子与平面约束，提升退化场景下的定位鲁棒性。支持ROS2环境，可通过配置文件适配不同传感器数据集。

## 主要特性
1.  构建全局体素地图存储表面法线特征，使用法线引导匹配策略实现帧间对应
2.  提出VNC法线一致性约束模块，为平面区域补充旋转自由度约束
3.  采用27邻体素搜索结合角度过滤的地图平面匹配，避免跨结构误匹配
4.  滑动窗口BA紧耦合IMU、法线一致性与平面约束，使用体素协方差最小特征值优化海森矩阵条件数，提升跨视图几何一致性
5.  支持多种LiDAR传感器配置，可直接读取ROS2 bag进行测试，自带RViz可视化选项
