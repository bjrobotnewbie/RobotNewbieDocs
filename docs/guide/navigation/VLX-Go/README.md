## 项目概述

## 项目介绍
VLX-Go是一款面向具身智能导航的轻量级视觉语言航点规划模型，属于open-world embodied AI导航项目。它可以输入近期单目帧、当前视觉观测和自然语言指令，预测短视野局部航点，可在仿真环境或实体机器人上由下游控制器执行。项目聚焦目标跟随、局部导航、动态避障与闭环评估，基于OmTrackVLA技术方向扩展而来。

## 主要特性
1.  **0.6B轻量航点规划器**：推理成本低，便于部署
2.  **指令驱动规划**：支持跟随、抵达、避障等自然语言任务指令
3.  **短视野航点输出**：直接预测局部运动目标，而非全局路线或纯文本动作
4.  **时序视觉上下文**：利用历史帧捕捉目标运动、遮挡变化与场景动态
5.  **闭环评估体系**：通过重复观测、预测、执行与反馈完成导航评估
