## 项目概述
VSLAM-LAB是一个面向视觉SLAM系统的综合框架和数据集平台，旨在简化视觉SLAM系统的开发、评估和应用。该框架允许用户编译和配置多种VSLAM系统，下载和处理数据集，并设计、运行和评估实验，支持多种视觉SLAM基线算法和数据集，是视觉SLAM研究和开发的优秀工具。
