# Vela

Android 地图与导航（地图 + 导航）- MapLibre + Jetpack Compose，无需 Google Play Services

## 项目链接

- GitHub: <https://github.com/PimpinPumpkin/Vela>
- 项目主页: <https://pimpinpumpkin.github.io/Vela/>

## 项目介绍
Vela Maps是一款无谷歌服务的Android地图导航应用，类比NewPipe之于YouTube，无需Google Play Services即可使用。它基于MapLibre和Jetpack Compose开发，适配GrapheneOS等无GMS的安卓系统。
该应用通过设备端自行抓取谷歌公开网页接口，获取优质POI、路线规划和实时交通预估时间等服务，同时使用OpenFreeMap开源矢量瓦片作为底图，全程无后端中转，保护用户隐私。

## 主要特性
1.  完整功能：支持实时路况、精准地点数据、带车道指引的逐向导航、路线标识、实时公交站牌与站点查询
2.  无谷歌依赖：无需Google Play Services，保护用户隐私
3.  自定义主题：支持明暗两套主题，与系统主题解耦
4.  优质体验：包含评分POI图标、分级地点标记、清晰的路况文字说明与路线避让选项
5.  开源可编译：支持社区编译、贡献代码与多语言翻译
