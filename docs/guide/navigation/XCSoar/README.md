## 项目介绍
XCSoar是一款面向滑翔机飞行员的开源战术滑翔电脑，无广告、无用户追踪。支持Android、iOS、Linux、macOS、Windows多平台，由开源社区开发维护。

## 主要特性
1.  核心功能：提供越野飞行所需全套工具，包含带地形、空域、机场的动态导航地图，集成高度、滑翔计算、气象等多类上下文信息面板，支持流量告警与滑翔计算机算
2.  任务与分析：支持任务规划申报，内置飞行分析工具，支持在线热气流数据源与热气流中心定位
3.  数据兼容：支持导入CUP、OpenAir等通用航点、空域与地图格式
4.  硬件适配：支持FLARM、Stratux防撞设备，XCVario、CAI 302等多款 variometer设备，可适配树莓派、OpenVario等嵌入式设备
5.  隐私安全：无广告、无数据收集，支持离线使用，无需注册账号。
