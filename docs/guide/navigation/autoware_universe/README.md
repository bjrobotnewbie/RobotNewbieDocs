## 项目概述

## 项目介绍
Autoware Universe是Autoware生态系统的基础支柱，是Autoware Core/Universe概念的核心组成部分，负责管理大量扩展自动驾驶车辆功能的软件包，对提升自动驾驶核心技术能力起到关键作用。

## 主要特性
1.  作为Autoware生态的核心模块，提供丰富的自动驾驶扩展功能包
2.  配套有官方文档站点，可通过MKDocs部署查看详细组件说明
3.  内置代码覆盖率统计，可查看整体及各组件（如Common、Control等包）的代码覆盖情况
4.  官方推荐通过Autoware官方文档了解完整生态及开发入门指南
