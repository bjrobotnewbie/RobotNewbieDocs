## 项目概述

## 项目介绍
本项目是一个精选的激光雷达-视觉融合SLAM相关资源列表，汇总了超过30篇顶会顶刊级别的激光视觉融合SLAM相关顶尖研究成果，作者会持续更新该项目。
激光视觉SLAM结合了激光雷达的精准距离测量能力与相机丰富的环境细节感知能力，能够在多样复杂场景下实现高精度、高鲁棒的定位与建图。

## 主要特性
1.  收录了30+篇激光视觉融合SLAM领域顶尖论文与相关资源
2.  支持提交PR来新增算法、配置文件或改进内容，欢迎提交顶会顶刊相关工作的更新请求
3.  包含部分开源项目的代码、数据集与演示资源，例如SR LIVO、Ultra-Fusion等项目
4.  覆盖了传感器退化、时空扰动等复杂场景下的鲁棒融合SLAM方案
