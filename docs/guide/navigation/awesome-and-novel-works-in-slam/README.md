## 项目介绍
本项目是一个SLAM领域前沿创新工作的精选汇总仓库，涵盖语义SLAM、3DGS、BEV、导航、大语言模型、多会话SLAM等方向，兼顾工程落地与学术研究需求，每周更新。仓库同时提醒用户注意预印本平台内容质量需甄别，且学术与工程落地存在一定差距，需结合具体场景分析。

## 主要特性
1.  收录前沿SLAM相关创新成果，覆盖3DGS-NeRF、V2X、语义SLAM、大模型融合等多个热门细分方向
2.  附带相关领域优质资源链接，包括顶刊顶会信息、数据集、竞赛、工具、仿真平台、传感器采购渠道等
3.  提供多个细分领域的优质作者/社区跟进渠道，方便获取最新动态
4.  兼顾学术研究与工程落地需求，同时提示需注意学术与工程落地的差异问题
