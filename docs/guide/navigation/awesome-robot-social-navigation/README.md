## 项目介绍
本项目是一个精选的机器人社会导航领域资源列表，收录了该领域历史和近期的前沿研究进展，涵盖人群导航、动态/人机共存环境导航等方向。项目维护者会持续更新资源，欢迎提交PR补充遗漏的优质工作或修正错误。资源链接优先使用论文官网，其次公开预印本。

## 主要特性
1.  分类完善：包含综述、数据集与基准测试、各类导航方法（基于模型、基于学习、混合方法、大模型应用、可解释性研究）、环境模型、用户研究以及相关研讨会等板块
2.  资源精选：收录了顶刊顶会的高质量研究，如2013到2024年的多篇权威综述论文
3.  标注友好：同一论文仅在首次出现的分类中添加链接，方便读者快速检索
