# cuVSLAM

支持 CUDA 加速的视觉位姿估计与 SLAM 库，实现快速、高精度、低延迟的相机跟踪

## 项目链接

- GitHub: <https://github.com/nvidia-isaac/cuVSLAM>
- 项目主页: <https://nvidia-isaac.github.io/cuVSLAM/>

## 项目介绍
cuVSLAM是NVIDIA推出的CUDA加速视觉里程计与SLAM库，可实现快速、精准、低延迟的相机位姿跟踪。该库开箱即用，无需手动调参，仅需提供相机标定参数与传感器配置即可运行。它支持多传感器融合，适配单目、RGBD、多相机、惯性、多传感器等多种跟踪模式，可用于各类视觉定位与建图场景。

## 主要特性
1.  **硬件加速**：基于CUDA实现，具备高计算效率与实时性能
2.  **多跟踪模式**：支持单目、RGBD、多相机、惯性VIO、多传感器融合共5种模式，适配不同硬件配置
3.  **易用性强**：内置默认参数，可自动适配环境与运动场景，无需手动调优
4.  **多接口支持**：提供C++、Python API，同时兼容ROS2生态
5.  **高精度低延迟**：可实现精准的相机位姿估计与建图，满足实时应用需求
