## 项目概述

## 项目介绍
本项目是Navigation2（Nav2）官方文档的源码与配置文件仓库，用于生成https://docs.nav2.org/ 官方文档网站，提供Nav2机器人导航框架的完整官方文档支持。

## 主要特性
1.  **支持多种本地构建方式**：提供原生安装、虚拟环境安装、Docker容器构建以及VS Code Dev Container四种部署构建方案，适配不同开发环境需求
2.  **支持实时预览**：通过`sphinx-autobuild`或`make autobuild`可实现文档修改自动重建，本地访问http://127.0.0.1:8000 即可实时查看更新后的文档
3.  **可生成多格式文档**：默认支持HTML格式文档构建，同时提供PDF版本生成的外部指引
4.  文档内容遵循原项目的版权、商标与许可协议规则。
