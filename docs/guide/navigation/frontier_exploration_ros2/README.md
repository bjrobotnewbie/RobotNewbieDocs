- GitHub: <https://github.com/mertgulerx/frontier_exploration_ros2>

## 项目介绍
frontier_exploration_ros2是一款面向自主移动机器人的现代化C++边界探索ROS 2包，核心为C++库，支持ROS 2 Humble与Jazzy版本，兼容Nav2，可用于自主移动机器人的未知区域探索任务。

## 主要特性
1. 基于现代C++开发，提供核心库便于自定义集成
2. 适配ROS 2 Humble、Jazzy版本，兼容Nav2
3. 具备完善的构建与测试流程，项目维护规范
4. 支持自主移动机器人的边界探索场景，可用于未知环境的探索任务
