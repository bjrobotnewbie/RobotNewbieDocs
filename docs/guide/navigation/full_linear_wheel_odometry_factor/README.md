# full_linear_wheel_odometry_factor

全线性轮式 odometry 因子为轮式避障机器人提供运动约束和在线标定。该约束可集成至您的 SLAM 框架。此处提供了一个使用该因子的示例视频：https://youtu.be/Vss86xUhU80

## 项目概述

## 项目介绍
本项目为`full_linear_wheel_odometry_factor`，专为滑移转向机器人提供运动约束与运动学参数在线标定功能，可集成到SLAM框架中使用。
它适用于无转向机构的两轮、六轮及履带式滑移转向机器人，基于全线性运动学模型构建约束，无需手动离线标定即可适配未知地面打滑等复杂环境，能够为LiDAR-IMU里程计提供可靠约束，解决运动学参数误差与特征匮乏环境下的定位鲁棒性问题。

## 主要特性
1.  **在线运动学参数标定**：可在线校准滑移转向机器人的运动学参数，解决轮打滑、轮胎气压/老化导致的模型误差这类不可直接观测的问题。
2.  **可靠运动约束**：基于在线标定结果输出准确的轮式里程计约束，提升LiDAR-IMU里程计在长走廊、隧道等点云退化场景下的定位精度与鲁棒性。
3.  轻量易用：以C++头文件形式实现，仅需引入头文件即可集成到基于GTSAM的因子图SLAM系统中，附带示例代码方便快速上手。
4.  测试环境：适配Ubuntu 22.04，依赖GTSAM 4.2a9版本。
