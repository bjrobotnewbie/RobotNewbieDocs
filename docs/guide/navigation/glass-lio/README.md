# glass-lio

适用于 Livox 的透明激光雷达 - 惯性里程计。已编写好以便阅读：D

## 项目链接

- GitHub: <https://github.com/Tim-HW/glass-lio>

## 项目介绍
glass-lio是一款面向Livox雷达的透明化激光惯性里程计项目，专为可读性设计。它基于ROS 2 Jazzy开发，采用C++17编写，适配Livox MID-360传感器。
该项目实现了扫描到地图的里程计功能：对Livox约100ms的非快照式雷达扫描通过陀螺仪数据进行去畸变，构建体素哈希局部地图，通过SE(3)上的高斯-牛顿法求解点到平面ICP得到位姿，最终输出里程计话题与TF变换。项目核心教学目标为流形上的李代数与最小二乘，所有非直观实现都附带了说明与正误验证。

## 主要特性
1.  **高可读性**：代码设计初衷为便于理解，详细记录了每一处非标准实现的决策依据
2.  **完整激光惯性里程计流程**：包含IMU初始化、数据同步、点云去畸变、降采样、配准、地图构建与更新全流程
3.  **稳定运行**：测试包中可稳定以10Hz实时运行，零丢包零发散，位姿RMSE稳定在约0.13m
4.  **教学导向**：针对李代数学习场景设计，即使代码存在细微错误也会输出看似合理的错误结果，便于开发者排查流形优化类问题
