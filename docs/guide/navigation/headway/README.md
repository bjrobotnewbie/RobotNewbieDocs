# headway

由OpenStreetMap提供支持的可自托管地图栈

## 项目链接

- GitHub: <https://github.com/headwaymaps/headway>
- 项目主页: <https://about.maps.earth>

## 项目介绍
Headway是一款基于OpenStreetMap的可自托管地图服务栈，用户仅需少量命令即可搭建完整的自有地图服务器，内置前端、底图服务、地理编码引擎与路径规划引擎。支持使用200+预设城市数据，或自定义任意范围的OpenStreetMap提取数据，覆盖从街区到全球的尺度。当前可实现地图展示、POI与地址搜索、区域内路径规划，支持驾车、骑行、步行三种出行方式，公共交通规划功能仍在开发中。

## 主要特性
1.  全栈式自有地图部署，无需依赖第三方地图服务
2.  支持自定义OpenStreetMap数据源，适配多尺度区域
3.  集成地图展示、地理编码、路径规划完整功能
4.  支持Linux、amd64架构的macOS系统部署
5.  采用Apache License 2.0开源协议
