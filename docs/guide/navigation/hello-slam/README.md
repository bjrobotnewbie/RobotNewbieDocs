# hello-slam

一个入门友好的 SLAM 迷你课程，使用 Jupyter 笔记本——涵盖贝叶斯滤波、卡尔曼滤波、粒子滤波以及基于图的 SLAM，并提供手头的 Python 示例。

## 项目链接

- GitHub: <https://github.com/nstathou/hello-slam>

## 项目概述

## 项目介绍
本项目是一个面向初学者的SLAM迷你课程，通过Jupyter交互式笔记本结合Python代码实例，讲解同时定位与地图构建（SLAM）的核心基础知识，涵盖贝叶斯滤波、卡尔曼滤波、粒子滤波以及基于图的SLAM方法。课程分为三讲，仅覆盖SLAM领域的入门内容，附带pygame实现的多种SLAM算法对比演示示例。

## 主要特性
1.  零基础友好的SLAM入门教程，搭配交互式学习笔记
2.  理论讲解与Python实战代码结合，覆盖四大主流SLAM技术路线
3.  提供多种运行环境支持：VS Code、JupyterLab、Docker以及Google Colab
4.  包含多种SLAM算法的可视化对比演示效果
