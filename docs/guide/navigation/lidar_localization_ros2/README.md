## 项目概述
lidar_localization_ros2是一个用于ROS 2的3D点云地图定位包，支持Nav2框架，提供了运行时定位器、Nav2启动包装器、基准测试工具和实验运行器，用于恢复和重定位工作。该包默认使用NDT OMP作为后端，支持ROS 2 Humble和Jazzy版本，适用于移动机器人的激光雷达定位任务，是机器人导航领域的优秀工具。
