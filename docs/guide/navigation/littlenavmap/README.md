# littlenavmap

Little Navmap 是一款适用于微软模拟飞行X、微软模拟飞行2020、Prepar3D 以及 X-Plane 的免费飞行计划器、导航工具、移动地图、机场搜索与机场信息系统。

## 项目概述

## 项目介绍
Little Navmap是一款免费的飞行规划、导航工具，同时也是移动地图、机场搜索与机场信息系统，支持Flight Simulator X、Microsoft Flight Simulator 2020、Prepar3D以及X-Plane多款飞行模拟软件。

## 主要特性
1.  提供多平台安装包，支持Windows、macOS、Linux（适配Ubuntu 22.04/24.04），包含安装程序、压缩包、Debian包等多种分发形式
2.  核心功能覆盖飞行计划制定、导航辅助、实时移动地图展示、机场信息查询与检索
3.  提供官方用户手册、功能截图以及备用下载渠道，同时附带常见下载与运行问题的解决方案链接。
