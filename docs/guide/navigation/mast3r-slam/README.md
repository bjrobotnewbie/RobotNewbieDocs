# mast3r-slam

## 项目链接

- GitHub: <https://github.com/rerun-io/mast3r-slam>

## 项目介绍
本项目是MASt3R-SLAM的非官方实现，属于带3D重建先验的实时稠密SLAM系统，已迁移至`rerun-io/examples-monorepo`仓库的`packages/mast3r-slam`路径下。项目使用Rerun进行可视化、Gradio搭建交互式UI，通过Pixi实现便捷安装。

## 主要特性
1.  实现基于3D重建先验的实时稠密SLAM功能
2.  集成Rerun可视化工具，支持直观的场景展示
3.  提供Gradio交互式Web界面，降低使用门槛
4.  依托Pixi实现一键式快速安装部署
