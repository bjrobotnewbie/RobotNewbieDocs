## 项目概述

MOLA (Modular Optimization framework for Localization and mApping) 是一个现代化、模块化的**定位与SLAM C++/ROS2框架**。主要特点：

1. **模块化设计**：支持可配置的pipeline，方便组合不同模块
2. **支持多种场景**：提供激光里程计、LIO（激光-惯性里程计）等多种解决方案
3. **现代化C++**：采用现代化C++开发，兼容ROS 2
4. **完整文档**：提供详细文档，说明为什么选择MOLA、解决方案列表等

MOLA为机器人定位和建图提供了一个灵活的模块化框架，开发者可以根据需求配置不同的SLAM pipeline。
