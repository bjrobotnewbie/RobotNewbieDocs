## 项目概述
mola_lidar_odometry是基于MOLA和MRPT框架的激光雷达里程计组件，兼容ROS 2。该库提供了C++实现的激光雷达里程计功能，支持通过MOLA组件提供传感器输入，附带ROS 2示例启动文件和离线数据集运行的CLI接口，适用于移动机器人的激光雷达位姿估计和定位任务，是机器人导航领域的优秀工具。
