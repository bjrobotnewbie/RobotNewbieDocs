## 项目概述
mp2p_icp是一个实现多原素到原素（MP2P）ICP算法的C++库，属于MOLA SLAM项目的一部分。该库提供了高效的点云匹配功能，支持多种ICP变体算法，包括点到点、点到平面ICP等，适用于机器人SLAM中的位姿估计和地图构建任务。该库兼容ROS 2 Humble和Jazzy版本，提供了完整的文档和测试覆盖，是机器人感知和定位领域的优秀工具。
