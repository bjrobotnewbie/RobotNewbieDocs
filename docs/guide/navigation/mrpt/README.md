## 项目介绍
MRPT即Mobile Robot Programming Toolkit，是一款始于2005年的成熟C++移动机器人开源框架，最初由马拉加大学开发，至今仍在持续维护，广泛应用于学术研究与工业领域。最新的3.0版本完成了重大重构，采用基于colcon的模块化构建系统，适配现代C++17标准，同时保留了核心的数据结构与算法。

## 主要特性
1.  **SLAM相关**：支持蒙特卡洛定位、RBPF、位姿图优化
2.  **几何处理**：覆盖SE(2)/SE(3)李群、刚体变换、点云操作
3.  **概率算法**：包含卡尔曼滤波、粒子滤波以及位姿与地图的概率分布处理
4.  **地图构建**：支持占据栅格地图、点地图、路标地图、体素地图
5.  **传感器适配**：兼容LiDAR、双目/RGB-D相机、IMU、GPS、Velodyne等多种传感器
6.  **可视化工具**：提供3D场景图、GUI窗口、绘图组件
7.  **导航功能**：支持反应式导航、路径规划、基于PTG的避障
