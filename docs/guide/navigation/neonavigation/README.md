# neonavigation

适用于 ROS 的 2-D/3-DOF 无缝全局/局部移动机器人运动规划包

## 项目链接

- GitHub: <https://github.com/at-wat/neonavigation>

## 项目介绍
这是一个面向ROS的自主移动机器人导航元包，支持2-D/3-DOF的全局/本地无缝运动规划。ROS 1停止官方维护后，该包已迁移至Alpine ROS发布。项目提供了完整的移动机器人导航工具链，包含多子功能包，可快速搭建机器人自主导航系统，附带演示launch文件可快速测试功能。

## 主要特性
1.  支持2-D/3-DOF的全局与本地无缝路径与运动规划，可处理串联关节避障
2.  提供3-DOF空间代价地图处理、分层地图管理、里程计打滑补偿、点云转换工具
3.  集成轨迹跟踪控制、碰撞预防控制功能
4.  配套RVIZ可视化插件与示例启动文件，支持快速演示
5.  采用ROS标准话题/服务命名规范，提供完善的代码测试与覆盖率保障，遵循BSD 3-Clause开源协议
