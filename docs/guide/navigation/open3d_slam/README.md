# open3d_slam

基于点云图的 SLAM 系统，使用 C++ 语言开发，基于 open3D 库。

## 项目链接

- GitHub: <https://github.com/leggedrobotics/open3d_slam>

## 项目介绍
open3d_slam是基于C++开发的点云图SLAM系统，依托Open3D库实现，支持ROS集成，专为教育场景设计，旨在降低SLAM领域的入门门槛。该系统仅采用成熟算法的基础形式，无需IMU等额外输入，可基于点云数据完成建图、在已有地图中定位，或扩展已有地图。

## 主要特性
1. 教育导向：算法采用成熟基础形式，便于SLAM领域新手学习使用
2. 纯点云驱动：无需IMU等额外传感器输入
3. 多场景功能：支持从零建图、在给定地图中定位、扩展已有地图
4. ROS兼容：提供catkin包装器，可便捷集成至ROS项目
5. 高性能：依托Open3D库实现高效3D数据处理
