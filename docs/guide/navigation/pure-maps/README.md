## 项目概述

## 项目介绍
Pure Maps是一款面向Sailfish OS和Linux平台的地图应用，可显示矢量/栅格地图、地点信息与规划路线，并支持导航功能，用户可灵活选择地图数据与服务提供商。该项目基于WhoGo Maps分叉开发，采用GPL开源协议，已适配Flatpak、Ubuntu Touch、Sailfish OS等多种平台。

## 主要特性
1.  支持矢量与栅格地图展示、地点检索、路线规划与导航指引
2.  可灵活切换地图数据和服务提供商
3.  支持通过DBus API实现搜索、POI展示、导航控制等功能
4.  支持命令行参数启动，可直接传入geo URI或搜索关键词，已运行实例可通过DBus转发请求
5.  提供GitHub讨论区、Matrix聊天室、TMO论坛等多渠道用户反馈通道
