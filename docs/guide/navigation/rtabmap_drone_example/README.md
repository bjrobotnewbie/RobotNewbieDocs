## 项目概述
这是一个无人机的2D导航示例项目，使用move_base框架结合mavros/px4和RTAB-Map视觉SLAM实现自主导航。项目支持ROS和ROS2版本，提供了Docker、Dev Container和本地主机三种安装方式，附带详细的使用指南和演示视频，适用于无人机导航和SLAM研究的学习和开发。
