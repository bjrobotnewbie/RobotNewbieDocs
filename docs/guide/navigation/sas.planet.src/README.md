# sas.planet.src

SAS.Planet 是一款免费开源的地理信息系统（GIS）软件，用于查看、下载和管理来自各类在线源的高分辨率卫星影像与常规地图。

## 项目链接

- GitHub: <https://github.com/sasgis/sas.planet.src>
- 项目主页: <https://sasgis.github.io>

## 项目介绍
SAS.Planet是一款免费开源的GIS软件，可用于查看、下载和管理来自多个在线源的高分辨率卫星影像与常规地图。

## 主要特性
1.  **多源地图访问**：聚合Google Maps、Bing Maps、OpenStreetMap、Yandex.Maps等多家服务商的地图资源，支持同一地点多图层对比
2.  **离线使用**：下载缓存地图瓦片，支持无网络环境下查看地图，适用于信号不佳区域的导航与分析
3.  **数据管理**：支持创建、管理地标，测量距离和面积、规划路线，可导入导出KML、GPX等格式的数据
4.  **扩展功能**：可拼接下载的瓦片生成完整大图，还可连接GPS接收机作为导航工具使用
