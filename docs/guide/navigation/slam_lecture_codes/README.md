## 项目概述
这是一个SLAM课程的代码练习仓库，包含了从基础编程（C++、Python）、数学基础（旋转、平移、李群李代数）到完整SLAM系统的各个模块的教程代码。项目涵盖了机器人学、计算机视觉、激光雷达处理和传感器融合等多个领域，适用于SLAM初学者和进阶学习者的学习和实践，提供了详细的课程内容和代码示例。
