# small_point_lio

Point-LIO 算法的高级实现

## 项目链接

- GitHub: <https://github.com/Yancey2023/small_point_lio>

## 项目介绍
Small Point-LIO 是 Point-LIO 算法的进阶实现，相比原版算法速度提升2-3倍。默认分支适配ROS2，若需脱离ROS运行可切换至`main`分支。该项目是一款激光-惯性SLAM方案，可通过配置文件自定义相关参数，支持Livox等类型激光雷达与IMU数据输入。

## 主要特性
1.  **性能优化**：相比原版Point-LIO提速2-3倍
2.  **多环境适配**：同时支持ROS2与无ROS运行模式
3.  **可自定义配置**：支持激光/IMU话题、点云滤波、IMU处理、地图参数、外参标定、卡尔曼滤波等多维度参数调整
4.  **完整SLAM流程**：实现激光-惯性里程计计算，支持点云保存、IMU饱和校验、重力方向校准等功能

使用场景：移动机器人自主定位导航、三维环境建图等需要实时激光-惯性SLAM的机器人项目。
