## 项目介绍
本项目是2026年视觉SLAM开发者学习路线图，面向想要成为视觉SLAM工程师或研究员的零基础学习者，旨在梳理从入门到从业所需掌握的全部知识点，解决当前视觉SLAM入门课程较少、尤其是非英语语言课程稀缺的问题，帮助初学者理清学习方向。

视觉SLAM是同时定位与地图构建的分支，通过相机获取外部感知数据，入门门槛相对较高，需要掌握多类技能而非仅复杂数学知识。

## 主要特性
1.  **学习层级清晰**：从零基础到专业从业者分为10个进阶阶段，覆盖全栈学习路径
2.  **知识点全面**：包含数学编程基础、SLAM系统原理、单目/RGB-D/立体/事件相机等各类视觉SLAM方案、深度学习融合SLAM、VIO、多机器人协同SLAM、激光-视觉融合SLAM等全方向内容
3.  **适配初学者**：提醒学习者无需一开始就学完全部内容，循序渐进即可掌握相关技能。
