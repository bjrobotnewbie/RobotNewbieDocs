## 项目概述
vortex-auv是NTNU学生开发的无人水下航行器（UUV）引导、导航与控制软件，专为AUV/ROV竞赛设计。该项目基于ROS2 Humble框架，旨在硬件独立，支持自主运行和遥控操作两种模式，提供了完整的软件栈，包括传感器驱动、路径规划、控制算法等模块，附带详细的文档和测试流程，适用于水下机器人的研究和开发。
