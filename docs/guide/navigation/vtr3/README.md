# vtr3

VT&R3 是 Teach and Repeat 导航框架的 C++ 实现。它允许机器人学习一组可通行路径，并能精确重复网络中的任何部分。

## 项目概述

## 项目介绍
VT&R3是一个C++实现的Teach and Repeat导航框架，可让机器人学习可通行路径网络，之后精准复现路径网络中的任意路段。它支持适配多种传感器（相机、激光雷达、雷达、GPS等）和机器人平台，目前已验证过单目相机、激光雷达、雷达以及相机+GPS组合的导航方案。

## 主要特性
1.  支持多传感器的多经验定位：包括立体相机、激光雷达、雷达的里程计与定位，以及立体相机的深度学习视觉特征
2.  支持通过编译时环境变量`VTR_PIPELINE`选择对应 pipeline（`LIDAR`/`VISION`/`RADAR`/`RADAR-LIDAR`）以缩短编译时长，未设置时可运行时通过配置文件选择
3.  主版本依赖支持CUDA 11.8的NVIDIA驱动，视觉管线、使用PyTorch模型的雷达/激光雷达处理需要GPU加速，提供Docker镜像支持快速部署
4.  各论文相关的复现步骤已拆分至独立仓库。
