# wave-go

WAVE-Go: Go2-W 世界模型动作适应、无地图充电及 Cosmos3-Edge 混合长距导航演示

## 项目链接

- GitHub: <https://github.com/vigorlee/wave-go>
- 项目主页: <https://github.com/vigorlee/wave-go/releases/latest>

## 项目介绍
WAVE-Go是一款面向Unitree Go2-W轮足机器人的开源项目，连接世界模型、导航规划与轮足控制，实现从高层任务到实体运动的完整链路。项目支持MuJoCo与UE仿真，可完成无图充电、Cosmos3-Edge混合长距离导航等任务，已通过19/19项验收测试。

## 主要特性
1.  **实时三维语义建图**：搭载MID360雷达结合LIO实现在线建图，通过Grounding DINO/SAM2完成语义关联与密度聚类，RViz可实时显示行人、圆柱、楼梯、坡道等目标的类别、编号与三维包围框，支持PCD/NPZ/JSON格式导出，原始雷达帧率约10Hz，实时语义点云帧率约2Hz。
2.  **多场景落地演示**：可完成楼梯穿越、双坡道通行、平地交错圆柱避障、动态障碍避让等复杂任务，实测行程可达60.88米，通过18/18阶段任务，动态避让时最近障碍中心距离最低1.62米，机身高度适配地形变化。
3.  **可验证执行：本次复测全项通过，支持无图充电功能，提供完整运行录像与验收数据。
