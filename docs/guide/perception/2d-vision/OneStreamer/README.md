OneStreamer: 统一流式视频交互中的感知、记忆与主动响应

## 项目链接

- GitHub: <https://github.com/MCG-NJU/OneStreamer>

## 项目介绍
OneStreamer是一款面向流式视频交互的技术方案，核心目标是实现感知当前、记忆历史、适时响应的一体化能力，在原生流式场景下达成高效视频交互，相关成果已在InteractionBench基准测试中取得优异表现。

## 主要特性
1. 实现感知、记忆与主动响应的统一架构，适配流式视频交互场景；
2. 原生流式交互性能突出，在InteractionBench中以36.7分位列开源方法榜首；
3. 配套提供OneStreamer-4B模型与OneStreamer-1M数据集，支持快速部署与研究使用；
4. 遵循Apache 2.0开源协议，提供项目页面与技术文档，便于开发者参考。
