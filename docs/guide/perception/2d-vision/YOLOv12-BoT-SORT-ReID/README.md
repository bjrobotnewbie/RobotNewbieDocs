## 项目介绍
本项目是CVPR 2025第四届反无人机研讨会挑战赛的获奖基线方案，提出了基于YOLOv12+BoT-SORT-ReID的多无人机跟踪方案。项目提供了完整的部署教程与在线演示，支持Linux、macOS、Windows多平台，已被收录于arXiv预印本与Zenodo开源仓库。

## 主要特性
1.  **核心功能**：基于YOLOv12实现高精度目标检测，结合BoT-SORT与ReID（行人重识别）完成多无人机场景下的多目标跟踪
2.  **配套资源**：提供Colab、Kaggle在线运行笔记本，Hugging Face在线Demo，以及全平台详细搭建教程
3.  **应用场景**：专为反无人机、多无人机监控场景设计，可快速落地落地多目标跟踪任务。
