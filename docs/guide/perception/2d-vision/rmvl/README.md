## 项目介绍
RMVL全称Robotic Manipulation and Vision Library，即机器人操控与视觉库，最初面向RoboMaster赛事开发，现已拓展基础算法、机器视觉、通信相关功能，目标打造通用简洁、架构统一的视觉控制一体库。支持Linux和Windows平台，提供官方用户手册与VSCode扩展插件，可通过GitHub Issues反馈问题，设有官方QQ交流群。

## 主要特性
1.  覆盖机器视觉、基础算法、机器人通信等多类功能
2.  适配多操作系统，拥有完善的测试与发布工作流
3.  提供官方文档与开发辅助工具，社区支持完善
