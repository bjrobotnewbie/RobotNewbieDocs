# Awesome-Global-Solvers-for-3D-Vision

3D 视觉领域全球求解器 curated 综述与论文列表：可验证优化、凸松弛、分支界限法与鲁棒估计。

## 项目链接

- GitHub: <https://github.com/ericzzj1989/Awesome-Global-Solvers-for-3D-Vision>
- 项目主页: <https://arxiv.org/abs/2602.14662>

## 项目介绍
本项目是一个针对3D视觉全局求解器的精选综述与论文列表，涵盖可验证优化、凸松弛、分支定界和鲁棒估计四大技术方向，配套发布了同名综述论文。项目由多高校科研团队联合整理，收录了该领域的前沿研究成果，可帮助研究者快速了解3D视觉全局求解器的技术脉络与最新进展。

## 主要特性
1.  系统性梳理3D视觉全局求解器的技术分类，包含可验证优化、凸松弛、分支定界、鲁棒 estimation 四大核心方向
2.  提供经过筛选的高质量论文清单，覆盖领域经典与前沿研究
3.  附带领域技术分类图谱，直观展示研究脉络
4.  开源维护，欢迎社区提交修正与新增内容
