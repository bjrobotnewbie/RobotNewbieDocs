# CSF

基于织物模拟的激光雷达点云地面滤波/分割（裸地提取）方法

## 项目链接

- GitHub: <https://github.com/jianboqi/CSF>
- 项目主页: <http://ramm.bnu.edu.cn/projects/CSF/>

## 项目介绍
CSF是一款基于布料模拟的机载LiDAR点云地面滤波/分割（裸地提取）方法，对应发表于2016年Remote Sens.期刊的研究论文。该项目提供了多语言调用接口，支持Python、Matlab、R以及C++，可将LiDAR点云中地面点与非地面点分离，广泛应用于机载LiDAR点云数据处理场景。

## 主要特性
1.  **核心功能**：实现高精度LiDAR点云地面滤波，提取裸地点云
2.  **多语言支持**：提供Python（可通过pip直接安装）、Matlab、R、C++调用接口，其中Python版本可无缝对接laspy库处理LAS格式点云，也支持直接读取TXT格式点云数据
3.  **易用性强**：仅需简单配置参数即可完成滤波任务，便于嵌入到大型点云处理项目中
4.  支持自定义布料分辨率、平滑开关等关键滤波参数
