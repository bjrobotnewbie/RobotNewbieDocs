# GNM

基于 GNM Head 的开放生态系统，包含参数化的人体模型和感知堆栈。

## 项目链接

- GitHub: <https://github.com/google/GNM>

## 项目概述

## 项目介绍
GNM（发音类似genome）是开源的参数化人体模型与感知生态系统，首个开源组件为GNM Head，是高精度的3D参数化人类头部统计模型，属于3D Morphable Models（3DMMs）范畴，可应用于计算机视觉、计算机图形学、生成AI领域。该生态系统采用宽松许可证，支持非商业与商业使用，目前已发布GNM Head的技术报告与代码包。

## 主要特性
1.  **模型能力**：支持对身份、表情、头部姿态进行细粒度解耦控制，内置眼球、牙齿、舌头等可调控的内部解剖结构
2.  **多框架支持**：兼容NumPy、JAX、PyTorch、TensorFlow多种深度学习框架
3.  **附加功能**：提供语义参数采样能力，支持跨平台CI测试与代码规范检查
4.  **应用场景**：可用于生成可控的人类头部3D资产、人体感知分析、数字人开发等方向。
