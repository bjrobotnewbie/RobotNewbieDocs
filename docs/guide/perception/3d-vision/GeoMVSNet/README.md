# GeoMVSNet

[CVPR 23] GeoMVSNet：基于几何感知的多视角立体视觉学习

## 项目链接

- GitHub: <https://github.com/doubleZ0108/GeoMVSNet>

## 项目介绍
GeoMVSNet是CVPR 2023收录的多视图立体匹配算法，聚焦于引入几何感知能力优化学习型MVS模型，提升稠密深度图重建的精度与鲁棒性。

## 主要特性
1.  **核心功能**：实现基于深度学习的多视图立体匹配，从多幅带内外参的图像中重建出高精度的稠密三维深度图与点云。
2.  **技术亮点**：创新性地融入几何感知模块，增强模型对场景几何结构的理解能力，缓解传统学习型MVS易出现的纹理缺失、伪影问题。
3.  **使用场景**：适用于三维重建、自动驾驶环境感知、数字孪生、文物数字化等需要高质量稠密深度估计的计算机视觉任务。
4.  项目已开源，附带论文链接可供参考。
