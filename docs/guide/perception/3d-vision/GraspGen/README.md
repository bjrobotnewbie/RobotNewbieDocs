## 项目概述

## 项目介绍
GraspGen是一个基于扩散模型的6-DOF机器人抓取生成模块化框架，官方开源仓库。项目支持适配多种机器人末端执行器、不同观测条件以及单物体/杂乱场景抓取任务，还提出了全新的生成器端训练的抓取判别器训练方案。
该框架在真实和仿真环境中均取得了领先性能，在FetchBench抓取基准上提升了17%，同时内存占用比同类方法低21倍，推理速度可达20Hz（TensorRT优化前）。仓库提供了数据生成、数据格式、训练与推理的完整基础设施。

## 主要特性
1.  多适配性：支持工业夹爪、吸盘等3种末端执行器，可适配完整/局部3D点云观测场景
2.  高性能：在主流抓取基准上达到SOTA水平，兼顾速度与内存效率
3.  完整工具链：开源数据生成、训练与推理全流程代码
4.  当前仅支持Franka-Panda、Robotiq-2f-140和吸盘三种夹具，更多夹具支持可参考扩展项目GraspGen-X
