# Interactive4D

[ICRA 2025] Interactive4D: 交互式 4D 激光雷达分割

## 项目链接

- GitHub: <https://github.com/ifradlin/Interactive4D>
- 项目主页: <https://ilya-fradlin.github.io/Interactive4D/>

## 项目介绍
Interactive4D是ICRA 2025收录的交互式4D激光雷达（LiDAR）分割模型，由亚琛工业大学、ETH AI中心联合研发，基于PyTorch、PyTorch Lightning框架构建，支持用户通过点击交互，与深度学习模型协作完成多帧连续LiDAR扫描的多目标分割，可提升标注效率、保证结果一致性，简化跟踪与标注流程。

## 主要特性
1. 单步完成多帧连续LiDAR扫描的多目标联合分割；
2. 支持交互式4D多目标分割，用户提供点击即可协同完成多对象分割；
3. 适配4D LiDAR数据，兼顾多帧时序信息与空间信息；
4. 提供完整的代码、安装与使用流程，支持训练、评估及交互式工具使用。
