## 项目概述

## 项目介绍
本项目是国内首个占据栅格网络全栈课程《从BEV到Occupancy Network，算法原理与工程实践》，覆盖自动驾驶环视语义占据感知领域，包含算法原理讲解、工程代码实现以及端侧部署内容，配套有课件、文档和在线学习资源。项目已搭建专属在线课程主页：http://111.229.117.200:8100/，标准版源代码和课件预计2024年4月开源。

## 主要特性
1.  覆盖BEV到Occupancy Network全栈技术栈，包含算法原理与工程实践
2.  配套完整学习资源：课件PPT、源代码、开发环境指导
3.  提供在线学习网站支持课程学习，同步更新项目动态
4.  内容涵盖自动驾驶环视语义占据感知相关技术方案讲解与实战
