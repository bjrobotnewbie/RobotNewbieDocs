# PE3R

[CVPR'26] PE3R: 感知高效的 3D 重建。只需使用手机拍摄 2-3 张照片，上传后等待几分钟，即可通过文本探索您的 3D 世界！

## 项目概述

## 项目介绍
PE3R是CVPR'26收录的感知高效3D重建项目，仅需手机拍摄2-3张2D图片，上传后等待数分钟即可完成3D场景重建，并支持通过文本进行语义交互探索。该项目由新加坡国立大学xML Lab团队开发，提供了在线Demo、论文和演示视频资源。

## 主要特性
1.  **输入高效**：仅需普通2D图像即可完成重建
2.  **时间高效**：加速实现3D语义重建流程
3.  **泛化性强**：支持跨场景、跨物体的零样本泛化
4.  支持通过文本指令对重建后的3D场景进行语义交互探索

同时提供了完整的本地部署流程，依赖MASt3R、SAM2、SigLIP等开源模型，用户可通过官方指引快速搭建运行环境。
