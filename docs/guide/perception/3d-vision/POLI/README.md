# POLI

## 项目介绍
POLI（Point-to-Ellipsoid）是一篇被RSS 2026收录的3D感知研究项目，核心是将点云几何建模为统计流形。它通过自监督神经网络为每个LiDAR点预测高斯椭球，实现对局部几何的精准建模，无需标注数据。该方法可即插即用至各类3D感知 pipeline，包括全局配准、物体位姿估计、LiDAR里程计等场景，无需修改原有架构即可提升任务精度。此外项目还配套了RSS 2026 workshop相关的LiDAR SLAM几何推理研究。

## 主要特性
1.  自监督学习，无需人工标注数据
2.  为每个点生成高斯椭球，基于统计流形建模局部点云几何
3.  即插即用，兼容现有3D感知系统，无需修改原有架构
4.  可应用于全局配准、物体位姿估计、LiDAR里程计等多个3D感知任务
