## 项目介绍
WebODM是一款易用的商业级航拍图像处理软件，可从航拍影像生成地理参考地图、点云、高程模型以及带纹理的3D模型。它现已脱离OpenDroneMap独立开发，官方安装包可免费下载，提供完整文档与技术支持。

## 主要特性
1.  支持多处理引擎：ODX、MicMac、LGT
2.  提供直观的可视化操作界面，降低航拍影像处理门槛
3.  可输出多种专业测绘与三维建模成果
4.  提供免费官方安装包与完善的官方文档
