# awesome-lidar

😎 awesome LIDAR 列表。该列表包含 LIDAR 制造商、数据集、点云处理算法、点云框架和模拟器。

## 项目链接

- GitHub: <https://github.com/szenergy/awesome-lidar>
- 项目主页: <https://szenergy.github.io/awesome-lidar/>

## 项目介绍
awesome-lidar 是一个精心整理的激光雷达（LIDAR）资源列表，涵盖激光雷达硬件厂商、数据集、点云处理算法、框架、模拟器等相关内容，还标注了资源对应的YouTube视频、学术论文、ROS 2兼容性、GitHub仓库等标识，方便开发者快速获取所需的激光雷达相关资源，适用于自动驾驶、机器人、测绘等依赖激光雷达技术的领域。

## 主要特性
1. 分类清晰：包含厂商、数据集、算法、框架、模拟器等多个核心分类，算法细分至匹配、语义分割、SLAM、目标检测等子类别
2. 标识完善：通过不同徽章标注资源属性，如YouTube视频、学术论文、ROS 2兼容、GitHub仓库等
3. 内容实用：覆盖激光雷达全产业链相关资源，支持社区贡献，可通过官网查看可视化列表
