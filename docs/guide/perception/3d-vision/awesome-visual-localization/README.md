## 项目概述

## 项目介绍
本项目是一个精选的视觉（重）定位相关研究资源汇总列表，旨在收集视觉定位领域的优质研究成果。视觉定位的核心任务是在已知场景数据库中，查询RGB/RGB-D帧的6自由度相机位姿。项目仍在持续更新中，欢迎通过PR或Issue贡献资源、修正信息。

## 主要特性
1.  **分类清晰**：按研究方向分为综述、图像检索、相机位姿回归、特征匹配、场景坐标回归、位姿优化 refinement、数据集与基准测试七大模块
2.  **资源精选**：收录了顶会顶刊的高质量研究，包含论文链接与部分开源代码
3.  **覆盖全面**：涵盖了视觉定位领域的主流技术路线与 benchmark 工具
