# limap

用于 3D 视觉定位、定位和 SfM 的工具箱，支持结构化几何特征（如点、线、平面、消失点、线框等）。

## 项目链接

- GitHub: <https://github.com/cvg/limap>

## 项目介绍
LIMAP是一款用于结构化几何特征的3D视觉建图、定位与SfM工具箱，由苏黎世联邦理工学院计算机视觉与几何组开发，源自CVPR 2023的顶刊论文，并在后续ECCV 2024、ECCV 2026论文中完善了SfM流程。
它支持点、直线、消失点、平面、参数化基元（球体、圆柱、椭球、长方体、圆锥）以及线框等多种结构化特征，可与相机位姿联合优化重建。自2.0.0版本起，它完全兼容COLMAP生态，可直接在COLMAP GUI中打开重建结果。

## 主要特性
1.  提供三类核心流程：
    - 已知相机位姿的视觉建图/三角化，可基于COLMAP重建结果生成3D模型
    - 联合点、线特征的视觉定位，支持标定与未标定的查询图像
    - 增量式整体SfM，仅通过输入图像即可恢复相机位姿与3D模型
2.  抽象了线检测器、匹配器、消失点估计器、平面检测器的注册机制，便于扩展新算法
3.  深度整合COLMAP生态，复用其场景类型、数据库、估计器等模块，支持多相机 rig 等新特性
