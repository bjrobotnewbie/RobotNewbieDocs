## 项目概述

## 项目介绍
ZED SDK是一款跨平台库，专为优化Stereolabs品牌ZED系列相机使用体验而设计，同时提供配套教程与代码示例帮助开发者快速上手SDK API。本项目可用于快速构建智能机器人与智能空间的空间感知应用。

## 主要特性
1.  **性能优化**：最新的5.4版本内置神经深度模型推理速度提升最高20%，Jetson Thor平台GPU负载降低约15%，该优化可覆盖Orin与桌面GPU，在多相机、NEURAL PLUS模式或并发录制等重负载场景下效果更明显。
2.  **自定义深度支持**：新增实验性`DEPTH_MODE::CUSTOM`模式，支持接入外部计算的视差/深度图，可直接使用SDK的点云、空间映射、目标检测、平面检测全流程工具链。
3.  **高效张量输出**：新增`retrieveTensor`接口，可一次性完成双相机校正视图的GPU融合预处理，输出可直接用于TensorRT等框架的推理张量。
4.  **轻量化录制与流传输**：SVO录制与流传输流程优化，仅在需要时执行立体校正，降低CPU/GPU开销；新增轮询API可直接获取编码后的H264/H265数据包，新增`LEFT_NV12`/`RIGHT_NV12`校正视图可直接用于硬件编码，无需额外色彩转换。
