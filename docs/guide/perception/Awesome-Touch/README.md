## 项目概述

## 项目介绍
Awesome-Touch 是一个开源的机器人触觉感知领域精选资源合集，涵盖触觉传感器、机器人应用、软件工具等全链条相关资源，聚焦于触觉传感在机器人操作、SLAM、机器学习等方向的落地与研究，支持数据采集、模仿学习(IL)、强化学习(RL)、大语言模型/多模态大模型(VLA/WM)、灵巧操作、仿真等场景。

## 主要特性
1.  **传感器分类**：按视觉基、视觉-触觉多模态、非视觉基三大类整理了经典触觉传感器研究成果
2.  **多场景应用**：覆盖数据采集、大模型交互、灵巧操作、表征学习、抓取、接触感知、力估计、腿部机器人触觉策略等机器人触觉核心应用方向
3.  **工具资源**：提供触觉相关仿真环境、开发库、公开数据集等开源软件资源
4.  同时收录了该领域的综述论文、学位论文、商用产品、开源项目和相关实验室信息。
