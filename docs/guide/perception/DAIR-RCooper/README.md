## 项目概述
这是CVPR2024论文“RCooper：路边协同感知真实世界大规模数据集”的官方实现，提供了真实世界的大规模路边协同感知数据集。项目包含数据下载、数据转换、快速开始、基准测试等完整的功能，支持路边协同感知任务的研究和开发，是自动驾驶协同感知领域的重要数据集资源。
