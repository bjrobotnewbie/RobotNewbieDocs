# MPRGDeepLearningLectureNotebook

## 项目链接

- GitHub: <https://github.com/machine-perception-robotics-group/MPRGDeepLearningLectureNotebook>

## 项目介绍
本项目是日本机器感知与机器人小组（MPRG）的深度学习课程讲义笔记本，提供了可直接在Google Colab上运行的实战教程，涵盖Python基础到深度学习入门内容，无需本地配置开发环境即可学习。

## 主要特性
1.  **配套教程结构清晰**：分为Python入门和深度学习初两大模块
2.  **即开即用**：所有笔记均附带Google Colab运行链接，点击即可直接运行代码
3.  **实战导向**：从基础优化算法、感知器、MLP入手，逐步实现AND/XOR逻辑电路、MNIST多分类任务，还包含正则化等深度学习技巧教学
4.  适合深度学习入门学习者，尤其适合机器人、ROS相关领域的开发者快速上手深度学习技术。
