## 项目概述
ODM是一个开源的命令行工具包，用于处理航拍无人机图像，能够将简单的2D图像转换为分类点云、3D纹理模型、地理参考的正射影像和数字高程模型。该应用支持Windows、Mac和Linux系统，适用于高级用户、脚本和与其他软件集成，是无人机影像三维重建和测绘领域的优秀工具。
