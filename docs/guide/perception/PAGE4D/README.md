# PAGE4D

- 项目链接：https://github.com/kaichen-z/PAGE4D

## 项目概述

PAGE4D 是 ICLR 2026 发表的研究工作，将 Visual Geometry Grounded Transformer (VGGT) 扩展到动态场景，是一个通过解耦姿态与几何估计实现 4D 感知的前馈神经网络。

该项目能够直接推断关键的 4D 场景属性，包括相机姿态、深度图和密集点云图，同时显式地对动态元素（如移动的人体和可变形物体）进行建模，**无需后处理或优化**。

### 核心特点

- **两种模型变体**：训练时掩码（仅训练阶段使用掩码，等同于 VGGT 结构）和推理时掩码（始终保持掩码），两种变体性能相近
- **解耦设计**：通过空间掩码机制解耦帧局部信息和全局跨视图信息
- **完整流程**：提供从数据准备、训练、特征可视化到评估的完整 pipeline
- **支持动态场景**：专为包含移动人体和可变形物体的动态场景设计

### 主要功能

- **相机姿态估计**：推断相机外参和内参矩阵
- **深度估计**：支持单目深度估计和视频深度估计
- **相对位姿估计**：评估相机轨迹估计，输出 ATE 和 RPE 指标
- **点云预测**：直接输出密集点云图

### 支持数据集

- TUM RGB-D
- Bonn RGB-D
- Sintel
- Dyncheck

### 预训练权重

项目在 Hugging Face 上发布了预训练权重，提供两种版本：
- `checkpoint_nomask.pt`（推荐）：仅在训练早期使用掩码
- `checkpoint_mask.pt`：训练过程始终保持掩码

PAGE4D 由 MIT Media Lab 和 Harvard Medical School 联合研究，基于 VGGT 框架改进，代码开源，提供完整的使用示例和训练脚本。
