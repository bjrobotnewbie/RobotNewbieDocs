# 机器人感知系统

机器人感知系统是机器人获取和理解外部环境的关键技术，包括视觉感知、点云处理、多传感器融合等多个分支，为机器人的导航、操作和交互提供基础支持。

## 分类导航

- [2D视觉感知](./2d-vision/README)：处理二维图像数据的视觉算法和工具
- [3D视觉感知](./3d-vision/README)：处理三维空间数据的视觉算法和工具
- [多传感器融合](./multi-sensor-fusion/README)：融合多种传感器数据的感知技术

## 核心技术方向

1. **2D视觉感知**：目标检测、分类、分割、姿态估计等二维图像处理技术
2. **3D视觉感知**：点云配准、分割、重建、特征提取等三维空间感知技术
3. **多传感器融合**：相机、激光雷达、毫米波雷达等多传感器数据融合技术
4. **语义理解**：场景理解、目标识别、环境建模等高级感知技术
