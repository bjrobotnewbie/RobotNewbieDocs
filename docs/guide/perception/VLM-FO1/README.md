# VLM-FO1

- 项目链接：https://github.com/om-ai-lab/VLM-FO1

## 项目概述

VLM-FO1 是一个连接高层推理与细粒度感知的桥梁，它在不损害预训练视觉语言模型固有的高层推理和通用理解能力的前提下，赋予其卓越的细粒度感知能力。

它作为一个即插即用模块，可以与任何现有的 VLM 集成，建立了一个有效且灵活的范式来构建下一代感知感知模型。VLM-FO1 在各种细粒度感知任务中表现出色，包括物体 grounding、区域生成理解、视觉区域推理等。

主要特点：
- 即插即用模块，可集成到任何现有 VLM
- 不损害高层推理能力的同时提升细粒度感知
- 在 HuggingFace 和 ModelScope 上发布了预训练模型（基于 Qwen2.5-VL-3B）
- 提供在线演示，支持与 SAM3 结合进行视频跟踪
- 支持多种细粒度感知任务

该方法为构建兼具高层推理和精细感知能力的 VLM 提供了新范式。
