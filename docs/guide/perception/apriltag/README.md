## 项目概述
AprilTag是一个流行的视觉定位系统，广泛应用于机器人研究。该项目包含最新版本的AprilTag 3，提供了更快的检测器（比之前快2倍以上）、改进的小标签检测率、灵活的标签布局和位姿估计功能，是一个小型的C库，依赖最少，适用于机器人导航、增强现实等领域的视觉定位任务。
