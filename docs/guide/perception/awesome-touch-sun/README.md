面向机器人操纵的触觉感知研究资源精选列表：涵盖论文、数据集、基准测试、仿真平台及框架，重点集成触觉与视觉 - 语言 - 动作（VLA）模型及世界模型，以支持富含接触场景的操纵任务。

## 项目链接

- GitHub: <https://github.com/sun254667/awesome-touch>

## 项目介绍
这是一个精选的、面向学习的机器人触觉感知研究资源列表，涵盖2025年1月至2026年7月期间的相关论文、数据集、基准测试、仿真平台与框架，重点关注触觉与Vision-Language-Action(VLA)模型、世界模型的结合，用于复杂接触式机器人操作任务。

## 主要特性
1.  **收录标准严格**：优先收录ICRA、IROS、CoRL等顶会顶刊的高质量研究
2.  **覆盖核心方向**：包含触觉VLA模型、视觉触觉世界模型、触觉世界动作模型、触觉模仿学习、触觉强化学习、触觉仿真与Sim2Real、触觉传感器硬件、触觉数据集与基准测试等领域
3.  **资源分类清晰**：按综述、模型类别、技术方向等进行模块化整理，便于快速检索学习
