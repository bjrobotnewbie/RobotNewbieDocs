# fuse

- 项目链接：https://github.com/locusrobotics/fuse

## 项目概述

fuse是一个基于ROS框架的**机器人传感器融合框架**，使用非线性最小二乘优化技术进行传感器融合。主要特点包括：

1. **插件化架构**：传感器测量、运动模型、优化结果发布都采用插件系统，方便扩展
2. **通用架构**：支持多种应用场景，包括状态估计、定位、地图构建和校准
3. **异步处理**：实际运行中大部分流程是异步的，各传感器独立工作
4. **扩展状态变量**：支持可扩展的状态变量定义
5. **常用实现**：提供了常见组件的实现，方便开发者快速上手

该框架为ROS机器人系统提供了一套结构化的传感器融合解决方案，便于研究和应用开发。
