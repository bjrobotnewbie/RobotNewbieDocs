# Collaborative_Perception

本仓库收录了近期在车辆至基础设施（V2I）、车辆至车辆（V2V）及车辆至外界（V2X）自动驾驶场景中协同/合作/多智能体感知的最新进展。

## 项目链接

- GitHub: <https://github.com/Little-Podi/Collaborative_Perception>

## 项目概述

## 项目介绍
本仓库是面向V2I、V2V、V2X自动驾驶场景的协同/协作/多智能体感知领域最新研究的论文整理库，按论文标题首字母排序整理相关文献。项目已不再收录复现基准测试结果，如需查看历史结果可访问归档版本。

## 主要特性
1.  **核心分类**：涵盖方法框架、数据集与模拟器两大板块
2.  **学习资源**：收录了多篇该领域高质量综述与前沿研究论文，包括多智能体自动驾驶、车路协同感知、V2X协作感知等方向的最新进展
3.  **适用场景**：服务于自动驾驶协同感知领域的研究者、开发者，用于快速了解领域前沿动态
