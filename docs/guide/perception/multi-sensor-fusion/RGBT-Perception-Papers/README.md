# RGBT-Perception-Papers

RGB-T 目标检测、语义分割与人群计数综述

## 项目链接

- GitHub: <https://github.com/zyrant/RGBT-Perception-Papers>

## 项目介绍
本项目是RGB-T感知领域的论文、官方代码、数据集与评测资源汇总仓库，其中RGB-T包含可见光-热成像/红外相关的多模态感知研究。涵盖显著目标检测、语义分割、人群计数三大主流任务，同时提供相关数据集与评测方法汇总。项目由ChatGPT协助整理文献收集、校验与文档组织。

## 主要特性
1.  **多任务覆盖**：收录RGB-T显著目标检测、语义分割、人群计数三大方向的顶会顶刊论文
2.  **资源联动**：点击论文链接可直达论文页面，点击Stars徽章可跳转对应官方代码仓库
3.  **分类清晰**：按任务模块拆分内容，同时附带数据集与评测资源专区
4.  持续更新：最后更新时间为2026年8月25日，收录了2025-2026年的最新研究成果
