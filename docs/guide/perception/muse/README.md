# muse

- 项目链接：https://github.com/iit-DLSLab/muse

## 项目概述

MUSE是**四足机器人实时多传感器状态估计器**，发表在IEEE Robotics and Automation Letters。该项目针对四足机器人融合本体感知与外部感知数据进行状态估计，主要特点：

1. **针对性设计**：专门为四足机器人设计的本体状态估计器
2. **输入需求**：需要IMU测量、关节状态和足部受力作为输入
3. **ROS2兼容**：此分支完全兼容Unitree SDK和ROS2通信，已在Unitree Go2机器人的仿真和实物实验中测试验证
4. **便捷环境**：提供现成的Conda环境配置，无需手动解决依赖问题
5. **完整示例**：给出了仿真和实物实验的操作指南，方便复现

该包为四足机器人状态估计提供了现成可靠的解决方案，可以直接集成到四足机器人软件系统中。
