## 项目概述

PAZ是一个**基于Python的层级感知库**，专为自主系统设计，支持多种计算机视觉感知任务。主要功能包括：

1. **多任务支持**：姿态估计、目标检测、实例分割、关键点估计、人脸识别、情绪分类等
2. **层次化设计**：采用层级化架构设计，便于扩展和复用
3. **完整示例**：提供多个实时demo和训练脚本，方便快速上手
4. **可直接安装**：通过pip可以直接安装使用

该库集成了多种经典感知算法，提供了统一的API接口，是学习和开发自主系统感知模块非常好的起点。
