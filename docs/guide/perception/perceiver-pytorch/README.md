# perceiver-pytorch

- 项目链接：https://github.com/lucidrains/perceiver-pytorch

## 项目概述

perceiver-pytorch是基于PyTorch实现的**Perceiver架构**，这是DeepMind提出的一种使用迭代注意力的通用感知方法。主要特点包括：

1. **处理任意大小输入**：通过迭代注意力机制，可以处理不同维度和大小的输入数据，不限于图像
2. **傅里叶位置编码**：自动对输入数据进行傅里叶编码，处理位置信息
3. **灵活架构**：支持图像（2轴）和视频（3轴）等不同维度输入，可用于分类等任务
4. **可直接安装**：提供pip包，方便使用

Perceiver架构通过交叉注意力将高维输入压缩到较小的潜在数组中，然后在潜在数组上交替进行交叉注意力和自注意力处理，解决了传统Transformer处理高分辨率输入计算量过大的问题。该仓库是清晰简洁的PyTorch实现，便于研究和使用。
