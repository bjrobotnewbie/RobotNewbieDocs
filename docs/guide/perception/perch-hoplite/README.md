# perch-hoplite

面向大型机器感知嵌入数据库的敏捷建模工具集

## 项目链接

- GitHub: <https://github.com/google-research/perch-hoplite>

## 项目概述

## 项目介绍
Perch Hoplite是一个用于在大规模机器感知嵌入数据库上开展敏捷建模的工具系统，主打结合向量搜索与主动学习的敏捷建模工作流，尤其适用于生物声学领域。
其核心流程为：先通过预训练基础模型将未标注音频转为语义嵌入，再通过示例搜索目标嵌入，结合用户反馈快速训练分类器，还可通过主动学习迭代优化模型，新分类器通常可在1小时内完成开发。项目提供了两个Colab/Jupyter示例笔记本用于快速上手。

## 主要特性
1.  支持大规模嵌入存储与管理，内置精确/近似向量搜索功能
2.  集成敏捷建模与主动学习工作流，可高效完成分类器快速开发与迭代优化
3.  包含生物声学模型库，支持任意可将音频窗口转为嵌入的模型接入
4.  内置鸟类分类学数据库，支持不同分类体系间的转换
5.  提供完整的子库文档，功能模块清晰，分为数据库核心、敏捷建模工具、模型库、分类学工具四个部分
