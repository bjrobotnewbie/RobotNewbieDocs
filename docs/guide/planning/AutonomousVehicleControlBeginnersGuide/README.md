# AutonomousVehicleControlBeginnersGuide

AutonomousVehicleControlBeginnersGuide 是一组面向初学者的自动驾驶控制、定位、建图、规划和感知算法 Python 示例与文档。

## 项目链接

- GitHub: <https://github.com/ShisatoYano/AutonomousVehicleControlBeginnersGuide>

## 项目概述

AutonomousVehicleControlBeginnersGuide 是一个面向自动驾驶算法学习的示例代码集合。项目用 Python 实现常见自动驾驶基础模块，并配套说明文档，目标是帮助初学者理解算法原理和软件架构，而不仅仅是运行现成程序。

README 中列出的内容覆盖自动驾驶入门中常见的核心主题：定位部分包括扩展卡尔曼滤波、无迹卡尔曼滤波和粒子滤波；建图部分包括栅格地图、代价地图、势场地图和 NDT 地图；路径规划部分包括 A*、Dijkstra、PRM、RRT、RRT*、Informed RRT* 等算法；路径跟踪部分包括 Pure Pursuit、LQR、Stanley、MPPI 等控制方法；此外还包含感知相关示例和传感器外参估计内容。

该项目适合用于教学、自学、课程实验和自动驾驶算法原型验证。它的价值在于把算法拆成可读、可运行的 Python 示例，降低学习门槛，同时也可以作为开发者整理自动驾驶控制软件架构和模块接口的参考。
