# BehaviorTree.CPP

- 项目链接：https://github.com/BehaviorTree/BehaviorTree.CPP
- 项目主页：https://behaviortree.dev

## 项目概述

BehaviorTree.CPP是一个**C++17行为树库**，设计目标是灵活、易用、响应快速。虽然主要用于机器人，但也可以用于游戏AI或替代有限状态机。主要特点：

1. **一流异步支持**：将异步（非阻塞）动作作为一等公民支持
2. **反应式行为**：可以并发执行多个动作，实现反应式行为
3. **XML定义树**：使用基于XML的领域特定语言定义行为树，可以在运行时加载，不需要硬编码
4. **支持静态链接或插件**：可以静态链接自定义节点，也可以转为插件
5. **支持ROS2**：官方提供ROS2支持，持续集成测试
6. **跨平台**：支持Ubuntu、Windows，支持pixi/conan包管理

该库是机器人领域非常流行的行为树实现，广泛用于机器人任务决策。
