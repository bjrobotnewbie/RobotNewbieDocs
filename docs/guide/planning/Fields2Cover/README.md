# Fields2Cover

Fields2Cover 是面向自主农业车辆的覆盖路径规划库，提供模块化、可扩展的田地覆盖规划算法。

## 项目链接

- GitHub: <https://github.com/Fields2Cover/Fields2Cover>
- 项目主页: https://fields2cover.github.io/

## 项目概述

Fields2Cover 是一个专注于覆盖路径规划（Coverage Path Planning, CPP）的开源库，主要面向自主农业车辆。覆盖路径规划的目标是在一个或多个车辆约束下生成路径，使目标区域被完整覆盖；在农业场景中，田地边界通常已知，但要求路径尽量高效、完整并满足车辆转弯和作业约束。

项目提供多阶段的覆盖规划能力，包括田地区域分解、作业条带生成、路线排序和最终路径生成。README 中提到 2.0 版本加入了对非凸田地和障碍物的支持，并引入梯形分解、Boustrophedon 分解、基于 OR-Tools 的路线优化以及自定义起终点等能力，提升了复杂地块中的实用性。

Fields2Cover 适合农业机器人、无人拖拉机、喷洒/播种/割草等作业路径规划，也可扩展到清洁机器人、巡检、排雷等其他覆盖任务。项目提供 C++ 与 Python 支持、完整文档和示例，适合工程集成和覆盖规划算法研究。
