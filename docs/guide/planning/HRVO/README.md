# HRVO

HRVO 是用于多移动机器人或虚拟智能体无碰撞、无振荡导航的混合互惠速度障碍 C++ 库。

## 项目链接

- GitHub: <https://github.com/snape/HRVO>
- 项目主页: https://gamma.cs.unc.edu/HRVO/

## 项目概述

HRVO（Hybrid Reciprocal Velocity Obstacle）是一个经典的多智能体避碰导航库，面向多个移动机器人或虚拟智能体在共享空间中的局部避碰问题。它的核心思想是让每个机器人基于自身感知独立选择速度，不依赖中心化协调或显式通信，同时避免互惠避障方法中常见的振荡问题。

README 和项目主页表明，该方法适合处理多机器人、群体仿真、游戏角色和虚拟人群等场景中的实时避碰。每个智能体只需要感知周围环境并独立决策，HRVO 通过混合互惠速度障碍约束来生成无碰撞速度，使系统能够在分布式条件下保持稳定导航。

该仓库提供 C++ 实现、构建说明、示例程序和引用信息。虽然项目年代较早，但其算法思想在多机器人路径规划、局部避障、人群仿真和实时导航研究中仍具有参考价值，适合用于教学、算法复现和轻量级多智能体避碰实验。
