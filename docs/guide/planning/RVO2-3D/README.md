# RVO2-3D

RVO2-3D 是三维空间中的最优互惠避碰 C++ 库，用于多智能体在无中心协调条件下实现局部无碰撞导航。

## 项目链接

- GitHub: <https://github.com/snape/RVO2-3D>
- 项目主页: https://gamma.cs.unc.edu/RVO2/

## 项目概述

RVO2-3D 是 RVO2 思想在三维空间中的实现，面向多个移动机器人、无人机或虚拟智能体的实时局部避碰问题。它基于 Optimal Reciprocal Collision Avoidance（ORCA）方法，让每个智能体独立选择速度，同时通过互惠约束避免与其他智能体发生碰撞。

与二维平面避碰库相比，RVO2-3D 更适合处理三维运动场景，例如空中机器人、三维群体仿真、虚拟角色或空间多智能体系统。README 和项目主页信息显示，该库强调分布式决策，不要求中心化调度或智能体之间显式通信，因此适合大规模智能体的实时避碰模拟。

该项目提供 C++ 实现、构建说明、示例程序和论文引用信息。它适合用于多智能体导航研究、三维群体仿真、无人机避碰原型验证和经典 ORCA/RVO 方法学习。
