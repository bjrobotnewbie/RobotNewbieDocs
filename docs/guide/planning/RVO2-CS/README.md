# RVO2-CS

- 项目链接：https://github.com/snape/RVO2-CS
- 项目主页：https://gamma.cs.unc.edu/RVO2/

## 项目概述

RVO2-CS 是**最优双边碰撞避免（Optimal Reciprocal Collision Avoidance）**算法的 C# 实现版本，用于多机器人运动规划中的碰撞避免。

这是一个开源库，提供了高效的局部碰撞避免算法，能够让多个机器人在共享空间中同时运动而不发生碰撞。

### 算法特点

- **互反碰撞避免**：每个机器人考虑其他机器人的运动，做出互反的避障决策
- **最优性**：在速度空间中寻找最优的无碰撞速度
- **局部规划**：仅基于邻域信息进行局部避障，计算效率高
- **可扩展性**：可以处理数十到数百个机器人的场景

### 主要应用

- 多机器人路径规划
- 群体机器人运动
- 无人机集群避障
- 移动机器人导航

RVO2 算法是机器人局部避障领域的经典工作，这个 C# 移植版本方便 .NET 开发者使用。
