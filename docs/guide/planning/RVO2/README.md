# RVO2

- 项目链接：https://github.com/snape/RVO2
- 项目主页：https://gamma.cs.unc.edu/RVO2/

## 项目概述

RVO2 是**最优双向碰撞避免（Optimal Reciprocal Collision Avoidance）**算法的官方 C++ 实现，用于多机器人运动规划中的局部碰撞避免。

这是机器人避障领域的经典开源库，提供了高效的 ORCA 算法实现，能够让数十到数百个机器人在共享空间中运动时实时避免碰撞。

### 算法特点

- **ORCA 算法**：基于最优互反碰撞避免理论，提供清晰的几何解释
- **计算高效**：局部避障算法，每个机器人的计算复杂度为 O(n)，支持实时计算
- **无悬挂碰撞**：每个机器人考虑其他机器人的运动，做出互惠决策，避免死锁
- **开源稳定**：经过多年使用和验证，代码简洁稳定

### 核心优势

- 处理多个动态机器人的同时运动
- 每个机器人只需要邻域信息，不需要全局规划
- 易于集成到更大的导航系统中
- 纯 C++ 实现，依赖少，编译方便

### 应用场景

- 多机器人路径规划
- 群体机器人协同运动
- 无人机集群飞行避障
- 移动机器人局部导航
-  crowd simulation（人群仿真）

RVO2 是多机器人避障领域的经典基础库，被广泛引用和使用在研究和项目中。
