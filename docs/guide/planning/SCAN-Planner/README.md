# SCAN-Planner

SCAN-Planner 是面向长距离四足机器人导航的空间碰撞感知局部规划器，可服务于自主探索和视觉语言导航等上层任务。

- GitHub: <https://github.com/wuyi2121/SCAN-Planner>
- 项目主页: https://wuyi2121.github.io/SCAN-Planner/

## 项目概述

SCAN-Planner 是一个面向四足机器人长距离导航的局部规划项目，重点解决复杂空间中的碰撞感知规划问题。README 中说明该局部规划器可以支持多种上层任务，包括自主探索和视觉语言导航，因此它更像是连接高层语义/探索目标与低层运动执行之间的局部规划模块。

虽然仓库 README 表示代码尚未发布，但项目展示了多个典型场景演示：杂乱房间、S 形弯道、动态障碍以及跨楼层长距离导航。这些示例表明 SCAN-Planner 关注的不只是平面路径，而是在四足机器人真实运动中需要处理的空间结构、动态障碍和复杂地形约束。

SCAN-Planner 适合关注腿足机器人导航、空间碰撞检测、长距离局部规划和具身智能导航的研究者跟踪。当前更适合作为论文/项目方法参考和演示材料来源，后续代码发布后可用于与自主探索、VLN 或四足机器人导航栈集成。
