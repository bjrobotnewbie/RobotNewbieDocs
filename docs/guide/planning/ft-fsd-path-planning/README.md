# ft-fsd-path-planning

ft-fsd-path-planning 是 FaSTTUBe Formula Student Driverless 团队开源的无人方程式路径规划算法，重点处理赛道锥桶颜色信息不完整时的中心线生成问题。

## 项目链接

- GitHub: <https://github.com/papalotis/ft-fsd-path-planning>

## 项目概述

该项目面向 Formula Student Driverless 场景，提供一套可供参赛车队快速集成和改造的路径规划算法。它的目标不是提供通用自动驾驶全栈，而是聚焦在由锥桶检测结果生成车辆可行驶中心线，帮助新进入无人驾驶组别的队伍更快搭建路径规划模块。

README 强调该算法与常见方法不同：它能够在一侧赛道边界不可见、锥桶颜色未知或颜色信息混合的情况下保持较强鲁棒性。这类情况在无人方程式中非常常见，尤其是检测系统不够成熟的车队。因此该算法对 Autocross、Skidpad 等任务都有专门考虑，并在后续版本中加强了无颜色路径规划、Skidpad 稳定性、重定位信息和排序步骤性能。

项目适合用于无人方程式路径规划学习、原型验证和车队工程实践。使用者可以基于该仓库适配自己的感知与控制流水线，也可以通过交互式演示了解算法效果。整体上，它提供的是一个实用型中心线计算和路径规划基础，而不是依赖 Delaunay 三角剖分或 RRT 的传统方案。
