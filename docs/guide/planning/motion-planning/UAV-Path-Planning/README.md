# UAV-Path-Planning

基于人工蜂群算法的无人航空器路径规划

## 项目链接

- GitHub: <https://github.com/libai1943/UAV-Path-Planning>

## 项目介绍
本项目是基于人工蜂群算法（ABC）的无人机路径规划实现，同时提供粒子群优化算法（PSO）作为对比，包含MATLAB、Python、C++、Julia四种可运行的数值路径规划示例实现。项目核心是让无人机路径在合成二维风险场中规划，平衡风险暴露与路径距离，无需额外工具或工具箱即可运行。

## 主要特性
1. 提供四种编程语言的独立实现，各版本有明确的环境要求与入口文件，输出路径图、收敛曲线、CSV等结果文件；
2. 默认采用ABC算法，支持切换为PSO算法进行对比，可自定义迭代次数、随机种子等参数；
3. 各版本实现轻量化，无额外依赖（如AMPL、CasADi等），Python版本支持非交互运行，C++与Julia版本可生成独立SVG路径图。
