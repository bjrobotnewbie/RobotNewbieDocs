# WAM-Flow

[CVPR 2026] WAM-Flow：基于离散流匹配的并行粗到细运动规划方法，用于自动驾驶

## 项目链接

- GitHub: <https://github.com/fudan-generative-vision/WAM-Flow>

## 项目介绍
WAM-Flow是一篇被CVPR 2026收录的自动驾驶运动规划算法，提出基于离散流匹配的并行粗到细运动规划方案。项目由复旦大学和银网智能科技团队联合开发，已在Arxiv发布论文，提供预训练模型、训练与推理代码、评测代码及数据集，相关资源可通过HuggingFace获取。

## 主要特性
1.  采用离散流匹配技术实现并行的粗到细运动规划，提升自动驾驶规划效率与效果
2.  已开源完整的SFT训练、推理、评测代码与配套数据集
3.  提供HuggingFace平台的预训练模型下载，方便快速部署使用
4.  支持后续RL相关代码的扩展开发
