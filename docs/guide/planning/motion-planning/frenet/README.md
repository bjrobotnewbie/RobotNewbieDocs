## 项目概述

## 项目介绍
本项目是一款基于Frenet坐标系的移动机器人轨迹规划工具，核心功能是将Frenet(s,d)坐标转换为局部笛卡尔(x,y)坐标，适用于高速公路等存在先验参考路径的结构化环境下的二维平面移动机器人轨迹规划。

## 主要特性
1.  支持两种横向规划模式：基于时间的$d(t)$和基于弧长的$d(s)$，可根据机器人速度自动切换
2.  分别在Frenet空间生成横向、纵向运动轨迹并附带成本计算，可过滤高横向加速度轨迹提升运算效率
3.  将纵横轨迹组合后转换回世界坐标系，验证曲率、加速度是否符合物理驾驶限制
4.  支持静态与动态碰撞检测，选择总成本最低的可行轨迹
5.  可根据初始 jerk 切换纵向运动模式，兼顾减速与能耗优化
