# gbplanner_ros

基于图的地下环境探索规划器

## 项目链接

- GitHub: <https://github.com/ntnu-arl/gbplanner_ros>

## 项目介绍
本项目是针对地下环境开发的基于图的探索规划器`gbplanner_ros`，适配ROS机器人开发框架，主要用于地下矿山等复杂地下场景的自主机器人探索规划。项目提供了完整的编译、运行教程，附带多种地下仿真环境，包括柱式矿井、长壁矿井以及真实矿井重建场景。

## 主要特性
1.  **核心功能**：为地下环境的自主机器人提供图探索规划能力，支持通过服务调用触发自动规划任务。
2.  **灵活的地图框架**：默认支持Voxblox，可通过编译开关切换至Octomap。
3.  **完整依赖支持**：提供预配置的工作空间`gbplanner_ws`，包含所有依赖包，简化部署流程，依赖包括pci_mav规划控制接口、RotorS MAV仿真工具、LiDAR仿真器等。
4.  **仿真支持**：内置多款地下矿井仿真场景，可快速开展算法测试。
5.  附带官方算法与架构教程文档，以及学术引用格式。
