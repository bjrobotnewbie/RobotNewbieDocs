## 项目概述

## 项目介绍
MoveIt是一款面向ROS的开源机器人运动规划框架，可用于开发商用机器人操作应用、原型设计以及算法基准测试。该项目分为ROS版本和ROS 2版本（MoveIt 2），同时提供商业支持版MoveIt Pro。

## 主要特性
1.  采用`master`分支开发最新功能，`*-devel`分支对应ROS特定发行版的稳定发布版本，当前`noetic-devel`与`master`同步
2.  支持持续集成测试，覆盖代码格式化、CI校验、代码覆盖率统计以及ROS构建农场构建状态监测
3.  提供便捷的安装指引、完整文档以及社区参与渠道，便于开发者快速上手和贡献代码
