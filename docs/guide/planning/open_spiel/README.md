# open_spiel

OpenSpiel 是一个用于研究一般强化学习、博弈论算法与游戏搜索/规划的环境和算法集合。

## 项目链接

- GitHub: <https://github.com/google-deepmind/open_spiel>

## 项目概述

OpenSpiel 是 Google DeepMind 开源的博弈强化学习研究框架，面向多智能体强化学习、博弈搜索、规划算法和学习动态分析。它提供大量可复现实验环境，并将游戏抽象为扩展式博弈，适合研究零和、合作、一般和、单步、序贯、同步行动、完美信息与非完美信息等不同类型的博弈问题。

项目的核心价值在于把环境、算法和评估工具统一到同一套 API 中。研究者可以在同一框架下测试 CFR、强化学习、搜索规划、多智能体学习等算法，也可以分析策略学习过程、均衡性质和常见评估指标。底层核心 API 与部分游戏环境使用 C++ 实现，并提供 Python 接口，便于同时兼顾性能和实验便利性。

OpenSpiel 适合用于博弈 AI、强化学习算法验证、多智能体协作与竞争研究，以及教学场景中的算法演示。仓库还提供安装文档、算法与游戏列表、API 教程、Colab 示例和论文引用信息，方便快速上手和复现实验。
