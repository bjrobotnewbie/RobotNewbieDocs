# 路径规划 (Path Planning)

路径规划是移动机器人导航的核心技术，研究如何在存在障碍物的环境中找到从起点到终点的无碰撞几何路径。与运动规划不同，路径规划关注的是**走哪条路**，而不考虑运动的时间和动力学约束。

## 分类总览

| 分类 | 核心思想 | 典型算法 | 优势 | 局限性 |
|------|---------|---------|------|--------|
| **基于图搜索** | 将环境离散化为图，搜索最优路径 | A*, Dijkstra | 保证最优性 | 计算复杂度高 |
| **基于采样** | 在连续空间中随机采样 | RRT, RRT* | 高维空间高效 | 不保证最优 |
| **局部避障** | 实时动态避障 | DWA, APF | 响应速度快 | 易陷入局部最优 |

---

## 一、基于图搜索的路径规划

### 核心概念

将连续环境离散化为网格或图结构，通过图搜索算法找到从起点到终点的最优路径。

### 主要算法

#### 1. Dijkstra 算法

Dijkstra 是经典的单源最短路径算法，通过广度优先搜索保证找到全局最短路径。

**核心流程：**
1. 初始化所有节点距离为无穷大
2. 从起点开始，逐步扩展最近节点
3. 更新相邻节点的最小距离
4. 到达终点即停止

**特点：**
- ✅ 保证找到最短路径
- ✅ 适用于无权图或正权图
- ❌ 搜索范围大，计算效率低
- ❌ 没有启发式信息

#### 2. A* (A-Star) 算法

A* 在 Dijkstra 的基础上引入启发函数，引导搜索方向，显著提高搜索效率。

**核心公式：** `f(n) = g(n) + h(n)
- `g(n)`：从起点到节点 n 的实际代价
- `h(n)`：从节点 n 到终点的启发估计代价

**常用启发函数：**
- 曼哈顿距离（网格）
- 欧几里得距离（连续空间）
- 切比雪夫距离

**特点：**
- ✅ 保证最优（启发函数可采纳时）
- ✅ 搜索效率远高于 Dijkstra
- ✅ 工业界最常用
- ❌ 启发函数设计影响性能

#### 3. Theta* / Lazy Theta*

Theta* 在 A* 的基础上支持任意角度路径，生成更平滑的路径。

**核心改进：
- 支持线可视性检查
- 绕过网格限制
- 生成更自然的路径

## 二、基于采样的路径规划

### 核心概念

在连续空间中随机采样，通过连接有效样本构建路径，适合高维空间和复杂环境。

### 主要算法

#### 1. RRT (Rapidly-exploring Random Tree)

快速扩展随机树，通过随机采样快速探索未知空间。

**核心流程：**
1. 在空间中随机采样一个点
2. 找到树上离采样点最近的节点
3. 从最近节点向采样点扩展一步
4. 重复直到到达目标区域

**特点：**
- ✅ 概率完备性（时间足够总能找到解）
- ✅ 高维空间效率高
- ❌ 路径质量不稳定
- ❌ 不保证最优性

#### 2. RRT* (RRT Star)

RRT 的优化版本，通过重新布线机制，渐近最优。

**核心改进：**
- 重新选择父节点
- 重布线优化路径
- 渐近收敛到最优路径

**特点：**
- ✅ 渐近最优
- ✅ 路径质量随时间提升
- ❌ 收敛速度较慢
- ❌ 计算开销更大

#### 3. PRM (Probabilistic Roadmap)

概率路线图，分学习阶段和查询阶段。

**核心流程：**
1. 学习阶段：采样大量路标点，构建路线图
2. 查询阶段：在路线图上搜索最短路径

**特点：**
- ✅ 多查询场景效率高
- ✅ 适合静态环境
- ❌ 单次查询开销大
- ❌ 动态环境适应性差

## 三、局部避障算法

### 核心概念

在机器人运动过程中，根据传感器信息实时避开动态障碍物。

### 主要算法

#### 1. DWA (Dynamic Window Approach)

动态窗口法，在速度空间中采样，评估最优速度指令。

**核心思想：**
- 在速度空间 (v, ω) 采样
- 评估每个速度的轨迹
- 根据目标函数选最优

**评价指标：**
- 朝向目标
- 避障
- 速度

**特点：**
- ✅ 实时性好
- ✅ 适合动态环境
- ❌ 易陷入局部最优
- ❌ 可能错过全局最优

#### 2. APF (Artificial Potential Field)

人工势场法，目标产生引力，障碍物产生斥力。

**核心思想：**
- 目标点：引力势场
- 障碍物：斥力势场
- 合力方向即为运动方向

**特点：**
- ✅ 计算简单，实时性好
- ✅ 物理意义直观
- ❌ 易陷入局部最优
- ❌ 窄通道易振荡

#### 3. TEB (Timed Elastic Band)

时间弹性带，优化带时间参数的路径。

**核心思想：**
- 将路径表示为弹性带
- 加入时间维度优化
- 考虑动力学约束

**特点：**
- ✅ 生成平滑轨迹
- ✅ 考虑动力学约束
- ✅ 动态避障能力强

## 与运动规划的区别

| 特性 | 路径规划 (Path Planning) | 运动规划 (Motion Planning) |
|------|-------------------------|---------------------------|
| **输出** | 几何路径点 [x, y, θ] | 带时间轨迹 [x(t), y(t), θ(t) |
| **约束** | 仅避障 | 运动学、动力学、速度、加速度约束 |
| **空间维度** | 2D/3D 几何空间 | 关节空间（6-7维及以上） |
| **典型算法 | A*, RRT*, Dijkstra, DWA | CHOMP, STOMP, IK |
| **应用对象** | 移动机器人、无人机 | 机械臂、人形机器人 |
| **时间信息** | 无 | 有 |
| **典型问题 | "走哪条路？" | "怎么运动过去？" |

### 概念对比图

```
路径规划输出：
[P0] → [P1] → [P2] → [P3] → （仅位置信息）
  x1,y1   x2,y2   x3,y3

运动规划输出：
t0: (x0, y0, v0, a0)
t1: (x1, y1, v1, a1)
t2: (x2, y2, v2, a2)
... （含时间、速度、加速度）
```

## 全局规划与局规划

| 类型 | 全局路径规划 | 局部路径规划 |
|------|------------|------------|
| **目标** | 找到全局最优路径 | 避开动态障碍物 |
| **信息** | 全局地图已知 | 局部传感器信息 |
| **实时性** | 低，一次规划 | 高，实时更新 |
| **典型算法** | A*, RRT* | DWA, APF, TEB |
| **优缺点** | 路径最优，计算慢 | 响应快，易局部最优 |

### 导航栈组合使用

```
全局规划器 (A*/RRT*)
    ↓ 输出全局路径
局部规划器 (DWA/TEB)
    ↓ 输出速度指令
机器人执行
```

## 技术选型指南

| 场景特点 | 推荐算法 |
|---------|---------|
| 已知静态地图，追求最优路径 | A* 算法 |
| 高维空间或复杂环境 | RRT / RRT* |
| 动态环境，需要实时避障 | DWA / TEB |
| 简单环境，计算资源有限 | Dijkstra / 蚁群算法 |
| 多查询场景，静态环境 | PRM |
| 需要平滑动态轨迹 | TEB |
