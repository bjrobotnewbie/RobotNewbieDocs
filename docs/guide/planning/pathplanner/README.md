## 项目概述

PathPlanner 是为 **FRC (FIRST Robotics Competition)** 机器人设计的**简单而强大的运动轮廓生成工具**，由 FRC 3015 战队开发。它提供图形化编辑器方便机器人创建自主路径。

### 核心特点

- **贝塞尔曲线路径**：每条路径使用贝塞尔曲线，可以精细调整精确的路径形状
- **全向轮支持**：全向模式支持将机器人旋转和移动方向解耦
- **实时路径预览**：图形化界面实时预览路径
- **事件标记**：可以在路径上放置事件标记，在路径跟随过程中触发其他代码
- **模块化自主程序**：可以使用其他路径构建模块化自主例程
- **热重载**：无需重新部署代码即可更新机器人上的路径和自主程序
- **自动寻路**：PathPlannerLib 使用 A* 算法支持自动寻路

### 主要功能

- 图形化路径编辑界面，可在 Microsoft Store 获取自动更新
- 提供机器人端库（PathPlannerLib）用于路径生成和自定义路径跟随控制器
- 自动生成完整自主命令，支持自动构建
- 实时路径跟随遥测数据显示
- 支持差速驱动和全向驱动

PathPlanner 是 FRC 机器人竞赛中非常流行的路径规划工具，极大简化了自主路径的创建和调试过程。
