# ruckig

- 项目链接：https://github.com/pantor/ruckig
- 项目主页：https://ruckig.com

## 项目概述

Ruckig 是一个用于机器人和机器的即时运动生成库，支持实时轨迹生成，具有加加速度（jerk）约束，并且能够生成时间最优轨迹。

Ruckig 可以动态生成轨迹，允许机器人和机器对传感器输入做出瞬时反应。它从任意初始状态计算到目标路点（具有位置、速度和加速度）的轨迹，受速度、加速度和加加速度约束。除了目标状态，Ruckig 还允许为路点跟随定义中间位置。

对于状态到状态运动，Ruckig 保证时间最优解。使用中间路点时，Ruckig 联合计算路径及其时间参数化，相比传统方法得到明显更快的轨迹。

主要特点：
- 即时在线轨迹生成，支持实时反应
- 考虑 jerk 约束，生成平滑轨迹
- 时间最优轨迹保证
- 零依赖，易于编译安装
- MIT 许可证开源
- 提供完整文档

Ruckig 被广泛应用于机器人运动规划领域，特别适合需要实时响应的场景。
