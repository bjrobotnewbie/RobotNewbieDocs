# EvoBot

LIBERO 操作任务专用的代理 + 可复用技能库（无需 RL / VLA / 世界模型；运行时不调用 LLM）

## 项目链接

- GitHub: <https://github.com/ABC12345anouys/EvoBot>
- 项目主页: <https://github.com/Lifelong-Robot-Learning/LIBERO>

## 项目介绍
EvoBot是针对LIBERO机器人操作基准的任务解决方案，采用Agent+可复用技能库的架构，无需RL、VLA、世界模型，运行时也不调用LLM。其核心逻辑为Agent负责决策任务执行顺序，技能库负责执行抓取、放置等动作单元，失败时会给出具体原因并触发恢复机制。

## 主要特性
1. 任务规划采用离线方式：将LIBERO任务定义解析为结构化数据，离线生成子目标顺序并存储为YAML文件，运行时直接读取，无需实时调用模型
2. 高任务成功率：在LIBERO的3个任务集共30个任务上，25个任务可通过，成功率达83%
3. 标准化执行控制：以仿真步数截断轨迹，不受机器负载影响，任务从示范轨迹初始状态开始，保证结果可复现
4. 模块化设计：包含感知、任务规划、技能库、失败恢复等模块，各模块有统一约定，便于扩展与维护
