# Xplanner

X-Planner：具身智能事件结构化任务规划

## 项目链接

- GitHub: <https://github.com/X-Square-Robot/Xplanner>

## 项目介绍
X-Planner是面向具身智能的事件结构化任务规划框架，作为长时程机器人操作的任务规划前端，可接收高层指令、同步多视角观测及可选执行历史，将下一行为转化为基于动作的事件表示，传递给下游世界动作模型。项目已开源9B参数模型、含1500个 episodes与3490条视频的XPlanner基准数据集，采用MIT许可协议。

## 主要特性
1. 采用事件基础数据，将演示内容组织为任务/子任务/动作/片段的层级结构；
2. 结构化规划状态，以确定性JSON形式实现初始计划、进行中事件状态或 episode 结束状态；
3. 提供两种规划接口：事件模式（暴露可读事件状态）与统一模式（采用紧凑潜在规划状态及阶梯解码）；
4. 支持基于Qwen3.5-VL的建模扩展，具备分布式SFT训练、数据流水线处理等能力。
