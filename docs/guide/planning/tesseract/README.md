## 项目概述

Tesseract 是一个开源的运动规划环境框架，为机器人运动规划提供了完整的基础设施支持。

主要特点：
- 支持跨平台（Linux 和 Windows）
- 提供 C++ 核心库，并提供 Python 绑定
- 持续集成测试保证代码质量，包括代码覆盖率检查
- 支持多种代码质量检查（Clang-Format、CMake-Format、Clang-Tidy）
- Apache 2.0 许可证开源
- PyPI 发布 Python 包

Tesseract 提供了丰富的运动规划功能，包括逆运动学、碰撞检测、运动轨迹规划等，是 ROS 生态系统中重要的运动规划库之一，被广泛用于工业机器人应用。
