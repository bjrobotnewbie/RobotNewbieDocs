## 项目概述

**toppra** (Time-Optimal Path Parameterization) 是一个用于计算**时间最优路径参数化**的机器人运动规划库，能够在给定几何路径和约束条件下，计算出满足动力学约束的最快轨迹。

### 问题定义

给定：
1. 几何路径 `p(s)`，其中 `s ∈ [0, s_end]`
2. 一系列约束（关节速度、关节加速度、笛卡尔速度等约束）

toppra 输出：时间最优路径参数化 `s_dot(s)`，从而得到满足所有约束的最快轨迹 `q(t)`。

### 核心特点

- **时间最优**：在给定几何路径下找到满足约束的最快执行轨迹
- **支持多种约束**：关节速度、关节加速度、力矩约束、笛卡尔速度约束等
- **Python 优先**：提供完整的 Python 接口，可通过 pip 直接安装
- **C++ 后端**：核心算法用 C++ 实现，保证计算效率
- **文档完善**：提供详细文档和教程

### 应用场景

- 机械臂轨迹时间参数化
- 已知路径下的时间优化
- 机器人运动生成
- 工业机器人轨迹规划

toppra 是机器人轨迹规划领域的经典开源库，被广泛用于研究和工业应用中。
