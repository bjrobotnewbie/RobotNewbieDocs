## 项目介绍
DroneAware Node是一个社区共建的开源远程识别（Remote ID）检测网络项目，目标是通过低成本传感器搭建分布式实时无人机活动监控网络，用户可通过部署节点贡献检测数据并共享全网观测结果。

用户仅需一条命令即可快速部署节点，无需Linux专业经验，部署后可实时监听区域内无人机的FAA强制远程识别广播，并将数据上传至DroneAware网络，在[droneaware.io](https://droneaware.io/live.html)的实时地图上查看全球无人机活动，同时可获取节点检测到无人机的邮件告警，还能回溯查看历史飞行路径。目前该网络已在美国、德国、加拿大等地部署运行。

## 主要特性
1.  快速部署：仅需执行一条一键安装脚本，10-15分钟即可完成节点上线
2.  低成本硬件：支持Raspberry Pi 4及指定USB蓝牙、WiFi适配器
3.  实时监控：可实时查看本地及全网无人机活动，支持历史飞行路径回放
4.  社区共建：分布式网络由全球节点共同维护，共享检测数据
5.  低门槛使用：无需专业Linux基础，仅需具备基础硬件插拔能力即可运行
