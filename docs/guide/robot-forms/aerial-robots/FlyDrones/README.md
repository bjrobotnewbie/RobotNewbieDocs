# FlyDrones

果蝇连接组作为无人机驾驶员：摄像头 -> 果蝇眼睛 -> 神经元放电 -> 下行神经元 -> 无人机。请在浏览器中体验实时 3D 演示。

## 项目链接

- GitHub: <https://github.com/SpikeCalls/FlyDrones>
- 项目主页: <https://spikecalls.github.io/FlyDrones/>

## 项目介绍
FlyDrones是一个以果蝇连接组作为无人机飞控的项目，将摄像头输入模拟为果蝇复眼视觉信号，通过脉冲神经网络的果蝇大脑模型处理后，输出下行神经元信号控制无人机。项目提供浏览器端实时3D演示，可直接在线体验。
该项目基于HHMI Janelia等机构发布的MaleCNS v1.0果蝇中枢神经系统连接组（16.6万个神经元），未在脑模型内编写飞行控制代码，仅通过视觉光流信号驱动果蝇原生反射完成飞行控制。

## 主要特性
1.  搭载完整果蝇大脑模型，加载约16.6万个神经元，经过滤后保留约2500万神经元连接
2.  用6个下行神经元输出作为无人机摇杆控制信号，支持4种无人机平台与仿真环境
3.  支持视觉避障、应急逃逸等原生果蝇反射行为，例如手掌靠近时触发巨纤维逃逸动作
4.  提供浏览器端实时3D在线演示，无需本地部署即可体验
5.  依赖Python 3.10+，采用MIT开源协议
