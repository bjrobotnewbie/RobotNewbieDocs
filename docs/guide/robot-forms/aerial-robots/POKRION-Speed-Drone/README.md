## 项目介绍
POKRION-Speed-Drone是POK-RC团队开发的开源高速微型四旋翼无人机研发平台，核心是提供可3D打印的机身参考方案与可复现的黑盒（Blackbox）飞行测试工作流，用于高速微型无人机的研究与迭代优化。该平台属于实验性工程参考，非认证飞行器，当前处于活跃开发状态，设计参数可能随版本更新调整。

## 主要特性
1. 提供可3D打印的机身零件、螺旋桨型号、机架/安装件参考及飞控参考配置，支持高速微型无人机的复现性搭建；
2. 具备黑盒驱动的可复现飞行测试工作流，包含配置备份指导与本地分析能力，支持单参数调整后的飞行数据（.bbl文件）与电机温度等结果记录；
3. 支持开放工程交流，通过Issues、Discussions等渠道分享带硬件版本、材料、测试条件等信息的观测结果，便于研究协作。
