# 空中机器人

空中机器人（无人机）是面向空中飞行能力的机器人形态，通过多旋翼、固定翼、扑翼等结构实现三维空间飞行。

## 分类体系

| 分类 | 说明 | 典型应用 |
|------|------|---------|
| [多旋翼无人机](./multirotor/README) | 多旋翼垂直起降 | 航拍、巡检、测绘、植保 |
| [固定翼无人机](./fixed-wing/README) | 固定机翼、长航时 | 大面积测绘、巡检、边防巡逻 |
| [倾转旋翼无人机](./vtol/README) | 垂直起降+平飞复合 | 长航程巡检、物流配送 |
| [扑翼与浮空机器人](./flapping-and-lighter/README) | 仿生扑翼或浮空结构 | 仿生研究、特种侦察、空中展示 |

## 归类说明

- 无人机是**机器人形态**，不应只放在"应用场景"分类中
- 无人机表演属于**应用场景**，应归入 applications
- 无人机集群属于**多机器人系统**，应归入 multi-robot-systems
- 本分类只描述单个无人机的飞行形态和结构类型
