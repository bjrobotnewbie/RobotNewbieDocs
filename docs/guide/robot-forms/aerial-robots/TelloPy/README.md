## 项目介绍
TelloPy是用于控制大疆特洛（DJI Tello）玩具无人机的Python软件包，核心代码移植自GOBOT项目的驱动程序。支持通过Python代码实现对Tello无人机的操作，同时可对接视频流处理、外设控制等扩展功能，适用于无人机二次开发、趣味控制及计算机视觉相关场景。

## 主要特性
1. 提供稳定的Python API，可通过PyPI直接安装，也支持从源码编译安装；
2. 内置示例代码，支持一键实现无人机起飞、实时视频流滤镜处理、PS3/PS4/XONE手柄操控等功能；
3. 支持对接第三方扩展项目，如基于手势的控制、基于OpenCV的目标跟踪等计算机视觉应用场景。
