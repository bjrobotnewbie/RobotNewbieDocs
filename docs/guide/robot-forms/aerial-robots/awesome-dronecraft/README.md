## 项目概述

## 项目介绍
这是一份面向软件工程师的自主旋翼无人机学习规划清单，由计算机工程与信息学专业学生整理的3年课余学习内容，旨在帮助开发者掌握自主无人机的工作原理、局限性及开发成本。项目收录了主流开源飞控固件和导航项目的参考资料与视频，兼具实战价值与行业调研意义。适合具备编程基础和线性代数、微积分、概率论等计算机科学基础的开发者学习。

## 主要特性
1.  **完整学习路径**：覆盖前置知识、控制理论、传感器与状态估计、SLAM、路径规划、飞控开发、硬件搭建等全流程学习模块
2.  **实战导向**：包含真实开源项目参考、工业级无人机应用案例
3.  **社区友好**：欢迎提交PR完善内容，参考了coding-interview-university的清单格式
4.  提供学习心态引导与避坑建议，降低入门门槛
