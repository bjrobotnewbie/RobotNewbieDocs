# awesome-drones

精选的 Awesome 无人机资源列表

## 项目链接

- GitHub: <https://github.com/janesmae/awesome-drones>

## 项目介绍
这是一个精选的无人机、无人飞行器(UAV)和四旋翼无人机相关资源汇总列表，旨在为想要学习该领域的爱好者、从业者整合一站式的实用学习材料。

## 主要特性
1.  **分类全面**：涵盖课程、软件库、硬件组件、相关产品项目、视觉定位等多个大类，其中软件库又细分为模拟器、飞控固件、地面站等细分领域。
2.  **资源类型丰富**：包含在线课程、开源项目、硬件配件、商业产品等多种类型资源，部分付费资源会标注`:dollar:`，过时/停用项目标注`:ghost:`。
3.  **适配多场景**：既包含面向入门学习者的考证课程、基础编程教程，也有面向开发者的飞控固件、机器人开发库，可满足无人机爱好者、开发者、从业者的不同学习和开发需求。
