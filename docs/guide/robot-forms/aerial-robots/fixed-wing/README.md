# 固定翼无人机

固定翼无人机通过机翼产生升力，需要跑道或弹射起飞，续航时间长、飞行速度快，适合大范围、长距离作业任务。

## 定义与特点

**固定翼无人机**：依靠前进时机翼上下表面气流速度差产生升力的无人机，通过螺旋桨或喷气推进提供前向速度。

**核心特点**：
- **长航时**：续航数小时至数十小时
- **高速度**：巡航速度快，可达100-200km/h
- **大航程**：单次飞行距离远，可达数百公里
- **高效率**：固定翼气动效率高，能耗低
- **需要起降条件**：需要跑道、弹射器或回收网

## 工作原理

**升力产生**：
- 机翼上表面弧度大，气流速度快，压力低
- 机翼下表面气流速度慢，压力高
- 压力差产生向上的升力
- 飞行速度越快，升力越大

**飞行控制**：
- **副翼**：控制横滚
- **升降舵**：控制俯仰
- **方向舵**：控制偏航
- **油门**：控制前进速度

## 分类体系

| 类型 | 起飞方式 | 特点 | 应用 |
|------|---------|------|---------|
| **常规起降** | 跑道滑行起降 | 载重大，航程远 | 大型测绘、军用 |
| **弹射起飞** | 弹射器/手抛 | 无需跑道，快速部署 | 野外侦察、巡检 |
| **伞降回收** | 降落伞回收 | 回收简单，适合复杂地形 | 临时任务 |
| **滑翔型** | 纯滑翔/动力滑翔 | 超低能耗，超长续航 | 高空长航时观测 |

---

## 优势与挑战

### ✅ 优势
- **续航长**：气动效率高，续航时间远超多旋翼
- **速度快**：巡航速度快，适合大范围覆盖
- **航程远**：单次飞行覆盖面积大
- **载重效率高**：相同载重下能耗更低

### ❌ 挑战
- **起降受限**：需要跑道或弹射装置
- **不能悬停**：必须保持前进速度维持升力
- **操作复杂**：起降操作门槛较高
- **飞行空间**：需要较大空域
