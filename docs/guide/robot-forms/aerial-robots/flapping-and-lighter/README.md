# 扑翼与浮空机器人

非传统飞行方式的空中机器人，包括仿生扑翼和浮空结构。

## 扑翼机器人

模仿鸟类或昆虫的翅膀扑动实现飞行。

### 特点

- 仿生设计，生物学研究价值高
- 低噪声，隐蔽性好
- 可实现悬停和慢速飞行
- 适合微型化

### 典型应用

- 仿生学研究
- 特种侦察
- 教育演示
- 微型空中机器人

## 浮空机器人

通过浮力实现飞行，如飞艇、系留气球。

### 特点

- 超长续航时间
- 大载荷能力
- 可长时间悬停
- 安全性高

### 典型应用

- 空中通信中继
- 大气监测
- 空中广告展示
- 应急通信基站
