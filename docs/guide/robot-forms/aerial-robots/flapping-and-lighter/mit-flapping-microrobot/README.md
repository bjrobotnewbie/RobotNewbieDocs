# MIT 高敏捷仿生扑翼飞行器

MIT 软体与微机器人实验室开发的昆虫级仿生扑翼飞行器，重量不到 1 克，利用新型软人工肌肉驱动，飞行速度可与大黄蜂媲美。

## 关键特性

- **尺寸重量**：小于 1 克，昆虫级别
- **驱动方式**：软人工肌肉驱动
- **性能**：飞行速度堪比大黄蜂
- **抗撞击能力**：极高的抗撞击和自我修复能力
- **机构特点**：仿生扑翼设计

## 技术亮点

- 微尺度仿生设计
- 新型软人工肌肉
- 极高碰撞容错能力
- 自主修复机制

## 典型应用场景

- 温室自动化授粉
- 灾区搜救侦察
- 室内环境监测
- 微型侦察无人机
