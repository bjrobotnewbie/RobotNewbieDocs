# MIT 微型跳跃扑翼机器人

MIT 开发的介于爬行与飞行之间的微型机器人，同时具备跳跃和扑翼能力，体积小于人类拇指，可穿越复杂地形。

## 关键特性

- **尺寸**：体积小于人类拇指
- **运动方式**：弹跳 + 扑翼飞行混合
- **适应能力**：可在冰面、潮湿环境、倾斜地面穿越
- **设计动机**：解决纯爬行无法越障、纯飞行能耗大的问题

## 技术亮点

- 混合运动模式设计
- 微型化机构集成
- 复杂地形适应能力
- 低能耗设计
