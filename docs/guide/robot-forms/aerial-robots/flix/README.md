# flix

从零开始制作基于 ESP32 的四旋翼飞行器

## 项目链接

- GitHub: <https://github.com/okalachev/flix>
- 项目主页: <https://t.me/opensourcequadcopter>

## 项目介绍
Flix是一款基于ESP32的开源四轴飞行器，名称取自“flight + X”，主打从零搭建的教育科研向四轴项目。项目提供3D打印机架版本以及原型机，支持通过多种方式飞行演示，还配套有飞行控制理论教材、完整的组装与使用文档，官方PCB版本Flix2正在开发中。

## 主要特性
1.  面向教育和科研场景，采用通用元器件搭建
2.  固件基于Arduino开发，代码简洁不足2000行
3.  支持通过Wi-Fi或ESP-NOW使用MAVLink协议通信
4.  可通过USB游戏手柄、遥控器、智能手机进行控制
5.  提供无线命令行界面与数据分析功能
6.  支持基于Gazebo的精准仿真，可运行原生固件代码
7.  配套Python库用于脚本编写与自动飞行
8.  正在开发位置控制功能，同时提供飞行控制理论教材与完整的项目文档
