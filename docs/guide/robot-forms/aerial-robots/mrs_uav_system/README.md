## 项目概述

## 项目介绍
本项目是捷克布拉格理工大学多机器人系统小组开发的MRS UAV系统入口项目，基于ROS Noetic（当前版本，正迁移至ROS2），专为多旋翼无人机设计，提供控制、状态估计、建图、规划等完整流水线，支持在机载 companion computer 上运行，可用于规划、控制、SLAM、计算机视觉等方向的可复现真实世界实验验证。

## 主要特性
1.  基于ROS Noetic开发，正迁移至ROS2
2.  支持在无人机机载 companion computer 上完整运行
3.  可控制欠驱动多旋翼直升机
4.  集成控制、状态估计、建图、规划全流程管线
5.  面向科研与教学，代码可读性强，鼓励用户通过源码与launch文件自主学习探索。官方文档可参考项目官网。
