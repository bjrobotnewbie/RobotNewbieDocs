# 多旋翼无人机

多旋翼无人机是最常见的无人机形态，通过多个旋翼的转速差控制飞行姿态，可垂直起降、悬停，在航拍、巡检、植保等领域应用广泛。

## 定义与特点

**多旋翼无人机**：通过多个旋翼产生升力，利用各旋翼转速差实现姿态控制和位置移动的旋翼飞行器。

**核心特点**：
- 垂直起降，不需要跑道
- 可悬停，适合定点作业
- 机械结构简单，无复杂活动部件
- 控制灵活，可全向飞行
- 操控门槛低，易于自动化

## 工作原理

**飞行控制**：
- **升力**：所有旋翼共同产生向上推力
- **俯仰/横滚**：通过改变对应方向旋翼转速差实现倾斜
- **偏航**：利用正反桨转速差产生偏航力矩
- **位置控制**：倾斜后产生水平分力实现平移

**传感系统**：
- IMU（惯性测量单元）：姿态感知
- GPS/GNSS：定位导航
- 气压计：高度测量
- 视觉传感器：避障与定位

## 分类体系

| 类型 | 旋翼数 | 特点 | 应用 |
|------|--------|------|---------|
| **四旋翼** | 4 | 最常见，结构紧凑，效率高 | 航拍、消费级 |
| **六旋翼** | 6 | 冗余度高，单桨失效仍可飞行 | 巡检、专业作业 |
| **八旋翼** | 8 | 大负载，高冗余，安全性好 | 农业植保、重型挂载 |
| **同轴多旋翼** | 4+对 | 上下同轴对桨，紧凑高效 | 工业级应用 |

## 优势与挑战

### ✅ 优势
- **垂直起降**：不需要跑道，起降灵活
- **悬停能力**：可定点悬停作业
- **结构简单**：无复杂机械传动
- **操控简便**：飞控系统成熟，易于自动化

### ❌ 挑战
- **续航有限**：电池能量密度限制，通常20-40分钟
- **载重受限**：有效载荷有限
- **抗风能力**：受风扰影响较大
- **噪声较大**：旋翼噪声明显
