## 项目介绍
pyDrone是基于MicroPython的开源无人机项目，适配01Studio ESP32-S3开发的四轴飞行器，旨在推广嵌入式Python编程。用户可通过MicroPython代码实现无人机的起飞、降落、悬停、移动、自转及多种姿态控制，支持无头飞行模式。

## 主要特性
- 硬件搭载ESP32-S3-WROOM-1芯片，集成WiFi/BLE、IMU、气压计、电子罗盘等传感器，配备4个716空心电机及多状态LED指示灯
- 提供简洁的Python API，可快速实现无人机核心飞行动作控制
- 包含示例代码、硬件设计资源（原理图、3D模型）、固件及配套Android应用
- 支持通过USB Type-C完成代码下载、调试及供电，提供官方Wiki教程与技术支持
