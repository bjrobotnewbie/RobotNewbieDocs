## 项目介绍
本项目为仅配备单个螺旋桨的欠驱动无人机，机身带有鳍状结构，可实现飞行功能。项目提供了该无人机的测试台、固件及3D模型文件，支持基于ArduPilot和moteus的飞行控制与电机控制。

## 主要特性
1. 核心结构：采用单螺旋桨设计，机身带鳍状结构，提供Fusion 360和STEP格式的3D模型文件（含机身、螺旋桨等部件）；
2. 固件支持：基于ArduPilot分支（飞行控制器）与moteus分支（电机控制器），可用于无人机的飞行与电机控制；
3. 配套测试：提供测试台相关资源，可开展单螺旋桨的旋转测试。
