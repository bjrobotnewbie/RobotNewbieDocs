# 倾转旋翼无人机（VTOL）

倾转旋翼无人机（Vertical Take-off and Landing, VTOL）结合了多旋翼垂直起降和固定翼高效巡航的优点，在不需要跑道的同时实现长航程高速飞行，是复合翼无人机的重要发展方向。

## 定义与特点

**VTOL无人机**：通过旋翼/机翼姿态切换，在垂直起降模式和水平巡航模式之间转换的复合型无人机。

**核心特点**：
- **垂直起降**：像多旋翼一样垂直起飞，不需要跑道
- **高效巡航**：平飞时切换为固定翼模式，气动效率高
- **任务灵活**：可在复杂地形起降，执行长距离任务
- **模式切换**：飞行中完成悬停到平飞的姿态转换

## 工作原理

**垂直起降模式**：
- 旋翼朝上，产生垂直升力
- 类似多旋翼控制姿态和位置
- 用于起飞、降落和定点悬停

**巡航模式**：
- 旋翼朝前，产生前向推力
- 机翼产生升力，类似固定翼飞行
- 气动效率高，续航时间长

**模式切换**：
- 旋翼从垂直方向倾转到水平方向
- 过渡阶段需要精确控制保证平稳
- 是VTOL技术的关键难点

## 分类体系

| 类型 | 结构特点 | 优势 | 应用 |
|------|---------|------|---------|
| **倾转旋翼** | 旋翼整体倾转 | 经典设计，效率高 | 长距离巡检 |
| **尾座式** | 整机竖立起降，平飞转换 | 结构简单，无多余部件 | 小型VTOL |
| **复合翼** | 固定翼+独立多旋翼 | 控制简单，可靠性高 | 测绘、巡检 |
| **四倾转旋翼** | 四个旋翼均可倾转 | 冗余度高，载重大 | 重载运输 |

---

## 优势与挑战

### ✅ 优势
- **起降灵活**：垂直起降，无需跑道
- **续航长**：巡航阶段固定翼模式效率高
- **航程远**：适合长距离任务
- **速度高**：巡航速度远超多旋翼

### ❌ 挑战
- **过渡控制复杂**：模式切换阶段气动特性复杂
- **机械结构复杂**：倾转机构增加复杂度和重量
- **成本较高**：比单一构型无人机成本高
- **载重受限**：相比纯固定翼载重有损失
