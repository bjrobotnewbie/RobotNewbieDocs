# 连续体机器人

连续体机器人（Continuum Robots）是一类模仿生物象鼻、蛇、章鱼触手的机器人，没有离散关节，通过整体连续弯曲实现运动，能够进入狭窄复杂空间，在医疗和特种探测领域有重要应用。

## 定义与特点

**连续体机器人**：机器人本身能够产生平滑连续的弯曲，没有传统意义上的离散关节，理论上具有无限自由度。

**与其他机器人的区别**：

| 机器人类型 | 关节特点 | 自由度 |
|-----------|---------|--------|
| 刚性机器人 | 离散关节 | 有限自由度（通常<10） |
| 软体机器人 | 全身可变形 | 无限自由度 |
| **连续体机器人** | 连续弯曲，支撑结构连续 | 超冗余自由度（通常>10） |

**主要特点**：
- 连续平滑弯曲
- 超冗余自由度
- 能绕开障碍物
- 可以进入狭窄管道
- 形状可控性优于纯软体机器人

## 分类体系

| 分类 | 驱动方式 | 特点 | 应用 |

| [腱驱动连续体](./tendon-driven/README) | 多根腱绳拉动 | 控制成熟，精度较好 | 工业检测、内窥镜 |

| [蛇形机器人](./snake-like/README) | 分段铰接连续弯曲 | 地面爬行 | 搜救、管道检测 |

## 优势与挑战

### ✅ 优势
- **避障能力强**：超冗余自由度可以绕过障碍物
- **狭窄空间进入**：能进入人体腔道、废墟缝隙
- **操作灵活**：末端姿态可以独立控制
- **安全性好**：柔顺性好，碰撞安全

### ❌ 挑战
- **建模复杂**：超冗余自由度运动学建模难
- **控制困难**：闭环控制精度难提高
- **负载能力低**：连续结构负载能力有限
- **重量分布**：驱动器放置影响平衡

## 核心应用场景

| 应用领域 | 具体应用 |
|---------|---------|
| **医疗微创手术** | 经口、经肛微创手术，减少创伤 |
| **航空发动机检测** | 进入叶片间隙检测损伤 |
| **灾难救援** | 废墟缝隙搜索幸存者 |
| **核工业维护** | 进入辐射环境管道维修 |
| **海底探测** | 水下船体缝隙检测 |
| **自然腔道手术** | NOTES手术（经自然腔道内镜手术） |

## 关键技术

1. **运动学建模**：常曲率模型是最常用的简化建模方法
2. **实时控制**：超冗余自由度的实时轨迹优化
3. **形状感知**：光纤传感、电磁跟踪等形状测量
4. **路径规划**：考虑连续体变形的运动规划

## 发展趋势

- **微型化**：直径越来越小，满足微创手术需求
- **增强感知**：集成更多传感器，实现形状闭环
- **AI增强**：学习型控制替代传统建模
- **人机协作**：安全柔顺操作人机协作
