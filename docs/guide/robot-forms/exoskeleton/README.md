# 外骨骼机器人

外骨骼机器人是一种可穿戴的机器人系统，通过机械结构与人体肢体耦合，为人提供力量增强、运动辅助或康复训练功能。外骨骼融合了机器人学、生物力学、传感技术和人机交互等多个领域，是具身智能的重要形态之一。

## 定义与特点

**外骨骼机器人**：穿戴在人体外部的机械结构，通过关节对齐、力传递等方式与人体运动协同，实现增强、辅助或康复功能。

**主要特点**：
- **穿戴式结构**：与人体肢体耦合，随人体运动
- **人机协同控制**：意图感知与力反馈，跟随而非主导人体运动
- **生物力学对齐**：关节轴心需与人体关节对齐，避免运动干涉
- **多模态传感**：肌电信号(EMG)、力矩传感、惯性测量单元等融合感知

## 分类体系

| 分类 | 驱动方式 | 特点 | 典型应用 |
|------|---------|------|---------|
| 电动驱动外骨骼 | 电机+减速器 | 精度高、控制灵活 | 康复训练、工业助力 |
| 液压驱动外骨骼 | 液压缸 | 功率密度大、输出力强 | 军事负重、重物搬运 |
| 气动驱动外骨骼 | 气动人工肌肉 | 柔顺性好、重量轻 | 上肢辅助、柔性穿戴 |
| 被动外骨骼 | 弹簧/弹性元件 | 无需外部能源、重量轻 | 工业减负、姿势支撑 |
| 仿生柔性外骨骼 | 软体驱动器+织物 | 轻便舒适、穿戴性好 | 日常辅助、步态训练 |

## 优势与挑战

### 优势
- **力量增强**：放大人体力量，减少搬运疲劳
- **康复训练**：精确控制训练强度和轨迹，辅助神经康复
- **运动保护**：减少关节负荷，预防职业病损伤
- **生活质量**：帮助行动障碍者恢复行走能力

### 挑战
- **人机物理耦合**：关节对齐误差导致交互力，长期穿戴不舒适
- **意图识别**：实时准确识别人体运动意图仍困难
- **重量与续航**：电池和驱动器重量限制长时间使用
- **个体差异**：不同体型和病症需要定制化适配

## 核心技术

- **意图感知**：表面肌电信号(sEMG)、脑电信号(EEG)、力/力矩传感、运动学估计
- **人机协同控制**：阻抗控制、导纳控制、自适应控制
- **生物力学建模**：人体肌肉骨骼模型、关节运动学/动力学
- **柔顺驱动**：串联弹性驱动器(SEA)、变刚度驱动

## 发展趋势

1. **柔性化**：从刚性结构向软体/织物外骨骼发展，提升穿戴舒适度
2. **智能化**：AI 驱动的意图识别和自适应控制
3. **轻量化**：新材料和新驱动方式降低重量
4. **个性化**：基于个体数据的定制化辅助策略
