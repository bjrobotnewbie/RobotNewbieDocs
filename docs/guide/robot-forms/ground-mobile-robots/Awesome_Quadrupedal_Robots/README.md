## 项目概述

## 项目介绍
这是一个四足机器人领域的精选资源汇总项目，收录了四足机器人相关的学习资料、硬件平台与学术论文，适合四足机器人开发、学习人员使用。项目内容按相关性分类，非仓库类资源按字母排序，欢迎提交issue或讨论修正内容。

## 主要特性
1.  **入门资源**：包含四足机器人基础教程、综述论文、MIT欠驱动机器人课程等入门学习材料
2.  **硬件平台**：收录了全球多款主流四足机器人产品，包括Boston Dynamics Spot、Unitree、CyberDog 2、ANYmal等商用及科研平台
3.  **学术资料**：分类整理了四足机器人相关研究论文，涵盖控制方法、强化学习(RL)等相关研究方向
4.  整体资源结构清晰，方便快速检索学习
