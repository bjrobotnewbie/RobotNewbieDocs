## 项目概述

## 项目介绍
GrowBot V0是一款从零开始学习的通用AI机器人项目，旨在打造最简单可行的实体AI机器人，让用户可以快速、低成本地拥有实体AI。项目最初设想通过进化算法和神经网络实现从零学习移动、操作等技能，后续拓展为结合现代AI大模型与运动神经系统的通用学习机器人，可从零开始学习移动、感知和反应。
本项目为研究用V0快照版本，仍存在硬件设计瑕疵，仅作为视频搭建参考，非新手分步指南。官方计划2026年秋季推出V1正式版，将包含分步搭建教程、定制PCB、校准数字孪生等内容。机器人基于树莓派Zero 2 W作为主控，无需外接电脑，搭载了伺服电机、摄像头、IMU、麦克风等外设。

## 主要特性
1.  **极简硬件设计**：砍掉冗余功能，实现低成本快速搭建，硬件包含树莓派主控、2个串行总线伺服腿部、多传感器及电源系统
2.  **通用学习能力**：支持从零开始学习移动、感知和反应，可结合大模型实现智能交互
3.  **开源资料完整**：提供物料清单、接线图、机械STL文件和MuJoCo仿真模型，附带基础配置校准软件
4.  **轻量化部署**：所有程序运行在树莓派本地，无需外接高性能计算机
