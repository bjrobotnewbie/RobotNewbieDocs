## 项目概述

## 项目介绍
MindPaw是一款基于ESP8266的桌面级四足机器狗开源项目，总物料成本仅约50元（基础版35元）。它集成了语音交互（HLK-V20/SU-03T）、手势识别（OV2640+轻量MLP）、豆包大模型AI对话、PAD情感计算、WiFi网页遥控功能，同时支持OLED表情显示与音效反馈，适合机器人入门、嵌入式AI、HRI情感交互研究。

## 主要特性
1.  多交互方式：支持语音控制、手势识别、网页点按遥控
2.  AI智能交互：接入豆包大模型，可实现智能对话并通过动作表情回复
3.  情感计算：可根据交互频率与内容自动切换开心、无聊等情绪状态
4.  全开源开放：提供代码、PCB电路图、3D打印STL文件，附带5分钟快速上手教程与烧录指南
5.  低成本入门：核心硬件均为常用廉价模块，无需高价开发板套件
