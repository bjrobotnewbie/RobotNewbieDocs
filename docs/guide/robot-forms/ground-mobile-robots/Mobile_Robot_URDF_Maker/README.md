# Mobile_Robot_URDF_Maker

这是一个可帮助你借助其向导在数分钟内轻松制作自定义移动机器人URDF文件的工作空间。快来试试吧！

## 项目概述

## 项目介绍
Mobile Robot URDF Maker是一款ROS 2桌面应用，可通过引导式PyQt5向导快速生成可直接用于仿真的移动机器人URDF文件，无需手动编写XML。用户可一站式完成底盘选择、运动学配置、传感器添加、控制器调参，并在Gazebo中实时遥控调试，最终输出标准`.urdf`和可编辑的`.urdf.xacro`文件，以及配套的控制器配置文件，可直接集成到机器人开发栈中。
该应用支持ROS 2 Humble（Ubuntu 22.04）和Jazzy（Ubuntu 24.04），会自动适配当前运行的ROS发行版，内置OpenGL实时3D预览窗口。

## 主要特性
1.  支持6种可选`ros2_control`控制器：差分、滑转差分、麦轮、三轮、转向三轮和阿克曼，仅会展示适配所选底盘的控制器
2.  动态多传感器系统：可添加任意数量的激光雷达和相机，支持全参数配置，自动生成Gazebo桥接配置
3.  控制器调参工具：可修改发布/更新频率、命令超时、速度/加速度/转向限制，支持基于物理的自动推荐值
4.  硬件接口选择：可直接选择Gazebo仿真、模拟硬件或自定义`ros2_control`插件
5.  内置遥控功能：可直接启动仿真，通过屏幕虚拟十字键或键盘遥控机器人
6.  支持预设与会话保存：可保存/加载底盘和传感器配置，或保存整个向导状态并恢复
7.  双格式输出：同时生成扁平化`.urdf`和可编辑的`.urdf.xacro`文件
