# OpenBot

OpenBot利用智能手机作为低成本机器人的大脑。我们设计了一辆成本约50美元的小型电动车，用作机器人机身。我们面向Android智能手机的软件栈支持人员跟随、实时自主导航等高级机器人任务。

## 项目概述

## 项目介绍
OpenBot是一款将智能手机作为机器人大脑的低成本机器人项目。其配套的小型电动机器人车身造价仅约50美元，搭配Android端软件栈，可以实现人员追踪、实时自主导航等高级机器人功能。

## 主要特性
1.  低成本方案：车身造价仅约50美元，以智能手机作为算力核心
2.  完整软件栈：提供Android端应用支持，可实现人员跟随、实时自主导航等高级机器人任务
3.  开放生态：提供完整的搭建、刷机、编程、训练流程，支持社区贡献与二次开发
4.  多语言支持：包含简体中文在内的多语言文档，适配全球开发者
