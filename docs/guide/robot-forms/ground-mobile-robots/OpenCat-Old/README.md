# OpenCat-Old

可编程且高度机动的人形机器人，专为 STEM 教育及增强人工智能服务设计。

## 项目链接

- GitHub: <https://github.com/PetoiCamp/OpenCat-Old>
- 项目主页: <https://www.petoi.com>

## 项目介绍
本项目是OpenCat旧版代码仓库，已过时，推荐访问适配Nybble和Bittle的新版OpenCat仓库，以及适配最新OpenCat机型的OpenCatESP32仓库。
OpenCat是可编程、高机动性的四足迷你机器人套件，主打物理AI教育与实体AI应用，可用于K12机器人课堂、高校研究实验室等场景，而非仅屏幕端编程练习。当前预告了新品Quaddle迷你四足机器人，将于2026年9月2日在Kickstarter上线。

## 主要特性
1.  仅需4个舵机即可实现四足运动，需设计独特的步态与腿部协调方案
2.  支持位置反馈舵机，可通过Puppet模式，无需代码即可手动录制动作
3.  提供可3D打印外壳与支架，支持自定义改装
4.  开放平台支持步态研究、强化学习(RL)、 sim2real等物理AI研究，提供在线模拟器提前体验
5.  源码将在Quaddle交付前开源，代码结构基于OpenCatESP32。
