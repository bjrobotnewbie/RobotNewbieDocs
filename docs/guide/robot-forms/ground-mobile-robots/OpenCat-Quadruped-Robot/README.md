# OpenCat-Quadruped-Robot

一个用于开发波士顿动力风格四足机器人的开源四足机器宠物框架，非常适合用于STEM、编程与机器人教育、IoT机器人应用、AI增强机器人应用服务、研究以及DIY机器人套件开发。

## 项目概述

## 项目介绍
OpenCat是由Petoi开发的开源 quadruped机器人框架，基于Arduino和Raspberry Pi打造，可用于开发类似Boston Dynamics的四足机器人，适配Bittle机器狗和Nybble机器猫两大硬件平台。项目始于2016年，初衷是让敏捷四足机器人变得平价且易于改造，目前已在全球K12学校、高校实验室、创客空间及个人项目中广泛应用。当前在售硬件为Bittle X和Nybble Q，旧版硬件仍获代码库支持。

## 主要特性
1.  支持多语言开发：C/C++、Python以及图形化积木编程
2.  开源软硬件，无厂商锁定，可自由修改扩展
3.  原生适配Arduino和Raspberry Pi生态，兼容常用开发工具
4.  内置步态协调、舵机控制、IMU集成等底层功能，支持摄像头、触摸传感器、超声波等外设接入
5.  支持Sim-to-Real，可以在实体机器人上测试强化学习模型
6.  兼容ROS，可对接社区提供的SLAM、导航及感知流水线
7.  适配从入门编程教学到高端AI研究的全场景使用需求
