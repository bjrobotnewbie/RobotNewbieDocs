# OpenMower

让我们将廉价的现成商用割草机器人升级为基于现代智能RTK GPS的草坪割草机器人！

## 项目链接

- GitHub: <https://github.com/ClemensElflein/OpenMower>

## 项目概述

## 项目介绍
OpenMower是一款开源DIY智能割草机器人项目，旨在将廉价的量产普通割草机器人升级为基于RTK GPS的现代化智能割草设备。项目通过替换原厂主控硬件和开源软件，将随机路径行走的传统割草机改造为支持GPS导航、地图感知、APP控制的智能设备。

## 主要特性
1.  **自主割草**：自动完成草坪修剪任务
2.  **安全可靠**：被抬起或碰撞时紧急停机
3.  **无需边界线**：支持多区域灵活规划割草范围
4.  **低成本**：售价低于中端量产割草机
5.  **全开源**：开放软硬件设计与知识共享
6.  **避障功能**：自动检测并规避障碍物
7.  **雨天检测**：恶劣天气下自动暂停作业
8.  支持手机APP远程控制与管理
