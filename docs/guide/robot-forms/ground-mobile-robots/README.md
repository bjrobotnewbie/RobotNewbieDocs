# 地面移动机器人

地面移动机器人是面向陆地环境中移动能力的机器人形态，核心能力是通过轮式、足式、履带式等结构在二维平面上自主移动。

## 分类体系

| 分类 | 说明 | 典型应用 |
|------|------|---------|
| [轮式机器人](./wheeled-robots/README) | 车轮驱动的移动机器人 | AGV/AMR物流、巡检、服务机器人 |
| [足式机器人](./legged-robots/README) | 腿部行走的移动机器人 | 复杂地形巡检、特种作业、家庭服务 |
| [履带机器人](./tracked-robots/README) | 履带驱动的移动机器人 | 越野、救援、军事、农业 |
| [轮腿混合机器人](./wheel-leg-hybrid/README) | 轮式和腿式复合结构 | 多地形适应、高性能移动 |

## 归类说明

- 纯四足机器人（如 Boston Dynamics Spot）归入此类，因为核心是地面移动能力
- 如果带机械臂的移动平台，同时具备操作能力，应归入"移动操作机器人"
- 原"蛇形机器人"如果重点是地面蜿蜒爬行，可归入此类或"特殊移动机器人"
