## 项目概述

## 项目介绍
Venom是一款12自由度的展开式四足机器人，搭载12个伺服执行器和板载ARM处理器，由VJTI机器人与自动化协会的腿部移动性研究项目开发。
该机器人采用展开式运动步态，已实现并测试了蠕动步态和小跑步态，目标是实现超越轮式、履带式车辆的全地形自主移动能力，可在人员或动物步行可达的区域自主行进，自带动力与有效载荷，仅需少量人工引导即可通过复杂地形。

## 主要特性
1.  硬件：12-DOF展开式四足结构，板载ARM计算单元，适配伺服舵机与多类传感器
2.  步态：支持蠕动、小跑等多种预设步态，还可通过动态步态实现地形自适应稳定行走
3.  软件：包含完整的运动控制模块，实现逆运动学计算、传感器融合、轨迹生成以及步态状态机控制
4.  适配场景：复杂非铺装全地形自主导航，可替代轮式/履带设备完成极限地形作业
