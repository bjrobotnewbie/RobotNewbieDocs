## 项目介绍
XLeRobot是一款售价仅660美元起的双足移动家用机器人，总组装时长不到4小时，旨在让大众都能接触具身AI。该项目基于LeRobot、SO-100/SO-101、LeKiwi、Bambot等开源项目开发，提供在线文档支持，还支持通过浏览器使用Mujoco和3DGS进行仿真体验，近期还发布了双轮版本，搭载差分底盘，可选 scooter 无刷电机。

## 主要特性
1.  **低成本高性价比**：售价低于iPhone，组装快捷
2.  **开源生态**：基于多个知名开源机器人项目构建，社区支持完善
3.  **多形态可选**：提供基础版本与双轮差分底盘版本，可选无刷电机升级
4.  **支持在线仿真**：可直接在浏览器中通过Mujoco和3DGS操控机器人
5.  主打家用场景，可落地实现日常家居的具身AI应用
