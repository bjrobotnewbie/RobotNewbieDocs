## 项目介绍
Jumper是一款拥有22个自由度的螃蟹机器人，本项目为其配套的AI工具包，支持外观设计、动作训练与场景创建，可通过自然语言指令完成相关创作，还可参与官方螃蟹机器人挑战活动获取免费机器人。

## 主要特性
1. 外观设计：通过自然语言指令设计机器人外观，生成`.skin`格式的外观文件，支持多种风格外观定制；
2. 动作训练：训练稳定的三脚架步态等各类动作，生成`.app`格式的动作文件，支持行走、跳跃、舞蹈、抓取等多种动作；
3. 场景创建：通过自然语言指令创建场景，生成`.map`格式的场景文件，支持公园泵道、卧室、足球场等多种场景定制。
