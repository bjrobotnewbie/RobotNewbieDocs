# Awesome_Quadrupedal_Robots

- 项目链接：https://github.com/curieuxjy/Awesome_Quadrupedal_Robots

## 项目概述

这是一个关于四足机器人的精选资源列表，收集了四足机器人领域相关的平台、软件框架、仿真环境、定位建图、路径规划、控制、运动学习、硬件设计等各类资源。

内容分类：
- **平台**：包含了从 Boston Dynamics Spot、ANYmal、Cheetah 到 CyberDog 2 等国内外众多四足机器人平台
- **软件框架**：各种开源控制框架
- **仿真环境**：可用的仿真工具
- **定位建图**：SLAM 相关资源
- **路径规划**：导航规划资源
- **控制**：各种控制方法
- **运动学习**：基于学习的运动方法
- **硬件设计**：硬件相关资源

这是一个持续更新的资源列表，为四足机器人研究提供了很好的起点。
