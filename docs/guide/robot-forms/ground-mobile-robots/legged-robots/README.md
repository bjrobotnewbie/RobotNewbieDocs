# 足式机器人

足式机器人通过腿部结构实现行走，具备优秀的地形适应能力，可跨越障碍物、上下楼梯，是复杂地形下最具优势的移动机器人形态。

## 定义与特点

**足式机器人**：模仿生物腿部运动方式，通过腿与地面的离散接触实现移动的机器人。

**主要特点**：
- 优秀的地形适应能力，可跨越障碍和台阶
- 只需离散落脚点，对地面要求低
- 可上下楼梯、穿越废墟等复杂地形
- 运动控制复杂，需动态平衡

## 分类体系

| 类型 | 腿数 | 特点 | 典型应用 |
|------|------|------|---------|
| **双足机器人** | 2 | 类人结构，人形机器人基础 | 服务、科研、人形机器人 |
| **四足机器人** | 4 | 稳定性好，负载能力强 | 巡检、特种作业 |
| **六足机器人** | 6 | 静态稳定，冗余度高 | 探测、仿生研究 |
| **八足机器人** | 8 | 仿生蜘蛛，超高稳定性 | 极端地形探测 |

## 子类

- **双足机器人**：类人双腿结构，人形机器人的移动基础，研究热点但控制难度最大
- **四足机器人**：四条腿，稳定性好，如 Boston Dynamics Spot，目前最成熟的足式机器人
- **多足机器人**：六足、八足等，仿生昆虫或蜘蛛，静态稳定性好

---

## 优势与挑战

### ✅ 优势
- **地形适应性强**：可跨越台阶、沟壑、碎石等复杂地形
- **离散落脚**：只需少量落脚点即可通行
- **高度灵活**：可调整身体姿态适应地形
- **仿生性强**：借鉴生物运动机理

### ❌ 挑战
- **控制复杂**：动态平衡和步态规划难度大
- **能耗高**：需要持续主动控制平衡，能耗远高于轮式
- **负载有限**：自重和驱动限制了有效载荷
- **可靠性**：关节驱动器故障率较高
