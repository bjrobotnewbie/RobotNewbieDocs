## 项目概述

Quad-SDK是卡内基梅隆大学Robomechanics Lab开发的**基于ROS的敏捷四足机器人运动全栈软件框架**。主要特点：

1. **垂直整合**：完整整合了规划、控制、估计、通信和开发工具，支持在仿真和硬件上实现敏捷四足运动，多平台 minimal 用户修改
2. **模块化架构**：研究者可以在复用现有框架基础上实验自己的组件实现
3. ** Gazebo仿真支持**：提供Gazebo仿真支持，方便开发测试
4. **可视化和数据处理**：提供一套可视化和数据处理工具，加速开发
5. **持续更新**：最新更新加入了EKF进行可靠机载状态估计，以及专门针对穿越障碍物设计的控制器

该框架为四足机器人敏捷运动研究提供了完整的软件基础，方便研究者开展工作。
