Microban 是一款经济实惠、完全可 3D 打印且 100% 开源的人形机器人。它由 Raspberry Pi Zero 2W 和 19 个 Dynamixel 伺服电机驱动，作为一个易于使用的 DIY 平台，用于学习、实验和机器人研究。

## 项目链接

- GitHub: <https://github.com/Rhoban/microban>

## 项目介绍
Microban是一款全3D打印、100%开源的小型人形机器人，身高约30cm，由Raspberry Pi Zero 2W和19台Dynamixel XL330-M288-T伺服电机驱动，总成本约550-600美元，面向创客、学生和机器人爱好者打造。它是一款低成本DIY机器人平台，可用于机器人学领域的学习、实验与研究，所有机械结构、3D模型和文档均开源，用户可通过标准桌面3D打印机和基础工具自行组装。

## 主要特性
1.  **100%开源设计**：机械结构、3D模型与文档均可免费使用和修改
2.  **创客友好**：提供详细组装指南，零件均可3D打印或轻松采购
3.  **紧凑便携**：尺寸小巧，支持USB-C充电，可作为桌面机器人实验平台
