# microduck

一个微型双足鸭机器人 🦆

## 项目链接

- GitHub: <https://github.com/pollen-robotics/microduck>
- 项目主页: <https://pollen-robotics.com/microduck>

## 项目介绍
Microduck是一款身长约25cm、重800g的小型双足机器人，也被称为"鸭子大脑"，搭载Rockchip RK3566主控。它通过神经策略实现50Hz控制环路驱动15个舵机，搭配无线通信与摄像头模块，同时支持安全的在线更新功能。
该机器人的强化学习策略在`microduck_rl`仓库中训练，基于MuJoCo与PPO算法，通过sim2real流程导出为ONNX模型后加载运行。用户可购买成品机器人，本仓库提供完整的运行部署方案。

## 主要特性
1.  **核心功能**：支持双足行走、加装滚轮后滚动、抓取物品、自主起身，还可完成坐下、踢球、发声等动作
2.  **配套资源**：提供快速上手手册、游戏手柄配对与按键映射说明，支持机器人配置、日志查看、固件更新等操作
3.  **技术栈**：基于ROS生态，使用强化学习(RL)训练控制策略，通过sim2real实现仿真到实物的迁移部署
