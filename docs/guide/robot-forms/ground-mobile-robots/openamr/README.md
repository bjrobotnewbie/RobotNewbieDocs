# openamr

面向中小企业的平价移动机器人：一个为内部物流自动化打造高性价比AMR的DIY项目。本指南涵盖机电一体化、嵌入式软件、基于ROS的软件（Linorobot）、用户界面，以及与用于车队管理的OpenRMF集成。适用于提升运营效率并促进后续开发。

## 项目概述

## 项目介绍
OpenAMRobot是一款开源实体AI开发平台，面向初创企业、科研机构、高校和领域专家，无需从零搭建完整机器人栈即可构建、训练、验证和部署机器人解决方案，旨在让领域专家将自身专业知识转化为机器人能力。该项目原为面向中小企业的低成本自主移动机器人(AMR)DIY项目，后演进为模块化开源生态，覆盖仓储物流自动化等场景，可帮助用户提升运营效率并支持二次开发。原仓库已拆分迁移，最新项目分为硬件、软件、固件三个独立仓库。

## 主要特性
1.  **完整技术栈覆盖**：提供包含机械设计、嵌入式固件、ROS 2软件的全套开发基础设施，支持SLAM、自主导航、自动对接等AMR核心功能
2.  **低门槛开发**：无需资深机器人工程师，领域专家即可快速搭建自动化解决方案
3.  **模块化架构**：拆分为独立的硬件、软件、固件仓库，便于二次开发和集成
4.  **配套工具支持**：内置Gazebo仿真环境、Docker部署方案、可视化UI以及车队管理集成能力
