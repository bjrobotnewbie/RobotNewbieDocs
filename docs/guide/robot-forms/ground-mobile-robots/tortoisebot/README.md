# tortoisebot

TortoiseBot 是一款对学习者极其友好、性价比出色的基于ROS的开源移动机器人，支持遥操作、手动建图、自主建图、导航、仿真等功能。

## 项目链接

- GitHub: <https://github.com/rigbetellabs/tortoisebot>

## 项目概述

## 项目介绍
TortoiseBot是一款基于ROS 2 Humble开发的开源移动机器人，主打低学习成本与高性价比，支持远程遥控、手动/自主建图、导航以及仿真等功能，适配ROS 2生态，面向机器人学习爱好者与开发者。

## 主要特性
1.  支持仿真与实体机器人两种部署模式，仿真后端采用Ignition Fortress
2.  完整覆盖遥控操作、自主SLAM建图、导航功能
3.  配套完善的安装、配置与使用教程，降低开发学习门槛
4.  兼容ROS 2 Humble生态，可直接使用官方ROS机器人开发工具链
