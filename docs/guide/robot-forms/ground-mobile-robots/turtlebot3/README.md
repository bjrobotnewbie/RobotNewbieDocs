## 项目概述

## 项目介绍
本项目是TurtleBot3的ROS功能包集合，支持ROS Humble、Jazzy以及Rolling版本，同时保留了适配Noetic等旧版ROS的分支。TurtleBot3是一款开源的小型移动机器人平台，本仓库是其官方开源生态的核心组成部分，配套了完整的官方文档、学习资源与社区支持渠道。

## 主要特性
1.  **完整生态覆盖**：提供了从基础驱动、仿真、应用到机器学习（包含RL相关项目）的全栈ROS工具包，涵盖基础移动、机械臂操作、自动驾驶、家居服务等多个场景
2.  **多ROS版本兼容**：支持最新的ROS发行版以及旧版长期支持分支
3.  **配套资源齐全**：提供官方电子手册、教学视频以及官方社区论坛支持，方便开发者快速上手开发与调试。
