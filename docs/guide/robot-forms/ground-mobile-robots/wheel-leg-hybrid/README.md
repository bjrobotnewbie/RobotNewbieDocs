# 轮腿混合机器人

轮腿混合机器人结合了轮式和腿式两种移动方式的优点，可在不同地形切换运动模式，兼顾平地高速移动和复杂地形通过能力，是地面移动机器人的重要发展方向。

## 定义与特点

**轮腿混合机器人**：在腿部结构末端安装轮子，通过轮式和腿式两种模式的切换，实现多地形自适应移动的机器人。

**核心特点**：
- **平地高速移动**：使用轮式模式，效率高、速度快
- **复杂地形通过**：切换腿式模式，跨越障碍
- **动态稳定性**：可实时调整姿态，适应地形变化
- **多模式切换**：根据地形自主选择最优运动模式

## 工作原理

**轮式模式**：
- 腿部收起，轮子接触地面
- 类似轮式机器人驱动行走
- 速度高、能耗低，适合平地

**腿式模式**：
- 腿部伸展，轮子离地
- 通过腿的摆动实现跨越
- 适合台阶、碎石等复杂地形

**混合模式**：
- 轮和腿同时工作
- 腿部主动调节车身姿态
- 轮子提供前进动力
- 可实现高速越障和姿态平衡

## 分类体系

| 类型 | 结构特点 | 优势 | 应用 |
|------|---------|------|---------|
| **轮在腿端** | 轮子安装在腿末端 | 集成度高，模式切换灵活 | 通用多地形平台 |
| **独立轮+独立腿** | 轮和腿分离安装 | 各自独立优化 | 重载多地形 |
| **可伸缩轮腿** | 腿长可调的轮式 | 结构紧凑 | 室内外巡检 |
| **飞行+轮腿** | 增加飞行能力 | 三模移动 | 极端环境探测 |

## 优势与挑战

### ✅ 优势
- **多地形适应**：兼顾平地效率和越野能力
- **高速移动**：平地轮式模式速度快
- **越障能力强**：腿式模式可跨越台阶和障碍
- **姿态调节**：可主动调节车身高度和倾角
- **效率最优**：根据地形选择最高效模式

### ❌ 挑战
- **机械复杂**：同时具备轮和腿，结构复杂
- **控制难度大**：模式切换和混合控制复杂
- **重量增加**：两套机构增加自重
- **成本较高**：设计和制造成本高于单一构型
