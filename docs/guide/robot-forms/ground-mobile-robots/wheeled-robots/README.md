# 轮式机器人

轮式机器人是通过车轮驱动实现移动的机器人形态，是最常见、最高效的地面移动方式。凭借结构简单、控制成熟、能耗低的优势，轮式机器人广泛应用于物流、巡检、服务等领域。

## 定义与特点

**轮式机器人**：依靠车轮与地面之间的摩擦力实现移动的机器人，通过控制各轮转速和转向实现不同运动轨迹。

**主要特点**：
- 结构简单，制造成本低
- 能耗低，续航时间长
- 控制模型成熟，运动学建模清晰
- 平地移动效率高，速度快
- 对地面平整度有一定要求

## 分类体系

| 分类 | 轮组配置 | 特点 | 应用 |
|------|---------|------|---------|
| **差分驱动** | 两轮差分驱动 | 结构最简单，可原地转向 | 教育、小型服务机器人 |
| **四轮驱动** | 四轮独立驱动 | 稳定性好，抓地力强 | AGV、户外巡检 |
| **全向移动** | 麦克纳姆轮/全向轮 | 可任意方向平移，灵活 | 精密对接、狭小空间 |
| **阿克曼转向** | 前轮转向+后轮驱动 | 类汽车运动，高速稳定 | 自动驾驶车辆 |
| **舵轮驱动** | 单舵轮+辅助轮 | 结构紧凑，转向灵活 | AGV叉车 |

## 子类

- **AGV/AMR移动平台**：自动导引车（AGV）按固定路线运行；自主移动机器人（AMR）具备自主导航能力，用于物流搬运
- **差分驱动轮式**：两轮差分驱动，最常见的移动方案
- **全向移动轮式**：麦克纳姆轮、全向轮，可实现任意方向移动

---

## 优势与挑战

### ✅ 优势
- **效率高**：平地移动能量效率最高
- **负载大**：可承载较重载荷
- **控制简单**：运动学模型成熟，易于实现
- **成本低**：机械结构简单，易于批量制造

### ❌ 挑战
- **地形受限**：无法跨越较高台阶和复杂地形
- **越障能力弱**：对楼梯、沟壑通过性差
- **转向空间**：部分构型需要一定转向半径

| **服务配送** | 餐厅送餐、酒店配送、医院物流 |
| **自动驾驶** | 园区接驳、港口运输 |
