## 项目概述

## 项目介绍
该项目是由具身智能研究室出品的人形机器人运动智能知识库，围绕人形机器人运动智能完整研发链组织内容，涵盖论文解读、开源项目、产业动态与求职招聘信息，帮助开发者将零散的技术资料、岗位需求整合为完整的知识体系，适配入门学习、算法开发、论文选题、系统架构规划、求职备考等多种场景。

## 主要特性
1.  **多场景适配**：支持入门学习路线规划、运动控制算法优化、论文选题指导、系统架构梳理、求职面试评估等全流程需求
2.  **结构化内容**：按技术路线分为动作数据与重定向等六大核心方向，配套论文总索引、开源项目主表、产业动态与求职专区
3.  **Agent辅助工具**：提供定制化交互指令，可根据用户背景生成学习计划、算法改进方案、简历岗位匹配分析等深度内容
4.  **完整资源入口**：包含技术路线总览、论文解读、开源项目、企业招聘等一站式跳转链接，支持本地克隆完整检索
