# 操作机器人

操作机器人是面向固定基座或半固定基座操作任务的机器人形态，核心能力是通过机械臂或末端执行器完成搬运、装配、焊接、分拣、抓取等任务。

## 分类体系

| 分类 | 说明 | 典型应用 |
|------|------|---------|
| [串联机械臂](./serial-manipulators/README) | 多关节串联结构 | 焊接、装配、搬运 |
| [协作机器人](./collaborative-robots/README) | 面向人机协作的安全机械臂 | 人机混合工作单元 |
| [SCARA机器人](./scara-robots/README) | 平面关节型机器人 | 电子装配、包装 |
| [并联机器人](./parallel-robots/README) | 闭环并联结构 | 高速抓取、分拣 |

## 归类说明

原“刚性机器人”下的机械臂类项目归入本分类。刚性是结构属性，不再作为一级形态分类。
