## 项目介绍
SO-ARM-102是Robonine推出的开源主从协作机械臂套件，为SO-ARM 101的升级款，支持遥操作与模仿学习场景，兼容Hugging Face LeRobot数据集与策略。

## 主要特性
1. 5自由度+平行夹爪，夹爪行程85mm，主从协作模式下可实现手动引导主臂、从臂复现动作；
2. 采用PET-CF材质框架，拓扑优化连杆结构，相比前代刚度提升、噪音降低，基座旋转范围达352°，水平行程483mm；
3. 搭载STS3250舵机，肩肘转速75RPM，300g负载下夹爪端挠度仅3.4-3.9mm；
4. 提供STEP/STL格式文件、物料清单（BOM）、打印及组装指南，DIY成本约404美元（不含打印材料）或444美元（含打印材料），硬件遵循CERN-OHL-P-2.0协议，软件遵循Apache-2.0协议。
