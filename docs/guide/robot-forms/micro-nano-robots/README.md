# 微纳米机器人

微纳米机器人是尺度在微米到纳米级别的单个机器人本体，其形态、驱动方式与宏观机器人完全不同，主要依靠外部场（磁场、声场、光场、电场）或化学反应驱动，在生物医学、微操作等领域有广泛应用前景。

本分类按"尺度 + 驱动方式"组织，区别于 [微纳米群体机器人](/guide/multi-robot-systems/micro-nano-swarm/README) 关注的群体协同行为。

## 尺度范围

- **微米级**：1-1000 微米
- **纳米级**：1-1000 纳米
- **分子机器人**：分子尺度

## 分类体系

| 分类 | 驱动方式 | 特点 | 典型对象 |
|------|---------|------|---------|
| 磁场驱动微纳米机器人 | 外部磁场控制磁性结构 | 容易控制，穿透生物组织 | 磁控圆盘、磁泳微机器人 |
| 生物杂化微纳米机器人 | 细菌/精子等生物体驱动 | 生物相容，能量自给 | 细菌驱动微机器人、精子驱动载体 |
| 化学驱动微纳米机器人 | 化学反应产生梯度推进 | 自主驱动，无需外部场 | 微纳米马达、自驱动粒子 |
| 声/光/电场驱动微纳米机器人 | 声场、光热、电场驱动 | 远程精准，可控开关 | 超声微泡、光驱微机器人、电泳粒子 |

## 与其他分类的边界

| 分类 | 职责 | 内容范围 |
|-----|------|---------|
| **微纳米机器人（本分类）** | 形态描述 | 单个微纳本体的结构、尺度、驱动方式 |
| [微纳米群体机器人](/guide/multi-robot-systems/micro-nano-swarm/README) | 协同描述 | 大量微纳个体的群体协同策略 |

两者通过双向引用关联：单个微纳机器人形态归入本分类；多个微纳机器人协同归入群体分类。

## 代表性研究

- **磁控涡流微型群体** - MIT 利用微米级磁控圆盘在旋转磁场中产生流体涡流，实现非接触式物体操控
- **细菌驱动微机器人** - 利用大肠杆菌等附着于微颗粒表面实现自主推进
- **纳米马达** - 过氧化氢分解驱动的微纳米管马达

## 关键技术挑战

1. **低雷诺数运动**：微尺度下粘性力主导，惯性可忽略
2. **能量供给**：无线供能与自驱动机制
3. **精确控制**：单个微纳个体的位姿控制
4. **生物相容性**：医用场景需可降解、无毒
5. **规模化制备**：低成本批量制造
