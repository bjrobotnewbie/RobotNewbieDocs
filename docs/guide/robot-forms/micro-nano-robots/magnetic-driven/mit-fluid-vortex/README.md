# MIT 磁控涡流微纳米机器人

MIT 开发的微米级磁控圆盘，在旋转磁场中运动，通过拖拽周围流体产生微型涡流，实现非接触式物体操控。

## 关键特性

- **尺度**：微米级
- **驱动方式**：外部旋转磁场控制磁性圆盘
- **工作原理**：磁驱运动 + 流体涡流效应
- **自供电变体**：依靠微小气泡破裂产生能量驱动，无需电池

## 技术原理

- 数百个磁控圆盘在旋转磁场中同步运动
- 每个圆盘拖拽周围流体产生微型涡流
- 涡流相互作用实现群体协同操控
- 可驱动微型齿轮、旋转大质量物体

## 典型应用

- 微流控芯片
- 微米级物体操控
- 微纳组装
- 生物颗粒分选
