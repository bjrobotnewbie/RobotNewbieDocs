## 项目概述

## 项目介绍
LeKiwi是一款低成本全向移动机械臂开源项目，由伊利诺伊大学等团队联合开发。项目提供完整的搭建教程、硬件设计方案与软件支持，可用于机器人教学、科研原型开发等场景。用户可选择5V简易版、12V重载版或有线版三种配置，计算单元采用树莓派5，可将数据流传输至笔记本电脑。

## 主要特性
1.  **硬件设计**：采用标准化堆叠底板，支持全向Kiwi三轮驱动，搭载SO-ARM101机械臂，配备工作台与腕部RGB摄像头，提供两种供电方案可选。
2.  **软件能力**：支持手柄/WASD或主控臂遥操作，内置数据采集流水线，可实时传输关节角度与摄像头画面。
3.  **配套资源**：提供Fusion 360 CAD源文件与导出的URDF仿真模型，另有基于Dynamixel电机的改版型号可选，附带完整的物料清单、3D打印与组装教程。
