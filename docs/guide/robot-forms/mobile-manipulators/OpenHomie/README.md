# OpenHomie

开源代码："HOMIE：异构外骨骼驾驶舱的人形机器人灵巧操作

## 项目链接

- GitHub: <https://github.com/InternRobotics/OpenHomie>

## 项目介绍
本项目是论文《HOMIE: Humanoid Loco-Manipulation with Isomorphic Exoskeleton Cockpit》的官方开源实现，是一套人形机器人移动操作遥操作系统，包含同构外骨骼驾驶硬件系统和对应的人形移动操作策略。项目由上海人工智能实验室与香港中文大学联合开发，支持通过外骨骼设备远程控制人形机器人完成移动与操作任务，附带论文、演示视频与完整开源资源。

## 主要特性
1.  基于RL强化学习的人形机器人移动操作策略，实现同构外骨骼遥操作
2.  完整的硬件系统与软件实现方案
3.  提供官方演示视频与项目主页
4.  附带最新模型使用建议与版本说明
5.  支持学术研究与二次开发，已开源全部相关资源
