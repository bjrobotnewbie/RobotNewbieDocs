## 项目概述

## 项目介绍
Party OS 是RoboParty_Lab打造的人形机器人全栈系统，覆盖从底层工具到上层交互能力的完整技术栈。其核心链路串联数据采集与生成、动作重定向、模仿学习与无监督学习，后续将逐步扩展人-物交互（HOI）、人-系统交互（HSI）、VLA以及自主智能人形机器人（Agentic Humanoid）方向。

## 主要特性
1.  **分层技术架构**：按Know-how文档、底层运控Infra、全身操作Infra分层构建能力
2.  **已开源子模块**：
    -  动作重定向工具`hhtools`：实现人体/机器人动作到任意人形机器人的快速迁移
    -  运动模仿框架`MimicLite`：支持运动数据加载、跟踪、训练、评估与部署全流程
    -  无监督学习框架`UFO`
    -  基于动作意图编码的JEPA世界模型`INTACT-JEPA`
3.  配套技术知识库：汇总人形机器人运动控制等领域的技术经验文档
4.  采用GPL-3.0开源许可证，各子项目保留独立许可协议。
