# 移动操作机器人

移动操作机器人是同时具备移动能力和操作能力的复合机器人形态，通常由移动底盘、腿式结构或人形躯体与机械臂、机械手等操作结构组成。

## 分类体系

| 分类 | 说明 | 典型代表 |
|------|------|---------|
| **人形机器人** | 双足移动 + 双臂操作 + 躯干结构 | 开源人形机器人、通用人形平台 |
| 轮式移动操作机器人 | 轮式底盘 + 机械臂 | 仓储搬运、服务机器人 |
| 足式移动操作机器人 | 足式平台 + 机械臂 | 四足挂载机械臂、野外作业 |

## 人形机器人说明

人形机器人是移动操作机器人的典型形态，通常具备双足移动、双臂操作、躯干结构以及面向人类环境的交互能力。

## 归类说明

人形机器人不只是足式机器人，因为它同时具备移动、操作、人机交互和整体人形构型。本分类用于承载这类复合形态。
