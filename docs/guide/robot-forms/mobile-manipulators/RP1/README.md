RP1: 一个开源全栈平台，用于代理型人形机器人

## 项目链接

- GitHub: <https://github.com/Roboparty/RP1>
- 项目主页: <https://roboparty.com/products/RP1>

## 项目介绍
RP1是RoboParty推出的全开源人形机器人全栈平台，整合了机械设计、电子系统、固件、控制与学习等全链路开发资源，为开发者提供可理解、可扩展的人形机器人开发基础，支持从子系统探索到完整机器人复刻的各类开发需求。

## 主要特性
1. 硬件层面：提供可查看的机械CAD、原理图、PCB布局、Gerber文件、BOM及装配文档；
2. 软件层面：包含Linux BSP、通信模块、设备接口、机器人描述及部署模块，支持二次开发；
3. 智能层面：提供运动训练、动作模仿、追踪及行为模型相关项目，支持探索机器人智能逻辑；
4. 整体架构为一体化开发栈，控制架构包含感知、运动控制、实时执行及高频反馈回路，支持人形机器人的运动控制与行为实现。
