## 项目概述

## 项目介绍
本项目是开源低成本仿人机器人工作空间，目标打造可复刻的实用型仿人机器人，硬件成本控制在5000美元以内。项目覆盖从机械控制协同设计、硬件搭建、机器人模型、运行部署到仿真参数辨识的全流程，所有子仓库均为独立Git仓库。

## 主要特性
1.  **轻量化设计**：优先减重与可维护性，多数定制机械零件支持3D打印并附带文档
2.  **全栈开源**：提供从CAD设计到实际部署、数据采集的完整可复现研究级堆栈
3.  拆分多个独立子仓库，分别负责机械控制设计、硬件搭建文档、机器人模型资产、实机/仿真运行、仿真参数辨识等功能，支持模块化使用。
