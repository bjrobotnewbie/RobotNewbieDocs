# 萝博头_原型机——全开源手搓级人形机器人

- 项目链接：https://github.com/Roboparty/roboto_origin

## 项目概述

Roboto_origin 是上海 Roboparty 公司推出的全开源 DIY 人形机器人原型机。整个研发过程，包括所有结构、电子、训练和部署，都完全开源。

项目由 Roboparty 团队在 2025 年 2 月成立，从 4 月开始开发人形机器人，仅用四个月就完成了原型 ROBOTO_ORIGIN。该机器人完全可以通过淘宝采购和嘉立创原型制造完成组装，可以真正通过 DIY 独立组装。配合开源的训练和部署代码，可以轻松实现行走和跳跃功能。

主要特点：
- 完全开源，包括硬件结构、电子设计、软件代码
- 支持 ROS 2 Humble，基于 Isaac Sim/Isaac Lab 仿真
- 使用 Python 3.10 和 C++ 17 开发
- 支持强化学习训练（基于 rsl_rl）
- GPL v3 许可证

这是一个完全开放的 DIY 人形机器人项目，爱好者可以自行组装开发。
