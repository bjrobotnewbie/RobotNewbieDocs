# 可重构机器人

可重构机器人是以模块重组、自动连接断开和整体构型改变为核心特征的机器人形态。它强调结构可变性和任务适应性，而不是固定的运动方式。

## 分类体系

| 分类 | 连接方式 | 特点 | 典型应用 |
|------|---------|------|---------|
| [格子型模块化机器人](./lattice-modular/README) | 三维网格排列 | 体积变化、三维重构 | 自组装机器人 |
| [链型模块化机器人](./chain-modular/README) | 模块串联成链状 | 类似蛇形、树形构型 | 移动机器人、操作臂 |
| [移动模块化机器人](./mobile-modular/README) | 多个独立移动模块对接 | 自主编队重构 | 多机器人协作 |
| [自重构模块化机器人](./self-reconfigurable/README) | 模块自动连接断开 | 完全自主变形 | 太空探索、未知环境 |

## 归类说明

原“模块化机器人”归入本分类。“模块化”不是运动方式，但它是清晰的结构类型，因此使用“可重构机器人”作为一级形态名称更准确。
