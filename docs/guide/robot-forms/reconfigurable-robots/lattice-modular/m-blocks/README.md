# M-Blocks 自组装方块机器人

M-Blocks 是 MIT CSAIL Daniela Rus 教授团队开发的格子型模块化自组装机器人，每个立方体模块内置高速飞轮和磁铁，通过跳跃翻滚相互吸附，自动变幻成各种形状。

## 关键特性

- **模块结构**：立方体微型模块，每个方块带高速飞轮+磁铁
- **运动方式**：利用角动量守恒，飞轮刹车产生惯性跳跃翻滚
- **连接机制**：磁铁自动吸附相邻模块
- **重构能力**：能够变幻成阶梯、椅子、墙壁等多种形状

## 技术原理

每个模块利用**角动量转移**实现跳跃：
- 模块内部飞轮高速旋转
- 刹车时角动量转移给整个模块，产生跳跃
- 跳跃到相邻位置后磁铁吸附固定
- 重复此过程实现整体构型变化

## 典型应用

- 灾后应急修复
- 环境自适应重构
- 自组装动态结构
