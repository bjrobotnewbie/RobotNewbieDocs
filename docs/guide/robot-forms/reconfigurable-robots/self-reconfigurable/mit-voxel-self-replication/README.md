# MIT 体素微型机器人自我复制阵列

MIT 比特与原子中心（CBA）提出的基于体素（Voxel）的微型组装机器人群概念，机器人不仅能独立移动，还能通过群体协作像细胞一样自我复制或建造比自身体积大数倍的结构。

## 关键特性

- **基本单元**：立方体体素（Voxel）作为基本构建单元
- **自我复制能力**：能够利用现有体素复制出新的机器人个体
- **分布式建造**：群体协作建造大型结构
- **可扩展尺度**：能够建造比自身体积大数倍的结构（车辆、建筑物乃至更大机器人）

## 核心概念

- **自我复制**：机器人能够复制自身，增加系统中模块数量
- **集体建造**：多个体素模块协作组装出更大结构
- **可编程物质**：体素单元通过编程组合出任意形状

## 典型应用

- 自主建造大型空间结构
- 未知环境中就地搭建 shelter
- 灾后自主修复基础设施
