# 刚性机器人

刚性机器人是传统机器人最主流的形态，由刚性连杆通过离散关节连接组成，运动学建模成熟，控制精度高，是工业应用中最常见的机器人形态。

## 定义与特点

**刚性机器人**：机器人的连杆由刚性材料（金属、硬质塑料等）制成，刚体假设成立，变形可以忽略不计。

**核心特点**：
- 离散关节+刚性连杆，自由度有限且明确
- 运动学建模成熟（DH参数法）
- 控制精度高，负载能力强
- 技术成熟，成本可控

**典型代表**：工业机械臂、SCARA机器人、并联机器人、移动轮式机器人

## 优势与局限

### ✅ 优势
- **精度高**：定位重复精度可达0.01mm级别
- **负载大**：从几克到几吨负载都有产品
- **控制成熟**：运动学、动力学建模成熟，成熟控制算法多
- **标准化程度高**：主流厂商（ABB、KUKA、发那科等）提供完整解决方案

### ❌ 局限
- **安全性低**：高速运动下碰撞可能造成人员伤害
- **环境适应性差**：无法适应非结构化环境和不规则物体
- **柔顺性差**：与人协作需要额外力控和安全传感器

---

## 关键技术

1. **DH参数建模**：标准的连杆坐标系建立方法
2. **逆运动学求解**：从末端位姿求解关节角度
3. **轨迹规划**：关节空间和笛卡尔空间轨迹生成
4. **动力学控制**：基于动力学模型的前馈控制
