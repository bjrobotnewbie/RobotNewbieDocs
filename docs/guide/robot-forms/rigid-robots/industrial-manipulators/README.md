# 工业串联机械臂

工业串联机械臂是最经典的刚性机器人形态，由多个刚性连杆通过旋转关节串联连接，模仿人类手臂结构，广泛应用于制造业自动化。

## 定义与结构

**串联机械臂**：多个连杆通过关节依次连接，从基座到末端执行器形成开链结构。

**典型配置**：
- **自由度**：通常6轴（3个位置+3个姿态）
- **结构**：基座 → 肩 → 肘 → 腕 → 末端执行器
- **工作空间**：球形或类似形状的可达空间

## 核心应用场景

| 应用 | 说明 |
|------|------|
| **焊接** | 汽车车身焊接，点焊/弧焊 |
| **装配** | 电子产品精密装配 |
| **搬运/码垛** | 物流仓储重物搬运 |
| **喷涂** | 汽车外壳、家具喷漆 |
| **打磨抛光** | 五金件表面处理 |
| **检测** | 尺寸测量、缺陷检测 |

## 技术特点

### 优势
- 工作空间大
- 结构简单，容易设计
- 成熟的运动学算法
- 大量商用产品可选

### 劣势
- 累积误差（每个关节误差累积）
- 刚性不如并联机器人
- 速度相对较慢
