# 并联机器人

并联机器人是一种闭链刚性机器人结构，动平台通过多个独立支链连接到基座，具有高刚性、高速度、高精度的特点，在高速分拣领域应用广泛。

## 定义与结构

**并联机器人**：末端执行器（动平台）通过两个或以上独立运动支链与基座连接，形成闭环结构的机器人。

**典型结构**：
- **固定基座**：机架
- **多条支链**：通常3-6条腿
- **动平台**：安装末端执行器
- **并联驱动**：每个支链独立驱动

**Delta机器人**是最常见的并联机器人类型。

## 对比：并联 vs 串联

| 特性 | 并联机器人 | 串联机器人 |
|------|-----------|-----------|
| 结构 | 闭链多支链 | 开链串联 |
| 精度 | 误差不累积 | 误差累积 |
| 刚性 | 高刚性 | 刚性较低 |
| 速度 | 高速 | 中速 |
| 负载 | 相对较小 | 范围广 |
| 工作空间 | 小 | 大 |
| 机构设计 | 复杂 | 相对简单 |

## 核心分类

| 类型 | 特点 | 应用 |
|------|------|------|
| **Delta机器人** | 3-4自由度，高速 | 分拣、包装、抓取 |
| **Stewart平台** | 6自由度，高承载 | 飞行模拟器、望远镜 |
| **平面并联** | 平面运动 | 精密定位 |

## 核心应用场景

- **食品分拣**：饼干、巧克力高速分拣
- **包装**：药品、电子产品包装
- **3D打印**：高精度打印平台
- **飞行模拟器**：六自由度运动平台
- **天文望远镜**：姿态调整
- **触觉设备**：力反馈设备

## 技术优势

✅ **高速**：可达数百次拾取每分钟  
✅ **高精度**：无累积误差，定位精度高  
✅ **高刚性**：闭链结构刚性好  
✅ **动态性能好**：加速度大，响应快  

## 技术局限

❌ **工作空间小**：相比串联机器人小很多  
❌ **机构复杂**：设计和制造难度大  
❌ **控制复杂**：运动学求解复杂  
❌ **负载受限**：大负载难实现  

## 发展趋势

- **高速化**：分拣速度不断提升，每分钟超过300次
- **视觉集成**：视觉引导动态抓取
- **轻量化**：新材料减轻臂重，提升速度
- **混联结构**：并联+串联结合优缺点
