# SCARA机器人

SCARA（Selective Compliance Assembly Robot Arm，选择性柔顺装配机器人手臂）是一种特殊结构的平面关节型刚性机器人，专门优化用于平面装配任务。

## 定义与结构特点

**SCARA机器人**：四轴机器人，具有两个旋转关节和一个直线关节，在XY平面具有柔顺性，Z方向刚性。

**结构特点**：
- **4个自由度**：X轴旋转 + Y轴旋转 + Z轴平移 + R旋转
- **选择性柔顺**：XY平面顺应，Z方向刚性
- **轻量化结构**：速度快，精度高
- **安装方式**：通常倒装安装在工作台上方

## 为什么叫"选择性柔顺"

柔顺性是专门设计出来的：
- **XY平面柔顺**：当插孔装配时，可以自动适应微小偏差
- **Z方向刚性**：保证竖直方向的插入力和定位精度
- **自动对中**：利用机械柔顺性补偿公差，减少装配失败率

## 核心应用场景

- **电子装配**：PCB板插件、连接器插入
- **包装**：食品包装、化妆品包装
- **搬运输送**：流水线上下料
- **3C制造**：手机、电脑零部件装配
- **检测**：自动检测上下料

## 技术优势

| 优势 | 说明 |
|------|------|
| **高速**：比6轴机械臂更快 | 适合流水线节拍生产 |
| **高精度**：装配精度可达0.01mm | 适合电子精密装配 |
| **成本低**：结构简单，价格亲民 | 适合大批量应用 |
| **占地小**：结构紧凑 | 节省生产线空间 |

## 技术局限

- **自由度有限**：只有4个自由度，无法实现复杂姿态
- **工作空间小**：通常臂长小于1000mm
- **单一功能**：专用于装配，通用性不如6轴

## 发展趋势

- **更高速度**：节拍速度不断提升
- **更高精度**：满足更精密装配需求
- **集成视觉**：视觉引导提高适应性
- **人机协作**：新型协作型SCARA出现
