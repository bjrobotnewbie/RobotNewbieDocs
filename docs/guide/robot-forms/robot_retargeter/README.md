# robot_retargeter

从SMPL-X/源机器人到目标人形机器人的动作重定向管线。

## 项目链接

- GitHub: <https://github.com/ccrpRepo/robot_retargeter>

## 项目概述

## 项目介绍
这是一个将SMPL-X人体动作或源机器人动作重定向到目标人形机器人的工具包，支持多机器人并排可视化。完整流程分为三个阶段：
1.  重放/关键点提取：从SMPL-X的`.npz`文件或源机器人的`.csv`动作文件中提取骨骼关键点
2.  重定向：通过逆运动学（结合mink和MuJoCo）将关键点映射到目标机器人模型，生成机器人动作
3.  可视化：并排播放一个或多个重定向后的机器人动作

## 主要特性
1.  支持SMPL-X人体动作、源机器人动作到人形机器人的动作重定向
2.  集成完整的动作重定向流水线，一键完成关键点提取、动作重定向和可视化
3.  提供多机器人并排可视化功能
4.  支持URDF/MJCF格式的机器人模型，内置丰富的配置文件和示例数据集
5.  兼容Python >=3.10环境，提供快速部署的一键脚本
