# 软体机器人

软体机器人是由软质材料（弹性体、硅胶、流体等）制成的机器人，具有连续变形能力，能够适应复杂环境，安全人机交互，是机器人学前沿研究方向。

## 定义与特点

**软体机器人**：机器人主体由模量接近生物软组织的软材料制成，能够产生连续大变形，与刚性机器人有本质区别。

**主要特点**：
- **连续变形**：无限自由度（理论上）
- **柔顺性**：能够自适应环境形状
- **安全性**：与人交互不会造成伤害
- **材料创新驱动**：新材料不断推动领域发展

## 分类体系

| 分类 | 驱动方式 | 特点 | 典型应用 |
|------|---------|------|---------|

| [介电弹性体驱动器](./dielectric-elastomers/README) | 电压驱动 | 响应快，高效率 | 人工肌肉、仿生游泳 |

## 优势与挑战

### ✅ 优势
- **安全性**：人机交互安全，碰撞不会伤人
- **环境适应性**：能够适应非结构化环境
- **抓取包容性**：能够抓取不规则易碎物体
- **生物相容性**：适合医疗植入和可穿戴设备

### ❌ 挑战
- **建模困难**：无限自由度动力学建模复杂
- **控制困难**：状态估计和闭环控制难度大
- **传感集成**：软材料中集成传感器技术难度大
- **能量密度**：驱动的能量密度仍然偏低
