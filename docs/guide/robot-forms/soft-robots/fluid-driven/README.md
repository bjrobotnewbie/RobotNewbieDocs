# 流体驱动软体机器人

流体驱动软体机器人通过控制内部流体（气体或液体）的压力分布实现全身连续变形，是软体机器人最常见的整体驱动方式。

## 工作原理

**基本原理**：
- 机器人本体由多个独立空腔组成
- 通过阀门控制每个腔室的压力
- 不同压力分布产生不同的整体变形
- 刚性骨架+软膜封装结构

**流体类型**：
- **气压驱动**：气体可压缩，响应快，容易爆炸危险
- **液压驱动**：液体不可压缩，力大，响应相对慢

## 典型结构

| 结构形式 | 特点 | 应用 |
|---------|------|------|
| **分段腔室** | 沿长度方向分段，逐段控制 | 象鼻机器人、蛇形机器人 |
| **纤维增强** | 纤维限制膨胀方向，产生特定变形 | 机械臂、抓手 |
| **折纸启发** | 基于折纸设计，预定变形模式 | 可变形结构 |
| **液压网格** | 均匀网格分布，全身变形 | 仿生皮肤 |

## 代表作品：哈佛八爪鱼机器人

哈佛大学Wyss研究所开发的全软体机器人Octobot：
- 完全由软材料制成
- 微流控气压驱动
- 无需电子电路即可自主运动
- 展示了完全软体机器人的可能性

项目论文：https://www.science.org/doi/10.1126/science.aah5454

## 特点

### ✅ 优点
- **全身连续变形**：真正无限自由度变形
- **安全性好**：完全柔软，碰撞安全
- **适应性强**：可以通过狭窄缝隙
- **建模相对简单**：流体压力模型相对清晰

### ❌ 缺点
- **需要泵阀系统**：系统复杂，不易小型化
- **带宽限制**：流体传输有延迟
- **密封问题**：长期使用容易泄漏
- **重量大**：流体本身增加重量

## 应用

- **微创手术机器人**：经自然腔道手术机器人
- **灾难救援机器人**：穿过废墟缝隙搜索
- **柔性抓取手**：自适应抓取不规则物体
- **仿生象鼻**：柔顺操作抓取

## 技术趋势

- **集成泵阀**：泵阀微型化，减少外接管线
- **建模控制**：数据驱动学习控制
- **多模态传感**：软体本体集成触觉传感
- **自主行走**：完全无缆自主软体机器人
