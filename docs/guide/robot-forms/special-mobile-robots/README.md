# 特殊移动机器人

非常规运动方式的机器人形态，采用特殊移动结构，用于特定场景或前沿技术探索。

## 分类体系

| 分类 | 说明 | 典型应用 |
|------|------|---------|
| [爬壁机器人](./wall-climbing/README) | 吸附式垂直攀爬 | 高空作业、船舶除锈、建筑检测 |
| [球型机器人](./spherical-robot/README) | 球壳滚动 | 教育娱乐、室内巡检 |
| [变形移动机器人](./transformable/README) | 可变形复合结构 | 多地形适应、特种任务 |

## 归类说明

- 本分类作为兜底分类，容纳不属于传统地面/空中/水下移动方式的机器人
- 蛇形机器人已归入"连续体机器人"分类（见 [连续体机器人/蛇形机器人](../continuum-robots/snake-like/README)）
