# AstroAnts 太空蚂蚁爬壁机器人

AstroAnts 是 MIT Media Lab 开发的磁轮吸附式微型爬壁机器人，专为月球轨道航天器外部检测设计，能在微重力环境下爬行于航天器金属外壳。

## 关键特性

- **吸附方式**：磁轮磁力吸附
- **应用场景**：航天器外壳垂直壁面爬行检测
- **环境适配**：微重力环境优化
- **尺寸**：微型设计，适合狭小间隙

## 技术亮点

- 磁轮设计，不打滑
- 微重力下可靠吸附
- 多机器人协同检测
- 轻量化结构
