# 水下机器人

水下机器人是面向水下运动能力的机器人形态，通过推进器、仿生鱼鳍等结构在水中实现移动和作业。

## 分类体系

| 分类 | 说明 | 典型应用 |
|------|------|---------|
| [ROV遥控水下机器人](./rov/README) | 有缆遥控操作 | 深海勘探、水下作业、潜水支援 |
| [AUV自主水下机器人](./auv/README) | 无缆自主航行 | 海洋科考、水下搜寻 |
| [水下机械手与作业臂](./underwater-manipulator/README) | 水下操作与作业 | 水下施工、维修、采样 |
| [水下滑翔机与仿生水下](./glider-bionic/README) | 水下滑翔和仿生结构 | 海洋监测、水下长航时观测、仿生研究 |

## 归类说明

- 水下机器人描述的是**单个水下移动和作业**的机器人形态
- 水下群体机器人属于**多机器人系统**，应归入 multi-robot-systems
- 水下表演、水下探测任务属于**应用场景**，应归入 applications
