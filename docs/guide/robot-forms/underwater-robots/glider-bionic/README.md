# 水下滑翔机与仿生水下机器人

采用特殊推进方式的水下机器人，包括水下滑翔机和仿生结构设计。

## 水下滑翔机

通过浮力调节和机翼升力实现滑翔式前进，能耗极低，超长续航。

### 特点

- 超长续航能力（数月）
- 超大航程（数千公里）
- 极低能耗
- 适合大范围海洋观测

### 典型应用

- 海洋气候监测
- 洋流观测
- 海洋环境长期监测
- 海洋生物分布调查

## 仿生水下机器人

模仿海洋生物形态和运动方式设计的水下机器人。

### 典型类型

- 仿生鱼机器人：模仿鱼类游动
- 仿生水母机器人：模仿水母推进
- 仿生章鱼机器人：模仿章鱼运动和操作

### 研究价值

- 高效水下推进机理研究
- 水下柔性结构研究
- 海洋生物行为观察
- 教育与科普展示
