# 高级机器人学


## 课程基本信息
- **课程名称**：CS 287: Advanced Robotics（高级机器人技术）
- **授课单位**：加州大学伯克利分校（UC Berkeley）电气工程与计算机科学系（EECS）
- **授课教师**：Pieter Abbeel 教授（强化学习先驱、OpenAI 创始成员）
- **课程时间**：2019年秋季学期
- **学分**：3学分
- **课程定位**：研究生高阶课程，面向具备算法、线性代数、概率与编程基础的学生，聚焦机器人**感知、控制、规划、学习**四大核心模块的前沿算法与系统集成。



## 先修要求
1. **数学基础**：线性代数、概率统计、凸优化、动态系统。
2. **算法能力**：数据结构、算法设计与分析、复杂度理论。
3. **编程能力**：熟练掌握Python/C++，能独立实现复杂算法。
4. **背景知识**：了解机器人学基础（如运动学、动力学）或人工智能基础（如机器学习、强化学习）。



## 课程主要内容（2019秋大纲）
### 1. 最优控制与动态系统（第1–5周）
- **基础控制**：LQR、iLQR、MPC（模型预测控制）、PD/PID 与稳定性分析。
- **动态建模**：刚体动力学、牛顿-欧拉方程、欠驱动系统（如直升机、双足机器人）。
- **优化方法**：无约束优化（梯度下降、牛顿法）、凸优化、非线性规划、轨迹优化（TrajOpt、CHOMP）。

### 2. 状态估计与概率感知（第6–9周）
- **贝叶斯滤波**：卡尔曼滤波（KF）、扩展卡尔曼滤波（EKF）、无迹卡尔曼滤波（UKF）、粒子滤波。
- **SLAM 与建图**：EKF-SLAM、GraphSLAM、FastSLAM、占据栅格地图、视觉SLAM基础。
- **不确定性建模**：高斯滤波、MAP/ML估计、EM算法、POMDP（部分可观测马尔可夫决策过程）。

### 3. 运动规划（第10–12周）
- **采样式规划**：PRM（概率路图）、RRT/RRT*（快速扩展随机树）、碰撞检测算法。
- **轨迹生成**：微分动态规划（DDP）、序列凸优化、非完整约束系统规划。
- **操作规划**：抓取点选择、力封闭（Force Closure）、视觉伺服、移动操作机器人规划。

### 4. 强化学习与模仿学习（第13–16周）
- **强化学习基础**：MDP、值迭代、策略迭代、Q-learning、TD学习、策略梯度（Policy Gradient）。
- **高级强化学习**：深度强化学习（DRL）、逆强化学习（IRL）、奖励塑形、分层强化学习、探索与利用权衡。
- **模仿学习**：行为克隆（Behavior Cloning）、DAgger、生成对抗模仿学习（GAIL）、从人类示范中学习（LfD）。

### 5. 前沿专题与案例研究（第17–18周）
- **系统辨识与仿真**：动力学参数辨识、物理引擎（如PyBullet、MuJoCo）、数字孪生。
- **实际案例**：自主直升机、自动驾驶（DARPA挑战赛）、双足行走机器人、工业机械臂操作、无人机集群。
- **具身智能**：学习与控制融合、接触动力学优化、感知-动作闭环设计。


## 课程特色
1. **理论与实践深度融合**：从数学推导到代码实现，从算法设计到系统集成，覆盖机器人全栈技术。
2. **前沿性强**：内容紧跟顶会（ICRA/IROS/RSS）与顶刊（IJRR/T-RO）最新成果，2019年已系统讲授深度强化学习、视觉SLAM、模仿学习等热点。
3. **科研导向**：项目鼓励创新，优秀成果可直接投稿学术会议，培养独立科研能力。
4. **名师授课**：Pieter Abbeel 为强化学习与机器人学习领域顶尖学者，课程融入其多年科研经验与工业界合作案例。
