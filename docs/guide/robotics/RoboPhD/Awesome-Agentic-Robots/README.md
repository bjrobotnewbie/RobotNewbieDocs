## 项目介绍
本项目是论文《Towards Agentic Robots: Model, Data, Environment, and Harness》的官方配套仓库，聚焦于智能体机器人领域，围绕模型、数据、环境、调度四个核心维度，梳理智能体机器人的相关研究成果，连接模型决策、数据管道、环境与机器人能力编排，覆盖从任务特定策略到VLA模型、世界模型及智能体机器人系统的全链条内容。

## 主要特性
1. 按领域分类整理智能体机器人文献，包含模型、数据两大核心领域及细分类别，模型领域涵盖训练、感知、规划、机器人控制、适配，数据领域涵盖采集、标注、优化等方向；
2. 提供文献分类浏览、引用参考、贡献指南等功能，支持用户系统了解智能体机器人领域的研究脉络。
