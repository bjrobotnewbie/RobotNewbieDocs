## 项目介绍
本项目是面向未来具身人工智能（Embodied AI）课程的教学材料，提供中英双语教程，基于项目经验并借助ChatGPT生成，覆盖机器人动力学、Isaac Sim、Isaac Lab、MuJoCo、机器人学习、ROS 2、相机标定、PPO、SAC、Flow Matching、GR00T、SONIC等内容。学习路径可按工具→标定/深度学习→物理/感知→强化学习→演示/生成策略→系统集成推进，Git与ROS 2为可选工具参考，配套课程地图可查看详情。

## 主要特性
1. 包含17个主题，共34个Markdown文件与34个PDF文件，所有PDF采用统一学术排版，首章从第2页开始
2. 覆盖VLA模仿学习、FQI/SAC、Dream-1零样本具身迁移等内容
3. 提供中英双语学习资源，支持Markdown与PDF格式的阅读/下载
