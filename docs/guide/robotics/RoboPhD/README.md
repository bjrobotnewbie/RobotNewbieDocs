## 项目介绍
RoboPhD 是一个为机器人研究打造的精选论文、研讨会、课程及技术资源合集，收录了多场顶级机器人学术会议的相关 workshop 资源，涵盖规划与无人机、多智能体系统等多个机器人研究方向。

## 主要特性
1.  **资源精选**：整理了 RSS、ICRA、IROS 等顶会的高质量机器人研究相关 workshop 资料
2.  **方向覆盖**：包含规划与无人机（如空中自主、农业机器人、野外机器人）、多智能体系统（如多机器人协作、大语言模型赋能多机器人系统）等热门研究方向
3.  **覆盖全时段**：收录了2022-2025年的多场学术研讨会资源，可用于跟踪机器人领域前沿研究动态。
