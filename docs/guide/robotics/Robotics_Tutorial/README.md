# Robotics_Tutorial

系统化的机器人教学文档，涵盖数学基础、C++ 进阶、规划与控制、SLAM 等。

## 项目链接

- GitHub: <https://github.com/Michael-Jetson/Robotics_Tutorial>
- 项目主页: <https://robotics-tutorial-wiki.vercel.app>

## 项目介绍
本项目是面向机器人与人工智能交叉方向的系统化教学文档，由达妙科技Pengfei Guo维护，采用CC BY-NC 4.0非商业许可协议。内容覆盖从数学基础到具身智能的完整机器人知识体系，包含数学、C++进阶、SLAM、移动机器人规控、运动控制、具身智能（RL相关）六大方向，所有428份文档均已完工并通过多轮审核。

## 主要特性
1.  **覆盖全面**：包含数学基础、C++工程、SLAM、机器人规划控制、全品类运动控制（足式/机械臂/移动操作等）、具身智能等完整机器人开发知识链，其中足式机器人拥有24章完整教学序列
2.  **质量严谨**：所有文档遵循内部编写规范，经过双轮独立审核，包含完整推导、类比讲解与事实核查，避免跳步表述
3.  **工程导向**：兼顾理论教学、算法实现、工程实践与论文解读，附带硬件栈、仿真工具等实战内容
4.  **使用便捷**：所有内容为独立Markdown文件，可直接克隆仓库按章节顺序学习。
