## 项目概述

## 项目介绍
本项目是一篇发表于IEEE TEVC的综述论文，主题为面向快速进化智能体的具身身心协同设计（Embodied Co-Design, ECD）。该研究受自然界动物大脑与身体协同进化的启发，提出ECD范式，可同时优化智能体的形态与控制策略，相比仅优化控制的传统方法，能更好地提升智能体与环境的交互能力和任务表现，覆盖实体机器人与虚拟生物两类智能体。

## 主要特性
1.  **体系化梳理**：首次提出分层分类法，对ECD领域的控制、形态、任务设计空间与表征方法进行归类，分析了百余篇近年相关研究
2.  **场景覆盖全面**：梳理了仿真与真实世界场景下的典型基准测试与应用案例
3.  **前沿展望清晰**：总结了当前ECD领域面临的核心挑战，并给出了未来研究方向的参考意见
4.  本项目同时作为开源综述资源库，维护良好且欢迎社区贡献。
