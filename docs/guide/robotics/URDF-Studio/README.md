# URDF-Studio

- 项目链接：https://github.com/OpenLegged/URDF-Studio
- 项目主页：https://urdf.d-robotics.cc/

## 项目概述

URDF-Studio是一款**基于Web的可视化URDF机器人模型构建器**，提供专业的URDF设计和可视化工作站。主要功能：

1. **浏览器端编辑**：无需写原始XML，在浏览器中即可编辑机器人拓扑、视觉/碰撞几何、硬件参数
2. **多种模式支持**：
   - 单模式编辑：拓扑编辑、几何测量、硬件参数配置
   - 多机器人组装：支持桥关节创建、工作空间文件管理、基于组件的机器人组装
   - AI助手：AI辅助机器人生成、检查，并支持导出PDF/CSV报告
   - 丰富可视化：基于React Three Fiber的工作空间画布，支持变换控制和辅助覆盖层
3. **多格式导出**：支持URDF/MJCF/USD格式导入导出
4. **AI辅助生成**：提供AI辅助机器人生成功能，加速机器人设计过程

该工具让机器人URDF模型设计变得更加直观高效，特别适合快速原型设计和模块化组装。
