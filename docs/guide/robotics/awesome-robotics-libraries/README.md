- 项目主页: <http://jslee02.github.io/awesome-robotics-libraries/>

## 项目介绍
这是一个精选的机器人学库与模拟器的汇总列表，涵盖了机器人开发全流程的各类工具资源，方便开发者快速查找相关技术栈。

## 主要特性
1.  **分类全面**：按功能划分为动力学仿真、逆运动学、机器学习、运动规划与控制、SLAM、机器视觉、强化学习机器人、抓取、人形机器人等16大类，还包含模拟器汇总和其他机器人相关精选列表
2.  **状态标注**：通过图标标注项目活跃度：🟢 活跃（更新不足1年）、🟡 维护缓慢（1-2年未更新）、🔴 停滞（超过2年未更新）、💀 已归档
3.  **收录优质资源**：包含Bullet、Drake、Genesis等高星开源项目，覆盖物理仿真、机器人建模、算法开发等多场景工具。
4.  附带部分项目的星标数据与官方链接，方便快速跳转获取详情。
