## 项目介绍
c4dynamics（Tsipor Dynamics）是一个Python框架，用于物理系统的状态空间建模、仿真、状态估计与控制算法开发，支持在机器人、航空航天、自主系统、导航等领域使用，可保持统一工作流，无需因系统变更重新搭建整套流程，已在JOSS期刊发表并通过pyOpenSci同行评审。

## 主要特性
1. 提供统一的系统定义、演化仿真、状态估计、控制设计工作流，适配不同物理系统
2. 支持机器人、航空航天、自主系统、导航等多领域应用
3. 配套真实场景的建模、估计、控制实现示例，遵循统一结构，可直接复用
