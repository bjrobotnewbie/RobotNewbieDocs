# CS 294-277 Robots That Learn（Spring 2026）

**CS 294-277 Robots That Learn**是加州大学伯克利分校2026年春季开设的**研究生级前沿机器人学习课程**，由计算机科学领域权威教授**Jitendra Malik**主讲，聚焦深度学习与强化学习驱动的机器人运动控制、具身智能，是连接生物运动机理、机器学习与机器人实操的顶尖进阶课程。

- 官方链接：https://robots-that-learn.github.io/
- YouTube链接：https://www.youtube.com/playlist?list=PLkFD6_40KJIxJMR-j5A1mkxK26gh_qg37

## 课程核心定位
- 填补机器人领域在深度学习革命中的滞后短板，解决机器人**数据稀缺、感知-行动闭环、泛化能力弱**等核心难题。
- 以**生物运动控制**为灵感，优先研究足式机器人、灵巧手、视觉/触觉感知、家用仿人机器人，而非传统轮式、工业专用机器人。
- 构建**从生物机理→学习范式→典型案例**的完整框架，培养前沿机器人学习算法设计与系统实现能力。

## 课程基本信息

- 地点：Berkeley Way West 1213教室

## 前置要求
需具备以下基础：
- 深度学习（Bishop教材水平）
- 强化学习（Sutton & Barto教材水平）
- 线性代数、概率统计、机器人运动学基础

## 课程三大模块（完整框架）
1. **生物运动控制基础**
   行走/跑步生物力学、人手与灵巧操作、本体感觉与触觉感知、发育视角、计算神经科学预测与控制。
2. **机器人运动技能学习核心范式**
   扩散模型、流模型、强化学习、行为克隆、视觉模仿、视频世界模型、长程规划与语言作用。
3. **典型案例实战**
   足式移动（Locomotion）、自主导航（Navigation）、灵巧操作（Dexterous Manipulation）。

## 课程安排（核心讲题）
- Lecture 1：课程导论
- Lecture 2：生物运动力学 / 机器人机构、运动学与动力学
- Lecture 3：扩散模型导论（特邀）
- Lecture 4：人手与机器人灵巧手 / 本体感觉与触觉
- Lecture 5：运动控制发育视角 / 机器人动力学、控制与规划
- Lecture 6：神经科学预测控制 / 视频世界模型
- Lecture 7：强化学习
- Lecture 8：行为克隆、视觉模仿
- Lecture 9–11：移动、导航、灵巧操作案例
- Lecture 12：长程规划与语言
- RRR Week：期末项目展示

## 课程考核与作业（50%权重在项目）
- 每周阅读作业（10%）：每篇阅读出2道多选题并作答
- 课堂笔记整理（10%）：LaTeX整理当周讲义
- 中期考试（30%）：30道左右多选题，可带1页双面 cheat sheet
- 期末项目（50%）：1–4人小组，提案→展示→4页CoRL格式报告，鼓励创新算法/应用/基准测试
