# idyntree

面向自由浮动机器人的多体动力学库

## 项目链接

- GitHub: <https://github.com/gbionics/idyntree>

## 项目概述

## 项目介绍
iDynTree是一款面向机器人动力学计算的开源库，主要用于控制、状态估计与仿真，专为自由浮动机器人设计，也可支持固定基座机器人。

## 主要特性
1.  基于C++开发，提供Python和MATLAB绑定
2.  使用无向图数据结构`iDynTree::Model`表示机器人模型，可以灵活切换运动学/动力学计算的基座连杆，无需重新加载模型
3.  支持读写URDF、SDFormat格式的机器人模型文件，可用于开发机器人运动学动力学参数辨识工具
4.  默认采用混合表示法描述连杆物理量，也可按需切换为体坐标系(left-trivialized)或惯性坐标系(right-trivialized)表示，适配全身体控制器合成研究需求
5.  实现了iCub人形机器人无需内置关节扭矩传感器即可估算关节扭矩的算法，适配人形机器人状态估计场景
6.  并非极致性能优先的多体动力学库，若追求极致运算速度可参考Pinocchio
