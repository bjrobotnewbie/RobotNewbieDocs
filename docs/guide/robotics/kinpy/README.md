# kinpy

机器人领域简单运动学计算工具集

## 项目链接

- GitHub: <https://github.com/neka-nat/kinpy>

## 项目介绍
kinpy是一个纯Python编写的机器人运动学计算工具包，支持读取URDF、SDF、MJCF格式的机器人模型文件，可用于机器人运动学相关计算与开发场景，如机器人正向运动学、逆向运动学、雅可比矩阵计算等。

## 主要特性
1. 纯Python实现，使用便捷；
2. 支持URDF、SDF、MJCF三种主流机器人模型文件格式；
3. 核心功能包含正向运动学（FK）、逆向运动学（IK）及雅可比矩阵计算；
4. 提供可视化支持（可选安装），可辅助调试关节角度相关参数。
