## 作者简介
1. **凯文·M·林奇（Kevin M. Lynch）**
西北大学机械工程系教授，机器人学、运动规划、生物力学领域权威学者，长期从事机器人机构设计、运动控制与自主规划研究，深耕机器人基础理论教学数十年。
2. **朴钟宇（Frank C. Park）**
首尔国立大学教授，机器人几何理论、旋量理论、机器人动力学与几何控制领域顶尖专家，是将**旋量系统理论**系统化引入机器人学教学的核心人物。

两位作者强强联合，本书集结了欧美经典机器人力学体系与韩式几何机器人理论精华，理论严谨、体系自成一派。

## 全书特色
1. **以旋量理论为统一主线**
区别于传统机器人学仅用齐次变换矩阵的讲解方式，全书**以旋量理论（Screw Theory）、李群李代数**为底层框架，统一描述刚体运动、机器人正逆运动学、雅可比矩阵、动力学建模，推导更简洁、物理意义更清晰，规避传统矩阵法繁琐冗余的计算。
2. **体系完整、覆盖两大机器人品类**
同时系统讲解**串联/并联机械臂（操作机器人）** + **移动机器人**两大主流方向，兼顾理论建模与工程应用。
3. **理论与算法并重**
不只讲公式推导，配套完整数值算法、例题解析、课后习题，适配课程教学、自学科研、工程算法落地。
4. **难度梯度适中**
从基础刚体运动学切入，逐步进阶到动力学、轨迹规划、反馈控制，数学门槛循序渐进，适合零基础入门机器人高端理论。

## 主要内容框架
### 1. 机器人基础与刚体运动几何
- 刚体位置、姿态的数学描述
- 旋量理论、运动旋量/力旋量核心概念
- 李群、李代数在机器人运动中的应用
- 空间速度、刚体运动的统一建模方法

### 2. 机器人运动学
- 串联机械臂正运动学、逆运动学
- 雅可比矩阵：微分运动、静力传递
- 奇异位形分析、冗余机器人运动学
- 移动机器人运动学模型（轮式机器人等）

### 3. 机器人动力学
- 刚体动力学基础、惯性参数建模
- 拉格朗日法、牛顿-欧拉法动力学推导
- 机器人逆动力学、正向动力学
- 动力学参数辨识基础

### 4. 轨迹生成与运动规划
- 关节空间/笛卡尔空间轨迹规划
- 多项式轨迹、梯形速度轨迹设计
- 基础运动规划原理、障碍空间路径规划基础

### 5. 机器人控制基础
- 机器人线性与非线性控制
- 轨迹跟踪控制、计算力矩控制
- 阻抗控制、力控制基础
- 面向机械臂与移动机器人的经典控制框架

## 适配场景与适用人群
1. **高校教学**
机器人工程、机械工程、自动化、人工智能、控制科学与工程专业高年级本科生、研究生教材及课程参考书。
2. **科研学习**
具身智能、机器人控制、运动规划、机械臂操作、移动机器人、SLAM方向科研入门必备理论工具书；也是UC Berkeley CS287等高级机器人课程**前置基础参考书**。
3. **工程从业者**
机器人算法工程师、机械臂控制工程师、移动机器人研发工程师，用于夯实底层运动学/动力学理论，支撑算法开发。

## 书籍价值总结
本书是**现代机器人学几何建模与力学分析的标杆教材**，打破传统机器人学零散的知识体系，用**旋量理论+李群李代数**建立统一理论框架，完美衔接本科基础机器人学与研究生高级机器人技术（最优控制、状态估计、强化学习、运动规划），是入门机器人高端理论、衔接学术科研与工程落地的经典必读著作。
