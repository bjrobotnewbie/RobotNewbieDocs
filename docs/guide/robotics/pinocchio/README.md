## 项目概述

Pinocchio是**高效刚体多体动力学计算的C++开源库**，专注于快速灵活地计算刚体动力学算法及其解析导数。主要特点：

1. **高效计算**：针对刚体动力学计算进行了优化，速度快内存占用小
2. **解析导数**：支持计算动力学的解析导数，利于基于优化的控制和状态估计
3. **多语言支持**：提供C++核心，同时支持Python绑定，conda/pip可直接安装
4. **广泛应用**：被广泛用于机器人定位、控制、运动规划等领域

Pinocchio是机器人学领域非常经典和实用的动力学计算库，许多开源机器人项目都基于它构建。
