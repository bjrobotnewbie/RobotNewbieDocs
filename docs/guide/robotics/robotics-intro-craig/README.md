## 书籍简介
《Introduction to Robotics: Mechanics and Control》是机器人学领域最经典的入门教材之一，全面系统地介绍了机器人学的基础理论和技术，包括机器人建模、运动学、动力学、控制等主要内容。

## 主要内容
- 机器人学基础概念
- 运动学与逆运动学
- 刚体动力学
- 轨迹规划
- 机器人控制技术
- 传感器与执行器
