## 项目介绍
本项目是MATLAB版Robotics Toolbox，为MATLAB提供机器人学相关功能，利用MATLAB原生的线性代数、可移植性、图形等能力，以MATLAB对象形式表示串联机械臂的运动学与动力学，支持创建自定义机械臂模型，内置Kinova、Universal Robotics、Rethink及经典Puma 560、斯坦福机械臂等知名机器人示例。该项目已停止主动开发，仅提供有限维护，适合使用MATLAB或《Robotics, Vision & Control》第2版（2017）的用户，对应版本为10.4，可通过下载RTB.mltbx在MATLAB中安装。

## 主要特性
1. 提供机器人学核心功能，支持串联机械臂的运动学、动力学建模与仿真
2. 内置多种经典及知名工业机器人模型示例
3. 适配MATLAB环境，利用其原生数值计算与可视化能力
4. 遵循LGPL v3开源协议，可自由使用与修改
