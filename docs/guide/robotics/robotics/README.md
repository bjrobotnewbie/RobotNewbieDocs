## 项目概述

## 项目介绍
本项目是Frank Dellaert与Seth Hutchinson编写的《机器人学与感知导论》草稿版配套资源，采用Notebook形式组织内容。项目仅允许个人复制笔记或复刻仓库用于私人使用，禁止商业/广播使用或二次分发修改后的非代码内容，代码部分遵循BSD开源协议。

## 主要特性
1.  按章节划分Python Jupyter Notebook，对应教材各小节内容
2.  提供Binder在线运行链接，可直接在浏览器中体验代码示例
3.  配套GitHub Actions自动部署书籍内容

本项目用于辅助学习机器人学与感知相关知识，覆盖机器人核心技术相关的教学实践场景。
