## 项目概述

RustRobotics是**以库优先的机器人算法Rust工作空间**，灵感来自PythonRobotics，扩展了基准测试、ROS2/Gazebo演示和可视化展示。主要内容：

1. **包含100+机器人算法**：涵盖路径规划（RRT、Dijkstra、A*等）、定位（EKF、粒子滤波等）、SLAM、控制等多个领域
2. **Rust语言**：使用Rust实现，性能更好内存安全
3. **基准测试**：提供算法基准测试
4. **演示支持**：提供ROS2/Gazebo演示
5. **可视化**：提供动态gif可视化展示算法运行过程

该项目是学习机器人算法非常好的资源，每个算法都有清晰实现和可视化演示，方便学习理解。
