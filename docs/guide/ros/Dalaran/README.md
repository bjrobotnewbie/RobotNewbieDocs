达拉兰 —— Apache 2.0 许可，面向机器人优先的可视化与数据基础设施，支持多模态时序数据。原生 ROS 2 支持，可读取现有 .rrd 格式记录。Rerun 的硬分支。

## 项目概述

## 项目介绍
Dalaran是一款Apache-2.0协议开源、面向机器人领域的多模态时序数据可视化与数据基础设施，是Rerun的硬分叉分支。它原生支持ROS 2，可以读取现有.rrd录制文件，能够将机器人、模拟器或离线 pipeline 产生的ROS 2话题、LiDAR点云、相机流、IMU、TF变换等多模态数据，统一存储在Arrow列式块存储中，并在同步的2D/3D viewer中渲染展示，同时还可以将数据导出为dataframe用于后续计算分析。

## 主要特性
1.  原生适配ROS 2生态，支持读取.rrd录制文件
2.  支持多模态时序数据统一存储与可视化，所有传感器数据可在同一条时间线上同步展示
3.  提供Python、Rust、C++多语言SDK，支持快速接入
4.  支持将录制数据保存为文件并离线回放
5.  内置viewer与CLI工具，可直接查看、回放录制的会话数据
