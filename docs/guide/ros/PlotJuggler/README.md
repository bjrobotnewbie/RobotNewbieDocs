## 项目概述

## 项目介绍
PlotJuggler是一款高性能、易用的时间序列可视化工具，主打快速处理海量时序数据，支持从文件加载或实时流获取数据，广泛应用于机器人、嵌入式设备等领域的数据可视化分析，尤其适配ROS1/ROS2生态，可读取rosbag并订阅ROS话题。当前存在仿冒恶意钓鱼网站，需注意甄别官方项目地址。

## 主要特性
1.  采用拖拽式直观UI，支持保存可视化布局与配置复用
2.  基于OpenGL实现高性能渲染，可轻松处理数千个时间序列、百万级数据点
3.  内置数据变换工具，支持求导、移动平均、积分等数据处理操作
4.  支持插件扩展机制，可灵活拓展功能
5.  支持多种数据源：CSV、PX4 ULog文件，MQTT、WebSocket、ZeroMQ等流数据，JSON/BSON等格式数据，Lab Streaming Layer设备数据，以及ROS1/ROS2话题与rosbag数据。
