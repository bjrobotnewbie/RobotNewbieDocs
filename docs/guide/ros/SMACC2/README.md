## 项目概述

## 项目介绍
SMACC2是一款面向ROS2（机器人操作系统）实时应用的C++事件驱动异步行为状态机库，用于帮助开发者以直观、系统化的方式构建多组件机器人的控制程序。

## 主要特性
1.  基于事件驱动、异步的行为状态机架构
2.  专为ROS2场景设计，支持实时机器人控制开发
3.  适配ROS2 Foxy、Humble等主流发行版，提供完整的CI构建与Doxygen官方文档支持，可通过ROS包索引直接获取发布版本。
