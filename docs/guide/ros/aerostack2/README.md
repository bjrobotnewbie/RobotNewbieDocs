# aerostack2

- 项目链接：https://github.com/aerostack2/aerostack2
- 项目主页：https://aerostack2.github.io/

## 项目概述

Aerostack2 是一个**ROS 2 无人机自主框架**，旨在以简单且强大的方式构建自主多旋翼无人机系统，支持多无人机集群。

### 核心特点

- **原生 ROS 2 开发**：完全基于 ROS 2 架构设计
- **完全模块化**：各个组件可以独立修改或替换，不影响系统其他部分
- **平台无关**：与具体飞行器平台无关，方便实现仿真到实物的部署（Sim2Real）
- **面向项目**：支持按需安装，只使用应用所需的必要包
- **集群导向**：原生支持多无人机集群

### 主要优势

- 提供完整的无人机自主能力：定位、导航、控制、规划等
- 支持多种仿真环境，方便开发测试
- 提供 Docker 镜像，预先安装好 ROS 2 Humble 版本
- 支持 Pixhawk 飞控等常见硬件
- 文档完善，活跃开发

Aerostack2 是开发自主无人机应用的良好框架，特别适合研究和教育用途。
