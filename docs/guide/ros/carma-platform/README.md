## 项目概述

CARMA 平台基于机器人操作系统（ROS）构建，利用开源软件支持合作式自动驾驶（CDA）功能，使自动驾驶系统能够通过通信与基础设施及其他车辆进行交互与协作。

该项目由美国交通部 FHWA 开发，旨在促进合作驾驶自动化的研发，加速市场准备和部署，同时推进自动驾驶技术的安全、安全、数据和人工智能。

主要特点：
- 可重用、可扩展的平台，用于控制 SAE L2 级联网自动驾驶车辆
- 提供丰富的通用 API，第三方插件可以实现车辆引导算法来规划车辆轨迹
- 使用 C++ 编写，在 Ubuntu 上的 ROS 环境中运行
- 可在多种适当配备的车辆上重复使用
- 正在从 ROS 1 框架迁移到 ROS 2
- 支持合作驾驶自动化，车辆与基础设施和其他车辆通信协作

CARMA 平台为合作式自动驾驶研究和开发提供了完整的开源基础设施。
