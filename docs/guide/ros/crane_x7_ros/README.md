# crane_x7_ros

- 项目链接：https://github.com/rt-net/crane_x7_ros
- 项目主页：http://wiki.ros.org/crane_x7

## 项目概述

crane_x7_ros 是日本 RT 公司 **CRANE-X7 7自由度机械臂**的官方 ROS/ROS 2 软件包，提供了驱动、控制、MoveIt 配置和示例代码。

CRANE-X7 是一款面向研究开发的协作机械臂，适合机器人学习和研究使用。

### 支持的 ROS 版本

- **ROS 1**: Melodic、Noetic
- **ROS 2**: Foxy、Humble

### 包含的包

- **crane_x7_description**: 机械臂 URDF 描述和 mesh 模型（非商业许可证）
- **crane_x7_control**: 硬件驱动和控制器配置
- **crane_x7_gazebo**: Gazebo 仿真配置
- **crane_x7_moveit_config**: MoveIt! 运动规划配置
- **crane_x7_examples**: 各种使用示例代码

### 主要功能

- 真实硬件驱动和控制
- Gazebo 仿真环境
- MoveIt 运动规划集成
- 丰富的示例代码帮助入门
- 支持 ROS 和 ROS 2 双版本

CRANE-X7 是一款适合研究的 7 自由度协作机械臂，这个软件包提供了完整的 ROS 开发环境，方便快速开始开发。
