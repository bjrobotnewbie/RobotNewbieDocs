# demos

ros2/demos 收集了 ROS 2 官方文档教程中使用的示例源码和自包含演示包。

## 项目链接

- GitHub: <https://github.com/ros2/demos>

## 项目概述

该仓库包含 ROS 2 Tutorials 中提到的示例代码，每个 ROS 2 包都围绕一个或多个独立演示展开，并通过各自 README 说明运行方式和相关概念。它通常用于展示 ROS 2 的基础通信、节点、参数、服务、动作、组件、launch、QoS 等功能。

项目面向学习和教学，而不是生产部署。对于刚接触 ROS 2 的开发者，它提供了比抽象 API 文档更直接的可运行参考；对于课程、工作坊或团队培训，它也可以作为讲解 ROS 2 基础机制和最佳实践的示例集合。
