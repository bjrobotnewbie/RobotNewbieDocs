# g1pilot

- 项目链接：https://github.com/hucebot/g1pilot

## 项目概述

G1Pilot是**Unitree G1人形机器人的开源ROS 2 package**，设计思路是让Unitree内置控制器处理下半身行走，而上半身提供完整的控制工具支持遥操作。主要特点：

1. **双控制器设计**：Unitree内置 loco 控制器处理行走 + 自定义上身控制器处理手臂操作
2. **双控制模式**：可以随时在关节空间控制和笛卡尔空间控制之间切换
3. **持续遥测**：持续发布IMU、里程计、每个电机的温度电压位置速度数据
4. **RViz就绪**：包含URDF和RViz配置，可以直接在RViz中可视化真实机器人
5. **Docker优先**：提供Ubuntu 22.04 + ROS 2 Humble可重复构建运行脚本
6. **可扩展**：清晰的节点边界和参数设计，方便添加新行为或替换规划器
7. **导航栈集成**：集成MOLA里程计和路径规划器，支持自主导航

该项目为Unitree G1人形机器人提供了完整的ROS 2集成，方便在上半身进行开发研究。
