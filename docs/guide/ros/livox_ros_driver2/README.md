# livox_ros_driver2

Livox 设备驱动支持 ROS（兼容 ros 和 ros2），支持激光雷达 HAP 和 Mid-360。

## 项目链接

- GitHub: <https://github.com/Livox-SDK/livox_ros_driver2>

## 项目概述

## 项目介绍
livox_ros_driver2是第二代Livox激光雷达ROS驱动包，兼容ROS和ROS2，支持HAP、Mid-360型号Livox激光雷达。仅推荐用于测试场景，不建议量产使用，用户可基于源码自行优化适配需求。支持的ROS版本包括ROS Melodic/Noetic，ROS2 Foxy/Humble/Jazzy，对应适配Ubuntu 18.04/20.04/22.04/24.04系统。

## 主要特性
1.  兼容ROS1和ROS2多版本，适配不同Ubuntu系统环境
2.  支持Livox HAP、Mid-360激光雷达设备
3.  提供完整的编译运行流程，需提前安装Livox-SDK2及对应ROS/ROS2环境
4.  附带多份launch示例文件，方便快速启动测试
