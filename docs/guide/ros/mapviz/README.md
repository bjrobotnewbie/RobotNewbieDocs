# mapviz

基于 2D 数据的模块化 ROS 可视化工具。

## 项目链接

- GitHub: <https://github.com/swri-robotics/mapviz>
- 项目主页: <http://swri-robotics.github.io/mapviz/>

## 项目介绍
Mapviz是一款基于ROS的模块化2D数据可视化工具，功能类似RVIZ，采用插件化架构设计，可用于机器人相关的2D数据可视化展示，官方提供了完整使用文档供参考。

## 主要特性
1.  基于ROS生态开发，兼容ROS生态链
2.  插件化系统架构，可通过扩展插件实现不同类型2D数据的可视化
3.  专注于2D数据可视化场景，轻量化适配相关机器人开发需求
4.  已通过ROS Noetic版本构建验证，可稳定部署使用
