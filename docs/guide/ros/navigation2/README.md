# navigation2 (Nav2)

- 项目链接：https://github.com/ros-navigation/navigation2
- 项目主页：https://nav2.org/

## 项目概述

Navigation 2 (Nav2) 是 ROS 2 的导航框架和系统，是 ROS 1 navigation 包的下一代升级版本。它提供了一套完整的导航功能，包括：

- 路径规划：全局规划和局部规划
- 路径跟随
- 代价地图
- 避障
- 行为树导航控制
- AMCL 定位
- 恢复行为

主要特点：
- 完整文档，包括概念介绍、入门指南、配置指南、插件开发等
- 活跃的社区开发，持续集成测试保证质量
- 支持多种机器人平台
- 可扩展的插件架构，方便添加新的规划器、控制器等
- 支持行为树进行灵活的导航行为控制

Nav2 是目前 ROS 2 生态系统中标准的导航解决方案，被广泛应用于移动机器人自主导航。
