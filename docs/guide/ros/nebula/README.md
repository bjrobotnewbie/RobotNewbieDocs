# nebula

ROS 2 通用 LiDAR 与雷达驱动，支持海思、Velodyne、Robosense 及 Continental 传感器。

## 项目链接

- GitHub: <https://github.com/tier4/nebula>
- 项目主页: <https://tier4.github.io/nebula/>

## 项目介绍
Nebula是一款面向ROS 2的通用LiDAR与雷达驱动平台，旨在为多类传感器提供统一的驱动框架，官方推荐作为Autoware项目的传感器驱动方案。它最初针对以太网接口的LiDAR传感器设计，同时具备良好的扩展性，可轻松适配新传感器与接口。目前已支持禾赛、Velodyne、Robosense、大陆集团的传感器，兼容ROS 2 Humble、Jazzy发行版。

## 主要特性
1.  支持多款主流品牌的LiDAR与雷达传感器
2.  基于ROS 2构建，适配Autoware自动驾驶项目
3.  提供统一的驱动框架，便于扩展支持新传感器和接口
4.  提供完整的官方文档，包含安装、使用、参数配置以及新增传感器开发教程
