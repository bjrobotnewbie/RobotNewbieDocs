- 项目主页：https://ai.robotis.com/

## 项目概述

open_manipulator是ROBOTIS **OpenMANIPULATOR平台**的官方ROS 2软件包。主要内容：

1. **提供完整接口工具**：提供控制机器人、集成传感器、开发物理AI应用所需的接口和工具
2. **支持LeRobot框架**：可以集成LeRobot等流行框架开发物理AI应用
3. **仿真模型支持**：提供Mujoco仿真模型，可以在仿真中开发测试
4. **Docker支持**：提供Docker镜像，方便运行ROS包和物理AI工具
5. **数据集预训练模型**：ROBOTIS在HuggingFace提供开源平台的数据集和预训练模型

该项目为OpenMANIPULATOR机械臂提供了完整的软件支持，方便开发者快速开始机械臂开发和物理AI研究。
