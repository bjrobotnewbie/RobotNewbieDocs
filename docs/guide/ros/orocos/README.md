# Orocos（开放式机器人控制软件）

## 简介
Orocos（Open Robot Control Software）是一个开源的机器人控制软件框架，专注于**实时控制**和**确定性行为**，特别适用于工业自动化、手术机器人、协作机器人等对实时性要求较高的场景。

该框架由比利时法兰德斯微电子研究中心（IMEC）发起，旨在为机器人开发者提供一套完整的实时控制工具链。

## 核心组件

### 1. Orocos Real-Time Toolkit (RTT)
实时工具包，提供核心的实时控制功能：
- 实时任务调度与执行
- 组件间通信机制
- 状态机管理
- 实时日志与监控

### 2. Orocos Component Library (OCL)
组件库，提供常用的机器人控制组件：
- 运动控制器
- 传感器接口
- 数据采集与处理
- 可视化工具

### 3. Orocos Kinematics and Dynamics Library (KDL)
运动学和动力学库，用于机器人运动学计算：
- 正向运动学求解
- 逆向运动学求解
- 雅克比矩阵计算
- 轨迹规划

## 主要特性
- **实时性保证**：支持硬实时系统，确保控制任务在严格的时间约束内完成
- **确定性行为**：可预测的执行时间，适用于安全关键型应用
- **模块化设计**：支持组件化开发，便于代码复用和系统扩展
- **跨平台支持**：支持 Linux、QNX 等实时操作系统
- **广泛的硬件支持**：支持各种工业机器人、传感器和执行器
- **ROS 集成**：可与 ROS 1/ROS 2 无缝集成

## 应用场景
- **工业自动化**：生产线机器人控制、自动化装配
- **医疗机器人**：手术机器人、康复机器人
- **协作机器人**：人机协作场景
- **移动机器人**：自主导航和控制
- **航空航天**：无人机、航天器控制

## 技术栈
- 核心语言：C++
- 实时操作系统：Linux RT_PREEMPT、QNX
- 通信机制：CORBA、ROS
- 许可证：LGPL 2.1
