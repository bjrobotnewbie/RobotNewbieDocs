## 简介
PyRobot是Facebook AI Research（Facebook人工智能研究院）开发的一个简化的机器人控制接口库，旨在提供统一的接口来控制多种机器人平台，简化机器人开发流程。

## 项目链接
- GitHub仓库: https://github.com/facebookresearch/pyrobot

## 主要特性
- 统一的机器人控制接口
- 支持多种机器人平台（LoCoBots, Sawyer arms等）
- 简化的API设计，便于快速开发
- 适用于机器人研究和实验
