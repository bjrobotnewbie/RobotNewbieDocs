## 项目概述

rclnodejs 是 ROS 2 的 Node.js 客户端库，让你可以使用 JavaScript/TypeScript 开发 ROS 2 应用程序。

主要特点：
- 原生绑定 ROS 2 rcl 库，提供完整的 ROS 2 功能
- 支持 TypeScript，提供类型定义
- 支持多个 ROS 2 版本（Humble、Jazzy、Kilted、Lyrical、Rolling）
- 跨平台支持：Linux x64/arm64、Windows
- 通过 npm 分发，安装方便
- 完善的测试覆盖，持续集成保证质量
- 支持创建节点、发布者、订阅者、服务端、客户端、动作客户端等

该项目属于 RobotWebTools 组织，使得开发者可以使用 Node.js 生态系统开发 ROS 2 应用，特别适合 Web 机器人应用开发。
