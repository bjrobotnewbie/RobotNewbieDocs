# realsense-ros

- 项目链接：https://github.com/realsenseai/realsense-ros
- 项目主页：http://wiki.ros.org/RealSense

## 项目概述

这是 Intel RealSense 深度相机的 ROS 封装包，支持在 ROS 生态系统中使用 RealSense 相机获取深度数据、彩色图像、点云等。

主要功能：
- 支持多个 ROS 版本（rolling、jazzy、humble、iron、foxy 等）
- 支持多个 Ubuntu 版本（20.04、22.04、24.04）
- 提供深度流、红外流、彩色流
- 生成点云数据
- 支持标定和内部参数校准
- 提供 TF 变换发布

该包已从 IntelRealSense 组织迁移到 realsenseai 组织，持续维护更新，是 ROS 中使用 RealSense 相机的标准驱动包。
