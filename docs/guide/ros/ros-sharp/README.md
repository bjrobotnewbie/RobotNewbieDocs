ROS# 是一套基于 C# 的开源软件库和工具集，用于从 .NET 应用程序（特别是 Unity3D）中向 ROS 通信。

## 项目链接

- GitHub: <https://github.com/siemens/ros-sharp>

## 项目介绍
ROS#是西门子开源的C#类库集合，用于在.NET应用（尤其是Unity3D）中与ROS通信。开发者可以通过它快速创建.NET程序，实现ROS话题订阅发布、服务/动作调用以及ROS消息交互，可用于开发机器人应用、仿真系统与自动化系统。

## 主要特性
1.  支持Unity引擎与任意兼容的.NET项目两种使用场景
2.  提供完整的ROS节点通信能力，覆盖话题、服务、动作交互
3.  可直接通过Unity Package Manager安装，也可通过NuGet获取.NET版本包
4.  拥有丰富的社区应用案例与详细的官方Wiki文档支持
