# ros2_control_demos

ros2_control_demos 是 ros2_control 框架的示例集合，用于演示控制器、硬件接口和机器人系统集成方式。

## 项目链接

- GitHub: <https://github.com/ros-controls/ros2_control_demos>
- 项目主页: https://control.ros.org

## 项目概述

该仓库通过一系列小型、可运行的示例展示 ros2_control 的功能和概念，帮助用户理解如何为不同机器人配置硬件接口、控制器管理器、控制器切换和仿真集成。示例包括 RRBot、DiffBot 等简单机器人，覆盖位置控制、差速移动底盘、多接口机器人和控制器组合等场景。

它更像 ros2_control 的教学和参考实现，而不是完整应用项目。对于正在学习 ROS 2 控制框架、准备为真实机器人编写硬件接口，或希望理解 ros2_controllers 如何与 robot description、launch、Gazebo 等组件配合的开发者，该仓库提供了清晰的起点。
