# ros2_controllers

- 项目链接：https://github.com/ros-controls/ros2_controllers
- 项目主页：https://control.ros.org

## 项目概述

ros2_controllers 包含了 ros2-control 框架常用的通用控制器，可以直接用于许多机器人，与 MoveIt2 和 Nav2 兼容使用。

这是 ROS 2 机器人控制框架的核心组成部分，提供了各种常用控制器实现：
- 关节轨迹控制器
- 位置控制器
- 速度控制器
- 力矩控制器
- 差分驱动控制器
- 四轮阿克曼控制器
- 等等...

主要特点：
- Apache 2.0 许可证开源
- 持续集成测试，代码覆盖率监控
- 支持多个 ROS 2 版本（Rolling、Jazzy、Humble 等）
- 文档完善，社区活跃，欢迎贡献
- 可以与 MoveIt2 和 Nav2 无缝集成

该项目是 ROS 2 生态系统中机器人控制的标准基础设施，被广泛应用于各类机器人项目。
