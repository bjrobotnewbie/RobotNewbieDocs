# ros2_rust

ros2_rust 是 ROS 2 的 Rust 绑定集合，让开发者可以用 Rust 编写 ROS 2 应用。

## 项目链接

- GitHub: <https://github.com/ros2-rust/ros2_rust>

## 项目概述

ros2_rust 包含 rclrs 客户端库、消息代码生成器、示例和相关工具，目标是把 ROS 2 的节点、消息、服务、action、QoS、参数、日志、时间、executor 等能力带到 Rust 生态。它支持 ROS 消息类型生成、publisher/subscription、异步通信、loaned messages、动态消息处理和图查询等功能。

项目适合希望利用 Rust 的内存安全、类型系统和并发能力构建机器人软件的开发者。虽然仍有部分能力在完善中，但它为高可靠 ROS 2 节点、嵌入式机器人组件和性能敏感模块提供了 C++/Python 之外的选择。
