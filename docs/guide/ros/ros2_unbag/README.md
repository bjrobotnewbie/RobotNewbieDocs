# ros2_unbag

一个 ROS 2 工具，用于将 bag 文件导出为人类可读的格式。支持可插拔的导出程序，以处理任意消息类型。

## 项目链接

- GitHub: <https://github.com/ika-rwth-aachen/ros2_unbag>

## 项目概述

## 项目介绍
`ros2_unbag`是一款ROS 2工具，用于将`.db3`或`.mcap`格式的ROS 2包文件导出为CSV、JSON、PCD、图片等易读格式。它同时提供直观的GUI界面和功能完整的CLI插件，支持自动化脚本工作流，可用于机器人研发中ROS bag数据的提取、转换与分析。

## 主要特性
1.  提供交互式GUI，可便捷浏览包文件、选择话题、配置导出参数、构建处理器链并管理重采样
2.  支持作为ROS 2 CLI插件使用，通过`ros2 unbag <args>`命令实现自动化批量处理
3.  支持可插拔的导出逻辑，可适配任意ROS 2消息类型与导出格式，内置覆盖传感器数据、点云、图像等常见类型的导出工具
4.  支持自定义处理器，可对消息进行过滤、转换与增强
5.  提供时间对齐重采样功能，支持`last`和`nearest`两种模式
6.  支持多进程导出，可自定义CPU占用率
7.  支持JSON配置文件的保存与加载，可复用工作流配置
