# ros2cli

ROS 2 命令行界面工具

## 项目链接

- GitHub: <https://github.com/ros2/ros2cli>

## 项目概述

## 项目介绍
本项目是ROS 2官方命令行工具集的代码仓库，随所有ROS 2发行版的标准安装包一同提供，用于通过命令行交互操作ROS 2系统。

## 主要特性
1.  **核心功能**：提供全套ROS 2命令行操作工具，可通过`ros2 --help`查看全部可用命令，通过`ros2 <command> --help`和`ros2 <command> <verb> --help`分别获取命令和子命令的详细使用说明。
2.  **扩展方式**：支持通过Python入口点自定义新增CLI命令和子命令，提供了官方和第三方的扩展示例参考。
3.  **使用场景**：适用于ROS 2开发、调试、运维场景，可快速完成节点、话题、服务、参数等ROS 2核心资源的查询与操作。
4.  配套提供了官方CLI速查表资源，可辅助快速上手使用。
