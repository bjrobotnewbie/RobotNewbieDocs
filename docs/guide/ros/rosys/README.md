# rosys

一个基于Web技术的全Python机器人系统。其用途与ROS类似，但它基于NiceGUI开发，更易于用于移动机器人领域。

## 项目链接

- GitHub: <https://github.com/zauberzeug/rosys>
- 项目主页: https://rosys.io

## 项目概述

## 项目介绍
RoSys是一款基于Web技术的全Python机器人系统，功能定位类似ROS，专注于移动机器人开发，且更易于使用。它依托现代Web技术栈，通过NiceGUI实现Web UI，支持离线本地网页操作或网关远程操控，内置仿真模式可快速测试算法，还可通过pytest编写集成测试。其核心采用asyncio实现无锁无互斥量的事件循环，性能优于ROS的多进程通信架构。

## 主要特性
1.  **全Python开发**：业务逻辑用Python编写，计算密集型任务通过进程、WebSocket或C++绑定调用
2.  **高度模块化**：无强制文件结构、配置和命名规则，模块可按需组织依赖
3.  **高效事件循环**：基于asyncio实现并行非并发执行，代码易读易调试，性能优于ROS
4.  **内置Web UI**：基于NiceGUI实现，支持离线本地操作或远程网关代理
5.  **仿真与测试**：提供硬件模拟模式，可模拟故障场景，支持pytest编写高速集成测试
6.  **灵活的模块机制**：模块可封装功能、维护状态、注册生命周期钩子、定时执行任务以及收发事件
