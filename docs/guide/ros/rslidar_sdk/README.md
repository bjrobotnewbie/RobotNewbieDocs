## 项目链接

- GitHub: <https://github.com/RoboSense-LiDAR/rslidar_sdk>

## 项目概述

## 项目介绍
rslidar_sdk是速腾聚创LiDAR针对Ubuntu平台开发的ROS/ROS2软件开发套件，内置LiDAR驱动核心rs_driver，提供ROS和ROS2原生支持。用户可通过该SDK快速通过ROS/ROS2获取点云数据，若需将LiDAR驱动集成到自有项目中则可直接使用rs_driver。

该SDK支持多款速腾聚创激光雷达，包括RS-LiDAR-16、RS-Bpearl、RS-Ruby系列、RS-LiDAR-M系列等，同时支持XYZI、XYZIRT两种点云数据格式。

## 主要特性
1.  原生支持ROS和ROS2，适配多版本Ubuntu系统
2.  覆盖绝大多数速腾聚创主流激光雷达型号
3.  支持XYZI、XYZIRT两种标准点云数据格式
4.  提供便捷的下载、编译和运行流程，依赖清晰明确
