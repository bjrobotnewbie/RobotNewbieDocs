# urdf-loaders

适用于Unity和THREE.js的URDF加载器，包含来自NASA JPL开源的ATHLETE URDF示例文件

- GitHub: <https://github.com/gkjohnson/urdf-loaders>
- 项目主页: https://gkjohnson.github.io/urdf-loaders/javascript/example/bundle/index.html

## 项目概述

## 项目介绍
本项目提供了适用于Unity和THREE.js的URDF加载工具，同时附带NASA JPL开源的ATHLETE机器人URDF示例文件。
其中Unity版本使用C#实现，THREE.js版本使用Javascript实现，还提供了THREE.js版本的在线Demo。项目还包含反转关节轴的ATHLETE变体URDF模型，可用于模拟底盘底部安装腿部的机器人构型。

## 主要特性
1.  支持Unity和THREE.js两大主流引擎的URDF文件加载
2.  附带官方开源的ATHLETE机器人完整URDF示例资源
3.  提供关节轴反转的ATHLETE变体模型，适配特殊构型
4.  遵循Apache V2.0开源协议，可商用二次开发
