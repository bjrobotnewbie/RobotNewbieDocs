ROS 对 Velodyne 3D 激光雷达的支持

## 项目链接

- GitHub: <https://github.com/ros-drivers/velodyne>
- 项目主页: <http://ros.org/wiki/velodyne>

## 项目介绍
本项目是面向Velodyne高清3D激光雷达（LIDAR）的ROS支持套件集合，为ROS环境提供Velodyne设备的驱动与集成能力。当前master分支适配ROS Kinetic和Melodic版本，主分支代码为下一版本的测试代码，若需最新稳定版本可查看最高版本号的标签。

## 主要特性
1. 提供ROS与Velodyne 3D LIDAR的对接支持，实现激光雷达数据在ROS生态中的流转与处理；
2. 具备持续集成（CI）构建验证，针对Kinetic和Melodic版本运行基础构建工作流；
3. 版本管理清晰，区分开发分支（master）与稳定发布版本，方便用户选择适配的代码。
