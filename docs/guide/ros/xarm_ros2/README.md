## 项目概述

## 项目介绍
本项目是UFACTORY机械臂产品的ROS2开发者工具包，为其旗下机械臂提供ROS2生态下的开发支持。原master分支基于ROS2 Foxy开发，2022年11月22日后停止更新仅作引导，用户需切换至对应ROS版本的分支使用。

## 主要特性
1.  适配多ROS2版本：提供foxy、galactic、humble、jazzy、rolling等主流ROS2发行版对应分支，保证与用户本地ROS环境匹配
2.  官方维护：由UFACTORY官方开发维护，适配其全系列机械臂产品开发需求
