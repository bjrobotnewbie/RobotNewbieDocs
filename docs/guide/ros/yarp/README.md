## 简介

YARP是一个开源的机器人开发中间件框架，类似于ROS，专注于模块化和实时通信，适用于各种机器人项目。

## 项目链接

- 官方网站: <https://www.yarp.it/>
- GitHub仓库: <https://github.com/robotology/yarp>

## 主要特性

- 模块化的机器人软件开发框架
- 实时通信和数据传输
- 广泛的硬件和软件支持
- 适用于学术研究和工业应用
