# yolo_ros

适用于 ROS 2 的 Ultralytics YOLOv8、YOLOv9、YOLOv10、YOLOv11、YOLOv12

## 项目链接

- GitHub: <https://github.com/mgonzs13/yolo_ros>
- 项目主页: https://mgonzs13.github.io/yolo_ros/

## 项目概述

## 项目介绍
这是一个ROS 2封装项目，集成Ultralytics旗下的YOLOv8、YOLOv9、YOLOv10、YOLOv11、YOLOv12模型，可在ROS 2环境中实现目标检测与追踪、实例分割、人体姿态估计、定向边界框（OBB）任务，同时支持基于深度图像的3D目标检测与3D实例分割、3D人体姿态估计。

## 主要特性
1.  支持最新一代Ultralytics YOLO全系列模型
2.  覆盖2D目标检测/追踪、实例分割、人体姿态估计、OBB多种视觉任务
3.  提供基于深度图的3D视觉任务支持
4.  兼容ROS 2生态，可直接在ROS 2机器人平台中部署使用
5.  开源协议为GPL-3.0，附带完整CI测试与文档部署流程
