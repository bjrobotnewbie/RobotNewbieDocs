## 项目概述

AirGym 是一个基于 NVIDIA IsaacGym 构建的高性能四旋翼无人机深度强化学习平台。支持多种任务环境包括悬停、跟踪、目标到达、动态避障和规划等。

主要特点：
- 基于 IsaacGym 实现高性能并行仿真
- 提供多种预设任务环境
- 支持自定义环境扩展
- 持续版本更新，修复 bug 并优化模型
- 提供预训练模型

该平台为无人机强化学习研究提供了完整的基础设施。
