# AirSim360

AirSim360 是面向无人机视角的 360° 全景高保真仿真平台，基于 Unreal Engine 5 构建。

## 项目链接

- GitHub: <https://github.com/Insta360-Research-Team/AirSim360>

## 项目概述

AirSim360 关注无人机全景数据稀缺问题，为 equirectangular 360° 航拍数据提供高保真仿真栈。它支持闭环飞行、与渲染对齐的多模态导出，并发布示例数据、用户文档和媒体资源，用于无人机视觉、全景感知、数据生成和仿真研究。

项目是 CVPR 2026 论文的官方实现，并提供 Air/Pro 版本路线、软件场景、Omni360-Scene 与 Omni360-WayPoint 等数据/场景计划。它适合研究全景无人机感知、航拍场景理解、合成数据训练和多模态视觉模型评估的团队。
