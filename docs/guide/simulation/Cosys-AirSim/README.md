# Cosys-AirSim

- 项目链接：https://github.com/Cosys-Lab/Cosys-AirSim
- 项目主页：https://cosys-lab.github.io/Cosys-AirSim/

## 项目概述

Cosys-AirSim 是基于 Unreal Engine 构建的无人机、汽车及其他移动平台模拟器，开源跨平台，支持物理和视觉逼真的仿真，支持与 PX4 等流行飞行控制器进行硬件在环仿真。它作为 Unreal 插件开发，可以直接放入任何 Unreal 环境中。

该项目基于微软 AirSim 的最后公开版本，Cosys-Lab 对 AirSim 平台进行了广泛修改，以支持多个项目和研究目标，增加了新的实现方案和传感器模态。

支持最新的 Unreal Engine 5.5，同时也提供 Unreal 5.2.1 长期支持版本。遵循 MIT 许可证开源。
