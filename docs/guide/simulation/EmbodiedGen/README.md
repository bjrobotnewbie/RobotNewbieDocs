## 项目概述

EmbodiedGen是面向具身智能的**生成式3D世界引擎**，旨在利用生成AI解决具身智能研究中的泛化挑战。该项目主要特点包括：

1. **六大核心模块**：包含Image-to-3D、Text-to-3D、Texture Generation、Articulated Object Generation、Scene Generation和Layout Generation
2. **高质量资产生成**：能够生成由高质量3D资产（网格和3DGS）组成的多样化交互式3D世界，并具有合理的物理属性
3. **在线体验**：提供多个HuggingFace Demo空间，支持图像转3D、文本转3D、纹理生成等功能在线体验
4. **完整文档**：提供详细的使用文档，方便研究者使用和二次开发

EmbodiedGen为具身智能研究提供了一个可扩展的生成式世界引擎，能够帮助构建多样化的训练环境。
