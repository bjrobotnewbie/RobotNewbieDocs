# FreeAskWorld

[AAAI 2026 口头报告] FreeAskWorld 是一个集成了大语言模型（LLM）的交互式仿真框架，用于具身AI中的高层规划与基于社会语境的交互。

## 项目链接

- GitHub: <https://github.com/AIR-DISCOVER/FreeAskWorld>

## 项目概述

## 项目介绍
FreeAskWorld是一个获AAAI 2026 Oral收录的交互式闭环仿真框架，面向以人为中心的具身AI研究，集成大语言模型（LLMs）实现高层规划与社交场景交互。项目提供了配套数据集与基线闭环框架，相关开源资源可在HuggingFace与对应GitHub仓库获取，采用Apache 2.0开源协议。

## 主要特性
1.  支持以人为中心的具身AI交互仿真，可搭建社交互动场景
2.  集成LLMs完成智能体高层规划任务
3.  支持接入OpenClaw、Codex、Claude等多种机器人智能体接口
4.  已发布数据处理、标注流水线代码与项目演示视频，核心仿真代码即将开源。
