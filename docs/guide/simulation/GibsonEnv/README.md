## 项目介绍
GibsonEnv是斯坦福大学开发的面向具身智能体的虚拟环境模拟器，旨在解决现实世界中感知与运动控制学习成本高、效率低的问题，为AI提供接近真实世界的感知训练场景，助力具身智能体的感知与运动控制研究，相关成果发表于CVPR 2018 Spotlight论文。

## 主要特性
1. 基于真实空间构建虚拟场景，还原真实世界的语义复杂性；
2. 内置Goggles机制，支持将仿真训练成果迁移至现实场景；
3. 集成Bullet物理引擎，实现智能体的空间与物理约束建模；
4. 提供轻量化核心资产包，包含39个场景，可扩展至572个空间、1440个楼层的完整数据库，还支持接入Stanford 2D3DS、Matterport 3D等外部数据集。
