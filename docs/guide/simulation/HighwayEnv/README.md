## 项目概述

## 项目介绍
HighwayEnv是一个面向自动驾驶与战术决策任务的仿真环境集合，由Edouard Leurent最初开发，目前由Farama Foundation维护。它可用于训练、测试自动驾驶智能体，支持Python环境，可通过PyPI快速安装，官方文档与Discord社区支持完善。

## 主要特性
1.  **核心功能**：提供10类驾驶场景仿真环境，涵盖高速路、环岛、停车场、交叉口等，还支持多智能体、连续控制、联网车道等变体场景。
2.  **使用场景**：适用于自动驾驶算法、SLAM、RL强化学习等自动驾驶相关的算法研发与测试。
3.  **兼容性**：优先支持Linux和macOS，Windows支持为最佳-effort级别，可通过`pip`或`uv`快速安装。
