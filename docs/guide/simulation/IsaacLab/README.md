## 项目概述

## 项目介绍
Isaac Lab是基于NVIDIA Isaac Sim构建的开源统一机器人学习框架，当前最新版本为3.0.0 Beta 2，兼容Isaac Sim 6.0.0和6.0.1版本，支持Linux和Windows系统，采用BSD-3和Apache-2.0双开源协议。
该框架GPU加速，可统一并简化机器人研究流程，涵盖强化学习、模仿学习、运动规划等方向，支持精准的物理与传感器仿真，适配机器人领域的 sim-to-real 迁移任务，可本地运行或云端分布式部署。

## 主要特性
1.  支持RTX相机、激光雷达、接触传感器等高精度传感器仿真
2.  GPU加速能力可快速运行复杂仿真与计算，适配强化学习迭代、数据密集型任务
3.  提供超16种常用机器人模型，涵盖机械臂、四足机器人、人形机器人等品类。
