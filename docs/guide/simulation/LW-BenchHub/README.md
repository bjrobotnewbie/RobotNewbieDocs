# LW-BenchHub

- 项目链接：https://github.com/LightwheelAI/LW-BenchHub
- 项目主页：https://lightwheel.ai/lightwheel-platform

## 项目概述

LW-BenchHub 是基于 Isaac Lab-Arena 构建的统一基准平台，专为具身智能设计，提供一致的接口、逼真的环境、多机器人支持以及可直接运行的大规模评估。

这是 Lightwheel 团队开发的端到端机器人仿真基准平台，专门用于评估机器人在厨房操作和定位操作任务中的表现。该平台无缝集成了遥操作数据采集与强化学习训练工作流。

主要特点：
- 支持 7 种适配机器人类型（Unitree G1、PandaOmron、DoublePanda、Agilex Piper 等），共 27 种具体机器人变体
- 提供真实厨房环境，包含 10 种布局和风格组合，100 种独特配置
- 包含 Lightwheel-Libero-Tasks 和 Lightwheel-RoboCasa-Tasks 两个任务集，共 268 个任务
- 支持可复现的强化学习配置，具备完整的机器人策略基准测试管道
- 提供完整文档和数据集支持

项目基于 Apache 2.0 开源。
