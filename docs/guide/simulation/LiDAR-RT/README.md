# LiDAR-RT

[CVPR 2025] LiDAR-RT：基于高斯射线追踪的动态 LiDAR 重仿真

## 项目链接

- GitHub: <https://github.com/zju3dv/LiDAR-RT>
- 项目主页: <https://zju3dv.github.io/lidar-rt>

## 项目介绍
LiDAR-RT是一篇被CVPR 2025收录的研究项目，提出了基于高斯的光线追踪方法，用于动态激光雷达重仿真。项目由浙江大学3DV团队等完成，提供了官方项目页面、论文arxiv链接与配套数据集，当前已发布训练与评估代码。

## 主要特性
1.  **核心功能**：基于3D高斯实现动态场景下的激光雷达点云重仿真，支持真实物理的激光雷达信号模拟。
2.  **技术路线**：结合高斯溅射与光线追踪技术，适配动态城市等复杂场景的激光雷达数据生成。
3.  **使用场景**：可用于自动驾驶激光雷达感知算法训练、仿真数据生成、激光雷达建模研究等方向。
4.  配套完整的安装、训练与评估文档，项目基于EnvGS、Street Gaussians等优秀开源工作开发。
