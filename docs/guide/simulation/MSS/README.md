# MSS (Marine Systems Simulator)

- 项目链接：https://github.com/cybergalactic/MSS
- 项目主页：https://mss.fossen.biz

## 项目概述

MSS (Marine Systems Simulator) 是一个用于**海洋控制系统设计**的 MATLAB/Simulink 工具箱，也兼容 GNU Octave。它是《Handbook of Marine Craft Hydrodynamics and Motion Control》（Fossen 2021 第二版）配套软件。

MSS 包含船舶、水下机器人、无人水面艇（USV）、浮动结构物的模型，以及时域仿真的制导、导航和控制（GNC）模块。

### 支持的海洋载具

- **船舶**：货轮、油轮、高速船等
- **水下机器人（AUV/ROV）**：自主水下航行器、遥控潜水器
- **无人水面艇（USV）**： unmanned surface vehicles
- **浮动结构物**：海上平台等

### 主要功能模块

- **CRAFT**：船舶模型库和时域仿真脚本
- **GUIDANCE**：制导系统模块
- **NAVIGATION**：导航系统和滤波器模块
- **CONTROL**：控制系统模块
- **HYDRODYNAMICS**：水动力学模型
- **TOOLS**：工具函数

### 特点

- 与经典教材配套，理论和代码对应
- 兼容 MATLAB 和 GNU Octave
- 大量实例模型，便于学习和修改
- 水动力模型和 GNC 算法完整实现

MSS 是海洋机器人、船舶控制领域研究的经典工具箱，被世界各地研究机构广泛使用。
