# ManiSkill

## 项目概述

ManiSkill 是一个开源框架，用于机器人仿真和训练，由 SAPIEN 提供支持，专注于操作技能。这是基于 GPU 的并行机器人模拟与基准测试系统。

主要特点：
- GPU 并行化视觉数据收集系统，高端配置在 4090 GPU 上可以 30,000+ FPS 收集 RGBD + 分割数据
- GPU 并行化仿真，支持高吞吐量基于状态的合成数据收集
- GPU 并行化异构仿真，每个并行环境可以有完全不同的场景/物体集合
- 示例任务涵盖各种不同机器人（人形、移动操作器、单臂机器人）以及各种不同任务（桌面、绘图/清洁、灵巧操作）
- 灵活简单的任务构建 API，通过面向对象设计抽象出复杂的 GPU 内存管理代码
- Real2sim 环境，通过 GPU 仿真可扩展地评估真实世界策略，速度快 100 倍
- 提供 Sim2real 示例，将在仿真中训练的策略部署到真实世界

ManiSkill 3 是当前最新版本，为机器人操作技能学习提供了高性能仿真基础设施。
