# Metaworld

- 项目链接：https://github.com/Farama-Foundation/Metaworld
- 项目主页：https://metaworld.farama.org/

## 项目概述

Meta-World 是一个开源基准，用于开发和评估连续控制机器人操作环境中的多任务和元强化学习算法，提供各种基准来评估强化学习算法的不同方面。

该项目遵循 Gymnasium API 进行环境创建和交互，支持多种基准测试：MT1、MT10、MT50 等，包含 50 多个不同的机器人操作任务。

主要特点：
- 开源，可通过 pip 直接安装
- 支持 Python 3.8-3.11，Linux 和 macOS
- 遵循标准 Gymnasium API，易于使用
- 提供完整文档和社区支持

是机器人强化学习研究中非常流行的多任务和元学习基准测试平台。
