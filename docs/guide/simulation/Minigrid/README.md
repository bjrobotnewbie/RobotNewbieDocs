- GitHub: <https://github.com/Farama-Foundation/Minigrid>

## 项目概述

## 项目介绍
Minigrid是一款面向强化学习研究的轻量级离散网格世界环境库，遵循Gymnasium标准API，前身是gym-minigrid，已被多篇学术论文引用。该库可快速搭建可自定义的网格场景，用于RL算法测试与研究，官方文档与Discord开发社区均可公开访问。支持通过`pip install minigrid`快速安装，兼容Python 3.10+的Linux、macOS系统，Windows暂未官方支持。

## 主要特性
1.  内置两类环境：原生Minigrid环境与BabyAI环境
2.  轻量高效，支持高度自定义配置
3.  适配Gymnasium标准接口，便于快速集成RL训练流程
4.  提供完整官方文档与社区开发支持
