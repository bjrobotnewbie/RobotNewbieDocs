# OpenModelica

OpenModelica 是一个开源的基于 Modelica 的建模与仿真环境，适用于工业和学术研究。

## 项目链接

- GitHub: <https://github.com/OpenModelica/OpenModelica>
- 项目主页: <https://openmodelica.org>

## 项目介绍
OpenModelica是一款基于Modelica的开源建模仿真环境，面向工业和学术领域使用。其核心为OpenModelica Compiler（OMCompiler），同时配套了多款工具：图形界面OMEdit、支持FMI和SSP的联合仿真工具OMSimulator，以及OMNotebook、OMPlot、OMShell等交互环境，另有OMOptim、OMParser、OMSens_Qt等扩展工具。

## 主要特性
1.  开源免费，遵循OSMC-PL许可证
2.  提供完整的Modelica建模与仿真工具链
3.  包含编译器、图形界面、联合仿真环境及各类辅助工具
4.  支持通过Git克隆获取完整项目，提供子模块管理方案，适配开发者进行二次开发与贡献代码
