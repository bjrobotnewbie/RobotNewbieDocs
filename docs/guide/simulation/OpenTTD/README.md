# OpenTTD

OpenTTD 是一款基于 Transport Tycoon Deluxe 开发的开源模拟游戏。

## 项目链接

- GitHub: <https://github.com/OpenTTD/OpenTTD>
- 项目主页: <https://www.openttd.org/>

## 项目介绍
OpenTTD是一款基于经典游戏《Transport Tycoon Deluxe》的开源交通模拟游戏，在还原原作体验的基础上新增了诸多扩展功能。该项目遵循GPLv2开源协议，同时包含部分第三方开源组件。

玩家可通过官方网站、Steam、GOG、微软商店或系统包管理器获取游戏，提供稳定版和每日开发版两个分支，支持Linux、macOS、Windows等主流操作系统，还可兼容部分BSD系统。游戏拥有社区维护的中文档和玩法指南，支持多人联机游玩，同时允许玩家提交贡献、翻译内容以及反馈bug。

## 主要特性
1.  还原原作核心玩法，同时新增扩展功能
2.  支持多平台运行，兼容绝大多数旧版本存档
3.  提供稳定版和 nightly 开发版两种下载渠道
4.  支持社区创作的模组与附加内容
5.  自带多人联机功能，拥有活跃的开发者与玩家社区
