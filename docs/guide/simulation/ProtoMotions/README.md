# ProtoMotions

ProtoMotions 是 NVIDIA Labs 开源的 GPU 加速仿真与学习框架，用于数字人和人形机器人运动学习。

## 项目链接

- GitHub: <https://github.com/NVlabs/ProtoMotions>
- 项目主页: https://nvlabs.github.io/ProtoMotions/

## 项目概述

ProtoMotions 3 面向物理仿真人体和人形机器人的快速原型开发，服务动画、机器人和强化学习研究社区。它强调模块化、可扩展和可伸缩，支持在 Newton、Isaac Lab、Isaac Gym、MuJoCo 等不同后端或生态中进行运动模仿、运动跟踪、技能学习和人形控制实验。

项目提供大量示例和数据展示，覆盖数字人动作、G1 humanoid tracking、跑跳翻越等任务。它适合研究人形机器人运动控制、物理角色动画、motion imitation、sim-to-real 和强化学习策略训练的团队，也可与 MimicKit 等相关工具配合使用。
