# SIMPLE

- 项目链接：https://github.com/physical-superintelligence-lab/SIMPLE
- 项目主页：https://psi-lab.ai/SIMPLE/

## 项目概述

SIMPLE（SIMulation-based Policy Learning and Evaluation）是一个面向人形机器人运动操作（loco-manipulation）的基于仿真的策略学习和评估环境。

这是一个全栈仿真环境，基于 AMO/SONIC 构建，并集成了主流视觉定位算法（VLAs）如 Psi0、Pi05、GR00T 等。

主要特点：
- 提供完整的数据生成流水线：数据收集、数据后处理、微调
- 支持在仿真中进行策略评估
- 提供基准测试结果比较不同算法
- 支持多种环境安装方式：UV、Nix、Docker
- 在 HuggingFace 上发布了模型和数据集
- MIT 许可证开源

SIMPLE 为人形机器人运动操作的策略学习提供了完整的仿真基准测试平台。
