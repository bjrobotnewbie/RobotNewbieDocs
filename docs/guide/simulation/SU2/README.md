## 项目概述

## 项目介绍
SU2是一款开源的多物理场仿真与设计优化套件，当前最新版本为8.5.0 "Harrier"，采用C++编写，可求解偏微分方程（PDE）并执行PDE约束优化。
其核心应用场景为计算流体动力学（CFD）与气动外形优化，同时已扩展支持电动力学、化学反应流等更通用的方程求解。该项目旨在打破专有计算分析工具的使用壁垒，向所有用户免费开放多物理场分析与设计优化功能。

## 主要特性
1.  开源免费，支持全社区参与开发
2.  支持多物理场数值仿真与PDE约束优化
3.  原生覆盖CFD、气动外形优化等主流工程仿真场景，可扩展至更多物理场
4.  提供Linux、MacOS、Windows预编译二进制包，也可通过meson+ninja构建系统从源码编译
5.  配备完善的持续集成与代码质量检测流程
