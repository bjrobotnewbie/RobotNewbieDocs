## 项目概述

## 项目介绍
SimWorld是一款面向自主智能体的开放式写实仿真平台，用于开发和评估LLM/VLM智能体，支持复杂物理与社交环境下的智能体测试。它提供三级使用模式：基础版包含2个轻量城市场景+1张空地图，可用于快速核心交互测试；可扩展版支持添加100+预制地图丰富场景；自定义版允许用户接入自有UE环境、资产与智能体模型，实现完全定制化仿真。

## 主要特性
1.  支持物理与社交双维度的复杂场景仿真
2.  适配LLM/VLM类AI智能体的开发与评测
3.  提供轻量化基础包、预制扩展场景、全自定义三种使用方案
4.  配套完整文档与快速上手示例，支持Python与UE服务器部署
