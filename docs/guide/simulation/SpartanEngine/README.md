# SpartanEngine

一个完全无绑定、基于 GPU 渲染的游戏引擎，支持实时全局光照路径追踪、硬件级光线追踪以及 200Hz 的物理模拟，历经 12 年以上的研发。

## 项目链接

- GitHub: <https://github.com/PanosK92/SpartanEngine>
- 项目主页: <https://panoskarabelas.com>

## 项目介绍
SpartanEngine是一款历经12年以上研发的个人游戏引擎，并非商业产品。它采用全无绑定、GPU驱动的渲染架构，搭载实时间接光追踪全局光照、硬件光线追踪功能，同时支持200Hz帧率的物理模拟。其渲染技术已应用于Godot引擎和S.T.A.L.K.E.R. Anomaly，并被收录于出版的编程书籍中，Discord社区拥有600+开发者成员。

## 主要特性
1.  全无绑定GPU驱动渲染架构，支持实时间接光追踪全局光照与硬件光线追踪
2.  200Hz高帧率物理模拟
3.  无遗留架构妥协，坚持实时优先、动态优先、现代技术优先的开发理念
4.  内置多个带物理功能的官方演示场景，支持交互操作
5.  拥有完善的社区支持与开发文档
