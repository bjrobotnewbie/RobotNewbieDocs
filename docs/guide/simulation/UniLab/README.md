# UniLab

- 项目链接：https://github.com/unilabsim/UniLab
- 项目主页：https://unilabsim.github.io

## 项目概述

UniLab 提出了一种超越 GPU 主导范式的机器人强化学习异构架构。核心思想是解耦物理仿真和策略训练，使用 CPU 进行物理仿真，GPU 仅用于策略训练，通过统一共享内存进行通信。

主要亮点：
- **CPU 物理仿真**：不需要 GPU 进行仿真，降低硬件要求
- **统一共享内存**：CPU 仿真和 GPU 训练之间高效通信
- **GPU 策略训练**：GPU 专注于策略训练，充分利用计算资源
- 这种异构架构相比传统方法实现了显著的吞吐量提升

支持中英文文档，提供 Apache 2.0 开源许可证，推荐使用 uv 进行环境管理，适合机器人强化学习研究，可以在没有高端 GPU 的情况下进行大规模仿真训练。
