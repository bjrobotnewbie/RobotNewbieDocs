## 项目介绍
Unity-Robotics-Hub是Unity机器人仿真相关工具、教程、资源与文档的核心仓库，核心围绕Unity平台的机器人仿真与开发场景，重点推出了Unity最新的机器人仿真工具包Simulation Pro，将Unity从游戏引擎转化为机器人仿真引擎，支持ROS、ROS 2等技术，适配Unity 6.3及以上版本，面向Unity Industry开发者开放早期访问权限，配套有5小时的实操培训课程。

## 主要特性
1. 提供URDF导入器，支持拖拽式导入URDF文件至Unity；
2. 内置传感器仿真功能，可仿真Lidar、RGB-D、IMU等传感器；
3. 原生支持ROS 2，可直接与ROS硬件通信；
4. 支持Linux无头构建目标，可在现有硬件栈上实现并行仿真；
5. 配套有5小时实操培训课程，覆盖机器人导入、ROS 2消息交互、传感器配置等核心内容。
