# XTDrone

基于 PX4、ROS 和 Gazebo 的无人机仿真平台

## 项目链接

- GitHub: <https://github.com/robin-shaun/XTDrone>

## 项目介绍
XTDrone是基于PX4、ROS与Gazebo构建的无人机通用仿真平台，支持多旋翼、固定翼、复合翼飞行器，以及无人车、无人船、机械臂等其他无人系统。该平台可用于快速验证各类算法，且经其验证的算法可便捷部署至真实无人机；目前已推出适配ROS2的XTDrone2版本。

## 主要特性
1. 支持多类无人系统仿真，涵盖多种飞行器及地面、水面、空中机械臂等设备
2. 可验证双目SLAM、视觉惯性导航、2D/3D激光SLAM、2D/3D运动规划、集群运动规划、目标检测追踪、多机编队与精准降落等算法
3. 提供单机、多机仿真架构，配套详细使用文档，便于开发者快速上手
