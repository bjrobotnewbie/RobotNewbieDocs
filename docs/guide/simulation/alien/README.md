## 项目概述

## 项目介绍
ALIEN是一款基于CUDA的人工生命模拟程序，全称Artificial LIfe ENvironment。它依托专用的2D CUDA粒子引擎模拟软体与流体，可创建由粒子网络构成的多细胞数字有机体，这些有机体搭载神经网络控制的传感器、肌肉等设备，能够通过基因组存储蓝图并繁衍后代。项目旨在研究前生物进化与生物系统复杂度，同时通过现代化UI与可视化渲染降低使用门槛，支持百万级粒子的大规模实时模拟。

## 主要特性
1.  **物理与图形引擎**：支持软体、刚体、流体、热传导等物理模拟，通过CUDA在GPU运行全部仿真逻辑，借助CUDA-OpenGL互操作性实现实时渲染与后处理，支持用户实时交互。
2.  **人工生命扩展**：实现多细胞有机体模拟、遗传系统与细胞级繁衍，可通过神经网络控制有机体高级功能，支持自定义细胞配色与空间可变仿真参数。
3.  **编辑工具**：提供粒子/连接编辑、几何/手绘绘图、遗传编辑器以及批量操作功能。
4.  **网络功能**：内置仿真浏览器，支持仿真文件上传下载与评分。
