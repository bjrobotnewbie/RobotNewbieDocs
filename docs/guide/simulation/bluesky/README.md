# bluesky

BlueSky 是开源航空交通模拟器，用于航空交通管理、交通流分析和空域运行研究。

## 项目链接

- GitHub: <https://github.com/TUDelft-CNS-ATM/bluesky>

## 项目概述

BlueSky 由 TU Delft CNS/ATM 团队维护，目标是为任何需要可视化、分析或模拟航空交通的人提供不受许可限制的开放工具。它面向 Air Traffic Management 与 Air Traffic Flow 研究，可用于构建可重复的航空交通场景、分析飞机运行轨迹、验证空管策略以及开展教学和科研实验。

项目采用开放数据和开源方式发布，强调用户可以自由复制、修改、引用和扩展。相比商业空管仿真系统，BlueSky 更适合研究人员快速搭建实验环境、测试算法或展示空域交通流行为，也为无人机交通管理和大规模航空运行模拟提供了可扩展基础。
