# brax

基于加速器硬件的大规模并行刚体物理仿真。

## 项目链接

- GitHub: <https://github.com/google/brax>

## 项目概述

## 项目介绍
Brax是一款基于加速器硬件的大规模并行刚体物理仿真引擎，由Google开发，基于JAX框架打造，可用于机器人、强化学习（RL）等依赖仿真的科研与开发场景。当前仅`brax/training`模块处于活跃维护状态，官方推荐如需物理仿真可直接使用MJX或MuJoCo Warp，未来可能将Brax纯作为RL库。它支持单设备高效仿真，也可在多设备上实现每秒百万级物理步的大规模并行仿真，无需依赖大型数据中心。

## 主要特性
1.  内置多种基线强化学习算法，包括PPO、SAC、ARS、进化策略，还支持利用仿真可微性的解析策略梯度算法
2.  提供四种可快速切换的物理仿真管线，包括MJX（JAX版MuJoCo）、广义坐标仿真管线等
3.  支持在TPU等加速硬件上高效运行，可在数秒到数分钟内完成智能体训练
