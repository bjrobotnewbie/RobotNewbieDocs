# carla

CARLA 是开源自动驾驶研究模拟器，用于开发、训练和验证自动驾驶系统。

## 项目链接

- GitHub: <https://github.com/carla-simulator/carla>
- 项目主页: http://carla.org

## 项目概述

CARLA 从零构建用于自动驾驶研发，提供开放代码、开放协议和可自由使用的数字资产，包括城市布局、建筑、车辆等。它支持灵活配置传感器套件、天气和环境条件，适合构建可重复的自动驾驶感知、规划、控制和端到端学习实验。

作为自动驾驶仿真领域常用平台，CARLA 可用于训练驾驶策略、生成多传感器数据、验证算法在不同道路和交通条件下的表现，也支持与外部控制器、ROS/ROS 2、评测工具和数据集管线集成。对研究者而言，它提供了比真实道路测试更安全、可控和低成本的实验环境。
