# chrono

Project Chrono 是用于多体动力学和多物理场仿真的高性能 C++ 开源库。

## 项目链接

- GitHub: <https://github.com/projectchrono/chrono>
- 项目主页: http://projectchrono.org

## 项目概述

Chrono 支持刚体多体系统、柔性体、颗粒动力学、流固耦合、一阶动态系统以及用于机器人和自动代理仿真的传感器模型。它提供成熟的核心多体动力学能力，并通过可选模块扩展到地面车辆、机器人、协同仿真、可视化、后处理、外部线性求解器、多核/GPU/分布式并行等场景。

该项目广泛用于科研、工程和政府研究问题，适合需要高可信动力学建模的车辆、机器人、机械系统和复杂物理交互仿真。相比通用机器人模拟器，Chrono 更偏底层物理与工程仿真库，可作为更复杂系统仿真、车辆动力学和传感器仿真的计算核心。
