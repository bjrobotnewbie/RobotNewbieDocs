# CoppeliaSim

## 相关项目与基准

- **RLBench**: [GitHub](https://github.com/stepjam/RLBench) - 机器人学习基准套件
- **PerAct2**: [网站](https://bimanual.github.io/) - 双臂操作任务
- **COLOSSEUM**: [网站](https://robot-colosseum.github.io/) - 机器人竞赛平台

## 概述

CoppeliaSim（原 V-REP）是一个功能强大的机器人仿真平台，支持多种物理引擎和编程语言。它在机器人教育和研究领域有广泛应用，特别适合复杂机器人系统的建模和仿真。
