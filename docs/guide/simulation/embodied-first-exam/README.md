## 项目介绍
embodied-first-exam是面向物理世界代码智能体的首个考试项目，旨在测试代码智能体在实体机器人场景中的能力。项目基于Harbor运行，整合了多个基准测试套件的固定机器人任务，要求智能体生成对应程序，并在独立沙箱中完成验证。

## 主要特性
1. 覆盖多类机器人任务场景，包含RoboPaint、RoboARC、DexHandExam等多个测试套件；
2. 采用程序生成+沙箱验证的模式，确保测试的独立性与准确性；
3. 聚焦物理世界的机器人能力评估，填补数字世界代码智能体测试向实体场景延伸的空白。
