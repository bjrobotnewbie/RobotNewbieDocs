# genesis-world

Genesis World 是面向 Physical AI、机器人和具身智能研究的通用仿真平台。

## 项目链接

- GitHub: <https://github.com/Genesis-Embodied-AI/genesis-world>
- 项目主页: https://genesis-world.readthedocs.io

## 项目概述

Genesis World 将统一多物理引擎、照片级渲染器 Nyx、跨平台编译器 Quadrants 和 Pythonic 仿真接口组合在一起，目标是为物理 AI 开发提供从单机实验到数据中心 GPU 规模的仿真基础设施。它既强调易读、易扩展、易嵌入研究代码，也关注大规模并行和高性能模拟。

项目原名 Genesis，后来由 Genesis AI 正式支持。它适合机器人控制、具身智能学习、物理交互、合成数据生成和仿真到现实研究等场景。相比只关注单一物理或单一机器人任务的模拟器，Genesis World 更倾向于构建通用、多物理、可扩展的 physical AI 仿真底座。
