# gz-sim

Gazebo Sim 是 Gazebo 项目的现代开源机器人模拟器，提供高保真物理、渲染和传感器模型。

## 项目链接

- GitHub: <https://github.com/gazebosim/gz-sim>
- 项目主页: https://gazebosim.org

## 项目概述

Gazebo Sim 继承自 Gazebo Classic，多年来一直是机器人仿真生态的重要基础设施。它提供物理仿真、图形渲染、传感器模拟、图形界面、插件系统、异步消息传递和服务接口，使用户可以构建移动机器人、机械臂、无人机、自动驾驶和多机器人系统的仿真场景。

项目属于 Gazebo 组件体系的一部分，通常与 ROS/ROS 2、SDF、Ignition/GZ 相关库配合使用。它适合机器人算法开发、仿真测试、教学演示和硬件部署前验证，尤其适用于需要传感器、控制、插件和可视化一体化的中大型机器人系统。
