# hash

🚀 开源的多租户平台，支持自研知识图谱与仿真

## 项目链接

- GitHub: <https://github.com/hashintel/hash>
- 项目主页: <https://hash.dev>

## 项目介绍
HASH是开源多租户自构建知识图谱与仿真平台，属于公共单体仓库，包含公开代码、文档等资源。它可以将原始信息转化为知识与流程图谱，打造基于图的世界模型，用于流程自动化、优化、决策与AI开发。
平台支持近实时数据集成，可通过智能代理自动从公网或私有连接源收集、结构化信息，非技术用户也能可视化浏览、管理数据实体与模式，作为可信数据源支撑高可信度决策。

## 主要特性
1.  支持自构建数据库，可自动生长、结构化并校验数据
2.  提供双时间戳（bitemporality）能力，支持记录和查询事件发生时间与获知时间，优化流程建模
3.  兼容非技术用户操作，提供可视化管理界面
4.  可集成多源数据，支持标准化语义化处理
