## 项目概述

IR-SIM (Intelligent Robot Simulator) 是一个基于 Python 的轻量级智能机器人模拟器，专为导航、控制和学习设计，使用 YAML 配置。

这是一个开源、基于 Python、轻量级的机器人模拟器，提供简单易用的框架，内置碰撞检测，可以对机器人、传感器和环境建模，非常适合学术和教育使用，支持机器人算法快速原型开发。

主要特点：
- 轻量级，纯 Python 实现，安装简单
- 通过 YAML 配置，易于使用
- 支持差分驱动、阿克曼、全向、四旋翼等机器人模型
- 支持多种传感器：LiDAR、相机、IMU、GPS、里程计等
- 可通过 PyPI 直接安装，支持 Python 3.10-3.14
- 完整文档，持续集成测试，代码覆盖率监控
- MIT 许可证开源

为机器人导航、控制和学习研究提供了便捷的仿真基础设施。
