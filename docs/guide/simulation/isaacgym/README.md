# IsaacGym

## 相关项目与基准

- **legged-gym**: [GitHub](https://github.com/leggedrobotics/legged_gym) - 足式机器人训练框架
- **parkour**: [GitHub](https://github.com/ZiwenZhuang/parkour) - 包含蒸馏与真机部署的跑酷任务
- **extreme-parkour**: [GitHub](https://github.com/chengxuxin/extreme-parkour) - 极限跑酷任务

## 概述

IsaacGym 是 NVIDIA 推出的基于 GPU 加速的强化学习仿真环境，专为大规模并行训练设计。它在足式机器人 locomotion 领域有广泛应用，支持高效的 sim-to-real 迁移。
