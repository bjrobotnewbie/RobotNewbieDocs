# jev-drone

在 MuJoCo 环境中，运行带有小判别模型（TypeSafe Jev）的纯相机自主无人机，运行频率为 2.5Hz。

## 项目链接

- GitHub: <https://github.com/RomanSlack/jev-drone>

## 项目介绍
jev-drone是一个仅依赖机载摄像头的自主四旋翼无人机项目，在MuJoCo仿真环境中完成五站障碍赛道飞行。项目搭载TypeSafe的轻量级Jev判断模型（运行频率约2.5Hz），负责解析场景并做出战术决策，实时飞行控制则由普通代码完成。无人机采用MuJoCo Menagerie中的Skydio X2模型，使用几何控制器驱动，未使用任何脚本化飞行逻辑。

## 主要特性
1.  **分层架构**：采用500Hz几何控制器、50Hz制导与安全反射层、15Hz视觉转符号场景模块、~2.5Hz战术判断模块的多级运行框架，代码保留最高安全否决权。
2.  **轻量化决策**：Jev模型不负责视觉感知，仅通过JSON输入输出带概率的类型化答案，解决常规代码难以表述的场景判断问题。
3.  **多场景赛道**：支持绕柱回旋、低空障碍翻越、旋转通道、滑动门穿越、密集柱群共5类不同障碍场景。
4.  **对比基线**： ablation实验显示，禁用Jev的贪心基线仅能通过前两站，而完整系统可完成全赛道飞行。
