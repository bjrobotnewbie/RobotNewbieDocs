# MuJoCo

- [文档](https://mujoco.readthedocs.io/en/stable/overview.html)

**MuJoCo（Multi‑Joint dynamics with Contact）** 是一款面向**机器人、生物力学、机器学习、图形动画**等领域的高性能通用物理引擎，专注于多关节结构与接触交互的快速精准仿真，由 Google DeepMind 开源并免费开放使用。



## 项目背景与定位
- 初始开发：Roboti LLC
- 2021 年 10 月：被 Google DeepMind 收购并免费开放
- 2022 年 5 月：正式开源，代码托管于 GitHub：google-deepmind/mujoco
- 核心定位：**科研导向的高精度物理仿真引擎**，兼顾控制综合、状态估计、系统辨识、逆动力学分析、机器学习并行采样等研究场景，也可用于游戏与交互式虚拟环境。


## 核心技术架构
MuJoCo 为 **C/C++ 库**，提供稳定 C API，采用**模型与数据分离**的核心设计，运行时无动态内存分配，极致优化性能。

### 1. 模型与数据分离
- **mjModel**：存储模型定义、物理参数、可视化配置等**静态不变信息**，编译后生成，运行时只读。
- **mjData**：存储**动态状态**（位置、速度、力、中间计算结果），运行时可读写，内存预分配，无运行时 malloc/free。
- 核心步进函数：`mj_step(const mjModel* m, mjData* d)`，支持多线程并行仿真（多 Data 共享同一 Model）。

### 2. 模型编译流程
1. 用户编写 **MJCF（原生 XML 格式）** 或 **URDF** 模型文件
2. 内置 XML 解析器 → 生成 mjSpec 高层描述
3. 模型编译器 → 优化为底层 mjModel 结构
4. 可保存为二进制 MJB 文件（不可反编译，建议维护源 XML）



## 特性概览
### 1. 先进的动力学与接触求解
- **广义坐标 + 优化型接触动力学**：融合机器人引擎精度与游戏引擎效率，避免笛卡尔坐标冗余约束。
- **凸优化软接触模型**：接触力求解为凸优化问题，解析可逆，支持逆动力学，兼容滚动/扭转摩擦、关节限位、肌腱摩擦等。
- **求解器丰富**：牛顿法（二次收敛）、共轭梯度、投影高斯‑赛德尔（支持椭圆摩擦锥）。

### 2. 强大的建模能力
- **MJCF 直观建模语言**：类 CSS 默认机制，极简配置即可完成复杂模型，可读性远超 URDF。
- **3D 肌腱几何**：支持绕球/圆柱包裹、路径点、滑轮，闭式解快速计算，可用于驱动与约束。
- **通用驱动模型**：统一描述电机、气缸、肌肉、PD 控制器等，含传动、激活动力学、力生成三大可配置模块。
- **柔性体自动生成**：一键生成绳索、布料、可变形 3D 物体，软约束保证稳定交互。

### 3. 高性能与并行
- 初始化后**零内存分配**，计算瓶颈极致优化。
- **约束孤岛（Constraint Islands）**：自动解耦独立刚体组，支持孤岛级并行，静止物体休眠大幅降载。
- **GPU 加速后端**：MJX（JAX）、MuJoCo Warp（NVIDIA Warp），无缝复用 mjModel/mjData，支持大规模并行仿真。

### 4. 交互式可视化与工具
- **OpenGL 原生 3D 可视化**：网格、纹理、阴影、透视、立体渲染，实时显示接触力、骨架、坐标系等调试信息。
- **实时交互**：鼠标拖拽施力，直观调试模型与控制器响应。
- **传感器系统**：IMU、力‑扭矩、触觉、测距、相机（彩色/深度）等，支持用户自定义传感器。

### 5. 可扩展与易用性
- **插件系统**：动态加载自定义传感器、执行器、被动力，不修改内核即可扩展引擎。
- **一等公民 Python 绑定**：完整覆盖 C API，快速开发、调试与数据处理。
- **多场景适配**：机器人控制、类人运动、灵巧操作、生物肌骨系统、强化学习环境等。



## 典型应用场景
1. **机器人学**：机械臂控制、足式机器人运动规划、手眼协调、柔顺控制
2. **生物力学**：人体/动物运动仿真、肌骨模型、步态分析、假肢设计
3. **机器学习**：强化学习环境、策略优化、离线数据生成、模型预测控制
4. **图形动画**：角色物理驱动、布料/毛发仿真、交互式虚拟人
5. **科研工具**：系统辨识、状态估计、逆动力学分析、机构优化设计



## 模型元素速览
- **世界体（worldbody）**：场景根节点
- **刚体（body）**：构建运动树，含质量、惯性，挂载几何、关节、位点
- **关节（joint）**：自由/球铰/移动/转动，添加自由度，支持参考位姿、弹簧参考
- **几何（geom）**：平面/球/胶囊/柱/盒/网格/高度场，负责碰撞与渲染
- **位点（site）**：轻量标记点，用于传感器、肌腱路径、执行器末端
- **肌腱（tendon）**：固定/空间肌腱，驱动、限位、约束
- **执行器（actuator）**：驱动关节/肌腱/位点，支持复杂动态特性
- **约束（equality）**：闭环、焊接、耦合，构建运动副
- **相机/灯光**：多视角、阴影、反射，提升可视化与真实感



## 六、关键设计澄清
1. **单位体系**：无强制单位，建议 MKS；重力默认 9.81 m/s²，密度默认水密度 1000 kg/m³。
2. **关节坐标 vs 笛卡尔坐标**：MuJoCo 用**广义关节坐标**，关节添加自由度，约束天然满足，精度更高；游戏引擎多用笛卡尔坐标，关节移除自由度，约束数值求解易不稳定。
3. **软接触与滑移**：原生软约束，解析可逆；轻微滑移为设计特性，调 solref/solimp、提高阻抗、用牛顿求解器可显著抑制，也可启用 NoSlip 后处理（牺牲部分鲁棒性）。
4. **碰撞过滤**：默认禁止父子体几何碰撞；静态体（世界/无自由度体）除外，可通过 contype/conaffinity 或 contact exclude 手动屏蔽。



## 快速上手示例
### 最简 MJCF 模型（hello.xml）
```xml
<mujoco>
  <worldbody>
    <light diffuse=".5 .5 .5" pos="0 0 3" dir="0 0 -1"/>
    <geom type="plane" size="1 1 0.1" rgba=".9 0 0 1"/>
    <body pos="0 0 1">
      <joint type="free"/>
      <geom type="box" size=".1 .2 .3" rgba="0 .9 0 1"/>
    </body>
  </worldbody>
</mujoco>
```

### 最简 C 仿真代码
```c
#include "mujoco.h"
#include "stdio.h"
char error[1000];
mjModel* m;
mjData* d;

int main(void) {
  // 加载模型
  m = mj_loadXML("hello.xml", NULL, error, 1000);
  if (!m) { printf("%s\n", error); return 1; }
  // 创建数据
  d = mj_makeData(m);
  // 运行 10 秒
  while (d->time < 10) mj_step(m, d);
  // 释放资源
  mj_deleteData(d);
  mj_deleteModel(m);
  return 0;
}
```


## 总结
MuJoCo 以**高精度动力学、凸优化接触、模型数据分离、极简建模、高性能并行**为核心优势，是机器人、生物力学、强化学习等领域的**标准仿真平台**。开源后生态持续完善，支持 CPU/GPU 并行、多语言绑定、插件扩展，兼顾科研深度与工程易用性。
