# mujoco_menagerie

- 项目链接：https://github.com/google-deepmind/mujoco_menagerie

## 项目概述

mujoco_menagerie是Google DeepMind为**MuJoCo物理引擎精心挑选收集的高质量模型集合**。主要特点：

1. **精选高质量模型**：物理模拟器的好坏取决于模型，这个集合提供了经过良好设计、开箱即用就能正常工作的模型
2. **多种使用方式**：可以通过robot-descriptions使用，也可以直接git clone使用
3. **社区贡献**：欢迎社区贡献新的模型，提供快速贡献者设置指南
4. **持续维护**：GitHub Actions自动构建验证，保证模型质量

对于使用MuJoCo进行机器人仿真研究来说，这是一个非常有价值的模型资源集合，省去了自己建模的麻烦。
