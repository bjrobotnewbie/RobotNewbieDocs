# o3de

Open 3D Engine (O3DE) 是一个采用 Apache 2.0 许可的多平台 3D 引擎，它允许开发者与内容创作者无需任何费用或商业义务，即可构建 AAA 级游戏、电影级 3D 世界和高保真模拟。

- GitHub: <https://github.com/o3de/o3de>
- 项目主页: <https://o3de.org>

## 项目概述

## 项目介绍
O3DE（Open 3D Engine）是一款基于Apache 2.0开源协议的多平台实时3D引擎，面向开发者和内容创作者，可免费无商业限制地制作AAA级游戏、影院级3D场景以及高保真仿真项目。

## 主要特性
1.  支持多平台，开源免费，无商业使用义务
2.  可用于开发高品质游戏、影视级3D内容和高精度仿真项目
3.  项目依赖Git LFS存储大型二进制文件，需提前安装配置Git LFS
4.  支持Windows等平台，编译需满足Visual Studio 2019 16.9.2+、CMake 3.24.0+等系统要求，还可可选集成Wwise音频SDK。
