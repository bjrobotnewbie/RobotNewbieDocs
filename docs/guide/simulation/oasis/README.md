# oasis

🏝️ OASIS：百万级多智能体开放代理社会交互模拟

## 项目链接

- GitHub: <https://github.com/camel-ai/oasis>
- 项目主页: <https://docs.oasis.camel-ai.org/>

## 项目介绍
OASIS是一款可扩展的开源社交媒体模拟器，集成大语言模型Agent，可逼真模拟Twitter、Reddit等平台上多达百万级用户的行为，用于研究信息传播、群体极化、从众行为等复杂社会现象，探索数字环境中的多样社会动态与用户交互。

## 主要特性
1.  **高可扩展性**：支持百万级Agent模拟，可开展接近真实平台规模的社交媒体动态研究
2.  **动态仿真环境**：适配社交网络与内容的实时变化，还原真实平台的流体交互特性
3.  **丰富交互动作**：Agent支持关注、评论、转发等23种动作，实现多维度交互
4.  **集成推荐系统**：内置基于兴趣和热度评分的推荐算法，模拟真实平台的内容发现与交互逻辑
