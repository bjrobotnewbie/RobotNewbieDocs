## 项目概述

## 项目介绍
OpenRocket是一款免费的全功能模型火箭气动与轨迹模拟软件，允许用户在实际制作发射前完成火箭设计与仿真验证。它基于Java开发，支持跨平台运行，提供丰富的内置组件用于火箭设计、3D可视化以及仿真结果分析。

## 主要特性
1.  支持六自由度飞行仿真
2.  自动优化火箭设计方案
3.  实时显示仿真中的高度、速度与加速度数据
4.  支持多级火箭分离与集群设计
5.  可导出数据至RockSim、RASAero II等其他仿真软件
6.  支持将火箭组件导出为OBJ文件用于3D打印
7.  提供丰富的内置示例项目帮助快速上手
