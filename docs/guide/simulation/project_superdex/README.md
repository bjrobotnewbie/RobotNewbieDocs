# project_superdex

SuperDex 整合了专用的物理引擎、机器人编写工具以及可扩展的强化学习接口，统一于仿真平台之中，并计划在未来版本中引入基于 VR 的远程操控及其他功能。

## 项目链接

- GitHub: <https://github.com/facebookresearch/project_superdex>
- 项目主页: <https://projectsuperdex.com>

## 项目介绍
Project SuperDex是一款面向灵巧操作研究的统一仿真平台，整合了定制化物理引擎、机器人开发工具与可扩展强化学习接口，还支持VR远程操控，未来还将推出更多功能。该平台可用于机器人灵巧操作相关的科研与开发工作。

## 主要特性
1.  **SuperDex Physics**：专为触觉操作打造的接触优先物理引擎，可精准模拟稳定接触与传感效果，作为平台仿真核心
2.  **SuperDex Robotics**：机器人开发SDK，提供机器人定义、控制器、传感器、执行器等组件，可快速组装完整仿真配置
3.  **SuperDex Studio**：轻量桌面GUI工具，用于创建、编辑和验证机器人、网格、任务预制件与场景等仿真资产
4.  **SuperDex Lab**：仿真工具集，封装了强化学习、模型预测控制与系统辨识所需的马尔可夫决策过程与动力学约束优化能力
5.  支持VR远程操控，可实现多种复杂灵巧操作任务演示。
