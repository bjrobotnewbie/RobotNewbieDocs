# robocasa

RoboCasa 是面向通用机器人日常任务的大规模仿真框架和基准平台。

## 项目链接

- GitHub: <https://github.com/robocasa/robocasa>
- 项目主页: https://robocasa.ai

## 项目概述

RoboCasa 最初由 UT Austin 研究者发布，目标是在大规模家庭厨房等日常场景中训练具备泛化能力的机器人。新版 RoboCasa365 扩展了任务、资产、示教数据和 benchmark 支持，包含由大语言模型辅助设计的 365 个任务、数千个厨房场景和三维物体，以及大量人类示教和自动生成机器人数据。

项目支持 Diffusion Policy、π、GR00T 等策略学习方法，并提供 leaderboard 让用户提交模型结果。它适合研究机器人操作、家庭服务机器人、模仿学习、数据驱动策略训练和大规模仿真基准，尤其适用于评估策略在多样日常任务和丰富资产组合下的泛化能力。
