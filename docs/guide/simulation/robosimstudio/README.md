## 项目链接

- GitHub: <https://github.com/robosimstudio/robosimstudio>

## 项目介绍
RoboSimStudio是一款开源交互式GPU仿真工具包，核心功能是加速机器人操作任务的Real2Sim（真实到仿真）转换，支持手动操作或借助编码代理完成仿真环境构建，可快速重建真实机器人操作任务的仿真场景。

## 主要特性
1. 基于Newton、Warp、MuJoCo Warp等成熟物理引擎与工具开发，依托viser实现交互界面；
2. 提供丰富示例快速上手，也可通过编码代理（如Codex、Claude Code），结合任务指令与对应视频快速生成仿真环境；
3. 支持构建各类机器人操作任务仿真场景，适配机器人模型来自i2rt、robosuite等项目；
4. 采用Apache License 2.0开源协议，相关技术细节可参考配套技术报告与项目页面。
