# robosuite

robosuite 是基于 MuJoCo 的模块化机器人学习仿真框架和可复现实验基准。

## 项目链接

- GitHub: <https://github.com/ARISE-Initiative/robosuite>
- 项目主页: https://robosuite.ai

## 项目概述

robosuite 为机器人学习提供标准化仿真任务、机器人模型、控制器和传感接口。它基于 MuJoCo 物理引擎，支持机械臂、灵巧操作、不同机器人 embodiment、自定义机器人组合、复合控制器、遥操作设备、真实感渲染和多种视觉模态，常用于模仿学习、强化学习和机器人操作算法评测。

项目强调可复现研究和模块化扩展，用户可以在统一框架下切换任务、机器人、控制器和观测设置。对于需要训练机器人抓取、搬运、装配、操作和视觉控制策略的研究者，robosuite 提供了成熟的 benchmark 环境，也适合构建新的操作任务和评估学习算法在不同动力学/视觉条件下的泛化能力。
