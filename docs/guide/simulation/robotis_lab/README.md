## 项目概述

robotis_lab是一个**基于Isaac Lab的研究仓库**，支持在仿真中使用ROBOTIS机器人进行强化学习和模仿学习实验。主要特点：

1. **针对ROBOTIS硬件定制**：提供专为ROBOTIS硬件定制的仿真环境、配置工具和任务定义
2. **利用NVIDIA技术**：利用NVIDIA Isaac Sim强大的GPU加速物理引擎和Isaac Lab模块化RL流水线
3. **支持Sim2Real**：支持在仿真中学习策略，然后部署到真实机器人
4. **Docker安装**：提供Docker安装方式，预安装所有依赖，环境一致

该项目为使用ROBOTIS机器人进行强化学习研究提供了完整的仿真 pipeline，方便开展研究。
