## 项目介绍
space_robotics_bench（SRB）是面向太空机器人领域的综合基准测试框架，专为太空环境下的机器人研究设计，提供统一的环境与任务集合，用于开发和验证地外场景下的自主系统，支持多样化的开发工作流与研究方向。

## 主要特性
- 支持高度并行化的仿真实例，可加速研发流程
- 按需生成多样化的仿真资产与场景，具备 procedural generation 能力
- 提供丰富的域随机化功能，提升算法的鲁棒性与泛化性
- 兼容 Gymnasium API，适配各类机器人学习框架
- 支持 ROS 2 接口，可与 ROS 2、Space ROS 生态无缝交互
- 采用抽象架构，适配不同机器人与太空领域场景
- 提供在线文档，包含安装、使用及开发资源，采用 MIT/Apache 2.0 双许可协议。
