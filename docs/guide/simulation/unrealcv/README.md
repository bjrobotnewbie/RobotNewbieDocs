## 项目概述

## 项目介绍
UnrealCV是一个帮助计算机视觉研究者基于Unreal Engine 4（UE4）构建虚拟世界的项目，通过插件扩展UE4功能。它支持两种使用方式：一是直接使用嵌入了UnrealCV的编译好的游戏二进制文件，无需掌握UE4知识；二是将插件安装到UE4中，使用UE4编辑器自定义搭建虚拟世界。它可以实现UE4与外部程序（如Caffe）的通信，提供交互命令操控虚拟场景。

## 主要特性
1.  提供一套可操控虚拟世界的UnrealCV命令集
2.  实现UE4与外部计算机视觉程序的通信对接
3.  支持两种部署模式，适配不同使用需求
4.  可用于生成带标注的计算机视觉训练数据，支持机器人、SLAM、RL等领域的虚拟场景研发
