# webots

- 项目链接：https://github.com/cyberbotics/webots
- 项目主页：https://cyberbotics.com

## 项目概述

Webots 是一个开源机器人仿真器，提供了完整的开发环境用于建模、编程和仿真机器人、车辆和机械系统。它对初学者友好，旨在介绍新手进入机器人世界。

主要特点：
- 完整的开发环境，包含图形界面编辑器
- 支持多种机器人类型：轮式机器人、腿足机器人、飞行器、固定机械臂等
- 支持多种传感器：LiDAR、摄像头、IMU、编码器、触摸传感器等
- 支持多种编程语言：C/C++、Python、Java、MATLAB、ROS
- 提供大量预置机器人模型和世界场景
- 支持在线仿真，可以在 webots.cloud 查看在线仿真
- Apache 2.0 许可证开源
- 活跃的社区开发，持续更新

Webots 是一个成熟的机器人仿真工具，被广泛用于机器人教育、研究和算法开发。
