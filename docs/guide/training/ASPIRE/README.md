# ASPIRE

ASPIRE：机器人领域的代理/技能发现

## 项目链接

- GitHub: <https://github.com/NVlabs/ASPIRE>

## 项目介绍
ASPIRE是一款面向机器人的自主技能发现框架，它革新了传统持续学习模式：不再通过梯度下降训练，而是以传感器运动技能仓库替代浮点权重作为训练产物，通过多智能体并行练习不同技能实现分布式训练。该项目支持仿真与实机机器人实验，可适配LIBERO-Pro、Robosuite、BEHAVIOR-1K等主流机器人仿真套件。

## 主要特性
1.  全新持续学习范式：以技能迭代替代梯度下降训练
2.  多智能体并行技能练习，实现分布式训练
3.  支持与Codex、Claude Code等编码智能体协同完成任务
4.  可复现LIBERO-Pro、Robosuite、BEHAVIOR-1K等套件的标准实验结果
5.  兼容多种编码智能体，提供通用操作指引与分场景快速启动流程
