# Awesome-Robot-Learning

本仓库包含一份关于机器人学习（主要聚焦于操作）的精选资源列表。

## 项目链接

- GitHub: <https://github.com/RayYoh/Awesome-Robot-Learning>

## 项目介绍
本项目是一个精选的机器人学习（主要面向机器人操作，属于Embodied AI子任务）资源汇总列表，旨在帮助领域研究者节省检索时间，聚焦算法研发。项目收录了活跃研究者、算法测试仿真环境等内容，不包含相关研究论文。

## 主要特性
1.  **核心定位**：聚焦机器人操作方向的机器人学习资源，服务于Embodied AI领域研究者
2.  **资源分类**：涵盖综述论文、优质Awesome列表、相关实验室、活跃研究者、各类基准仿真环境（包含Isaac、MuJoCo、SAPIEN、PyBullet等）以及数据集
3.  **维护状态**：项目持续维护，欢迎提交PR或邮件补充资源
4.  **近期更新**：2024年8月22日更新了Awesome-Video-Robotic-Papers相关内容
