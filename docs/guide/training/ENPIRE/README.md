# ENPIRE

ENPIRE 是一个代理框架，它允许 AI 编程代理通过闭环的物理试错与演化，自主优化现实世界的机器人策略。

## 项目链接

- GitHub: <https://github.com/NVlabs/ENPIRE>
- 项目主页: <https://research.nvidia.com/labs/gear/enpire/>

## 项目介绍
ENPIRE是一款智能体框架，支持AI编码代理通过闭环的物理试错与进化流程，自主迭代优化真实机器人策略。它通过四个核心模块搭建完整循环：环境管理、策略迭代优化、策略部署测试、失败分析与进化改进，形成「重置→执行→验证→记录→优化」的闭环工作流。
该框架支持两种策略训练方式：通过Python技能脚本实现启发式学习的代码即策略（CaP），以及基于actor/learner pipeline的真实场景RL神经网络策略训练，可复用机器人、感知与校准硬件工具。

## 主要特性
1.  支持真实物理环境下的机器人策略自主迭代优化
2.  集成四大功能模块，覆盖从环境重置到策略进化的完整闭环
3.  兼容启发式学习、RL、BC等多种策略优化范式
4.  支持硬件无依赖示例与真实机器人部署两种运行模式
5.  提供完整的安装、代理使用与真实场景工作流文档
