## 项目概述
EmbodiChain是一个端到端、GPU加速的具身人工智能框架，其核心特点包括：
1. 提供高保真的GPU仿真环境，支持刚性和可变形物体的物理模拟，以及高级光线追踪传感器
2. 统一的机器人学习环境接口，支持模仿学习、强化学习等多种训练范式
3. 可扩展的自动化数据生成管道，高效生成训练数据
4. 模块化的模型架构和高效的训练工作流，加速实验迭代和智能体部署
5. 支持Sim2Real迁移，为真实机器人系统提供无缝的部署方案

该框架处于Alpha开发阶段，持续添加新功能，欢迎社区反馈和贡献，为具身智能的研究和开发提供了完整的解决方案。
