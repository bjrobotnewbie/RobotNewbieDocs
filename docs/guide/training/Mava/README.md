# Mava

🦁 适用于研究的 JAX 多智能体强化学习快速实验代码库

## 项目链接

- GitHub: <https://github.com/instadeepai/Mava>

## 项目介绍
Mava是由InstaDeep研发团队打造的面向研究场景的多智能体强化学习（MARL）代码库，基于JAX实现，支持快速开展分布式多智能体强化学习实验，能够帮助研究人员高效迭代、修改并测试全新算法思路。

## 主要特性
1.  **先进MARL算法实现**：内置多款当前主流的分布式MARL算法，可充分利用硬件加速资源实现高效运行。
2.  **环境封装支持**：原生适配多款JAX生态的MARL环境套件，同时支持通过现有封装模板快速接入新环境。
3.  **标准化统计评估**：原生支持将实验日志导出为符合行业标准的JSON文件，可直接通过MARL-eval工具库进行后续绘图与结果聚合。
4.  基于JAX的单文件实现，兼顾开发速度与运行性能，适配快速科研迭代需求。
