# MetaClaw

- 项目链接：https://github.com/aiming-lab/MetaClaw
- 项目主页：https://arxiv.org/abs/2603.17187

## 项目概述

MetaClaw是一个**机器人夹爪技能元学习进化框架**，核心理念是"只需与你的代理对话——它学习与进化"。主要特点：

1. **受大脑学习启发**：从每次对话中元学习并进化你的夹爪，不需要GPU就能运行
2. **完全异步**： fully asynchronous 设计
3. **不需要GPU集群**：不需要GPU集群就能运行
4. **一键部署**：提供便捷的一键部署流程
5. **技能进化**：支持技能进化，让夹爪在野外环境中不断学习

该项目提出了一种新颖的夹爪技能学习方式，通过对话交互让机器人夹爪不断学习进化，降低了机器人技能学习的门槛。
