## 项目介绍
PARL是一款高性能的强化学习（RL）分布式训练框架，专为强化学习场景设计，支持分布式训练模式，助力RL任务的高效执行。

## 主要特性
- 核心定位为强化学习分布式训练框架，具备高性能特性，适配RL相关的训练需求。
