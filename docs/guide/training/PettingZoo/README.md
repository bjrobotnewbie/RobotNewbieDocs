# PettingZoo

面向多智能体强化学习环境的标准API，内置常用参考环境及相关工具

## 项目链接

- GitHub: <https://github.com/Farama-Foundation/PettingZoo>
- 项目主页: https://pettingzoo.farama.org

## 项目概述

## 项目介绍
PettingZoo是一款Python多智能体强化学习标准API库，对标单智能体领域的Gymnasium，提供了多款主流参考环境与配套工具，用于多智能体强化学习研究。官方文档站点为pettingzoo.farama.org，同时配有公共Discord开发协调社区。

## 主要特性
1.  **环境丰富**：内置Atari、Butterfly、Classic、SISL四类多智能体环境，覆盖合作、竞争、混合收益场景，包含双人街机游戏、自定义协同图形游戏、经典棋牌游戏等
2.  **安装灵活**：支持基础库安装，可按需安装单类环境依赖或全量依赖，官方支持Linux和macOS系统
3.  **配套完善**：提供基础使用教程、自定义环境开发教程，以及CleanRL、Tianshou等主流RL框架的训练示例代码。
