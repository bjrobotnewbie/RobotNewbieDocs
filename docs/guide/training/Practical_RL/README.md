## 项目介绍
Practical_RL是一门面向实际应用的强化学习（RL）公开课程，由俄罗斯高等经济学院（HSE）与Yandex数据学校（YSDA）联合开设，支持英语、俄语双语学习，兼顾校内学生与线上学习者需求。课程以实用为核心，配套实验与作业帮助学习者掌握RL核心方法，提供Google Colab、本地部署、Azure Notebooks等多种运行环境，还包含FAQ、反馈渠道及RL阅读小组等配套资源。

## 主要特性
1. 实用优先：覆盖RL核心问题解决所需的技巧与启发式方法，每个核心知识点配套实践实验
2. 支持探索：对未详细讲解的内容提供拓展资料链接，作业设置 bonus 部分供深入学习
3. 开放协作：欢迎通过Pull Request提交课程改进建议、修正错误、优化代码或适配框架
4. 灵活环境：提供Google Colab、本地依赖安装、Azure Notebooks等多种运行方式，降低使用门槛
