## 项目概述

## 项目介绍
ProRL-Agent-Server（又名Polar）是一款面向真实世界智能体的大规模智能体强化学习（RL）部署框架，可将现有智能体套件直接作为RL可用环境，无需修改原有代码。它采用服务化设计，支持通过异步方式结合任意训练框架扩展RL训练，能够通过并行部署调度大幅节省GPU计算资源。

## 主要特性
1.  **即插即用环境**：直接将现有智能体套件转为RL训练环境，无需修改原有代码
2.  **高效部署流水线**：通过并行部署暂存与运行时池化技术，减少GPU闲置耗时
3.  **服务化异步扩展**：原生支持服务部署模式，可灵活对接各类训练框架实现大规模异步RL训练
4.  支持对接SGLang、vLLM等推理服务，提供可选的可视化仪表盘UI
