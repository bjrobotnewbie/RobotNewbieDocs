# 机器人训练 (Robot Training)

该分类收集机器人训练相关的框架、教程和项目资源，帮助开发者从零开始训练机器人技能模型。

## 项目列表

- [FluxVLA](/guide/training/fluxvla/README.md) - 开源机器人视觉-语言-动作（VLA）框架，提供完整的训练和部署支持
- [Gymnasium-Robotics](/guide/training/gymnasium-robotics/README.md) - 基于 Gymnasium 的机器人强化学习环境集合
- [Habitat Lab](/guide/training/habitat-lab/README.md) - 具身智能研究平台，提供仿真环境和基准任务
- [Isaac Lab](/guide/training/isaaclab/README.md) - NVIDIA 开发的统一模块化机器人学习框架
- [LeRobot](/guide/training/lerobot/README.md) - 开源机器人学习代码库，提供预训练模型和数据集
- [RLinf](/guide/training/rlinf/README.md) - 灵活可扩展的强化学习基础设施，专为基础模型后训练设计
- [RLlib](/guide/training/rllib/README.md) - 开源强化学习框架，支持多种强化学习算法
