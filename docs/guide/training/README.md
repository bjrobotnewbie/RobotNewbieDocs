# 机器人训练 (Robot Training)

该分类收集机器人训练相关的框架、通用 RL 训练库和大模型训练工具，帮助开发者训练机器人技能模型和大语言模型。

## 二级分类

- [大模型训练](./llm-training/README) - LLM 后训练、通用大模型训练和 LLM Agent 训练框架

## 机器人训练框架

- [FluxVLA](./fluxvla/README) - 开源机器人 VLA 训练框架，提供完整训练和部署支持
- [Gymnasium-Robotics](./gymnasium-robotics/README) - 基于 Gymnasium 的机器人 RL 环境集合
- [Habitat Lab](./habitat-lab/README) - Meta 具身 AI 研究平台，提供仿真环境和基准任务
- [Isaac Lab](./isaaclab/README) - NVIDIA 统一模块化机器人学习框架
- [LeRobot](./lerobot/README) - HuggingFace 开源机器人学习框架
- [RLinf](./rlinf/README) - 灵活可扩展的 RL 基础设施，专为具身 AI 后训练设计
- [quadrupedal-agility](./quadrupedal-agility/README) - 四足机器人敏捷运动训练 pipeline
- [EmbodiChain](./EmbodiChain/README) - 端到端 GPU 加速的具身 AI 训练框架
- [AllenAct](./allenact/README) - AI2 模块化具身 AI 研究框架
- [MuscleMimic](./musclemimic/README) - 基于 JAX 的运动模仿学习基准
- [tmrl](./tmrl/README) - 面向实时机器人控制的分布式 RL 框架
- [LeIsaac](./leisaac/README) - LeRobot + IsaacLab 遥操作与策略训练
- [rl_games](./rl_games/README) - 高性能 GPU 加速 RL 训练库，广泛用于机器人学习
