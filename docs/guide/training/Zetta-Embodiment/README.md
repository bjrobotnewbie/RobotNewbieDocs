## 项目概述

## 项目介绍
Zetta是一款高效的闭环具身智能开发框架，支持在线进化基于代码的运行时评判器与恢复技能，同时保持基础策略固定。它在LIBERO-Pro（90.8%）和RoboCasa（93.6%）基准上取得了顶尖性能，推理速度提升11.1倍。

## 主要特性
1.  **核心能力**：在线进化代码化运行时评判器与恢复技能，冻结基础策略，实现高成功率的具身智能任务
2.  **性能表现**：在LIBERO-Pro、RoboCasa基准上达到当前最优水平，推理速度大幅提升
3.  **标准化进化流程**：包含失败轨迹聚类、因果诊断、候选评判恢复包生成、影子回放、种子校验等完整进化协议
4.  **模块化架构**：提供进化引擎、部署运行时、多环境客户端、工具脚本与测试套件，支持快速集成新模型与仿真环境
5.  **已开源内容**：包含Zetta核心框架与Z-Infra，支持LIBERO、RoboCasa环境
