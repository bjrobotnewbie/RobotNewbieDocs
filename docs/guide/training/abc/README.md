## 项目概述

## 项目介绍
ABC是一个面向可扩展行为克隆的开源项目，提供开放数据集、训练流程与评估工具，主打机器人技能学习。项目目前已发布最小化训练 pipeline、数据转换脚本，以及部分模拟与真实任务数据集供用户快速上手，完整代码、VLA训练部署框架与预训练模型将在后续逐步开源。项目提供了官方网站、论文、原始数据集的访问入口。

## 主要特性
1.  **核心功能**：支持基于大规模开放机器人数据的行为克隆训练，可适配箱中取瓶等机器人操作任务，支持模拟与真实场景部署
2.  **技术栈**：基于PyTorch实现，依赖uv进行环境管理，支持多GPU单机训练，集成DINO、CLIP等视觉模型
3.  **数据支持**：提供13万条规模的原始数据集，用户可选择下载示例数据或全量任务数据，同时支持自定义缓存路径
4.  **灵活配置**：通过CLI参数可调整模型隐藏层大小、深度等核心配置，默认提供与预训练 checkpoint 兼容的ABC-DiT XL模型架构
