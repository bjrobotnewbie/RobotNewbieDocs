# amazon-sagemaker-examples

示例 📓 Jupyter笔记本，展示了如何使用🧠 Amazon SageMaker构建、训练和部署机器学习模型。

## 项目链接

- GitHub: <https://github.com/aws/amazon-sagemaker-examples>
- 项目主页: <https://sagemaker-examples.readthedocs.io>

## 项目介绍
本项目是亚马逊官方的Amazon SageMaker示例仓库，提供一系列Jupyter Notebook示例，用于演示如何使用Amazon SageMaker构建、训练和部署机器学习模型。
本仓库分为官方示例库和社区示例库：官方库专注覆盖SageMaker全量功能，由SageMaker团队直接维护；社区库则收录官方库未涵盖的额外示例与参考方案，由AWS工程师和解决方案架构师社区维护。

## 主要特性
1.  覆盖Amazon SageMaker全量核心功能，包含分布式训练、托管部署等关键能力
2.  可快速加载至SageMaker Notebook实例中直接运行，也可少量修改后在本地运行
3.  提供完整的前置环境配置指南，包括AWS账号、IAM权限、S3存储桶等依赖项
4.  官方PR仅收录未覆盖的SageMaker新功能示例，社区贡献请提交至社区仓库
