# awesome-model-based-RL

精选基于模型的强化学习资源列表（持续更新）

## 项目链接

- GitHub: <https://github.com/opendilab/awesome-model-based-RL>

## 项目介绍
本项目是一个持续更新的优质基于模型的强化学习（model-based RL，MBRL）资源集合，核心收录MBRL领域的研究论文，涵盖经典文献及ICML、ICLR、NeurIPS等顶会的最新成果，同时包含算法分类、教程、代码库等相关资源，用于追踪MBRL领域的前沿进展，供相关研究者参考使用。

## 主要特性
1. 资源持续更新，定期同步ICLR、ICML、NeurIPS等顶会的MBRL论文列表，最新更新包含2026年ICLR、ICML论文；
2. 资源分类清晰，涵盖MBRL算法分类、经典论文、顶会论文、教程、代码库等模块；
3. 属于优质资源集合（Awesome）类项目，便于研究者快速检索MBRL领域的核心资料。
