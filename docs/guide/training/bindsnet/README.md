# bindsnet

使用 PyTorch 模拟脉冲神经网络（SNNs）。

## 项目链接

- GitHub: <https://github.com/BindsNET/bindsnet>

## 项目介绍
BindsNET是一款基于PyTorch的脉冲神经网络(SNN)仿真Python库，可在CPU或GPU上运行，面向开发受生物启发的机器学习算法。该库由马萨诸塞大学阿默斯特分校生物启发神经与动态系统(BINDS)实验室以及塔夫茨大学艾伦探索中心用于SNN、机器学习(ML)和强化学习(RL)的相关研究。
项目提供了示例实验、结果分析工具与可视化脚本，完整文档可查阅官方文档站点，同时通过了持续集成与代码安全检测。

## 主要特性
1.  基于PyTorch张量实现SNN仿真，支持CPU/GPU加速
2.  支持受生物启发的ML、RL相关算法研究
3.  提供多渠道安装方式：Poetry环境安装、Pip安装、源码编译、Docker容器部署
4.  兼容OpenAI Gym RL环境
5.  配套示例与完整文档支持
