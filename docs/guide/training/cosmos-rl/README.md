# cosmos-rl

Cosmos-RL 是一个灵活且可扩展的强化学习框架，专为物理人工智能应用设计。

## 项目链接

- GitHub: <https://github.com/nvidia-cosmos/cosmos-rl>

## 项目概述

## 项目介绍
Cosmos-RL是NVIDIA推出的专注于Physical AI应用的灵活可扩展强化学习框架，目前已停止活跃开发，仅会收到有限维护更新，官方推荐用户迁移至新一代的Cosmos 3平台。该框架可支持大规模RL训练工作负载，配套有官方文档。

## 主要特性
1.  **多维度并行支持**：包含张量并行、序列并行、上下文并行、FSDP并行、流水线并行
2.  **全异步架构**：采用训练实例副本（Policy）与生成引擎副本（Rollout）分离的专业化异步部署，支持FP8低精度训练与FP8/FP4低精度推理
3.  **单控制器架构**：通过高效消息系统协调策略与推理副本，支持动态NCCL进程组，可实现容错与弹性的大规模RL训练。
