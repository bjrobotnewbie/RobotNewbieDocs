# deep-rl-class

本仓库包含 Hugging Face 深度强化学习课程。

## 项目链接

- GitHub: <https://github.com/huggingface/deep-rl-class>

## 项目介绍
本项目是Hugging Face出品的深度强化学习课程仓库，包含课程的Markdown文档与实操Jupyter笔记本。课程官网为https://huggingface.co/deep-rl-course/unit0/introduction?fw=pt，大纲页为https://simoninithomas.github.io/deep-rl-course。目前课程处于低维护状态，但理论内容与实操练习仍可正常使用，仅Unit7（AI对战）功能失效、排行榜无法正常运行。

## 主要特性
1.  覆盖深度强化学习的理论与实操全流程，适合系统学习DL+RL相关技术
2.  提供配套的可运行代码练习，帮助学习者快速上手深度强化学习实战
3.  支持社区互助，可通过GitHub Issues查询常见bug的解决方案
4.  可通过星标仓库支持项目维护
