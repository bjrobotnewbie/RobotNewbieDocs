# dimos

Dimensional 是面向物理空间的智能体操作系统。你可以通过自然语言指挥人形机器人、四足机器人、无人机及其他硬件平台，并构建能与物理输入（相机、激光雷达、执行器）无缝协作的多智能体系统。

- 项目主页: <https://dimensionalos.com/>

## 项目概述

## 项目介绍
dimos是面向实体空间的智能体操作系统，也是通用机器人开发的新一代SDK。它支持通过自然语言控制人形机器人、四足机器人、无人机等硬件平台，可搭建本地或云端的多智能体系统，无缝对接摄像头、激光雷达、执行器等物理外设。该项目无需依赖ROS，仅通过Python即可开发物理机器人应用，适配多数机器人厂商的硬件平台，目前处于预发布测试阶段。

## 主要特性
1.  支持自然语言编程控制机器人，采用智能体原生设计
2.  无需ROS，仅用Python即可开发机器人应用
3.  兼容人形、四足、无人机等多类硬件平台
4.  可对接摄像头、激光雷达、电机驱动器等外设，支持感知、空间记忆、控制闭环等功能模块
5.  支持Docker、CUDA、Nix flakes与NixOS环境，适配多种开发部署场景
