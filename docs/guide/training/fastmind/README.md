# fastmind

面向具身AI系统的轻量级事件驱动式多智能体框架。

## 项目链接

- GitHub: <https://github.com/kandada/fastmind>

## 项目概述

## 项目介绍
FastMind是一款轻量级、事件驱动的具身智能多智能体框架，采用LLM+VLA双循环架构，可用于构建具身AI智能体。支持Python 3.10+，基于GPL-3.0开源协议，核心代码约8000行，依赖轻量化。

## 主要特性
1.  **双循环架构**：LLM慢循环负责规划推理，VLA快循环负责实时控制，可并发运行
2.  双通信原语：`Event`处理离散消息，`Signal`处理高频连续数据
3.  类FastAPI装饰器：提供`@app.agent`、`@app.tool`等熟悉的语法
4.  状态图工作流：通过节点、边和条件路由构建智能体流程
5.  事件驱动：基于Asyncio实现无轮询的高性能异步执行
6.  支持人机交互：可中断会话等待人工审批
7.  原生适配感知模块：支持传感器、定时器和外部触发器
8.  多通道动作路由：VLA输出可通过通道名映射到多个执行器
9.  会话隔离：支持多用户，每个会话拥有独立状态
10. 轻量无 heavy 依赖
