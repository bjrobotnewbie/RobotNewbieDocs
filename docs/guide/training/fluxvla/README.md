# FluxVLA

FluxVLA 是一个开源的机器人视觉-语言-动作（VLA）框架，为机器人技能学习提供完整的训练和部署支持。该框架致力于帮助研究者和开发者高效地进行机器人策略学习，并支持从仿真到真实机器人的部署。

## 主要特性

- **完整的工作流支持**：提供从数据准备、模型训练到模型评估和部署的全流程工具链
- **多种部署选项**：支持从零开始安装和阿里云镜像快速启动两种安装方式
- **支持多种任务**：涵盖仿真环境任务训练和真实机器人部署
- **预训练模型支持**：提供预训练模型可直接用于推理和评估
- **详尽的文档**：提供完整的快速入门指南和API文档

## 核心模块

FluxVLA 文档包含以下主要内容：

- **安装指南**：支持多种安装路径，满足不同环境需求
- **数据准备**：详细的数据准备工作流说明
- **模型训练**：完整的模型训练指导
- **模型评估**：标准化的评估工作流
- **推理演示**：使用预训练模型进行推理
- **真实机器人部署**：以 Agilex Cobot Magic 为例的真实机器人训练和部署教程

## 快速开始

根据官方文档，FluxVLA 提供了以下基础指南帮助你快速入门：

1. **安装** - 选择适合你的安装方式，详见 [安装指南](https://fluxvla.limxdynamics.com/md_source/start/installation/index.html)
2. **Libero 推理** - 使用预训练模型在 Libero 任务上进行推理和评估
3. **Libero 训练** - 使用 Libero 数据训练你自己的模型
4. **真实机器人训练与部署** - 以 ALOHA 为例学习真实机器人的训练和部署
