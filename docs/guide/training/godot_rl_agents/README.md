# godot_rl_agents

这是一个开源包，为电子游戏开发者、AI研究者和爱好者提供了为其非玩家角色（NPC）或智能体学习复杂行为的机会。

## 项目链接

- GitHub: <https://github.com/edbeeching/godot_rl_agents>

## 项目概述

## 项目介绍
Godot RL Agents是一个开源工具包，面向游戏开发者、AI研究者和爱好者，用于为游戏中的非玩家角色（NPC）或智能体训练复杂行为。它可以搭建Godot引擎开发的游戏与Python端机器学习算法之间的交互接口，支持通过Ray RLLib框架提供的21种前沿机器学习算法进行训练，兼容2D和3D游戏，还提供配套的AI传感器工具增强智能体的环境感知能力。本项目基于MIT开源协议，完全免费无授权费。

本项目旨在降低游戏AI开发的门槛，让开发者可以端到端完成从创意到落地的AI增强游戏开发，相关研究成果发表于AAAI 2022 Workshop。

## 主要特性
1.  打通Godot游戏与Python机器学习算法的交互链路
2.  支持Ray RLLib提供的21种前沿ML算法
3.  支持基于LSTM或注意力机制的记忆型智能体
4.  兼容2D、3D游戏场景
5.  内置AI传感器套件，丰富智能体观测空间
6.  完全开源免费，无使用限制
