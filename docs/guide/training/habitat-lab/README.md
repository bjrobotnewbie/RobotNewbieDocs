# Habitat Lab

## 资源简介

Habitat Lab 是 Meta AI 开发的模块化高级库，用于训练具身 AI 智能体在各种任务、环境和模拟器中进行视觉导航和交互研究。官方定义为"一个模块化的高级库，用于在各种任务、环境和模拟器中训练具身 AI 智能体"。

## 官方链接

* 官方文档：<https://aihabitat.org/docs/habitat-lab/>
* GitHub仓库：<https://github.com/facebookresearch/habitat-lab>

## 主要特点

* **模块化设计**：任务、环境、模拟器分离，便于定制和扩展
* **丰富任务支持**：支持视觉导航、物体操作、问答等多种具身任务
* **大规模室内场景**：提供真实感极强的室内环境数据集
* **高效仿真**：支持快速仿真和数据采集
* **多模拟器支持**：可与 Habitat-Sim 等仿真器紧密集成

## 支持的机器人平台

* Classic：Cartpole、Humanoid、Ant
* 四足机器人：ANYmal 系列
* 人形机器人：Unitree H1
* 机械臂：UR5、Franka
* 灵巧手：Shadow Hand

## 核心任务类型

* PointGoal 导航
* ObjectGoal 导航
* 视觉语言导航（VLN）
* 物体抓取与操作
* 室内场景重建
* 多智能体协作
