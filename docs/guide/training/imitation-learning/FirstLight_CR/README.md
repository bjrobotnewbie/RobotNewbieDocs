# FirstLight_CR

离线 Clash Royale AI 研究：原生仿真、模仿学习、PPO 及交互式评估。

## 项目链接

- GitHub: <https://github.com/Jaasssoooonnnnn/FirstLight_CR>

## 项目介绍
FirstLight_CR是一个《皇室战争》（Clash Royale）离线AI智能体研究项目，支持从对局回放训练智能体，通过模仿学习（Imitation Learning）和近端策略优化（PPO）强化学习算法实现智能体训练，提供离线对局模拟与交互评测能力，包含预训练模型与完整训练、推理工具链。

## 主要特性
- 原生对战环境：支持无头/渲染执行，提供标准化观测与操作接口
- 模仿学习：可重构Parquet格式回放数据，生成IL训练所需的观测/动作序列
- 自对弈强化学习：带匹配机制、对手池的PPO算法，支持分布式数据采集
- 标准化模型与输入：V4演员-评论家模型，采用卡牌特征、实体关系等多维度输入，训练与推理格式统一
- 交互功能：支持与模型对战、手动控制双方、离线回放查看
- 配套资源：包含预训练模型（通用模型、野猪2.6专属模型）、训练工具、模型架构说明等
