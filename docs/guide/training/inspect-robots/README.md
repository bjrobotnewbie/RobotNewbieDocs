## 项目概述

## 项目介绍
Inspect Robots是一个开源的实体AI评估框架，对标Inspect AI，专注机器人领域。用户只需定义一次机器人基准测试，即可让任意LLM/VLA策略在兼容的实体（真实机械臂、人形机器人）或模拟器上运行测试，同时支持可审计的日志记录（评分结果、LLM对话记录、完整配置）以及Rerun可视化。当前项目处于alpha开发阶段。

## 主要特性
1.  跨策略兼容：支持任意LLM、VLA智能体作为执行策略
2.  多载体适配：可对接真实机械臂/人形机器人或仿真环境
3.  完整可追溯日志：留存评分、LLM对话、配置等全量测试数据
4.  内置可视化：集成Rerun实现流畅的运行时可视化
5.  支持Python3.10~3.13，通过严格类型检查，测试覆盖率100%，采用MIT开源协议。
