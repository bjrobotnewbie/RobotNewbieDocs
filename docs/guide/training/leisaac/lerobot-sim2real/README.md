# lerobot-sim2real

LeRobot sim2real 代码。在快速仿真中训练，零样本将视觉策略部署到真实世界

## 项目链接

- GitHub: <https://github.com/StoneT2000/lerobot-sim2real>

## 项目概述

## 项目介绍
LeRobot sim2real 是一个机器人 sim2real 工具库，支持通过 GPU 并行化仿真平台 ManiSkill 结合强化学习（RL）快速训练视觉策略，并可直接零样本部署到真实机器人环境中。该项目基于 🤗 LeRobot 库开发，后者负责处理所有硬件交互相关代码。用户可通过官方教程完成仿真训练，并直接将训练好的策略应用到真实场景中。

## 主要特性
1.  支持基于 GPU 并行化的快速机器人仿真与渲染，依托 ManiSkill 实现高效训练
2.  实现仿真训练结果零样本直接部署到真实机器人
3.  代码设计简洁易读，便于二次开发与定制
4.  适配 SO100 机械臂等硬件，可结合 🤗 LeRobot 库完成硬件对接

该项目可用于机器人视觉策略的仿真训练与真实部署，适合机器人学、具身智能相关的研究与开发场景。
