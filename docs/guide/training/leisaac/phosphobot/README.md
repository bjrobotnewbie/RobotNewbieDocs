# phosphobot

控制人工智能机器人。社区驱动的 UI 中间件，用于控制机器人、记录数据集、训练动作模型。兼容 SO-100 和 SO-101。

## 项目链接

- GitHub: <https://github.com/phospho-app/phosphobot>
- 项目主页: <https://docs.phospho.ai>

## 项目介绍
phosphobot是一款社区驱动的机器人控制中间件，核心功能是控制AI机器人、采集机器人数据集、训练视觉语言动作（VLA）模型，兼容SO-100、SO-101等多款机器人，支持多操作系统运行，还提供Meta Quest应用用于遥操作。

## 主要特性
- 提供简洁易用的UI界面，支持多种控制方式（键盘、游戏手柄、主从臂、Meta Quest等），可快速采集机器人数据集
- 内置机器人仿真环境，支持快速校准
- 一键训练ACT、smolVLA、π0.5、gr00t-n1.5等动作模型
- 兼容LeRobot、HuggingFace，提供开发者友好的API，支持扩展自定义机器人与相机
- 支持主流相机（普通、深度、立体），适配macOS、Linux、Windows系统
