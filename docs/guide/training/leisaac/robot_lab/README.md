## 项目介绍
robot_lab是基于IsaacLab开发的机器人强化学习（RL）扩展库，支持在独立环境中开发，无需依赖核心Isaac Lab仓库。项目适配Linux 64位、Windows 64位系统，兼容Python 3.11，采用Apache 2.0许可，支持IsaacSim 5.1.0、IsaacLab 2.3.2版本。

## 主要特性
提供多类机器人的强化学习环境，涵盖四足机器人（如Anymal D、Unitree Go2、Unitree B2等）和轮式机器人（如Unitree Go2W），可直接使用对应环境名称（如RobotLab-Isaac-Velocity-Rough-Anymal-D-v0）开展机器人RL相关开发。
