# linesight

AI 在 Trackmania 中运用强化学习

## 项目链接

- GitHub: <https://github.com/Linesight-RL/linesight>
- 项目主页: <https://linesight-rl.github.io/linesight/build/html/>

## 项目介绍
Linesight是一个基于强化学习（RL）的开源项目，核心目标是探索AI在《Trackmania》这款特色赛车游戏中的应用极限。该项目借助Trackmania Interface工具实现与《Trackmania Nations Forever》的编程交互，支持发送操作指令、获取车辆状态与游戏画面等功能，可作为RL算法的测试基准。

## 主要特性
1. 实现了《Trackmania》的高水平AI，2023年5月达到人类驾驶水平，2024年5月首次在官方赛道上打破世界纪录，是目前该领域最先进的AI方案；
2. 适配游戏的离散输入特性，支持DQN等离散输入算法；
3. 提供通用的游戏交互接口，可复用至其他RL项目；
4. 项目开源，鼓励社区参与优化。
