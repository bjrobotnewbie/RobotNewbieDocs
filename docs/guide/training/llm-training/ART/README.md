# ART

ART（Agent Reinforcement Trainer）是 OpenPipe 的智能体强化学习训练框架，用 GRPO 等方法训练多步智能体完成真实任务。

## 项目链接

- GitHub: <https://github.com/OpenPipe/ART>
- 项目主页: https://art.openpipe.ai

## 项目概述

ART 是一个面向多步智能体的强化学习训练框架，目标是让开发者能够针对真实任务定义环境、数据和奖励函数，然后用 GRPO 等策略优化方法提升智能体表现。它关注的不是传统控制环境，而是大语言模型智能体在工具调用、决策流程、游戏任务、业务流程等多步任务中的“在岗训练”。

README 中重点介绍了 W&B Training / Serverless RL 工作流：训练和推理基础设施由服务端管理，用户主要关注任务定义、奖励设计和模型训练配置，从而减少 GPU 环境搭建、并发推理和 DevOps 成本。项目示例中也展示了 Qwen、Llama、GPT-OSS 等基础模型的训练方式。

ART 适合构建和优化 LLM Agent、工具调用智能体、语音/客服/流程自动化智能体，以及需要通过强化学习提升多步骤任务成功率的应用。它的价值在于把 RL 后训练流程包装为更接近应用开发的工具链，使智能体训练从研究实验走向可部署场景。
