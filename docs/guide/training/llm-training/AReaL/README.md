# AReaL

用于基于LLM的智能体应用的RL Bridge。简单易用，灵活通用。

## 项目链接

- GitHub: <https://github.com/areal-project/AReaL>
- 项目主页: <https://areal-ai.io>

## 项目介绍
AReaL是一款面向大模型智能体应用的强化学习（RL）桥接框架，旨在简化并灵活构建AI智能体应用，由清华IIIS与蚂蚁集团AReaL团队开发。它采用全异步RL训练范式，优化了效率与扩展性，专为大规模推理与智能体模型训练设计，目标是让开发者和研究者能够低成本、高效地搭建AI智能体。

## 主要特性
1.  **灵活性强**：支持自定义智能体RL与在线RL训练，仅需替换`base_url`即可适配黑盒智能体应用
2.  **可扩展性佳**：采用行业领先速度的稳定全异步RL训练
3.  **性能顶尖**：在数学、编码、搜索、客服等智能体场景均有出色表现
4.  最新的AReaL 2.0重构为微服务架构，拆分了训练、推理、智能体、权重更新等独立服务，提供了Hermes在线RL循环与端到端SWE RL训练示例。
