# AgentsMeetRL

精选Agentic RL资源列表

## 项目链接

- GitHub: <https://github.com/thinkwee/AgentsMeetRL>
- 项目主页: <https://thinkwee.top/amr/>

## 项目介绍
AgentsMeetRL是一个开源资源精选列表，汇总了使用强化学习（RL）训练大语言模型智能体（LLM Agents）的开源仓库。项目收录标准为支持多轮交互或工具使用的智能体项目，包括工具集成推理（TIR）类项目。
项目附带交互式在线仪表盘，最后更新于2026年6月20日，欢迎通过Issue或PR提交错误反馈与新的项目贡献。

## 主要特性
1.  分类全面：涵盖基础框架、通用智能体、搜索与RAG、Web与GUI、工具调用、代码开发、推理、多智能体、记忆、具身智能、特定领域、奖励与训练、安全、VLM智能体、自我进化、仿真环境等16大细分领域
2.  聚焦技术细节：重点收录项目依赖的RL框架、算法、奖励机制与训练环境，帮助开发者参考技术选型方案
3.  开源免费：所有收录资源均为开源项目，支持免费获取与二次开发
