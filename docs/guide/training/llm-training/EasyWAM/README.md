# EasyWAM

EasyWAM: 一个统一且高效的框架用于训练和评估世界动作模型。

## 项目链接

- GitHub: <https://github.com/OpenMOSS/EasyWAM>
- 项目主页: <http://openmoss.ai/EasyWAM/>

## 项目介绍
EasyWAM是一款用于训练和评估World Action Models（世界动作模型）的统一高效研究代码库，旨在让WAM开发更高效、可复现且易于扩展。它通过统一的工作流串联起模型实现、数据处理、分布式训练、参数高效微调与大规模评估全流程。

## 主要特性
1.  **模块化统一设计**：模块化模型组件共享一致的数据、训练、 checkpoint和评估接口，便于快速集成新的WAM方案。
2.  **高效计算优化**：原生集成FlashAttention 2/3/4加速注意力计算，完整支持LoRA从训练、checkpoint到推理合并的全流程，同时通过BF16、梯度检查点、DeepSpeed ZeRO和PyTorch SDPA优化速度与内存占用。
3.  **端到端流水线优化**：通过稀疏视频解码、索引文本缓存、持久化工作进程、提示缓存和可恢复评估，减少重复工作，加速训练与推理流程。
4.  **易用工作流**：基于Hydra的配置系统、标准化训练评估脚本、分布式启动器、自动GPU分片和结果汇总，简化常规开发流程。
