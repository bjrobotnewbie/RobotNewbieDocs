## 项目概述
Flow-Factory是一个用于扩散和流匹配模型的强化学习框架，提供了统一的实现方式，支持多种模型和算法，适用于具身智能和生成式AI领域的研究和开发，支持多种注意力后端和最新的模型如LTX-2 Audio-Video，能够简化扩散模型的强化学习微调过程。
