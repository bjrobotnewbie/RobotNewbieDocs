# LlamaFactory

100+大语言模型与视觉语言模型的统一高效微调（ACL 2024）

## 项目链接

- GitHub: <https://github.com/hiyouga/LlamaFactory>
- 项目主页: <https://llamafactory.readthedocs.io>

## 项目介绍
LlamaFactory是一个支持100+大语言模型(LLM)和多模态大模型(VLM)统一高效微调的工具，入选ACL 2024。该项目被亚马逊、NVIDIA、阿里云等企业采用，提供了在线试用入口，包括Colab、Hugging Face Spaces等平台。

## 主要特性
1.  支持超100种LLM和VLM的高效微调，兼容主流模型架构
2.  提供轻量化微调方案，降低硬件使用门槛
3.  集成Web可视化界面，方便用户快速完成模型微调、推理等操作
4.  支持多种微调范式，包括全参数微调、LoRA、QLoRA等
5.  提供开箱即用的数据集加载与预处理工具，适配主流训练数据集格式
