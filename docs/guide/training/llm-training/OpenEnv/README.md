# OpenEnv

- 项目主页：https://huggingface.co/docs/openenv/index

## 项目概述

OpenEnv 是 Hugging Face 推出的一个端到端框架，用于创建、部署和使用智能体强化学习训练的隔离执行环境，使用 Gymnasium 风格的简单 API。

这是一个用于训练后 RL 环境接口的库，主要特点：
- 提供简单的 Gymnasium 风格 API
- 支持创建隔离的执行环境，避免训练过程中的环境污染
- 支持远程环境客户端，可灵活部署
- 提供完整教程和示例，包括使用 GRPO 训练 LLM 玩 BlackJack 的完整示例
- 可通过 pip 直接安装

OpenEnv 为智能体强化学习训练提供了基础设施支持，让研究者能够更方便地进行环境管理和实验。
