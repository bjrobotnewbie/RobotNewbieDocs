# RAGEN

LLM 代理框架：基于 StarPO 的多轮强化学习与推理 - 崩塌诊断

## 项目链接

- GitHub: <https://github.com/mll-lab-nu/RAGEN>
- 项目主页: <https://ragen-ai.github.io/>

## 项目介绍
RAGEN（Reasoning AGENT）是一款基于StarPO算法的灵活强化学习框架，用于训练推理型LLM智能体，支持多轮强化学习。它可以诊断智能体强化学习训练的失效模式，比如Echo Trap和reasoning collapse问题，帮助优化RL训练效果。

## 主要特性
1.  专注于推理型LLM智能体的多轮RL训练
2.  内置智能体训练失效模式诊断工具，可以定位如Echo Trap、reasoning collapse这类隐藏问题
3.  提供轻量化干预手段，帮助实现稳定的智能体RL训练
4.  配套有官方论文、项目主页与实验日志等资源，支持快速上手与复现研究。
