# TextWorld

TextWorld 是一个用于训练和评估基于文本的游戏中的强化学习（RL）代理的沙盒学习环境。

## 项目链接

- GitHub: <https://github.com/microsoft/TextWorld>

## 项目介绍
TextWorld是一个沙盒式学习环境，用于在文本游戏中训练和评估强化学习（RL）智能体，同时也是一款可扩展的文本游戏生成工具。它支持Linux和macOS系统的Python 3.9/3.10/3.11/3.12版本，Windows用户可通过Docker使用。用户可通过PyPI或源码安装该工具，还可额外安装可视化依赖来查看游戏状态。

## 主要特性
1.  专为文本游戏场景设计的RL智能体训练、测试环境
2.  可自定义生成各类文本游戏内容
3.  提供可视化工具辅助查看游戏状态
4.  支持通过邮件或Gitter渠道获取技术支持与反馈
