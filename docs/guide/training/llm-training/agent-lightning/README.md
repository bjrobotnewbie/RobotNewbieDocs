# agent-lightning

绝对训练器，点亮 AI 智能体。

## 项目链接

- GitHub: <https://github.com/microsoft/agent-lightning>
- 项目主页: <https://microsoft.github.io/agent-lightning/>

## 项目介绍
Agent Lightning是微软推出的AI智能体训练工具，定位为轻量化的AI智能体训练框架。它支持通过PyPI快速安装，也提供夜间开发版下载，配套完整的官方文档与示例代码，可用于各类AI智能体的优化训练。

## 主要特性
1.  **零侵入式优化**：几乎无需修改原有智能体代码即可完成训练
2.  **框架兼容性强**：支持LangChain、OpenAI Agent SDK、AutoGen、CrewAI、Microsoft Agent Framework等几乎所有主流智能体框架，也可直接用于原生Python OpenAI开发
3.  **灵活优化范围**：可针对多智能体系统中的一个或多个智能体进行选择性优化
4.  **支持多种训练算法**：内置强化学习(RL)、自动提示优化、监督微调等多种优化算法
