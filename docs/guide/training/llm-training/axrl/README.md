## 项目概述

## 项目介绍
AxisRL是一款基于SGLang推理、Megatron训练和真实智能体工作流构建的智能体强化学习（RL）后训练框架。它将高吞吐推理、大规模训练、权重同步、数据迁移、资源调度和可复现调试整合在一个统一框架中，底层依托SGLang和Megatron作为核心服务与训练引擎，自身负责智能体后训练的系统层工作。

## 主要特性
1.  基于SGLang实现高吞吐推理，依托Megatron支持大规模分布式训练
2.  适配多轮轨迹长度超300的智能体RL工作流，可支持千亿参数级模型训练
3.  提供PPO、GRPO/GRPO2、GSPO、TOPR、TIS等多种可配置的策略优化目标
4.  同时支持白盒智能体环境和通过OpenAI兼容代理实现的黑盒测试环境
5.  通过部分推理和轻量控制平面减少推理/训练空闲时间
6.  提供句柄式数据迁移、上下文打包、路由回放、失配分析和峰值回放功能，保障推理与训练一致性
