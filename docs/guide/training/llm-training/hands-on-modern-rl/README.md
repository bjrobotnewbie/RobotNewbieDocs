# hands-on-modern-rl

🚀 一门开源的实操课程，填补了从基础RL概念到LLM对齐、RLVR与高级智能体系统之间的知识缺口。

## 项目链接

- GitHub: <https://github.com/walkinglabs/hands-on-modern-rl>
- 项目主页: <https://walkinglabs.github.io/hands-on-modern-rl/>

## 项目介绍
本项目是一个开源的实践导向型现代强化学习（RL）教程，旨在帮助学习者从基础RL概念过渡到LLM对齐、RLVR以及高级智能体系统。项目提供在线课程与PDF下载，基于VitePress构建，要求Node >=18环境，采用CC BY-NC-SA 4.0开源协议。

## 主要特性
1.  **清晰学习路径**：从基础到前沿主题的完整学习地图，通过章节树快速导航
2.  **代码逐行讲解**：针对PPO、DPO、GRPO等算法实现提供公式与代码的对应映射
3.  **训练可视化**：附带训练指标曲线、解释与故障排查指引，支持实验调试
4.  **覆盖前沿方向**：包含经典控制、LLM后训练、多模态智能体等全链路内容
5.  附带配套实验代码，支持快速上手实践
