# notebooks

250+ 面向文本、视觉、音频、嵌入、TTS模型的微调与RL Notebook。

## 项目链接

- GitHub: <https://github.com/unslothai/notebooks>
- 项目主页: <https://unsloth.ai/docs>

## 项目介绍
本项目是Unsloth官方推出的Notebooks仓库，提供250+个针对文本、视觉、音频、嵌入模型、TTS模型的微调与强化学习（RL）教程脚本，全部可在Google Colab运行，也支持本地部署，涵盖数据预处理、模型训练、推理全流程，附带官方微调指南与文档支持。

## 主要特性
1.  覆盖多模态模型类型：包含Gemma 4、Qwen3.5等主流视觉、文本模型，以及Unsloth Studio聊天UI工具
2.  提供一键Colab运行入口，降低部署门槛
3.  涵盖完整模型开发链路，从数据准备到推理全流程覆盖
4.  附带官方文档与社区Discord支持渠道
