RAX 框架：通过在线探索学习机器人任务的编码智能体

## 项目链接

- GitHub: <https://github.com/robot-agent-exploration/rax>

## 项目介绍
RAX是面向机器人智能体的在线探索扩展框架，核心是通过在线探索让编码智能体学习机器人任务，相关研究成果已发布arXiv论文，配套提供项目网页、机器人任务演示视频、技能库及机器人会话日志数据集，支持本地部署大模型驱动机器人。

## 主要特性
1. 支持多类大模型（DeepSeek、Kimi、Codex、Claude Code等）的本地部署与调用，无需依赖托管API
2. 适配机器人任务的在线探索学习场景，可驱动机器人完成各类任务
3. 提供配套的技能库与会话日志数据集，便于研究与开发使用
