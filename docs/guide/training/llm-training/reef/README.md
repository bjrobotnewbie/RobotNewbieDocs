# reef

持续学习基础设施：自改进智能体

## 项目链接

- GitHub: <https://github.com/Human-Agent-Society/reef>
- 项目主页: <reefinfra.ai>

## 项目介绍
Reef是首个面向自我进化智能体的开源持续学习基础设施，用于连接智能体推理、反馈、学习与版本化交付。它支持通过Slime、SGLang等工具训练模型权重，也可优化智能体的提示词、规则、技能等整体框架。适用于需要让智能体通过交互反馈持续自我提升的场景。

## 主要特性
1.  覆盖模型权重训练、智能体框架优化、测试时训练三类核心使用场景
2.  支持服务线上流量、训练模型权重、版本管理、在线更新以及技能/框架进化
3.  可适配vLLM、SGLang等推理引擎，以及Slime、veRL等RL训练框架
4.  支持Python 3.12+，采用Apache-2.0开源协议，可通过PyPI包`reef-infra`快速安装
