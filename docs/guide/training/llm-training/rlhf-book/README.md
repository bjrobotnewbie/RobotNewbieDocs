# rlhf-book

基于人类反馈的强化学习教科书

## 项目链接

- GitHub: <https://github.com/natolambert/rlhf-book>
- 项目主页: <https://rlhfbook.com/>

## 项目介绍
本项目是一本关于人类反馈强化学习（RLHF）的开源教科书，同时也是对后训练大语言模型的全面入门指南。作者分享了自己在开源大模型前沿领域积累的专业知识，填补了拒绝采样等经典方法缺乏权威参考、角色训练等行业实践无公开研究资料的空白。项目提供在线阅读渠道，实体书可在Manning和亚马逊购买，同时设有Discord社区供学习者交流。仓库包含书籍源码、参考实现代码、绘图源文件以及教学材料等内容。

## 主要特性
1.  覆盖RLHF全流程相关技术，包含指令微调（SFT）、策略梯度（PPO、REINFORCE、GRPO、RLOO）、奖励模型训练、DPO及其变体、拒绝采样、模型蒸馏等算法的参考实现
2.  提供完整的书籍构建系统与多格式输出支持
3.  附带绘图源文件与教学素材，可作为相关课程的辅助资源
4.  开源社区驱动，鼓励用户反馈与贡献
