# unsloth

Unsloth 是用于本地运行、微调和强化学习训练开源模型的工具集，提供 Studio 图形界面与 Core 代码接口。

## 项目链接

- GitHub: <https://github.com/unslothai/unsloth>
- 项目主页: https://unsloth.ai/docs

## 项目概述

Unsloth 关注让用户更高效地在本地训练和运行开源大模型。Unsloth Studio 提供面向 Windows、Linux、WSL 和 macOS 的 Web 界面，支持模型搜索、下载、运行、导出、工具调用、代码执行、API 服务和可视化数据处理；Unsloth Core 则提供代码方式的微调和训练能力。

项目的核心卖点是训练效率和显存节省，支持数百种文本、视觉、音频和 embedding 模型，并覆盖全量微调、LoRA、预训练、4-bit/16-bit、FP8 以及 GRPO 等强化学习流程。它适合希望在消费级或本地硬件上快速微调、部署和实验开源模型的用户，也适合需要更低显存成本进行大模型后训练的团队。
