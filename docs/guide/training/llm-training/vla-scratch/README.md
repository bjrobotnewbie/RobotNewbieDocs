# vla-scratch

## 项目链接

- GitHub: <https://github.com/EGalahad/vla-scratch>

## 项目介绍
VLA-Scratch是一个模块化、高性能且轻依赖的工具栈，用于快速上手训练、评估和部署视觉语言动作（VLA）模型，依赖PyTorch FSDP2、TensorDict等技术，提供了官方预训练 checkpoint 下载渠道。

## 主要特性
1.  **标准化数据模型**：使用`TensorClass`定义模块间明确的数据边界，实现全类型化模块化开发，支持多异构数据集联合训练，清晰定义数据集、策略与转换模块间的数据流转。
2.  **针对性性能优化**：重写VLM前向传播流程消除主机-设备同步开销，不依赖通用加速库，直接使用PyTorch原生FSDP2、梯度检查点等能力做专属性能调优。
3.  **开箱即用的丰富功能**：支持多源数据集联合训练，兼容Qwen3-VL、PaliGemma 1/2、SmolVLM等多款视觉语言模型作为骨干网络。

项目支持通过uv管理依赖，提供了训练、评估、部署的快速启动命令，可用于机器人视觉语言策略模型的开发与落地。
