# loco-mujoco

基于 MuJoCo 的复杂动作模仿学习基准，专注于使用强化学习（RL）进行复杂运动任务。

## 项目概述

## 项目介绍
LocoMuJoCo是一个专注于复杂运动控制任务的模仿学习基准测试套件，基于MuJoCo开发。它提供了丰富的四足机器人、人形机器人以及生物力学骨骼人体模型环境，每个环境附带超22000条运动捕捉数据集。项目不仅支持模仿学习，还可自定义奖励函数，同样适用于纯强化学习场景，兼容Gymnasium接口。最新v1.1版本新增了MjWarp后端，可在兼容GPU上实现更快的并行仿真。

## 主要特性
1.  支持MuJoCo单环境仿真与MJX/MJWarp并行仿真
2.  包含12个人形、4个四足机器人环境，内置4种生物力学人体模型
3.  提供基于JAX的简洁单文件算法实现，涵盖PPO、GAIL、AMP、DeepMimic等主流算法
4.  将训练与环境编译为统一JIT函数，训练速度极快
5.  内置AMASS、LAFAN1等超22000条运动捕捉数据集，支持机器人间运动数据重定向
6.  集成动态时间规整、离散弗雷歇距离等JAX实现的轨迹对比指标
7.  支持领域与地形随机化，采用模块化设计可灵活替换观测、奖励、终止条件等组件
8.  提供完整的官方文档支持
