# meltingpot

多智能体强化学习测试场景套件。

## 项目链接

- GitHub: <https://github.com/google-deepmind/meltingpot>

## 项目概述

## 项目介绍
Melting Pot是由DeepMind推出的多智能体强化学习测试场景套件，用于评估智能体在新型社交场景下的泛化能力，可测试合作、竞争、欺骗、信任等多种社会交互行为。
它提供了超过50个多智能体RL基础场景（substrates）用于训练智能体，以及256+专属测试场景用于评估训练后的智能体，通过测试结果可以量化智能体在陌生交互对象与未知社交场景中的表现，以此对比不同多智能体RL算法的泛化能力，是多智能体强化学习领域的标准基准测试套件之一。

## 主要特性
1.  覆盖50+多智能体游戏基础场景与256+专属测试场景
2.  支持测试合作、竞争、欺骗等多种社会交互场景
3.  可量化评估智能体对陌生社交场景与陌生交互对象的泛化能力
4.  基于DeepMind Lab2D构建，可通过PyPI快速安装使用
