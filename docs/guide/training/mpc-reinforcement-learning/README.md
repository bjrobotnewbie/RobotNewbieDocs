# mpc-reinforcement-learning

- 项目链接：https://github.com/FilippoAiraldi/mpc-reinforcement-learning
PyPI页面：https://pypi.org/project/mpcrl/

## 项目概述
mpc-reinforcement-learning（简称mpcrl）是一个用于训练基于模型的强化学习代理的库，其核心是使用模型预测控制（MPC）作为函数近似方法。核心特点包括：
1. 专注于模型预测控制与强化学习的结合，提供高效的训练流程
2. 支持Python 3.11及以上版本，通过PyPI可直接安装
3. 提供完整的在线文档和测试覆盖率，保证代码质量
4. 支持多种强化学习场景和模型预测控制算法
5. 活跃的社区维护和持续的更新

该库为研究人员和开发者提供了便捷的工具，用于开发和测试基于模型预测控制的强化学习解决方案。
