## 项目概述

quadrupedal-agility是论文**"Learning Diverse Natural Behaviors for Enhancing the Agility of Quadrupedal Robots"**的官方实现，致力于增强四足机器人的敏捷性。主要内容包括：

1. **行为多样性学习**：通过学习多样化自然行为来提升四足机器人的敏捷性
2. **完整训练流程**：开源了BBC训练流程、TSC-teacher、TSC-student、EASI等训练pipeline
3. **部署支持**：提供完整的部署pipeline，已经在真实四足机器人上验证
4. **基于Isaac Gym**：使用Isaac Gym进行仿真训练

该项目提出了一套提升四足机器人敏捷性的学习方法，实验证明能够让四足机器人展现出更多样化的自然行为，提升运动能力。
