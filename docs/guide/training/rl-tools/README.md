# rl-tools

深度学习最快的库

## 项目链接

- GitHub: <https://github.com/rl-tools/rl-tools>
- 项目主页: <https://rl.tools>

## 项目介绍
rl-tools是一款宣称是当前最快的深度强化学习库，提供了官方文档、在线浏览器演示、示例模型库Zoo以及训练工作室Studio等配套工具。它支持在本地快速训练强化学习智能体，例如在2020款MacBook Pro(M1)上，可在18秒内完成飞行控制任务训练，也能高效完成倒立摆、赛车、多任务机器人等场景的训练。

## 主要特性
1.  极致训练速度，主打业界最快的深度RL训练性能
2.  支持SAC、TD3、PPO、多智能体PPO等主流强化学习算法
3.  内置Mujoco等经典强化学习环境
4.  提供Python接口、在线可运行教程，支持Binder和Colab快速体验
5.  配套完善的官方文档与社区Discord交流渠道，通过了单元测试与代码覆盖率检验。
