# rl

TorchRL 是 PyTorch 原生的强化学习工具库，提供可组合的数据结构、环境、采集器、损失函数和训练组件。

## 项目链接

- GitHub: <https://github.com/pytorch/rl>
- 项目主页: https://pytorch.org/rl

## 项目概述

TorchRL 是 PyTorch 官方生态中的强化学习库，面向强化学习、决策、机器人和仿真任务。它不是单一算法仓库，而是一组可组合的基础组件，帮助研究者和工程师用接近 PyTorch 的编程方式搭建从原型到分布式训练的 RL 系统。

项目围绕 TensorDict 数据模型组织训练流程，使数据在采样、回放、模型、损失函数和设备迁移过程中保持命名、结构、批维度和设备信息。README 中强调环境、策略、回放缓冲区、目标函数和采集器都应当是可替换模块，这让用户可以在不重写整体训练栈的情况下切换算法、环境或并行方式。

TorchRL 适合 MuJoCo 控制、多智能体训练、循环强化学习、离线强化学习、模型式强化学习和机器人控制实验。它提供教程、API 文档、示例和 benchmark，并与 PyTorch、TensorDict 等生态紧密结合，适合作为现代 RL 研究和工程项目的基础库。
