# RLinf

RLinf 是一个灵活可扩展的开源基础设施，专为基础模型的强化学习后训练设计。"inf" 代表 `Infrastructure`，强调它作为下一代训练坚实骨干的作用；同时也代表 `Infinite`，象征系统支持开放式学习、持续泛化和智能发展的无限可能。

## 核心特性

### 架构设计
- **Macro-to-Micro Flow (M2Flow)**：一种新范式，通过微观执行流执行宏观逻辑流，将逻辑工作流构建（可编程）与物理通信和调度（高效）解耦

### 灵活的执行模式
- **Collocated 模式**：所有工作器共享所有 GPU
- **Disaggregated 模式**：支持细粒度流水线
- **Hybrid 模式**：可定制组合不同放置模式，整合同地和分解两种模式

### 自动调度
- **动态调度**：动态调度资源分配，最大化资源利用率
- **静态调度**：根据训练负载自动选择最合适的执行模式，无需手动资源分配

### 性能优势
- **混合模式细粒度流水线**：相比其他框架实现 **120%+** 的吞吐量提升
- **自动在线扩展策略**：动态扩展训练资源，GPU 切换在数秒内完成，在保持 RL 算法 on-policy 特性的同时进一步提升效率 20-40%

### 具身智能支持
- 对主流 VLA 模型提供快速适配支持：OpenVLA、OpenVLA-OFT、π₀、GR00T-N1.5
- 通过标准化 RL 接口支持主流 CPU/GPU 模拟器：ManiSkill3、LIBERO、IsaacLab
- 首次实现了 π₀ 模型家族结合流匹配动作专家的 RL 微调

### 易用性和灵活性
- **多后端集成**
  - FSDP + Hugging Face：快速适配新模型和算法，适合初学者和快速原型开发
  - Megatron + SGLang：针对大规模训练优化，为有复杂工作负载的专家用户提供最大效率
- 异步通道自适应通信
- 内置支持流行 RL 方法，包括 PPO、GRPO、DAPO、Reinforce++ 等
