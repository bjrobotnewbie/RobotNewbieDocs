# sample-factory

高吞吐量同步与异步强化学习

## 项目链接

- GitHub: <https://github.com/alex-petrenko/sample-factory>

## 项目介绍
Sample Factory是一款高性能强化学习（RL）代码库，专注于实现高效的同步与异步策略梯度算法（PPO），是目前速度最快的RL库之一。该项目经过充分测试，被众多研究者和从业者使用，可在ViZDoom、IsaacGym、DMLab-30、Megaverse、Mujoco、Atari等多种领域达到SOTA性能，同时能显著减少训练时间与硬件需求。

## 主要特性
1. 支持同步与异步两种模式的PPO算法实现
2. 高性能设计，训练效率高、硬件需求低
3. 适配多种RL环境，涵盖游戏、机器人、连续控制等多个领域
4. 提供完善的文档、论文参考及社区支持（Discord）
5. 遵循规范代码风格，具备持续集成测试保障代码质量
