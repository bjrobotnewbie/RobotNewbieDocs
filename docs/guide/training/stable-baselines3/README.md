## 项目概述

Stable Baselines3 (SB3) 是**基于PyTorch的可靠强化学习算法实现集合**。这是Stable Baselines的下一个主要版本，提供了多种经典RL算法的可靠实现：

1. **可靠实现**：提供经过验证的强化学习算法实现，方便研究社区复现、改进和验证新思路
2. **易用性**：实现简单，初学者也能使用这个高级工具集进行实验
3. **文档完善**：提供完整文档，方便学习和使用
4. **持续集成**：GitHub Actions CI保证代码质量

该库已经成为强化学习研究领域非常流行的基础库，为机器人强化学习研究提供了很好的基础。
