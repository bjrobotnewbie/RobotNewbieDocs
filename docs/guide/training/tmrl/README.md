# tmrl

TMRL 是面向实时机器人控制与 TrackMania 自动驾驶示例的分布式强化学习框架。

## 项目链接

- GitHub: <https://github.com/trackmania-rl/tmrl>
- 项目主页: https://pypi.org/project/tmrl

## 项目概述

TMRL 是一个用于实时应用的分布式强化学习框架，目标是帮助开发者训练能够直接作用于实时环境的深度强化学习智能体。项目以 TrackMania 2020 游戏中的自动驾驶为代表性示例，同时也把自身定位为可用于机器人和工业实时控制任务的 Python 强化学习库。

项目提供了从环境封装、远程训练架构、实时 Gym 接口到示例训练流程的一整套工具。对于 TrackMania 用户，它内置自驾驶训练管线、LIDAR/视觉等观测形式、比赛相关说明和预训练演示；对于机器学习和机器人开发者，它提供可改造的实时控制框架，便于构建面向无人机、车辆或其他实时系统的专用 RL 流水线。

TMRL 的特点是把训练端、采样端和真实/仿真环境之间的交互组织为分布式结构，适合处理实时控制中常见的延迟、采样频率和环境连接问题。它适用于强化学习教学、实时控制原型验证、游戏自动驾驶研究，以及需要把 SAC、REDQ 等算法迁移到实际控制循环中的实验项目。
