## 项目介绍
本项目是MME-VLA-Suite，聚焦于机器人策略学习与评估，依托ROS等技术，为机器人领域提供了完整的策略训练、评估工具链，配套有官方网站、论文、基准仓库、数据集、预训练模型及排行榜，可支持机器人相关的策略开发与性能验证。

## 主要特性
1. 提供多类安装方式，支持uv、docker部署；
2. 支持模型训练，涵盖π₀.₅基线、MME-VLA策略、VLM子目标预测器的训练流程；
3. 提供两种评估方式，集成脚本评估与单模型手动评估；
4. 配套完整资源，包含训练数据、预训练模型、微调VLA/VLM检查点，可直接用于开发与测试。
