# vowpal_wabbit

Vowpal Wabbit 是一个机器学习系统，利用在线、哈希、allreduce、归约、学习2搜索、主动学习和交互式学习等技术，推动机器学习的前沿。

## 项目概述

## 项目介绍
Vowpal Wabbit是一款高性能在线机器学习系统，主打前沿机器学习技术，涵盖在线学习、哈希技巧、allreduce、特征约简、learning2search、主动学习与交互式学习等方向，尤其强化了上下文多臂老虎机算法的实现，适配在线强化学习场景。它支持跨Linux、macOS、Windows平台编译运行，内存占用与训练数据量解耦，可高效处理大规模数据集。

## 主要特性
1.  **灵活输入格式**：支持自由文本特征的词袋式解析，还可通过命名空间实现多组文本特征输入
2.  **高性能**：基础实现为稀疏梯度下降算法，整体运行速度快，内置多种优化算法可选
3.  **高可扩展性**：内存占用不随训练数据量增长，通过哈希技巧限制特征集合规模，无需提前加载全量训练集到内存
4.  **特征交互能力**：可自动对特征子集进行交叉组合，适配排序类任务，避免显式特征展开带来的计算与空间开销
