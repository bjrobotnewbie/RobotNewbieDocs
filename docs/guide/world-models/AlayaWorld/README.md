# AlayaWorld

全栈开源交互式长时世界模型。

## 项目链接

- GitHub: <https://github.com/AlayaLab/AlayaWorld>

## 项目介绍
AlayaWorld是一款全栈开源交互式长时序视频世界模型，支持实时相机控制、提示词切换和长时序记忆一致性，可生成可交互的长时序视频世界。项目提供了网页在线演示、完整训练与推理代码、预训练权重以及部分训练数据，相关技术报告已在arXiv发布。

## 主要特性
1.  支持实时交互：可通过键盘操控相机视角，在生成过程中切换提示词
2.  完整开源栈：涵盖推理、训练代码，v1.1版本权重与部分训练数据已开源
3.  长时序一致性：保证长时序生成内容的记忆连贯性
4.  支持AR与DMD两种模型架构，可部署于浏览器端实现实时流式生成
