# Awesome-Interactive-World-Model

交互式视频世界模型的全面综述

## 项目链接

- GitHub: <https://github.com/liujiuming123/Awesome-Interactive-World-Model>

## 项目介绍
本项目是交互式视频世界建模领域的精选综述资源库，配套同名综述论文，收录了该领域的论文、代码库与行业产品资源。支持三种浏览方式：按应用领域（开放世界探索、游戏引擎、自动驾驶、具身AI等）、按行业产品（Genie、Happy Oyster等）、按技术主题（发展趋势、可控性、长时序、记忆机制、实时效率等）。项目团队来自剑桥大学、北京大学、加州大学伯克利分校等多所海内外高校。

## 主要特性
1.  系统化整理交互式视频世界建模领域的前沿研究与落地资源
2.  提供多维度分类浏览方式，方便不同需求的开发者、研究者快速定位相关内容
3.  持续更新最新开源论文、产品、数据集与基准测试成果
4.  覆盖从学术研究到工业落地的全链路相关资源
