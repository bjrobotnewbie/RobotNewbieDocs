# Awesome-Memory-for-Robotics

机器人领域的记忆研究阅读清单

## 项目链接

- GitHub: <https://github.com/Everloom-129/Awesome-Memory-for-Robotics>

## 项目介绍
Awesome-Memory-for-Robotics 是一个机器人记忆领域的研究资源汇总列表，聚焦于机器人专用记忆技术（非通用大语言模型记忆），涵盖相关论文、代码、数据集与基准测试资源，旨在为机器人感知、规划、决策提供经验存储、检索与利用的技术支撑，助力机器人在复杂动态环境中学习适应。

## 主要特性
1. 分类清晰：按记忆类型（上下文记忆、 episodic记忆、语义记忆、长期记忆等）、机器人任务（操作、导航、运动等）及技术方向（空间记忆与SLAM、世界模型、终身学习等）划分资源类别；
2. 持续更新：定期补充最新研究成果，扩展基础模型、操作、基准测试等领域的覆盖范围；
3. 资源全面：包含综述、具体记忆系统架构、任务专用记忆方案、评估基准及数据集等多类研究资料。
