# Awesome-Physics-Cognition-based-Video-Generation

- 项目链接：https://github.com/minnie-lin/Awesome-Physics-Cognition-based-Video-Generation
- 项目主页：https://arxiv.org/abs/2503.21765

## 项目概述

这是一份**基于物理认知的视频生成领域研究论文清单**，整理了该方向的相关论文、代码和资源，配合同名综述论文使用。主要内容包括：

1. **分类体系**：按照研究方向分为：基础示意感知、物理知识被动认知、世界模拟主动认知、数据集基准与评测指标等
2. **覆盖范围**：涵盖T2V、V2V、基于物理的动态3D/4D生成，也包含相关的世界模型和世界模拟器研究
3. **活跃更新**：持续收录最新研究，欢迎社区贡献PR
4. **配套综述**：配合arXiv综述论文《Exploring the Evolution of Physics Cognition in Video Generation: A Survey》，系统梳理该领域发展脉络

该仓库为对物理感知视频生成和世界模型感兴趣的研究者提供了很好的文献导航。
