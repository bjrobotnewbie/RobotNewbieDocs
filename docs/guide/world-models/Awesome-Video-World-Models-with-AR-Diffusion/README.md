# Awesome-Video-World-Models-with-AR-Diffusion

精选的超现实视频世界模型列表：涵盖算法、应用与基础设施，旨在为研究人员、从业者及爱好者提供全面的资源。

## 项目链接

- GitHub: <https://github.com/gracezhao1997/Awesome-Video-World-Models-with-AR-Diffusion>

## 项目介绍
本项目是一个关于**AR Diffusion（自回归扩散）视频世界模型**的精选资源列表，面向研究者、开发者和爱好者，涵盖相关算法、应用与基础设施，旨在提供全面的学习参考资料，且每周更新。
项目附带开源全栈框架minWM，可实现从双向文本生成视频基础模型到动作条件视频世界模型的端到端开发，包含示例数据、可运行脚本、实操经验和入门指南。

## 主要特性
1.  **结构化分类体系**：从算法基础、实际应用、基础设施加速三个维度整理该领域的完整生态，覆盖从模型设计到实时交互部署的全栈内容。
2.  **一站式引用资源**：提供整合了所有收录论文的BibTeX文件，可一键导入LaTeX或Zotero项目。
