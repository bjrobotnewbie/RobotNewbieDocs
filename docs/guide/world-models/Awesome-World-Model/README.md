# Awesome-World-Model

- 项目链接：https://github.com/LMD0311/Awesome-World-Model
- 项目主页：https://arxiv.org/abs/2502.10498

## 项目概述

Awesome-World-Model是专门针对**自动驾驶领域世界模型研究的论文收集清单**，配合综述论文《The Role of World Models in Shaping Autonomous Driving: A Comprehensive Survey》使用。主要内容包括：

1. **系统性整理**：记录、追踪和整理近年来自动驾驶和机器人领域的世界模型方法
2. **持续更新**：欢迎社区提交PR补充遗漏的论文，保持内容的全面性
3. **配套综述**：配合综述论文系统阐述世界模型在自动驾驶中的作用，帮助研究者理解领域发展脉络

该仓库是研究自动驾驶世界模型非常好的入门资源，方便快速了解该方向的研究进展。
