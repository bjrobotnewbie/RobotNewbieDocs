# Awesome-World-Models

- 项目链接：https://github.com/knightnemo/Awesome-World-Models

## 项目概述

Awesome-World-Models是一份**世界建模领域精选佳作的综合清单**，旨在为研究者、从业者及爱好者提供一站式世界建模资源。该项目整合了多个领域的世界模型相关研究，主要内容：

1. **覆盖广泛应用**：包含具身智能、自动驾驶、自然语言处理、智能体等多个领域的世界模型研究
2. **整理完善**：整合了原Awesome-World-Model-for-Autonomous-Driving和Awesome-World-Model-for-Robotics，并持续扩展更新
3. **便捷访问**：每个条目都提供arXiv论文、项目网站和代码链接，方便快速查找资源
4. **活跃维护**：社区开放贡献，持续更新最新研究进展

该项目已获得1k+ GitHub Stars，是世界建模领域非常有价值的资源汇总。
