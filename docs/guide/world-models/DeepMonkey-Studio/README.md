# DeepMonkey-Studio

从 Vibe Coding 到 Vibe World：面向元宇宙、科学及世界模型的 AI 原生可编程三维世界开源底座

## 项目链接

- GitHub: <https://github.com/fatasia/DeepMonkey-Studio>
- 项目主页: <https://fatasia.github.io/DeepMonkey-Studio/>

## 项目介绍
DeepMonkey-Studio是一款面向元宇宙、AI for Science、世界模型的开源AI原生可编程三维世界底座，定位为通用技术底座而非数字孪生平台。项目支持Web、Windows、Android多平台，采用TypeScript、Rust、React、WebGPU等技术栈，底层自研引擎对WebGPU、渲染、工业与BIM模型做了优化，可作为独立SDK使用，上层包含2D/3D编辑器、脚本编辑器及插件，还提供模型接入、AI工作流等能力，支持Docker一键部署。

## 主要特性
1. 多端适配：支持Web、Windows、Android平台，提供在线体验与本地下载部署方式
2. 灵活渲染：可切换WebGL 2、Deep WebGPU、Deep WASM多种渲染引擎
3. 开源协议：采用带伦理限制的MIT协议，禁止忽视员工人权的特定企业使用
4. 丰富工具：内置SMT产线、275项模型与环境材质，提供示例数据与素材包，支持AI开发相关的Skill、MCP与SDK能力
