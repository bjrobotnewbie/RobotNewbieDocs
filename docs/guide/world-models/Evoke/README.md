# Evoke

EVOKE 官方实现：具有有限状态和长时监督的无限交互式世界。一种无需 CFG 的三步交互世界模型。在 WBench 上达到 SOTA 水平。

## 项目链接

- GitHub: <https://github.com/AlayaLab/Evoke>

## 项目介绍
Evoke是Alaya Lab推出的无分类器引导（CFG-free）交互式世界模型官方实现，采用三步式架构，在WBench榜单上达到SOTA水平。它可实现长时序视频生成，单张H200显卡下2.11秒可生成1.5秒的384×640分辨率视频，后续还推出了Evoke-Turbo优化版本，以及支持交互式探索的UI，五张H200下平均1.34秒即可生成1.5秒视频块。

## 主要特性
1.  **性能顶尖**：在WBench上达到当前最优水平，同时在VBench-Long和VBench-2.0上视觉质量表现出色
2.  **高效无CFG**：仅需单步前向传播，三步架构兼顾速度与效果
3.  **无限长时序**：通过外部相机索引世界状态库存储场景几何，上下文大小不受会话时长限制
4.  **可中途调整指令**：支持在生成过程中修改提示词，无需中断重启
5.  **长时序监督友好**：采用分块分组、远帧检索和线性注意力全局状态，内存与计算开销随时长线性增长，支持30秒长时序自监督训练
