# ForgeWM

使用 8 张 GPU 训练实时可玩的视频世界模型，支持键盘与鼠标及游戏手柄控制，完全开源且可复现。

## 项目链接

- GitHub: <https://github.com/asdfo123/ForgeWM>
- 项目主页: <https://asdfo123.github.io/ForgeWM/>

## 项目介绍
ForgeWM是一个开源的端到端少步动作条件视频世界模型训练方案，可以生成可实时交互的视频世界模型，支持通过键盘、鼠标或游戏手柄进行操控。该项目基于Causal Forcing蒸馏范式，搭载游戏原生I2V主干网络Matrix-Game 2，使用GameFactory开源数据集训练，可在8块GPU上复现，同时提供了完整训练代码、模型权重和预编码数据。

## 主要特性
1.  **实时交互**：单张H20显卡可实现72 FPS的推理速度，单块数据处理延迟仅168ms
2.  **少步模型支持**：提供1步、2步、4步三种规格的学生模型（ForgeWM-1/-2/-4）
3.  **渐进式训练流程**：包含双向SFT、教师强制因果自回归、一致性蒸馏、在线策略DMD四个训练阶段
4.  **跨域迁移**：仅需调整动作接口即可将训练方案移植到第一人称射击游戏等其他游戏场景
5.  **完全开源可复现**：配套公开数据集、模型权重和完整训练代码
