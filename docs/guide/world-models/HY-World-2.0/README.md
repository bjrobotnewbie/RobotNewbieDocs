# HY-World-2.0

HY-World 2.0：用于重建、生成和模拟 3D 世界的多模态世界模型

## 项目链接

- GitHub: <https://github.com/Tencent-Hunyuan/HY-World-2.0>
- 项目主页: <https://3d-models.hunyuan.tencent.com/world/>

## 项目介绍
HY-World 2.0是腾讯混元推出的多模态世界模型框架，可用于3D世界重建与生成。它支持文本、单视图图像、多视图图像、视频等多种输入模态，可以输出网格模型、高斯溅射等3D世界表征，还支持3D世界模拟。项目提供了官方在线体验站点、HuggingFace/ModelScope模型仓库以及技术报告链接。

## 主要特性
1.  支持多模态输入，可完成从文本、图像到3D世界的转换
2.  已开源WorldMirror 2.0、HY-Pano 2.0、WorldStereo 2.0等模型的推理代码与权重
3.  具备3D世界重建、生成与模拟三大核心能力
4.  配套提供在线演示产品与社区交流渠道
