# HelixWorld

🪐 HelixWorld: 实时交互式音视频世界模型。

## 项目链接

- GitHub: <https://github.com/NoizAI/HelixWorld>
- 项目主页: <helixworld.io>

## 项目介绍
HelixWorld 1.0是Noiz AI推出的实时交互式音画世界模型。用户可以输入一张图片和提示词，通过操控相机前进、转向来和场景交互，画面和声音会随相机视角同步更新，空间声场会跟随视点变化，并非后期叠加的固定音轨。项目相关权重、推理代码和技术报告即将在未来几周发布。

## 主要特性
1.  支持漫游与相机导航交互
2.  实现实时交互响应
3.  支持联合音视频生成
4.  声场随相机视点同步变化
5.  模型权重与代码即将开源
