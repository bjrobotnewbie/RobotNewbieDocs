## 项目介绍
Matrix-Game是Skywork AI推出的开源世界模型系列，本仓库提供该系列1.0、2.0、3.0版本的官方实现。其中最新的3.0版本为实时流式交互式世界模型，具备长时序记忆能力；2.0版本为用于实时长视频生成的交互式世界基础模型；1.0版本为该系列首个开源版本。项目采用MIT许可证。

## 主要特性
- 开源世界模型系列，覆盖不同应用场景的迭代版本
- 3.0版本支持实时流式交互与长时序记忆
- 2.0版本适配实时长视频生成需求
- 提供官方实现代码，便于开发者使用与二次开发
