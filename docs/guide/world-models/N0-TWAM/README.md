# N0-TWAM

N₀-TWAM: 一种基于触觉的世界动作模型，用于接触丰富的操作

## 项目链接

- GitHub: <https://github.com/neoteai/N0-TWAM>
- 项目主页: <https://research.neoteai.com/n0-twam/>

## 项目概述

## 项目介绍
N₀-TWAM是一款面向接触丰富操作任务的原生触觉世界动作模型，基于混合Transformer（MoT）架构联合建模视觉、触觉与动作信号，通过修正流/流匹配目标实现未来视觉、触觉预测以及底层动作生成。本仓库提供预训练与微调后的仿真权重、推理服务端、后训练工具包，支持加载预训练权重并适配自有机器人与任务，未包含大规模预训练流程。

## 主要特性
1.  基于Wan2.2 TI2V-5B视频扩散Transformer重构的3专家MoT作为主干网络
2.  支持加载官方预训练权重，可通过自有演示数据进行后训练微调
3.  提供WebSocket推理服务，可从观测数据中生成动作
4.  支持在NeoSim视觉触觉基准测试中进行闭环评估，也可接入自有机器人或模拟器实现闭环控制
5.  支持20维双臂末端执行器动作空间，采用π0.5风格的时域增量动作表示
