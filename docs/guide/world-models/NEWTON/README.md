# NEWTON

NEWTON：具物理约束的视频生成代理规划

## 项目链接

- GitHub: <https://github.com/CUTEPKQ/NEWTON>
- 项目主页: <https://newton026.github.io/newton/>

## 项目介绍
NEWTON是一款面向物理贴合视频生成的智能规划框架，针对当前视频生成模型普遍存在物理常识违背的问题，提出了**规划-执行-验证**多轮循环的解决方案。它将视频生成降级为智能体工具库中的一个动作，通过可学习的规划器调度物理感知工具，结合闭环验证迭代优化生成结果，无需修改底层视频生成模型即可提升物理准确性。在VideoPhy-2数据集上，基于LTX-Video的联合准确率从21.4%提升至29.7%，基于Veo-3.1的准确率从30.7%提升至37.4%。

## 主要特性
1.  提出物理条件生成的三大核心要求：充分性、动态性、可验证性，解决现有方案的规范瓶颈问题
2.  采用多轮智能体循环框架，包含规划器LLM、物理工具集（Genesis物理仿真、关键帧生成等）和Gemini A/B验证器
3.  规划器为唯一可训练组件，通过Flow-GRPO在线策略优化
4.  兼容现有主流视频生成模型，无需针对模型做定制化修改
