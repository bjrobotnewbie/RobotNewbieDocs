## 项目介绍
Puffin是一系列面向空间智能的以相机为中心的统一多模态模型，可统一跨视角、朝向的世界理解与生成，其中Puffin-World支持原生3D世界状态建模。本项目包含两个子项目：
1.  Puffin：ICLR 2026收录模型，专注相机中心的多模态理解与生成，配套Puffin-4M数据集
2.  Puffin-World：支持原生3D世界状态的缩放版统一多模态模型，配套Puffin-16M数据集
相关代码、模型权重与数据集已在Hugging Face平台发布。

## 主要特性
1.  以相机为核心构建统一多模态空间智能模型，打通多视角、多朝向的世界感知与生成
2.  支持原生3D世界状态建模，实现更完整的空间智能能力
3.  配套超大规模多模态数据集，目前Puffin-4M上线三月下载量已破2万
4.  完整开源了训练推理代码、模型权重、数据集与评估脚本，部分工具仍在筹备发布中
