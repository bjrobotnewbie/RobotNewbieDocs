# 世界模型 (World Models)

世界模型是**具身智能的核心技术**之一，旨在让智能体学习环境的动态规律，从而实现未来预测、行为规划和决策。通过建模物理世界的变化规律，机器人可以在与环境交互前进行想象推演，大幅提高样本效率和规划质量。

截至 2026 年 5 月，以下世界模型均已**开源可下载权重**，可以直接部署使用。

## 分类说明

| 分类 | 核心内容 | 应用场景 |
|------|---------|---------|
| **通用/机器人世界模型** | 物理世界动态预测 | 机器人具身智能、规划、仿真 |
| **自动驾驶世界模型** | BEV空间交通预测 | 城市NOA、高速领航 |
| **3D/虚拟世界模型** | 3D场景生成交互 | VR、游戏、虚拟仿真 |
| **代码世界模型** | 程序状态推理 | 代码智能体、软件工程 |
