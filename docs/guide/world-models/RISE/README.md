## 项目概述

RISE是RSS 2026接收的研究工作，提出了**具有组合世界模型的自改进机器人策略学习框架**。该框架利用世界模型实现机器人策略的自主改进，主要贡献包括：

1. **组合式世界模型设计**：将可控多视图动力学模型与进度值模型相结合，为鲁棒的策略改进提供有效信息
2. **想象中强化学习**：可扩展的自改进框架，通过想象rollout来bootstrap机器人策略，避免真实环境交互的硬件成本和繁琐重置
3. **真实世界操作增益**：在复杂灵巧操作任务上取得显著性能提升：动态砖块排序+35%、背包打包+45%、合箱+35%

该项目为利用世界模型改进机器人策略提供了一个实用可行的方案，在真实世界操作任务上验证了方法的有效性。
