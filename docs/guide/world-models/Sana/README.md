# Sana

- 项目链接：https://github.com/NVlabs/Sana
- 项目主页：https://nvlabs.github.io/Sana/

## 项目概述

Sana是NVIDIA Research开发的**基于线性扩散变换的高效高分辨率图像生成模型**，属于世界模型方向的重要工作。该项目提供了完整的生成模型生态，主要特点包括：

1. **高效生成**：基于线性扩散变换，在保持生成质量的同时大幅提升推理效率
2. **多版本支持**：提供SANA、SANA-1.5、SANA-Sprint、SANA-Video、SANA-WM等多个版本，覆盖图像生成、视频生成、世界模型等不同应用场景
3. **生态完善**：支持HuggingFace、ComfyUI、SGLang等主流工具，便于开发者使用和部署
4. **可在线体验**：提供Demo网站支持在线试生成，支持ControlNet等控制功能

Sana在高分辨率图像生成任务上展现出优秀的性能平衡，为文生图、世界模型等任务提供了高效的基础模型。
