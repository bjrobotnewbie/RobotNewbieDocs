# SimWAM

SimWAM：用于端到端自动驾驶的简单世界动作模型

## 项目链接

- GitHub: <https://github.com/H-EmbodVis/SimWAM>

## 项目介绍
SimWAM是一款面向端到端自动驾驶的简易世界动作模型，本仓库提供了该模型的官方实现，支持在NAVSIM数据集上进行监督训练与仅动作空间的强化学习，相关研究成果已发布于arXiv。项目由华中科技大学与东风研发中心团队联合开发。

## 主要特性
1.  轻量化设计：采用简易世界动作模型架构，降低端到端自动驾驶模型的训练与部署复杂度
2.  完整训练流程：支持监督训练与基于动作空间的RL强化学习两种训练方式
3.  配套资源齐全：已开源代码、预训练模型权重，可在PhysicalAI-AV数据集上直接使用
4.  适配主流自动驾驶仿真场景：可在NAVSIM仿真环境中完成自动驾驶任务验证
