# SuperMap

SuperMap 是具身人工智能的活态空间记忆——它感知世界、铭记其演化，并支持推理与行动。

## 项目概述

## 项目介绍
SuperMap是一款面向具身智能的动态空间记忆系统，由卡内基梅隆大学AirLab研发，已被RSS 2026收录。它是一款无需训练的时空SLAM系统，可感知现实世界、记录场景演化，并支持智能体推理与行动。它能融合高频几何SLAM与异步开放词汇感知，构建可查询的4D场景图，为真实机器人提供带空间和时间信息的持久化语义世界模型，可应用于视觉语言导航、长时序推理等具身智能任务。

## 主要特性
1.  **感知能力**：通过3D感知实例关联实现遮挡和场景变化下的稳定物体识别
2.  **持久记忆**：保留物体唯一标识，记录长期场景演变
3.  **推理支持**：可查询的4D场景图支持空间与时序推理
4.  **落地行动**：天然适配视觉语言导航(VLN)、视觉语言行动(VLA)等具身智能场景
5.  **模型无关**：兼容Grounding DINO、YOLOE等主流检测模型输出结果
6.  **全在线运行**：同一套代码可在机器人硬件上实时运行，也可通过ROS2离线处理数据集
7.  **实地验证**：已在CMU校园完成连续2小时的实际部署测试
