# TriWorldBench

一个评估三视图具身世界模型的基准测试

## 项目链接

- GitHub: <https://github.com/TriWorldBench/TriWorldBench>

## 项目介绍
TriWorldBench是一个用于系统性评估三视角具身世界模型的统一基准测试平台，支持从头部、左手腕、右手腕三个同步机器人视角进行模型评测。它从六个维度共19项评估信号来衡量模型表现，核心维度为三视角一致性，同时还会评估任务对齐度、物理与3D一致性、运动质量、时间一致性和视觉质量，最终输出综合评分TWB-Score。

## 主要特性
1.  支持多机器人视角的具身世界模型统一评测
2.  覆盖六大维度共19项评估指标，核心聚焦三视角一致性
3.  提供参考锚定对比、语义判断等多维度量化评估方式
4.  支持自定义测试数据集，附带官方测试集与快速测试数据集
5.  包含完整的环境搭建、推理与评估流程，配套排行榜与挑战赛通道。
