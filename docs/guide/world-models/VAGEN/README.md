## 项目概述

## 项目介绍
VAGEN是一个面向多轮视觉语言模型（VLM）智能体的强化学习（RL）框架，被NeurIPS 2025收录。该框架通过显式的视觉状态推理，帮助智能体构建内部世界模型，区别于仅奖励任务完成度的传统方案，它通过轮次级别的世界模型奖励（LLM-as-Judge）和双层广义优势估计（Bi-Level GAE）实现轮次感知的信用分配，将世界模型推理拆解为状态估计（当前状态是什么）和过渡建模（下一步会发生什么）两个核心部分。

## 主要特性
1.  针对多轮VLM智能体的训练框架，强化世界模型推理能力
2.  采用双层广义优势估计实现轮次感知的信用分配
3.  经测试，使用该框架训练的3B参数VLM在5个视觉智能体基准测试中得分达到0.82，相比未训练的主干模型提升3倍，优于GPT-5、Gemini 2.5 Pro、Claude 4.5等现有模型。
