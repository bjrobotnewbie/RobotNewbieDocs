# Video2World

从具身视频评估编码代理的交互式世界建模能力——重新审视具身现实到模拟：软件工程视角

## 项目链接

- GitHub: <https://github.com/AetherLabsAI/Video2World>
- 项目主页: <https://aetherlabsai.github.io/Video2World/>

## 项目介绍
Video2World是针对具身视频交互式世界建模编码智能体的基准测试项目，从软件工程视角重新思考具身真实到仿真的转化，旨在验证前沿基础模型与编码智能体能否端到端自动化构建交互式仿真环境，替代传统依赖人工构建校准的流程。项目构建了222个重建实例，涵盖39类任务家族，基于189段视频剪辑（含机器人执行、第一人称人类记录、第三人称人类演示），从几何保真度、动态保真度、功能正确性三个维度评估重建效果，覆盖空间感知、物理推理与可执行交互能力。

## 主要特性
- 以软件工程视角定义“自主视频转仿真”任务：智能体仅通过视频、仿真器API、文档等，在隔离沙箱中构建仿真环境与机器人行为，通过执行反馈迭代优化结果
- 提供多类型视频源构建的基准数据集，覆盖机器人、人类等不同具身场景
- 建立多维度评估体系，从几何、动态、功能层面量化仿真重建质量，支撑编码智能体的性能评测
