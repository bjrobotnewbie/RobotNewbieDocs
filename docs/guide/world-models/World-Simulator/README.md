[IEEE TPAMI 2026] 模拟真实世界：综述与资源，包含我们的综述"模拟真实世界：多模态生成模型的统一综述"（IEEE TPAMI, 2026）以及 Awesome-Text2X-Resources。关注本仓库以获取最新更新！🔥

## 项目介绍
本项目是一个面向真实世界仿真的调研与资源仓库，包含IEEE TPAMI 2026收录的综述论文《Simulating the Real World: A Unified Survey of Multimodal Generative Models》，以及Awesome-Text2X资源合集。
综述部分将2D、视频、3D、4D生成任务统一到单一框架下进行系统性梳理；Text2X资源板块则收集了当前最先进的Text-to-X相关论文、代码与数据集，用于追踪该领域的最新进展，为研究者提供参考。项目持续更新，欢迎社区贡献。

## 主要特性
1.  收录顶刊综述论文，统一梳理多模态生成模型的全维度研究
2.  维护全面的Text2X领域前沿资源库，覆盖论文、代码与数据集
3.  持续更新最新研究进展，支持社区提交PR或Issue贡献资源
