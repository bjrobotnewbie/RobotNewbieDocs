# WorldFoundry

统一的全球模型推理与评估基础设施

## 项目链接

- GitHub: <https://github.com/OpenEnvision/WorldFoundry>
- 项目主页: <https://openenvision.github.io/WorldFoundry/>

## 项目介绍
WorldFoundry是一款开源的世界模型统一推理与评估基础设施，提供通用的本地资源管理、推理（支持TUI、CLI、Studio界面）以及跨多场景的基准测试能力，覆盖视频生成、3D/4D表征、具身智能交互、交互式世界等领域。当前项目仍处于活跃开发阶段，支持Python 3.10~3.13，采用Apache-2.0开源协议。

标准使用流程分为三步：配置环境与资源、通过多种方式执行推理生成结果、匹配基准布局后完成评估并生成评分报告。

## 主要特性
1.  提供统一的世界模型开发堆栈，包含内置运行器、本地资源暂存模块
2.  支持多端推理交互：TUI、CLI、脚本以及Studio可视化界面
3.  覆盖多类型世界模型任务的基准评估能力
4.  配套完整的官方文档与社区支持，可通过Discord或微信社群参与交流。
