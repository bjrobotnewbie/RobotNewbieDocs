## 项目介绍
WorldinWorld是官方实现的视频自由创作项目，基于14B参数量的LingBot-World 2.0冻结视频世界模型，可无需训练或微调，仅需单张80GB GPU，为普通视频生成新视角的拍摄效果。
其核心思路是将源视频、场景几何、相机参数转化为视觉证据：通过深度信息将源帧变换到新相机视角，作为模型注意力的额外键值对，让模型生成新视角下的画面。当前已发布的功能支持真实视频的自由相机重拍、子弹时间效果和视频编辑。

## 主要特性
1.  **自由相机重拍**：支持沿自定义路径重放视频，可实现圆弧运镜、摇镜头、原地旋转、推拉镜头等自由视角探索
2.  **子弹时间效果**：可在任意帧冻结动作，环绕冻结场景移动相机
3.  **视频编辑**：修改视频首帧后，可沿新相机路径将编辑效果贯穿整个片段
4.  低门槛使用：无需额外训练微调，单张80GB GPU即可运行
