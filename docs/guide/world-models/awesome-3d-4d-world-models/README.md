## 项目概述

awesome-3d-4d-world-models是一份关于**3D与4D世界建模领域的最新综述和精选资源列表**，由学术界整理维护。该项目系统梳理了该领域的研究进展，主要内容包括：

1. **分类框架**：将领域统一分为三个互补的研究范式：
   - VideoGen：从连续视频流学习生成预测模型，关注长视界一致性、可控性和场景级生成
   - OccGen：在体素空间中对3D/4D占用网格建模，提供物理一致的场景骨架，桥接低层传感器数据和高层推理
   - LiDARGen：利用LiDAR点云序列生成或预测几何接地场景，强调高保真3D结构，适用于自动驾驶等安全关键领域
2. **系统性整理**：涵盖基准测试、数据集、各个范式下的代表性工作、应用场景（自动驾驶、机器人、游戏XR、数字孪生等）
3. **开放维护**：欢迎社区贡献PR更新最新研究，持续跟踪领域进展

这份综述是进入3D/4D世界建模领域非常好的入门资料，统一了术语、范围和评估方法，对研究者有重要参考价值。
