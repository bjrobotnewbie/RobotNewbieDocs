## 项目介绍
Visionary是一个开源的Web原生平台，基于WebGPU和ONNX Runtime构建，作为承载世界模型的载体，可在浏览器中直接实现多种高斯溅射（Gaussian Splatting）变体（包括3DGS、基于MLP的3DGS、4DGS、神经化身等）及传统3D网格的实时渲染，还支持通过前馈网络进行后处理。

## 主要特性
1. 基于WebGPU技术，支持在浏览器中直接运行各类3D内容渲染
2. 兼容多种高斯溅射算法变体及传统3D网格格式
3. 具备良好扩展性，可适配未来新增的各类算法
4. 提供在线编辑器、项目页面、技术文档及相关演示资源，便于开发者使用与研究
