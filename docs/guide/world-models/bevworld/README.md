# 百度 BEVWorld

BEVWorld 是百度 Apollo 在 2026 年 2 月发布的**自动驾驶世界模型**，采用统一鸟瞰图（BEV）表示，实现多模态融合的世界建模。

## 资源简介

- **发布机构**：百度 Apollo
- **发布时间**：2026年2月
- **模型架构**：BEV 潜在空间世界模型
- **核心能力**：多模态融合世界模型，统一鸟瞰图（BEV）表示
- **开源内容**：模型权重 + 推理代码全开源
- **应用场景**：城市NOA、高速领航辅助、自动驾驶运动预测

## 特点

1. **统一 BEV 表示**：将感知、预测、规划都统一在 BEV 空间下
2. **端到端一体化**：BEV 感知 + 未来轨迹预测一体化训练
3. **多模态融合**：融合相机、激光雷达、地图等多模态信息
4. **产业级应用**：已经在百度自动驾驶产品中验证，实用可靠
5. **中国路况优化**：针对国内复杂城市道路场景优化
