# boundless-world-model

- 项目链接：https://github.com/boundless-large-model/boundless-world-model

## 项目概述

Boundless-World-Model (BWM) 是**面向通用具身智能的高保真世界模型**，可作为数据引擎和世界模拟器使用。主要特点包括：

1. **物理一致性**：基于Wan2.2-TI2V-5B构建的动作条件视频世界模型，保持物理一致性
2. **低成本高保真**：作为机器人操作的模拟器，相比传统物理仿真成本更低保真度更高
3. **竞赛成绩优异**：在CVPR 2026 WorldArena Challenge中，BLM模型在Track 1和Track 2数据引擎开源模型中排名第一，BWM-fast在Track 1总排名第二
4. **已开放推理代码**：支持使用BWM生成动作条件的机器人操作视频，架构和核心组件已公开

该项目为机器人操作任务提供了一个高性能的基于生成模型的世界模拟器方案。
