一个从实时经验中学习的智能大脑。默认系统 1：感知、记忆、可塑性和行动。可选的系统 2 用于自我观察和缓慢修正。

- GitHub: <https://github.com/muellerberndt/cadence>
- 项目主页: <https://floatingpragma.io/cadence/>

## 项目介绍
Cadence是一款模拟类人脑的研究型软件，核心是构建具备持续学习与修复能力的“持续平衡大脑”，默认以类动物的System 1为核心，具备感知、可塑性连接、记忆与行动能力，可选System 2实现自我观察与慢速修正，支持通过实时经验学习、在环境中行动并修复故障，属于alpha阶段的研究工具。

## 主要特性
1. 核心架构：基于简化生物机制，采用模块化深度神经网络设计，具备局部神经状态、工作记忆及线索-结果关联存储能力
2. 动态平衡：支持在变化的证据与上下文下形成“平衡态家族”，避免冻结于单一状态
3. 功能支持：已实现持续行动、局部学习与记忆功能，可通过`Brain.last_settlement`进行行动诊断
4. 开发方向：计划整合学习型世界预测与故障触发自动修复，当前为研究阶段的alpha版本，遵循GPL v3协议。
