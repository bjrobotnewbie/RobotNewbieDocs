## 项目概述

## 项目介绍
cortex-mem是一款基于Rust开发的AI原生内存框架，可用于构建具备上下文感知能力的智能应用，尤其适用于OpenClaw、具身AI等自主系统。它提供了完整的生产级长期内存系统，能让AI代理跨会话实现记忆、学习和个性化交互。框架内置了从记忆提取、搜索到自动优化的全流程内存管理能力，还自带SKILL、CLI、API、MCP以及可视化仪表盘。

## 主要特性
1.  采用三层分级记忆架构（L0抽象→L1概述→L2细节），自动提取、组织和优化信息
2.  混合存储架构，结合虚拟文件系统的持久化能力与基于向量的语义搜索能力
3.  支持快速分层上下文加载，以虚拟文件形式组织记忆数据，使用`cortex://` URI规范管理不同维度的记忆（会话、用户、代理等）
4.  开箱即用的多端交互能力，包含SKILL、CLI、API、MCP和可视化仪表盘
5.  高性能、持久化的智能内存系统，已通过性能基准测试验证表现优异，采用MIT开源协议。
