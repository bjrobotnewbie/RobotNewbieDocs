## 项目概述
cosmos-predict1是一套通用的物理AI世界基础模型集合，支持针对下游应用进行微调，以构建定制化的世界模型，适用于具身智能和物理AI的研究和开发，提供了预训练模型和相关资源，不过当前已迁移到新一代的Cosmos 3平台。
