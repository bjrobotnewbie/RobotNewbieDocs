# cosmos-predict2.5

- 项目主页：https://research.nvidia.com/labs/dir/cosmos-predict2.5

## 项目概述

Cosmos-Predict2.5是NVIDIA推出的**Cosmos世界基础模型（WFMs）家族的2.5版本**，专为物理AI设计，能够以视频形式模拟和预测世界未来状态。虽然该版本已不再活跃开发（开发重心已转移到Cosmos 3），但它仍具有重要的技术价值：

1. **世界预测能力**：基于大规模数据训练，能够对复杂物理环境的未来状态进行准确预测，支持自动驾驶、机器人等物理AI应用
2. **多样化模型支持**：提供不同参数规模（2B、14B）的预训练模型，支持文本到世界生成、多视图推理、机器人策略等多种应用场景
3. **开放生态**：提供完整的推理、蒸馏、后训练流程，支持Diffusers框架，方便开发者使用和二次开发
4. **重要演进**：作为Cosmos 3的前身，奠定了NVIDIA物理AI世界模型的技术基础

该模型为具身智能、自动驾驶等需要环境预测的任务提供了强大的基础模型支持，现在推荐迁移到新一代Cosmos 3获取更强能力。
