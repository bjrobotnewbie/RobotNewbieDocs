## 项目概述
cosmos-reason1是一个用于物理AI和机器人的开放、可定制的7B参数推理视觉语言模型，能够通过长链式思维推理，理解物理常识，并在自然语言中生成恰当的具身决策，适用于具身智能和机器人领域的研究和开发，不过当前已迁移到新一代的Cosmos 3平台。
