## 项目概述
NVIDIA Cosmos是一个开放的全球模型、数据集和工具平台，帮助开发者为机器人、自动驾驶汽车、智能基础设施等构建物理人工智能，提供了多种模型和工具，适用于具身智能和物理AI的研究和开发，包含了Cosmos 3等新一代的物理AI模型。
