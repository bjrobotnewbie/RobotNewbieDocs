# Meta CWM (Code World Model)

CWM (Code World Model) 是 Meta AI Research 在 2026 年 4 月发布的**代码世界模型**，专门用于理解代码对系统状态的影响，支持代码生成和程序状态推理。

## 资源简介

- **发布机构**：Meta AI (Facebook Research)
- **发布时间**：2026年4月
- **模型类型**：代码专用大语言模型
- **核心能力**：代码生成 + 程序状态推理，理解代码执行对系统状态的影响
- **开源权重**：提供预训练、SFT、Instruct 三个阶段权重
- **应用场景**：代码智能体、软件工程自动化、自动程序测试

## 特点

1. **世界模型视角**：将代码执行看作状态转移，用世界建模思路学习程序行为
2. **状态推理能力**：不仅能生成代码，还能推理代码执行后的状态变化
3. **多阶段训练**：提供预训练、监督微调、指令微调不同版本
4. **工业级应用**：可用于构建代码智能体，自动完成编程任务
5. **Meta官方开源**：FAIR 团队出品，质量有保证
