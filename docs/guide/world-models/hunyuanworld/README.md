# 腾讯 HunyuanWorld (混元世界模型)

HunyuanWorld 是腾讯发布的**原生3D世界生成模型**，支持从文本或图像生成可交互探索的3D场景，当前最新版本是 2026 年 4 月发布的 2.0。

## 资源简介

- **发布机构**：腾讯
- **版本迭代**：1.0 (3D生成) / 1.5 (实时交互) / 2.0 (2026.4)
- **模型架构**：3D扩散 + Transformer
- **核心能力**：原生3D世界生成，文本/图像 → 可探索3D场景
- **开源权重**：HuggingFace 腾讯组织下开放下载
- **性能亮点**：WorldScore 基准排名第一
- **导出支持**：支持点云视频导出
- **应用场景**：VR内容生成、游戏开发、虚拟仿真、3D重建

## 特点

1. **原生3D生成**：直接生成3D场景，不需要从2D升维
2. **可交互探索**：生成后支持用户在场景中移动探索
3. **版本持续迭代**：从 1.0 到 2.0 持续优化生成质量
4. **多种输入支持**：支持文本描述、参考图像多种输入方式
5. **产业落地**：可直接用于游戏和VR内容生产流水线
