# infinite-world

一个开源系统，用于构建具有多模态 AI 能力的持久世界。

## 项目链接

- GitHub: <https://github.com/BuzzPlay/infinite-world>

## 项目介绍
Infinite World 是一款开源的多模态AI持久化世界构建系统，可打造持续进化的交互式世界。它通过多模态理解、世界模拟和交互的闭环流程，实现对世界的认知、状态模拟与实时交互，并可记录场景、选择分支与状态变化。
该系统可用于开发新型互动游戏、交互式内容，也能帮助具身智能体理解环境、模拟结果并做出决策，面向开发者、创作者与研究者开放开源。

## 主要特性
1.  支持多模态交互：已实现文本、语音、图片区域选择交互，计划支持键鼠、聊天等更多交互方式
2.  持久化世界状态：可跨场景与分支保留世界上下文与运行状态，支持本地预览、重播已保存的世界分支
3.  闭环工作流：依次完成世界理解、状态模拟、交互影响、持续记录的完整流程
4.  开源可扩展：支持自定义添加模型、输入输出与交互逻辑，共建开放生态

当前仍处于早期开发阶段，API与存储数据可能发生变更。
