## 项目介绍
本项目是面向世界模型（World Models）的系统化学习教程，处于Alpha预览阶段，旨在通过动手搭建的方式带领学习者从基础直觉出发，掌握完整的世界模型、仿真、规划与评估系统。教程包含5个主题讲座与6个实战项目，可在线阅读，采用MIT开源协议。

## 主要特性
1.  **学习路径清晰**：提供结构化的课程主页与学习卡片，以概念为先进行讲解，搭配Mermaid图表与深度学习背景补充说明
2.  **内容覆盖全面**：涵盖世界模型的发展历程、观测编码与隐态动力学、架构模式与规划机制、模型诊断以及前沿研究争议
3.  **实战导向**：配套6个实操项目，包括训练VAE编码器、搭建RSSM动力学模型、训练Dreamer智能体等，附带可视化结果示例
4.  **对比详实**：提供9种架构家族、3种规划机制的横向对比表格与深度拆解讲解
