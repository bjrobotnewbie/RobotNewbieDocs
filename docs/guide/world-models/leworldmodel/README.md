# LeWorldModel

- [项目主页](https://le-wm.github.io/)

## 概述

LeWM（LeWorldModel）是由Yann LeCun团队研发的轻量化端到端世界模型，依托JEPA架构设计，突破了传统视觉世界模型训练不稳定、依赖复杂损失函数与额外预训练模块的痛点。该模型直接以原始像素作为输入，仅依靠预测损失与高斯分布正则项两项核心约束就能完成稳定训练，有效杜绝表征坍塌问题，整体结构精简、超参数数量大幅减少，硬件门槛更低，仅需单块显卡、数小时即可完成完整训练。在架构层面，LeWM通过编码器将视觉观测转化为低维隐空间表征，结合动作信息预测未来状态嵌入，依托简洁的推理逻辑大幅提升规划效率，相较同类主流模型规划速度提升显著。在实际测试中，该模型在二维、三维多项机器人控制任务中具备优秀的综合性能，能够精准编码环境空间特征与动态变化规律，隐表征可有效解耦位置、角度等物理信息，同时能识别违背现实物理规则的异常事件，证明其具备基础的物理常识理解能力。整体而言，LeWM以极简设计、低成本训练、高速规划与可靠的物理建模能力，为轻量化、可落地的机器人世界模型研发提供了全新高效的技术路线。
