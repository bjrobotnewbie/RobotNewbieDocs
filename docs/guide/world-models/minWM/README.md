# minWM

极简优雅框架与教程：实时交互式世界模型

## 项目链接

- GitHub: <https://github.com/shengshu-ai/minWM>

## 项目介绍
minWM是首个全栈开源世界模型框架，定位为面向新手的完整教程式框架而非单一模型。它提供从双向文本到视频（T2V）基础模型到动作条件视频世界模型的端到端实现流程，附带示例数据、可运行脚本、记录实操经验的Claude技能教程，以及新手入门知识。

## 主要特性
1.  **全栈流程支持**：开源完整的「数据构建→训练→推理」全流程，每个阶段都提供输入输出 checkpoint，可随时中断、替换或分支开发
2.  **多骨干网络支持**：兼容多种模型骨干
3.  **LLM辅助开发**：内置Claude技能，可通过大语言模型助手修改框架
4.  支持FSDP+序列并行、单/多节点训练，以及从双向扩散模型到4步自回归学生模型的完整蒸馏流程
