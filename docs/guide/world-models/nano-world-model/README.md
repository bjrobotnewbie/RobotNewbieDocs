# nano-world-model

一个极简、带电池仓的仓库，用于推动世界模型科学的发展。

## 项目链接

- GitHub: <https://github.com/simchowitzlabpublic/nano-world-model>
- 项目主页: <https://simchowitzlabpublic.github.io/nano-world-model/>

## 项目介绍
Nano World Model是一个极简且开箱即用的视频世界模型研究仓库，基于扩散强制（diffusion-forcing）技术训练视频世界模型，配套提供了完整的训练、推理与评估代码、模型 checkpoint 以及技术报告，已在Hugging Face和ArXiv公开。

## 主要特性
1.  **快速上手**：依赖极简，数据加载便捷，从克隆仓库到首次完成视频推演仅需数分钟
2.  **统一流程**：基于Hydra配置系统管理训练、验证、评估全流程
3.  **科研透明性**：代码结构清晰，支持针对预测目标、动作注入、模型规模的对照 ablation 实验，所有内容完全开源
4.  **多场景适配**：开箱支持长时序视频推演、3D点云推演、模型预测控制（MPC）规划任务
