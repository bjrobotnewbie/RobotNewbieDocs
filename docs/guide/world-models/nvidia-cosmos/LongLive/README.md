# LongLive

长视频生成/世界模型/世界动作模型（具身）基础设施

## 项目链接

- GitHub: <https://github.com/NVlabs/LongLive>
- 项目主页: <https://nvlabs.github.io/LongLive>

## 项目介绍
LongLive是NVIDIA推出的长视频生成与世界动作建模研究基础设施，包含多个独立子项目，各项目拥有独立目录、代码、文档及模型权重，支持按需通过稀疏克隆下载所需项目。

## 主要特性
- **Long-WAM**：长上下文世界动作模型，可用于训练评估机器人策略、生成机器人视频，支持在YAM、Franka、Unitree G1等机器人平台部署，相关研究已发表于arXiv。
- **LongLive-Plug**：视频生成的一次性蒸馏方案，可在基础模型上蒸馏一次能力后复用至下游模型，无需重新训练，相关研究已发表于arXiv。
- **LongLive 2.0**：基于NVFP4并行架构的长视频生成基础设施，支持通过NVFP4量化与序列并行快速训练或部署长视频模型，相关研究已发表于arXiv。
- **LongLive 1.0**：实时交互式长视频生成系统，支持通过输入提示词实时生成可交互控制的长视频，相关研究已发表于ICLR 2026。
