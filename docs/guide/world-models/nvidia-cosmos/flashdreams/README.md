## 项目概述

## 项目介绍
FlashDreams是NVIDIA推出的高性能交互式自回归视频与世界模型推理及服务库，其前身是GTC 2026的NVIDIA OmniDreams闭环演示优化运行时，现已发展为通用实时世界模型应用平台，可应用于游戏、自动驾驶、机器人、虚拟仿真等场景。

## 主要特性
1.  **核心功能**：为自回归视频和世界模型提供高性能推理与部署服务
2.  **适用场景**：覆盖游戏、自动驾驶、机器人、虚拟仿真等多领域实时世界模型开发
3.  **系统要求**：需搭配80GB及以上VRAM的NVIDIA GPU、R580及以上版本NVIDIA驱动、CUDA 13.x、Python 3.10+、PyTorch 2.11.0+cu130，支持Linux x86-64/arm64架构，推荐100GB+存储空间
4.  **快速部署**：提供基于uv的快速安装流程，支持容器化部署，附带完整官方文档与模型画廊说明各模型资源需求
