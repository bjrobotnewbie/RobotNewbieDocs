# utopia

世界首个开源企业级世界模型。

## 项目链接

- GitHub: <https://github.com/deeplethe/utopia>

## 项目介绍
Utopia是全球首个开源企业级世界模型，由DeepLethe团队打造，是一款被动学习且自主治理的知识工程基座。它将时间与本体论作为底层基础，可随新数据更新本体结构，记录自身认知变化过程，通过公理解决冲突，并能复现任意历史节点的世界认知状态。

可部署在企业内网、云服务器或本地笔记本，可作为企业知识底座、可信智能体决策核心，或是个人/企业的历史纪事系统。

## 主要特性
1.  被动演化的企业级世界模型，可理解企业内的人员、事件、规则与关系及其动态变化
2.  整合记忆、知识、规则、推理与行动能力
3.  支持复现任意历史节点的世界认知状态
4.  可作为知识枢纽、决策基础、受控执行入口与未来推理验证场
5.  采用Rust语言开发，基于Apache 2.0开源协议
