# WoW (World-Omniscient)

WoW (World-Omniscient) 是由多校联合（包括 UC Berkeley）在 2026 年 4 月发布的**物理一致生成式世界模型**，基于 Cosmos 和 Wan2.1 架构，用 200 万机器人轨迹训练。

## 资源简介

- **发布机构**：多校联合 (UC Berkeley 等)
- **发布时间**：2026年4月
- **模型规模**：2B / 7B / 14B 多种参数量版本
- **基础架构**：基于 Cosmos/Wan2.1，采用 DiT 结构
- **训练数据**：200万机器人轨迹数据
- **核心特点**：物理一致性保证，生成式世界建模
- **应用场景**：机器人具身智能、物理仿真、轨迹预测

## 特点

1. **物理一致性保证**：通过精心设计的训练目标保证生成结果符合物理规律
2. **大规模机器人数据**：200万机器人轨迹训练，覆盖多样化机器人操作场景
3. **基于成熟架构**：在 Cosmos 和 Wan2.1 基础上改进，站在巨人肩膀上创新
4. **DiT 扩散结构**：采用 Diffusion Transformer 架构，适合视频生成任务
5. **多版本选择**：从 2B 到 14B 不同规模，满足不同部署需求
