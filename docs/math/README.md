# 机器人数学基础

数学是机器人技术的基础，涵盖线性代数、微积分、概率论等多个领域，为机器人建模、控制和学习提供理论支持。本章节涵盖机器人领域常用的数学工具和方法，包括国际经典资源和中国学者优质教程。

## 项目列表

- [线性代数与几何](math/linear-algebra-geometry/README.md)：机器人学核心线性代数与几何资源
- [微积分与数值方法](math/calculus-numerical/README.md)：微积分与机器人学数值计算资源
- [概率与统计](math/probability-statistics/README.md)：概率与统计在机器人学中的应用
- [优化理论](math/optimization-theory/README.md)：机器人学优化理论资源
- [机器人学专用数学](math/robotics-math/README.md)：机器人专用数学理论与方法
- [深度学习数学基础](math/deep-learning-math/README.md)：具身智能深度学习数学基础
