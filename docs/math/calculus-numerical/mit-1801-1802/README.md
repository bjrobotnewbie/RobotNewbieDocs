# MIT 18.01/18.02 微积分系列课程

## 资源简介

MIT 18.01单变量微积分和18.02多变量微积分是由Jeremy Orloff教授开设的经典微积分课程，涵盖微积分的基础理论和应用，是机器人学、物理学等领域的必备数学基础。

## 官方链接

- 18.01单变量微积分：<https://ocw.mit.edu/courses/18-01sc-single-variable-calculus-fall-2010/>
- 18.02多变量微积分：<https://ocw.mit.edu/courses/18-02sc-multivariable-calculus-fall-2010/>

## 核心内容

- 单变量微积分：导数、积分、微分方程
- 多变量微积分：偏导数、多重积分、向量微积分
- 微积分在机器人动力学、运动学中的应用

## 适用场景与学习人群

- 机器人学开发者，需要微积分基础用于动力学建模、运动规划
- 理工科学生，系统学习微积分基础
- 机器人动力学、控制研究者

## 学习建议

- 完成课后习题，巩固微积分概念
- 结合机器人动力学案例理解微积分的应用
