# Numerical Recipes

## 资源简介

Numerical Recipes 是数值计算领域的经典著作，由 William H. Press 等人编写，涵盖了几乎所有常用数值算法，提供了完整的代码实现，被誉为数值计算领域的"圣经"。该书强调实用性，非常适合工程应用。

## 官方链接

- 官方网站：<https://numerical.recipes/>
- GitHub 社区代码整理：<https://github.com/ninkaninus/Numerical-Recipes>
- 第3版在线阅读（免费）：<https://numerical.recipes/book.html>

## 核心内容

- 线性代数方程组求解
- 插值与拟合
- 数值积分与微分
- 非线性方程求解
- 傅里叶变换与频谱分析
- 统计描述与数据处理
- 常微分方程与偏微分方程数值解
- 随机模拟与蒙特卡洛方法
- 优化方法
