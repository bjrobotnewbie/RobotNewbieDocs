# Deep Learning Specialization (Andrew Ng)

## 资源简介

由Andrew Ng教授开设的深度学习专项课程，涵盖神经网络、卷积神经网络、循环神经网络、强化学习等深度学习核心内容，是具身智能机器人学习深度学习数学基础的经典入门资源。

## 官方链接

* Coursera课程页面：<https://www.coursera.org/specializations/deep-learning>

* 中文翻译课程：<https://www.bilibili.com/video/BV1FT4y1E74V/>

## 核心内容

* 神经网络与反向传播算法

* 卷积神经网络（CNN）与计算机视觉

* 循环神经网络（RNN）与序列数据

* 结构化机器学习项目

* 强化学习基础

## 适用场景与学习人群

* 具身智能机器人开发者，需要深度学习数学基础

* 机器学习初学者，系统学习深度学习理论

* 机器人研究人员，开展深度学习在机器人领域的应用研究

## 学习建议

* 配套学习PyTorch/TensorFlow实践代码

* 结合机器人感知、控制场景理解深度学习应用

* 完成课程中的编程作业，掌握算法实现

## 配套资源

* 课程幻灯片、编程作业、课后习题等可在Coursera平台获取

* 大量中文翻译和社区整理的学习资料
