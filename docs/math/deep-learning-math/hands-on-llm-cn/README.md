# Hands-On Large Language Models 中文版

## 资源简介

《Hands-On Large Language Models》中文翻译版，由 bbruceyuan 发起的中文社区翻译项目。本书涵盖了 LLM 的核心技术、训练方法、提示工程、模型部署等完整知识体系，是学习大语言模型的权威入门书籍。

## 官方链接

* GitHub代码仓库：<https://github.com/bbruceyuan/Hands-On-Large-Language-Models-CN>
* 原版书籍网站：<https://www.hands-onllm.com/>

## 核心内容

* LLM 基础概念与发展历程
* Transformer 架构详解
* 大语言模型训练方法
* 提示工程（Prompt Engineering）
* 模型微调技术（Fine-tuning）
* RLHF 与人类反馈学习
* LLM 推理优化与部署
* RAG 与知识增强
* 多模态大语言模型
* LLM 安全与对齐

## 适用场景与学习人群

* 具身智能开发者，学习大语言模型基础
* AI 方向研究生，LLM 研究入门
* 算法工程师，快速掌握 LLM 技术栈
* 产品经理，理解 LLM 能力边界
* 对大语言模型感兴趣的学习者
