# 动手学深度学习（李沐）

## 资源简介

由李沐博士等人编写的深度学习入门教材，采用PyTorch框架，理论与实践相结合，是学习深度学习数学基础的经典中文教材。全书配有完整的代码实现和视频课程，适合具身智能机器人开发者系统学习深度学习。

## 官方链接

* 官方网站：<https://d2l.ai/>
* GitHub代码仓库：<https://github.com/d2l-ai/d2l-zh>
* 哔哩哔哩视频课程：<https://www.bilibili.com/video/BV1PX4y1g7KC/>

## 核心内容

* 深度学习预备知识（线性代数、概率论、数值计算）
* 线性回归与 Softmax 回归
* 多层感知机（MLP）
* 卷积神经网络（CNN）
* 循环神经网络（RNN）
* 注意力机制与 Transformer
* 优化算法与正则化
* 计算机视觉与自然语言处理应用

## 适用场景与学习人群

* 具身智能机器人开发者，需要系统学习深度学习
* 计算机相关专业学生，深度学习入门学习
* 机器学习从业者，巩固深度学习基础
* 机器人研究人员，应用深度学习到机器人领域

## 学习建议

* 按照章节顺序学习，配合代码实践
* 完成每章后的练习和动手实验
* 结合PyTorch官方文档深入理解API
* 将所学知识应用到机器人感知、控制任务中
