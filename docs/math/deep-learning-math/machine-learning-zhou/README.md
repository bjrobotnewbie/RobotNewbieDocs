# 机器学习（周志华）

## 资源简介
《机器学习》是周志华教授编写的经典中文机器学习教材，系统讲解机器学习的基础理论和方法，是国内最广泛使用的机器学习教科书之一，被众多高校采用为教材。

## 官方链接
- 教材官网：https://cs.nju.edu.cn/zhouzh/zhouzh.files/books/mlbook.htm
- GitHub仓库：https://github.com/d2l-ai/d2l-zh

## 核心内容
- 机器学习基础概念
- 线性模型与神经网络
- 决策树与集成学习
- 支持向量机与核方法
- 聚类与降维
- 强化学习基础

## 适用场景与学习人群
- 机器人学学习者，需要机器学习基础
- 理工科学生，系统学习机器学习理论
- 科研人员与开发者，作为机器学习参考手册

## 学习建议
- 配合《机器学习实战》等实践书籍学习
- 结合Python机器学习库（Scikit-learn）实践算法
- 完成课后习题，巩固理论知识
