# 线性代数与解析几何（郑宝东）

## 资源简介

哈工大郑宝东教授的线性代数与解析几何视频课程，讲解线性代数核心概念与几何直观，帮助理解向量空间、矩阵运算、特征值等重要知识点在几何视角下的本质。
