# 线性代数的本质

## 概览
**《线性代数的本质》(Essence of Linear Algebra)** 是3Blue1Brown（Grant Sanderson）制作的免费动画视频课，总时长约**2.5–3小时**，核心是用**几何直观+动态可视化**讲清线性代数的核心概念，避开枯燥计算，直击本质。


## 理念
- **几何优先，代数在后**：矩阵=空间变换、行列式=面积/体积缩放、特征向量=变换中不变方向，把抽象符号变成看得见的运动。
- **少计算，多理解**：不堆砌公式，聚焦“**为什么**”而非“**怎么算**”。
- **短而精，全程动画**：共**11集**，每集约10分钟，全动态图解，直观易懂。

## 目录
1. **向量究竟是什么**：物理（箭头）、计算机（数组）、数学（抽象）三种视角。
2. **线性组合、张成的空间与基**：基向量、线性无关、张成空间的几何意义。
3. **矩阵与线性变换**：矩阵=对空间的拉伸/旋转/压缩；线性变换的定义（直线不变、原点不动）。


4. **矩阵乘法与线性变换复合**：矩阵相乘=变换的先后叠加（先右后左）。
5. **行列式**：二维=面积缩放倍数，三维=体积缩放；**det=0** 表示降维（压缩到线/点）。


6. **逆矩阵、列空间与零空间**：逆矩阵=逆变换；列空间=变换后能到达的空间；零空间=被压缩到原点的向量。
7. **点积与对偶性**：点积=投影+缩放；从“对偶”视角看点积与线性变换的关系。
8. **叉积（几何+变换视角）**：二维叉积=平行四边形面积；三维叉积=垂直于两向量的向量（长度=面积）。


9. **基变换**：不同坐标系下同一向量的坐标转换；基变换矩阵的几何意义。


10. **特征向量与特征值**：特征向量=变换后**方向不变、仅缩放**的向量；特征值=缩放倍数；对角化的直观理解。
11. **抽象向量空间**：从几何向量到函数、多项式等抽象空间；线性代数的普适性。
