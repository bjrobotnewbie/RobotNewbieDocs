# 机器人规划 (Robot Planning)

机器人规划是指机器人根据任务目标和环境信息，生成合理的行动序列和运动轨迹的过程。规划是机器人智能化的核心能力，根据抽象层级和应用场景分为三个主要方向。

## 三大规划层级

| 层级 | 英文名称 | 抽象程度 | 核心问题 | 典型输出 |
|------|---------|---------|---------|---------|
| **任务规划** | Task Planning | 最高 | "做什么？" | 子任务序列 |
| **运动规划** | Motion Planning | 中间 | "怎么动？" | 关节/末端轨迹 |
| **路径规划** | Path Planning | 最低 | "走哪条？" | 几何路径点 |

---

## 层级详解

### 1. 任务规划 (Task Planning)

**定位**：高层决策，将复杂目标分解为可执行的子任务

**核心技术**：
- **传统方法**：行为树、HTN、PDDL
- **LLM 驱动**：ReAct、Reflexion、多智能体协作

**应用场景**：
- 家庭服务机器人（"去厨房拿一瓶水"）
- 自主智能体（完成多步骤复杂任务）
- 任务调度与编排

**详细内容**：[任务规划](planning/task-planning/README.md)

---

### 2. 运动规划 (Motion Planning)

**定位**：中层运动生成，为机械臂等高自由度机器人生成无碰撞轨迹

**核心技术**：
- **集成框架**：MoveIt!, MoveIt 2
- **算法库**：OMPL, SBPL
- **轨迹优化**：CHOMP, STOMP

**应用场景**：
- 6轴/7轴机械臂操作
- 拾取放置任务
- 工业机器人焊接、装配

**详细内容**：[运动规划](planning/motion-planning/README.md)

---

### 3. 路径规划 (Path Planning)

**定位**：低层几何寻路，为移动机器人生成无碰撞的几何路径

**核心技术**：
- **基于图搜索**：A*, Dijkstra
- **基于采样**：RRT, RRT*
- **局部避障**：DWA, APF

**应用场景**：
- AGV/AMR 自主导航
- 移动机器人避障
- 无人机路径规划

**详细内容**：[路径规划](planning/path-planning/README.md)

## 三者关系示意图

```
用户指令: "把桌上的杯子放到架子上"
    │
    ▼
┌────────────────────┐
│   任务规划          │  → [移动到桌前, 抓取杯子, 移动到架子, 放置杯子]
└────────────────────┘
    │ 每个子任务
    ▼
┌────────────────────┐
│   运动规划          │  → 关节角度轨迹 + 速度约束
└────────────────────┘
    │ 移动到桌前
    ▼
┌────────────────────┐
│   路径规划          │  → [x1,y1] → [x2,y2] → ...
└────────────────────┘
    │
    ▼
机器人执行控制
```

## 技术选型建议

| 机器人类型 | 主要规划需求 | 推荐技术组合 |
|-----------|-------------|-------------|
| **移动机器人** | 导航避障 | 路径规划 (A* + DWA) |
| **机械臂** | 操作抓取 | 运动规划 (MoveIt! + OMPL) |
| **服务机器人** | 任务+运动 | 任务规划 (LLM) + 运动规划 |
| **人形机器人** | 全栈规划 | 三层规划协同 |
