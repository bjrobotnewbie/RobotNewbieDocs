# 轨迹优化方法

轨迹优化方法将运动规划转化为数值优化问题，通过最小化代价函数生成高质量的运动轨迹。这些方法特别适合需要平滑运动和满足动力学约束的场景。

## 方法概览

| 方法 | 优化策略 | 核心特点 | 鲁棒性 |
|------|---------|---------|-------|
| [**CHOMP**](planning/motion-planning/optimization/chomp/README.md) | 协变梯度下降 | 高效平滑 | 中等 |
| [**STOMP**](planning/motion-planning/optimization/stomp/README.md) | 随机采样优化 | 逃脱局部最优 | 高 |

## 技术对比

### CHOMP (Covariant Hamiltonian Optimization)

CHOMP 使用协变梯度下降法优化轨迹，是 MoveIt! 中默认的轨迹优化器之一。

**核心思想：**
- 将轨迹表示为高维曲线
- 最小化平滑代价和碰撞代价
- 协变梯度自然适应构型空间几何

**核心特点：**
- ✅ 生成高度平滑的轨迹
- ✅ 计算效率高
- ✅ 数值稳定性好
- ✅ 支持高维空间

**代价函数：**
```
总代价 = 平滑代价（加速度惩罚） + 碰撞代价（距离惩罚）
```

**适用场景：**
- 工业机械臂高速运动
- 需要平滑运动的应用
- 计算资源受限系统
- 初始轨迹质量较好

---

### STOMP (Stochastic Trajectory Optimization)

STOMP 使用随机采样方法优化轨迹，通过概率采样探索轨迹空间，对局部最优具有较好的鲁棒性。

**核心思想：**
- 在当前轨迹周围采样噪声轨迹
- 评估每条轨迹的代价
- 使用权重更新轨迹参数
- 不需要显式计算梯度

**核心特点：**
- ✅ 对局部最优鲁棒性好
- ✅ 不需要梯度计算
- ✅ 参数调优相对简单
- ✅ 容易并行化

**代价函数：**
```
总代价 = 平滑代价 + 碰撞代价 + 关节限制代价
```

**适用场景：**
- 复杂环境下的运动
- 存在多个局部最优的场景
- 需要高鲁棒性的应用
- 计算资源充足

## 算法对比

| 特性 | CHOMP | STOMP |
|------|--------|-------|
| 优化方法 | 协变梯度下降 | 随机采样优化 |
| 梯度计算 | ✅ 显式计算 | ❌ 不需要 |
| 局部最优 | 容易陷入 | 更易逃脱 |
| 计算效率 | ✅ 高 | ⚠️ 中等 |
| 结果确定性 | ✅ 确定 | ❌ 随机 |
| 参数调优 | ⚠️ 复杂 | ✅ 简单 |
| 并行化 | ⚠️ 困难 | ✅ 容易 |
| 对初始轨迹敏感性 | ⚠️ 较高 | ✅ 较低 |

## 选择指南

### 选择 CHOMP 如果：
- 追求计算效率
- 需要高度平滑的轨迹
- 初始轨迹质量较好
- 环境相对简单
- 结果可重复性重要

### 选择 STOMP 如果：
- 环境复杂，存在多个局部最优
- 需要高鲁棒性
- 计算资源充足
- 可以接受一定的随机性
- 初始轨迹可能质量较差

### 组合使用策略：
1. **OMPL + CHOMP**：快速找到可行路径，然后 CHOMP 平滑优化
2. **OMPL + STOMP**：复杂环境下，STOMP 帮助逃脱局部最优
3. **多阶段优化**：先用 STOMP 全局探索，再用 CHOMP 局部精细调优

## 代价函数设计

### 通用代价组件

| 代价类型 | 目的 | 典型权重 |
|---------|------|---------|
| 平滑代价 | 鼓励平滑运动 | 0.1 - 1.0 |
| 碰撞代价 | 避免障碍物 | 1.0 - 10.0 |
| 关节限制代价 | 避免关节极限 | 0.5 - 2.0 |
| 操作性代价 | 优化操作性 | 0.01 - 0.1 |

### 调优建议

1. **碰撞代价通常设为最高**，确保安全性
2. **平滑代价影响轨迹自然程度**，根据应用调整
3. **观察代价曲线**判断是否收敛
4. **逐步调整权重**，不要一次改变太多

## 快速开始

### MoveIt! 中启用轨迹优化

```yaml
# 在规划器配置中启用
planner_configs:
  CHOMP:
    type: chomp/PlannerManager
  STOMP:
    type: stomp/PlannerManager

# 或者作为后处理优化器
trajectory_processing:
  - name: chomp_optimizer
  - name: stomp_optimizer
```

### 使用建议

```cpp
// 典型工作流：
// 1. 先用 OMPL 找到粗略路径
auto plan = ompl_planner->plan(start, goal);

// 2. 用 STOMP 或 CHOMP 优化
auto optimized_plan = optimizer->optimize(plan);

// 3. 检查优化结果
if (optimized_plan.isValid()) {
  execute(optimized_plan);
}
```
