# 腱驱动连续体机器人

腱驱动是连续体机器人最经典的驱动方式，通过多根腱绳从基拉克制连续体弯曲，结构简单，控制相对成熟，广泛应用于工业检测和内窥镜。

## 结构与原理

**基本结构**：
- 中心弹性脊柱（弹性材料或弹性关节）
- 多个均匀分布的驱动腱绳
- 基座电机拉紧/放松腱绳
- 末端执行器安装在尖端

**工作原理**：
- 不同腱绳差动力差产生弯曲力矩
- 力矩使弹性脊柱产生连续弯曲
- 多段独立控制实现复杂形状
- 通常3-4根腱绳实现平面/空间弯曲

## 特点

### ✅ 优点
- **驱动器后置**：电机放在基座，末端重量轻
- **结构简单**：制造相对容易
- **控制成熟**：运动学模型相对清晰
- **成本较低**：不需要特殊材料

### ❌ 缺点
- **摩擦问题**：腱绳摩擦导致迟滞
- **绳子寿命**：反复拉伸容易疲劳断裂
- **耦合运动**：多段驱动存在运动耦合
- **弹性变形**：脊柱弹性建模误差影响精度

## 设计参数

| 参数 | 典型范围 | 影响 |
|-----|---------|------|
| 长度 | 100mm - 2000mm | 工作空间深度 |
| 直径 | 5mm - 50mm | 适用场景 |
| 段数 | 1 - 5段 | 形状自由度 |
| 腱根数 | 3 - 4根/段 | 弯曲能力 |

## 应用

- **工业内窥镜**：发动机检测、管道检测
- **微创手术**：腹腔手术机器人
- **搜救机器人**：废墟缝隙搜索
- **核工业检测**：辐射环境管道检查
