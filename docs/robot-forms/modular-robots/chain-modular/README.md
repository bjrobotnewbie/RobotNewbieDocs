# 链型模块化机器人

链型模块化机器人（Chain Modular Robots）由标准模块串联成链状结构，可以组装成机械臂、蛇形机器人、四足机器人等多种构型，是模块化机器人中最实用的一类。

## 结构特点

**基本结构**：
- 每个模块是一个或两个自由度关节
- 模块头尾可以相互连接
- 串联形成链状结构
- 可以分支形成树状结构

**典型构型**：
- 6自由度机械臂：6个模块串联
- 蛇形机器人：10+个模块串联
- 四足机器人：身体模块+四个腿模块
- 人形机器人：躯干+四肢分支

## 代表项目

- **PolyBot** - CMU最早链型模块化机器人
- **ReBiS** - 可重构机器人系统
- **ChainBot** - 开源链型模块化机器人

## 特点

### ✅ 优点
- **构型多样**：可以组装成多种机器人形态
- **重构速度快**：连接点数比格子型少很多
- **实际应用多**：已经有实际应用案例
- **控制相对成熟**：类似串联机器人控制

### ❌ 缺点
- **连接负载**：根部模块承受所有重量
- **树状分支复杂**：分支连接机构设计难
- **规划复杂**：重构规划比格子型复杂
- **模块自由度不同**：需要多种模块类型

## 应用

- **柔性制造**：根据产品换型快速重构生产线
- **研究教育**：机器人教学实验平台
- **灾难救援**：根据环境重构合适形态
- **空间机器人**：天地重构适应不同任务

链型模块化机器人是目前最接近实际应用的模块化机器人类型，在柔性制造领域有很好前景。
