# 格子型模块化机器人

格子型模块化机器人（Lattice Modular Robots）是模块化机器人的一种，所有模块排列在三维网格节点上，通过改变模块连接关系实现三维重构，适合改变整体体积和形状。

## 结构特点

**基本结构**：
- 每个模块占据三维网格的一个节点
- 模块可以连接相邻格子中的其他模块
- 通过模块在网格中移动实现重构
- 整体形状由网格中活动模块组成

**典型特点**：
- 三维空间均匀分布
- 每个模块连接能力有限（通常最多连接6个相邻）
- 适合整体体积变化
- 实现膨胀收缩变形

## 代表项目

- **Crystalline** - 晶体模块化机器人
- **3D M-TRAN** - 三维格子模块
- **Atom** - 麻省理工格子机器人

## 特点

### ✅ 优点
- **三维重构能力强**，支持复杂三维形状
- 每个模块均匀，容易制造
- 并行重构算法相对简单
- 可实现中空结构

### ❌ 缺点
- **运动速度慢**，一次只能移动一个模块
- **连接机构复杂**，每个模块需要多个连接面
- **间隙问题**，网格间隙影响精度
- **规模受限**，规模扩大难度大

## 应用

- **可变形机器人身体**
- **自修复机器人**
- **太空探索**，任务需求变化重构
- **三维显示**，模块组成可变形状显示

格子型模块化机器人理论优美，但实际应用受到重构速度限制，主要还在研究阶段。
