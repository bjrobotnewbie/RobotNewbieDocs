# 移动模块化机器人

移动模块化机器人（Mobile Modular Robots）由多个独立移动机器人模块组成，每个模块能够自主移动，并可以主动对接形成更大的组合机器人，是模块化机器人的重要分支。

## 结构特点

**每个模块特点**：
- 完整的自主移动能力
- 独立的电池和控制系统
- 自主对接机构
- 传感器感知环境

**组合方式**：
- 多个模块自主对接
- 形成更大的复合机器人
- 可以拆分重新组合
- 根据任务需要改变构型

## 典型构型变化

- **四条腿**：四个模块对接成四足机器人
- **机械臂+移动底盘**：底盘模块加臂模块组合
- **拖车**：多个模块串联拖动
- **桥**：多个模块连接架桥通过 gap

## 代表项目

- **Swarm-Bot** - 欧洲移动模块化机器人项目 https://www.swarm-bot.org/
- **AMRB** - 自主移动机器人模块
- **CMU Distributed** - CMU分布式模块化机器人

## 特点

### ✅ 优点
- **完全自主**：每个模块都能独立工作
- **对接灵活**：不需要固定格子位置
- **容错性极强**：一个模块坏了移除即可
- **分布式智能**：每个模块都有计算能力

### ❌ 缺点
- **对接复杂**：自主对接机构设计难
- **协调控制复杂**：多模块协同控制难
- **重量重**：每个模块都带电池和驱动
- **成本高**：每个模块都需要完整系统

## 应用

- **灾难救援**：多个模块自主组队适应环境
- **快速构建**：应急情况下快速构建桥梁
- **月球/火星探索**：多个小车模块协同探索
- **物流搬运**：根据货物大小组合不同大小

移动模块化机器人结合了模块化和群体机器人的特点，在未知环境探索中有独特优势。
