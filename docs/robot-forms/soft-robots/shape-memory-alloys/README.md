# 形状记忆合金

形状记忆合金（Shape Memory Alloy, SMA）是一种特殊金属材料，能够"记住"特定形状，温度变化时发生相变恢复形状，可用于软体机器人驱动。

## 工作原理

**形状记忆效应**：

- **低温马氏体相**：柔软，可以变形
- **加热奥氏体相**：恢复到原来记忆的形状
- **冷却**：重新变软，可以再次变形

**超弹性效应**：

- 在室温下能承受大变形
- 卸载后自动恢复原状
- 用于弹性元件和传感器

**典型材料**：

- 镍钛合金（NiTi）：最常用
- 铜基形状记忆合金
- 铁基形状记忆合金

## 驱动方式

| 加热方式     | 特点      | 应用     |
| -------- | ------- | ------ |
| **电阻加热** | 直接通电加热  | 机器人关节  |
| **激光加热** | 局部加热，远程 | 微型机器人  |
| **化学加热** | 化学反应放热  | 自驱动机器人 |
| **电磁加热** | 感应加热    | 植入式医疗  |

## 特点

### ✅ 优点

- **大变形**：可达百分之几应变
- **高力重比**：驱动力大重量轻
- **结构简单**：不需要额外机构
- **无线驱动**：可以远程加热驱动

### ❌ 缺点

- **低效率**：能量转换效率低
- **响应慢**：散热慢导致带宽低
- **能耗高**：需要持续加热维持形状
- **疲劳寿命**：循环次数有限

## 应用

- **医用支架**：血管支架，植入后膨胀张开
- **软体抓手**：自适应抓取
- **微创手术器械**：可变形手术工具
- **主动假肢**：轻质驱动关节
- **变形机翼**：航空航天自适应机翼

## 代表性项目

- **NiTi SMA** - 镍钛形状记忆合金 <https://en.wikipedia.org/wiki/Shape-memory_alloy>
- **SMA Surgical Robots** - 形状记忆合金手术机器人&#x20;
- **OpenSMA** - 开源形状记忆机器人项目

## 研究方向

- **快速冷却**：提高响应速度
- **提高寿命**：抗疲劳改进
- **集成传感**：SMA同时作驱动器和传感器
- **微加工**：MEMS尺度形状记忆合金

## 临床应用

形状记忆合金最成功的应用是在医疗领域：

1. 冠状动脉支架植入后受热膨胀，撑开血管
2. 正畸牙齿矫正丝，利用超弹性持续施力
3. 可变形骨钉，便于植入和固定
