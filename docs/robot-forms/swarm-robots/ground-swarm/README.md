# 地面群体机器人

地面群体机器人是群体机器人研究最多的分支，多个轮式或足式机器人在地面协同工作，算法验证容易，是群体机器人算法研究的主要平台。

## 典型系统特点

- 个体：小型轮式移动机器人
- 尺寸：10cm - 50cm
- 传感器：里程计、相机、超声、激光
- 通信：WiFi、蓝牙、ZigBee

## 研究热点

| 问题 | 研究内容 |
|-----|---------|
| 队形保持 | 群体保持特定几何形状运动 |
| 聚集/分散 | 根据环境聚集或分散 |
| 覆盖搜索 | 覆盖整个搜索区域 |
| 协同搬运 | 多个机器人一起搬运大物体 |
| 围捕追捕 | 群体围捕单个目标 |

## 代表性项目

- **Khepera** - 瑞士联邦理工小型群体机器人平台
- **Pioneer swarm** - ActivMedia pioneer机器人群体
- **MIT Micro Swarm** - MIT微型机器人群体 https://groups.csail.mit.edu/rrg/
- **CMU Distributed Robotics** - CMU分布式机器人

## 应用

- **灾难搜救**：多个机器人搜索废墟
- **环境监测**：大面积环境传感器网络
- **仓储物流**：多个AGV协同搬运
- **科研教育**：群体算法研究平台

地面群体机器人技术相对成熟，已经有一些实际应用案例，比如仓储物流多AGV系统。
