# Robotic Systems (Illinois)

## 一、基础信息
- **名称**：Robotic Systems（草案版）
- **作者**：Kris Hauser（伊利诺伊大学厄巴纳-香槟分校 UIUC 计算机科学、电气与计算机工程、机械科学与工程教授）
- **来源**：基于作者在 UIUC、杜克大学、印第安纳大学的机器人课程讲义整理
- **版本**：在线开放书稿，持续更新（最新更新：2024-07-06）
- **形式**：HTML + Jupyter Notebook 双版本，支持交互式代码、可视化、测验
- **配套工具**：Klamp’t 机器人仿真与可视化库，可直接运行示例

## 二、核心理念
本书以**系统化机器人学**为核心思想，强调机器人是**感知—决策—控制—执行**高度集成的闭环系统，而非孤立知识点的堆砌。目标是帮助读者建立**从数学建模到系统工程**的完整思维框架，理解各模块如何协同工作，掌握从理论到落地的全链路方法。

## 四、内容特色
1. **系统化组织**：按“建模→规划→控制→感知→学习→系统集成”层层递进，贴合真实机器人研发流程
2. **理论与实践结合**：每章配套 Jupyter 交互式代码、Klamp’t 可视化，可直接运行验证
3. **跨学科覆盖**：融合机械、电控、算法、优化、机器学习、系统工程
4. **开放可交互**：支持 Binder、Google Colab、本地 Jupyter、VSCode 多种运行方式
5. **持续更新**：以草案形式公开迭代，内容紧跟机器人领域前沿

## 五、适用人群
- 机器人、自动化、计算机、机械工程专业**高年级本科/研究生**
- 机器人算法、系统、控制方向**研发工程师**
- 需系统夯实机器人全栈基础的**自学者与科研人员**
