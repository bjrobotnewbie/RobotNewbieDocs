# Drake（龙）

## 简介
Drake（中古英语意为“龙”）是面向机器人领域的**模型驱动设计与验证**开源工具包，以 C++ 为底层、搭配 Python 接口，由麻省理工学院 CSAIL 机器人运动团队发起，丰田研究院主导持续开发，同时获得 DARPA、美国国家科学基金会等多方支持。

它专注机器人动力学分析与控制系统构建，高度侧重**基于优化的设计与分析**，可精准模拟摩擦、接触、空气动力学等复杂机器人动态行为，不做封闭黑箱，而是清晰呈现控制方程的稀疏性、解析梯度、多项式结构、不确定性量化等内在数学特性，为高级规划、控制与分析算法提供透明可用的信息。

Drake 提供完整的动态系统建模、数学规划求解、多体运动学与动力学计算能力，开放 Python 接口支持新算法快速原型开发，同时提供大量前沿算法的可靠开源实现、丰富示例与基准用例，方便快速上手与社区贡献。

配套有基于 Jupyter notebook 的 Python 教程，源码树与项目画廊包含大量应用案例，也支持作为外部库集成到各类项目与构建系统中，可对接 LCM、ROS 2 等生态组件，兼顾学术研究与工程落地需求。
