# NeRD（神经机器人动力学）
NeRD是面向多关节刚体机器人的神经模拟框架，用于预测机器人与环境接触时的后续状态，可在长时间仿真步长内保持稳定与精准输出，由NVIDIA团队提出并集成于Newton物理引擎，相关成果发表于CoRL 2025。

<video src="https://neural-robot-dynamics.github.io/static/videos/NeRD_video.mp4" width="600" controls="controls"></video>

## 一、定位与作用
NeRD以数据驱动方式学习专属机器人的动力学规律，替代传统解析模拟器里的低级动力学与接触求解器，形成解析碰撞检测搭配神经求解的混合架构，无需重构现有策略学习环境，仅切换求解器即可接入使用。

## 二、设计思路
1.  **混合预测框架**
    仅替换传统模拟器中与应用无关的时间积分与求解模块，复用碰撞检测等组件，输入机器人状态、接触信息、关节扭矩等中间量，不局限于特定任务与动作，降低过拟合风险。
2.  **以机器人为中心的状态表示**
    把状态与接触相关量转换到机器人基坐标系，让模型在未见过的空间位置也能稳定预测，提升空间泛化与长时段精度。

## 三、训练与部署
- 训练数据由模拟器生成，面向单机器人采集十万条随机轨迹，每条含100个时间步，采用随机初始状态、关节扭矩与环境配置。
- 网络基于轻量级GPT‑2类因果Transformer构建，输入最近10步仿真状态完成时序预测。
- 训练完成后作为可替换求解器嵌入Newton等模块化物理引擎，兼容原有开发流程与策略训练环境。

## 四、优势表现
- **长时段稳定精准**：单模型可稳定预测双摆等混沌系统数百至数千步，适配多种地面接触构型。
- **跨任务与场景泛化**：同一模型适配同机型的不同任务、场景与底层控制器，在ANYmal四足机器人上完成直走、侧走等策略学习，迁移至真值解析模拟器几乎无性能损失。
- **零样本仿真到现实迁移**：在7自由度Franka机械臂上，纯仿真习得的点位到达策略可直接部署到实体设备。
- **支持真实数据微调**：模型具备可微分特性，能用真实世界数据快速优化，在抛方块等任务中显著缩小仿真与现实的动力学偏差。

## 五、应用与展望
NeRD已在四足机器人、多自由度机械臂上完成验证，未来可拓展至人形机器人等更复杂结构、支持从局部观测真实数据微调，并覆盖抓取操作等场景，助力数字孪生与持续进化的机器人仿真系统。
