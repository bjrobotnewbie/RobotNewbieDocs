# CarDreamer

CarDreamer 是 UCD-Dare 在 2024 年 5 月发布的**基于 CARLA 的世界模型学习平台**，为自动驾驶世界模型研究提供开箱即用的轻量级解决方案。

## 资源简介

- **发布机构**：UCD-Dare (University College Dublin)
- **发布时间**：2024年5月
- **项目定位**：世界模型学习研究平台
- **基于环境**：CARLA 自动驾驶仿真器
- **开源内容**：轻量预训练模型 + 完整训练代码
- **应用场景**：自动驾驶算法研究、世界模型教学实验

## 特点

1. **开箱即用**：基于 CARLA 封装，环境配置简单
2. **轻量级模型**：适合学术研究和教学实验，不需要超大GPU
3. **完整基准**：提供标准评测基准，方便对比不同算法
4. **可扩展框架**：模块化设计，容易接入新的世界模型算法
5. **教学友好**：文档完善，适合课程项目和毕业设计
