# NVIDIA DreamDojo

DreamDojo 是 NVIDIA Jim Fan 团队在 2026 年 2 月发布的**机器人专用世界模型**，采用纯神经网络预测替代传统物理引擎，用大规模人类视频训练实现实时推理。

## 资源简介

- **发布机构**：NVIDIA (Jim Fan 团队)
- **发布时间**：2026年2月
- **模型特点**：轻量级实时版本
- **核心创新**：无物理引擎纯神经预测，4.4万小时人类视频训练
- **性能指标**：实时 10FPS 推理，真实任务成功率提升 +17%
- **开源范围**：全量开源（含训练代码、推理代码、数据集）
- **应用场景**：机器人强化学习、世界模型训练、仿真环境

## 特点

1. **纯神经世界模型**：不依赖传统物理引擎，直接从数据学习物理规律
2. **大规模视频训练**：4.4万小时人类操作视频，覆盖多样化操作场景
3. **实时推理**：优化后的轻量级模型，在常见GPU上可达 10FPS 推理速度
4. **任务泛化**：在真实机器人任务上验证，成功率相比基线提升 17%
5. **全栈开源**：训练、推理、数据全部开放，可直接复现论文结果
