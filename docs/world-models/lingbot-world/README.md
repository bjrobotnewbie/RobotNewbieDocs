# 蚂蚁 LingBot-World

LingBot-World 是蚂蚁灵波在 2025 年发布的**实时交互3D环境世界模型**，对标 Google Genie 3，支持实时交互生成。

## 资源简介

- **发布机构**：蚂蚁集团 (灵波团队)
- **发布时间**：2025年
- **核心定位**：实时交互3D环境世界模型
- **对标模型**：Google Genie 3
- **开源内容**：模型权重 + 推理代码开源
- **应用场景**：游戏、具身智能、虚拟助手、交互仿真

## 特点

1. **实时交互生成**：支持用户实时交互，动态生成环境变化
2. **对标Genie 3**：技术路线对标 Google Genie 3，效果接近
3. **国产开源**：国内团队开发，中文文档支持友好
4. **轻量部署**：优化推理速度，适合本地部署测试
