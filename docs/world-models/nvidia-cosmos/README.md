# NVIDIA Cosmos

- 官方文档：[NVIDIA Cosmos](https://docs.nvidia.com/cosmos/)

**NVIDIA Cosmos™** 是英伟达专为**物理AI**打造的开发平台，核心组件包括：

| 组件 | 说明 |
|:---|:---|
| **世界基础模型 (WFMs)** | 最先进的生成式模型，用于模拟物理世界 |
| **护栏机制 (Guardrails)** | 安全约束与合规控制 |
| **加速数据处理管线** | 高效的数据筛选与整理流程 |

**应用场景**：开发者利用 Cosmos 加速三类物理 AI 的开发——
- 自动驾驶汽车 (AVs)
- 机器人
- 视频分析 AI 智能体
